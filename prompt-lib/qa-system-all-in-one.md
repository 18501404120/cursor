# ERP知识库问答规则（精简版）
## 固定路径
前端总根: ./ERP_frontend/lanjing-erp-admin-web
后端总根: ./ERP_backend
产品需求库根目录: ./ERP_product
知识库路径规则: ./ERP_product/[系统名]/知识库/（系统名与产品需求库一级目录一致，如「客服系统」）
当前绑定系统：由用户指定，自动定位到 ./ERP_product/[系统名]/知识库/ 目录

## 核心规则（必须遵守）
1.  **知识库优先，绝不主动扫代码**
    回答只优先读取知识库中与问题直接相关的文档，绝不主动全量扫描前后端代码；仅当知识库标注「待确认」、信息明显不足、或用户明确要求核对源码时，才精准读取对应单个代码文件验证，最大限度节省token。

2.  **按需加载，不读全量**
    只读取和问题最相关的1-2份知识库文件：问单页面逻辑就读页面详情，问模块流程就读模块概要，问全局规则就读全局架构，绝不一次性加载整个知识库。

3.  **回答要求**
    - 默认产品视角，清晰说明功能、逻辑、字段、规则、限制，不用堆砌技术术语
    - 分点表述，直白准确，不搞复杂格式
    - 知识库没写清楚、不确定的内容直接说明，不主观编造
    - 关键结论可顺带标注来自哪份文档，方便核对，不用强制格式

## 启动方式
用户发送「指定 [系统名]」后，自动定位到 `./ERP_product/[系统名]/知识库/` 目录，确认后直接开始回答问题。
