# ERP 原型分享服务

在本地启动一个网页，浏览 `ERP_product` 与 `方案设计/文件夹` 下的需求目录，一键复制局域网链接给同事查看 HTML 原型。  
**无需提交 Git，无需发送文件。**

## 启动

### 方式一：双击快捷方式（推荐）

在 Finder 中打开：

`本地/方案设计/原型分享服务/启动原型分享服务.command`

双击即可：若服务未运行会自动启动，并打开浏览器 `http://127.0.0.1:8787/`。

可将该 `.command` 文件拖到 **程序坞** 或 **桌面**，以后点一下就能用。

> 首次双击若提示无法打开：右键 → **打开** → 确认一次即可。

### 方式二：终端

```bash
cd /Users/ckw/Documents/erp/本地/方案设计/原型分享服务
chmod +x start.sh   # 仅首次需要
./start.sh
```

浏览器打开终端提示的本机地址（默认 `http://127.0.0.1:8787/`）。

## 使用

1. 左侧展开 **ERP_product** 或 **文件夹** 根目录  
2. 悬停需求目录或 HTML，点旁侧 **分享** 复制局域网链接  
3. 点目录名可在右侧查看文件并分享  
4. 同事打开链接即可预览原型  
5. 停止：终端 `Ctrl + C`

## 发布标注到 GitHub Pages 预览

在 **GitHub Pages 在线链接**上编辑标注后：

1. 先确保本机已启动原型分享服务（双击 `启动原型分享服务.command`）
2. 回到在线预览页，点右上角 **「发布到预览」**
3. 允许浏览器弹窗（会打开本机 `127.0.0.1:8787` 桥接页完成 git push）
4. 约 1～2 分钟后，所有在线预览链接即可看到最新标注

> 页内「保存」仅写入本机浏览器；**必须点「发布到预览」** 才会推送到 GitHub。

- 默认端口：`8787`  
- 默认挂载两个根目录：  
  - `ERP_product` → 产品需求原型  
  - `文件夹` → `本地/方案设计/文件夹`（如全渠道管报等方案原型）  
- 自定义端口：`PORT=9000 ./start.sh`  
- 自定义目录：  
  - `PRODUCT_ROOT=/path/to/ERP_product ./start.sh`  
  - `DESIGN_FOLDER=/path/to/文件夹 ./start.sh`  
- 分享链接会带根目录前缀，例如：  
  - `.../share?path=文件夹/项目/全渠道管报/原型/费用管理&paView=1`（`paView=1` 为只读，供协作者查看标注）  
- 本机点「打开」不带 `paView=1`，可编辑 **原型标注002**（若页面已注入）  
- 旧版 `ERP_product` 链接（无 `ERP_product/` 前缀）仍可访问  
- 仅局域网可用；关掉服务后链接失效  
- 不要把含敏感信息的上级目录挂出去；当前仅暴露已挂载目录内可分享类型文件
