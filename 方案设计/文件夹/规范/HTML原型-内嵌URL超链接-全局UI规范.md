# HTML 原型与说明页 · 内嵌 URL 超链接（全局 UI 规范）

适用于：本仓库 **`文件夹/项目/`** 下各业务 **HTML 原型**、**说明版原型**，以及通过工具生成的、以 `innerHTML` / 模板字符串写入页面的 **需求说明红点、气泡、弹层正文** 等富文本片段。

## 1. 原则（强制）

- 凡面向用户展示、且希望用户可跳转访问的 **http(s) 地址**（钉钉文档、Axure、GitHub、内部 Wiki、CDN 文档等），**禁止**仅以纯文本形式出现在页面或浮层中（用户无法点击、不便复制）。
- **必须**使用语义化超链接：`<a href="完整URL" target="_blank" rel="noopener noreferrer">可见文案</a>`。
  - **`target="_blank"`**：新标签页打开，不离开当前原型页。
  - **`rel="noopener noreferrer"`**：安全与隐私基线（新开页不挂 `window.opener`，不默认传递来源）。
- **可见文案**优先使用业务语义（例如「在钉钉文档打开导出模版」），避免整段裸 URL 作为唯一链接文字；若需展示完整 URL 便于核对，可在链接后以次要样式追加一行「完整地址：…」**且该段仍建议用同一 `href` 的第二个链接触达**，或仅用代码样式展示、不作为唯一入口（避免双链接重复时可只保留一条可点击主链）。

## 2. 与「红点 / 说明气泡」的配合

- 红点说明（如 `reqPopover.innerHTML = reqTextMap[key]`）内容为 HTML 字符串时，其中的外链 **必须**按第 1 节写成 `<a>`。
- 气泡容器 CSS 应为链接提供可辨样式（如下划线、主色、换行），见各页 `.req-popover a` 或等价类。
- **交互**：用户点击气泡内的链接时，**不应**因全局 `document` 点击关闭逻辑导致链接未触发；实现上应在关闭气泡的判断中 **排除 `#reqPopover`（或等价容器）内部点击**。

## 3. 与 `alert` / `confirm` 的关系

- 浏览器原生 **`alert` / `confirm` / `prompt` 内文本不支持 HTML**，其中的 URL **不可**做成可点击超链接。
- 若导出说明、模版地址等需可点击：应改为 **页面内弹层 / 已有 Dialog**，在正文中放置 `<a>`；或 **先提示再 `window.open(url)`**（需在文案中明确「将打开新标签页」）。**禁止**依赖 `alert` 内裸 URL 作为唯一跳转方式。

## 4. Markdown 需求文档

- Markdown 中外链应使用标准 `[文案](URL)`；与本规范一致，无需再包一层 HTML（渲染器会生成 `<a>`）。

## 5. 参考实现

- 全渠道管理报表看板（标准版 / 渠道版）：`export-template` 红点文案中的钉钉模版链接。
- 销量预测管理说明版：导出说明使用 `showDlgDetail` 内嵌 `<a>`（替代 `alert` 内 URL）。
