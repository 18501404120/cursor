# 当 EOM 退市会上说「发起后禁止继续下单」时，该怎样把禁止挂到节点上？

会上有一句「发起后禁止继续下单」。按字面写进规则，单子一发起，采购就不能再下，准备退市阶段的 Last Buy 就下不出去。这句话禁的是正式退市之后的采购。Last Buy 要在方案确认、状态变成正式退市之前进入在途，检查挂在确认整单上。

## 1. 准备退市还要下 Last Buy

退市发起之后，产品先进入准备退市。这个阶段采购还要下 Last Buy：清库方案里写了最后一批买多少，就得在这时下出去。方案生效、进入正式退市之后，才不能再下任何采购单。Last Buy 进入在途的时间，要赶在变成正式退市之前。

## 2. 在途检查放在确认整单

发起的时候，Last Buy 通常还没下。检查要是放在发起，单据还没走到下单，就会被拦在起点。确认整单才是方案生效的那一步，在这里看该下的 Last Buy 有没有进入在途。过了，状态才能变成正式退市；不过，工单停在待方案决策，方案不能生效。采购单从正式退市这一下才真正停掉。

## 3. 按渠道链接逐条看

工单按 8 位 SKU 管，Last Buy 是按渠道链接下的。确认整单时，只看方案里 Last Buy 数量大于 0 的那些渠道链接，每一条都要已经进入在途。某个 SKU 下面已经有一张采购单，说明不了这些链接都下过。

## 4. 确认整单只看有没有进入在途

方案上的数量留在方案字段里，采购按实单去下。确认整单不拿这两套数量来比，只看该下的链接进没进在途。

确认整单过了才进入正式退市，采购从这里停。Last Buy 得赶在这一下之前进入在途。
