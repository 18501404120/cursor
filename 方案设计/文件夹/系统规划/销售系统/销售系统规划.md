# 销售系统规划

本文档基于《销售系统功能介绍》及业务梳理资料，对销售系统进行模块化规划。规划涵盖现有模块的定位与演进方向，以及建议新增模块的功能范围与价值说明，供产品路线与需求优先级决策参考。

---

## 一、规划总览

销售系统围绕「**计划—履约—监控—分析**」闭环，支撑多渠道（亚马逊、Shopify、TTS、APP 商城等）从销售预测、备货、发货到业绩分析的端到端能力。规划按以下模块组织：

| 类别 | 模块 | 现状 | 规划重点 |
|------|------|------|----------|
| **计划与履约** | 发货计划与物流计划 | 已有 | 与智能发货、透明计划深度打通 |
| | 智能发货 | 已有 | 规则可配置化、策略可扩展 |
| | 透明计划 | 已有 | 与采购计划、发货计划状态联动 |
| **备货与供应链衔接** | 采购计划管理 | 已有 | 与 Forecast、库存看板一体化 |
| | 入库明细 | 已有 | 责任追溯与异常预警 |
| **物流与成本** | 物流计划/自动拼柜 | 已有 | 规则可配置、异常提醒 |
| | 海运比看板 | 已有 | 目标与空运审批闭环 |
| | 成品库龄看板 | 已有 | 全流程库龄、呆滞预警与清库建议 |
| **运营支撑** | Forecast 与审核 | 已有 | 预警规则、版本与准确率分析 |
| | 调价申请 | 已有 | 与促销、平台价格同步 |
| | 促销管理 / Deals 管理 | 已有 | 与销售报表、促销-SKU 联动 |
| | 样品推广订单 | 已有 | 与库存、费用分摊区分 |
| **报表与分析** | 销售报表（新） | 已有 | 多维度下钻、与大促看板统一 |
| **建议新增** | 销售目标与绩效看板 | 新增 | 目标分解、达成率、绩效可视化 |
| | 价格与利润分析 | 新增 | 定价建议、毛利归因、促销 ROI |
| | 客户与订单洞察 | 新增 | 复购、客群、订单异常归因 |
| | 异常与风控中心 | 新增 | 缺货/滞销/超龄/价格异常集中处置 |
| | 销售数据服务与开放 | 新增 | 统一指标、报表可配置、对外 API |

## 二、计划与履约

### 2.1 发货计划与物流计划

- **功能定位**：统一创建、审批与执行发货计划，支持从国内/海外仓发往 FBA、海外仓或直发终端；通过自动拼柜降低零散发运成本。
- **核心能力**：
  - 创建发货计划（店铺、SKU、数量、目的国、运输方式等）；
  - 计划状态流转与审批；
  - 自动拼柜（同一目的国/分区/平台/运输方式等规则合并为 DL）；
  - 与智能发货、透明计划衔接，形成计划到出库闭环。
- **规划方向**：
  - 拼柜规则可配置化（阈值、例外店铺/SKU）；
  - 与库存、Forecast 联动，支持「按覆盖日销/售完日期」的建议发货量；
  - 计划模板与复制，减少重复录入。

---

### 2.2 智能发货

- **功能定位**：在发货计划与物流计划基础上，通过规则与策略辅助「发什么、发多少、走什么渠道」，提升效率与成本可控性。
- **核心能力**：策略化、自动化发货决策（详见现有原型与产品说明）。
- **规划方向**：
  - 策略引擎可配置（优先级、渠道选择、数量分配）；
  - 与海运比目标、库龄、售完日期等联动，避免高成本渠道滥用与呆滞加剧；
  - 执行日志与效果复盘，支撑策略迭代。

---

### 2.3 透明计划

- **功能定位**：从需求到发货的进度与状态统一可视，减少信息不透明带来的重复沟通与责任不清。
- **核心能力**：需求→预测→备货→采购→发货各环节状态与时间节点可视化、可追溯。
- **规划方向**：
  - 与采购计划、发货计划、入库明细状态强关联，一处更新全局可见；
  - 支持按 SKU/店铺/计划单下钻，异常节点高亮与责任人；
  - 与「异常与风控中心」联动，计划延误自动进入待办。

---

## 三、备货与供应链衔接

### 3.1 采购计划管理

- **功能定位**：将销售预测与备货建议转化为可执行、可审核、可拆单的采购计划单，衔接销售需求与生产/采购执行。
- **核心能力**：
  - 首单/量产/额外等计划类型，状态流转变更（Sales 确认→计划复核→TL 审核→拆单等）；
  - SKU 状态、店铺与销售专员等校验；
  - 采购在途参与 Forecast 总计库存、备货覆盖日销、售完日期与下单参考。
- **规划方向**：
  - 与 Forecast 下单参考、备货提醒一键生成采购计划草稿；
  - 交期与到货异常反馈回销售与透明计划，形成闭环。

---

### 3.2 入库明细

- **功能定位**：商品从采购下单到入库的全链路可追溯，支撑责任界定与对账。
- **核心能力**：按单、按 SKU、按时间查询入库明细，与采购单、订单履约对照。
- **规划方向**：
  - 应到未到、延迟入库预警，与透明计划、异常中心联动；
  - 与成品库龄看板衔接，入库时间作为库龄起点之一。

---

## 四、物流与成本监控

### 4.1 海运比看板

- **功能定位**：监控海运比（海运发货量/总发货量），引导在满足时效前提下多走海运，控制物流成本；空运申请需原因与 TL 审核。
- **核心能力**：海运比指标与趋势、店铺维度目标、空运申请与审核、按店铺/时间下钻与预警。
- **规划方向**：
  - 目标达成率与同比、环比；未达标店铺自动进入 TL 待办；
  - 与智能发货策略联动，在策略中体现「优先海运」约束。

---

### 4.2 成品库龄看板

- **功能定位**：全流程库龄统一口径（国内入库 + 在途/在库），支持呆滞分析、清库与备货决策。
- **核心能力**：
  - 呆滞占比趋势、库存节点分布、呆滞 TOP 产品；
  - 多场景与节点（国内仓、海外仓在途/在库、FBA 在途/在库）；
  - 库龄计算与数据来源（金蝶、物流计划、FBA 库存等）统一。
- **规划方向**：
  - 未来预计呆滞（结合 Forecast 与库龄），提前触发清库/促销建议；
  - 与促销管理、调价申请联动，呆滞品优先参与促销与调价审批；
  - 清库任务与责任人跟踪，形成「发现—决策—执行」闭环。

---

## 五、运营支撑

### 5.1 Forecast 与 Forecast 审核

- **功能定位**：销售预测统一录入、三级审核与版本管理；审核后数据支撑备货覆盖日销、售完日期、下单参考及 MDS/备料。
- **核心能力**：
  - 审核流程与预警（与年度目标匹配度、Forecast 变动率、近期有效性）；
  - 按天/按整月/按天均导入方式；平均日销权重配置；
  - 总计库存、备货提前期、售完日期、下单参考、采购在途口径统一。
- **规划方向**：
  - Forecast 准确率看板（R1/R2/R3 等）与考核/改进闭环；
  - 与销售目标、历史预测对比的偏差分析与原因标注；
  - 大促/活动期间预测模板与批量调整。

---

### 5.2 调价申请

- **功能定位**：调价留痕、审批、定时执行与平台价格同步，到期自动恢复。
- **核心能力**：创建调价申请、审核、PriceAdjustmentJob 执行、与电商后台同步校验、重叠与失效处理。
- **规划方向**：与促销管理、Deals 关联，避免重复配置；毛利影响预估展示。

---

### 5.3 促销管理 / Deals 管理

- **功能定位**：促销类型与规则配置、Deals 报名与状态监控，与销售报表、促销-SKU 等看板联动。
- **核心能力**：促销类型配置、Deals 列表与状态、与销量/折扣/毛利分析结合。
- **规划方向**：
  - 促销-SKU 与库龄、呆滞联动，推荐「适合做促销」的 SKU；
  - 促销 ROI（销量提升 vs 折扣与广告成本）分析，支撑下次大促选品与力度。

---

### 5.4 样品推广订单

- **功能定位**：样品订单独立建单、审批与发货，与正常销售区分，可追溯且不干扰库存统计。
- **核心能力**：创建样品订单、审核、发货；按类型区分推广样与测试样。
- **规划方向**：与费用分摊、达人/渠道效果跟踪（若业务需要）打通。

---

## 六、报表与分析

### 6.1 销售报表（新）

- **功能定位**：按日查看店铺/SKU 维度的销量、销售额、毛利、广告与折扣等核心指标，做业绩快照、趋势追溯与产品/店铺下钻。
- **核心能力**：核心指标看板、日维度折线图、产品销售明细表、店铺销售明细、品线等维度；数据来自 ih_sales_day_profit，与 Forecast 平均日销口径一致。
- **规划方向**：
  - 与大促看板同源同口径，性能与筛选体验统一；
  - 支持自定义保存视图与订阅（如日报/周报推送）；
  - 与销售目标、毛利归因联动，见下文「销售目标与绩效看板」「价格与利润分析」。

---

## 七、建议新增模块（突出价值）

### 7.1 销售目标与绩效看板（新增）

- **价值说明**：
  - **痛点**：目标分散在蓝鲸等系统，销售与 TL 需多处查看，达成率、缺口、排名不直观；绩效评估缺少统一数据来源。
  - **收益**：目标在销售系统内按店铺/SKU/时间可分解、可对比；达成率、同比/环比、排名一目了然；为 TL 审核空运、备货优先级、资源调配提供依据；与 Forecast、销售报表同源，减少口径不一致。
- **功能范围建议**：
  - 销售目标导入/维护（支持与蓝鲸等同步或手工维护）；
  - 按日/周/月/季的达成率、缺口、完成排名；
  - 与销售报表（新）联动，下钻到产品/店铺明细；
  - 目标调整与版本记录，便于复盘与考核。

---

### 7.2 价格与利润分析（新增）

- **价值说明**：
  - **痛点**：定价多凭经验，难以系统评估「调价/促销后毛利与销量平衡」；毛利波动原因（成本、运费、折扣、广告）分散，归因困难。
  - **收益**：为调价与促销提供「毛利影响预估」与历史对比；毛利归因（成本、头程、FBA、佣金、广告、折扣）清晰，便于优化定价与促销力度；识别高毛利/低毛利产品与店铺，支撑选品与资源倾斜。
- **功能范围建议**：
  - 单 SKU/店铺维度的毛利分解与趋势；
  - 调价/促销前后毛利与销量对比，简单 ROI 视图；
  - 定价建议（基于成本、竞品、历史弹性，可做规则化建议）；
  - 与调价申请、促销管理、销售报表打通，形成「分析—决策—执行」闭环。

---

### 7.3 客户与订单洞察（新增）

- **价值说明**：
  - **痛点**：复购率、客群结构、订单异常（取消、退货、差评）缺少系统化视图；问题订单归因（库存、物流、 listing）依赖人工排查。
  - **收益**：复购与客群分析支撑 CRM 与精准营销；订单异常归因（缺货、延迟、价格、listing）可统计、可下钻，便于改进运营与供应链；与透明计划、缺货预警联动，减少「订单下了却发不出」的被动响应。
- **功能范围建议**：
  - 复购率、客单件数、客单价分布按店铺/站点/品类；
  - 订单状态分布与异常订单列表（取消、退货、延迟发货等）；
  - 异常原因标签与归因统计（缺货、物流、价格、listing 等）；
  - 与销售报表、Forecast 缺货天数、库存看板联动，支撑根因改进。

---

### 7.4 异常与风控中心（新增）

- **价值说明**：
  - **痛点**：缺货、滞销、超龄库存、价格异常、计划延误等散落在各看板，没有统一「待办」与升级机制，容易遗漏或响应滞后。
  - **收益**：异常集中展示、按角色/严重程度分配待办，避免遗漏；规则可配置（阈值、责任人、升级条件），与现有看板数据联动；形成「发现—分配—处理—关闭」闭环，便于 TL/计划侧做每日巡检与复盘。
- **功能范围建议**：
  - 异常类型：缺货/即将缺货、呆滞/库龄超阈值、计划延迟、空运超标、价格异常、订单逾期未发等；
  - 列表与筛选（按店铺、SKU、责任人、状态、时间）；
  - 规则配置：触发条件、责任人、升级规则（超时未处理升级 TL/Leader）；
  - 与透明计划、成品库龄、海运比、Forecast、入库明细等模块数据源打通，支持一键跳转下钻；
  - 简单处理记录与关闭状态，便于统计响应时效与改进。

---

### 7.5 销售数据服务与开放（新增）

- **价值说明**：
  - **痛点**：指标与报表分散在多处，口径不统一；业务或 BI 需要重复取数、对口径，开发成本高、易出错。
  - **收益**：统一指标定义与计算逻辑（销量、销售额、毛利、库存、Forecast 等），报表与看板同源；支持报表/看板可配置（维度、指标、筛选、权限），减少定制开发；通过 API 或数据服务对外提供标准数据集，支撑 BI、大屏与外部系统，提升数据复用与一致性。
- **功能范围建议**：
  - 销售域指标字典（名称、口径、来源、刷新频率）；
  - 可配置报表/看板模板（选维度、选指标、选筛选与权限）；
  - 对外数据服务/API：如按店铺/SKU/日期查询销量、库存、Forecast 等，带权限与限流；
  - 与现有销售报表、Forecast、库龄、海运比等共用数据层，避免重复加工。

---

## 八、模块依赖与实施顺序建议

- **强依赖**：Forecast、采购计划、入库明细、发货计划、透明计划、销售报表等已形成「预测—备货—发货—业绩」主链路，优先保持稳定与口径统一。
- **建议实施顺序**（新增模块）：
  1. **异常与风控中心**：复用现有看板数据，先做集中展示与待办，见效快、风险低。
  2. **销售目标与绩效看板**：与目标制定系统对接或手工维护，与销售报表联动，支撑日常管理。
  3. **价格与利润分析**：在现有销售报表与调价/促销基础上扩展毛利归因与简单建议，再考虑定价模型。
  4. **客户与订单洞察**：依赖订单与客户数据质量，可先做异常归因与统计，再扩展复购与客群。
  5. **销售数据服务与开放**：在指标与报表相对稳定后，再做统一指标字典与 API，避免频繁变更。

---

## 九、总结

| 模块类别 | 现有模块 | 新增模块 | 价值聚焦 |
|----------|----------|----------|----------|
| 计划与履约 | 发货计划、物流计划、智能发货、透明计划 | — | 计划到出库闭环、成本与时效可控 |
| 备货与衔接 | 采购计划、入库明细 | — | 销售与供应链协同、责任可追溯 |
| 物流与成本 | 海运比、成品库龄 | — | 物流结构优化、呆滞与清库 |
| 运营支撑 | Forecast、调价、促销、Deals、样品订单 | — | 预测与执行一致、促销可分析 |
| 报表与分析 | 销售报表（新） | 销售目标与绩效、价格与利润、客户与订单洞察 | 业绩可视、目标可达、利润可归因、异常可归因 |
| 管控与平台 | — | 异常与风控中心、销售数据服务与开放 | 异常不遗漏、数据统一可复用 |

本规划在保留并强化现有模块的基础上，通过**销售目标与绩效看板**、**价格与利润分析**、**客户与订单洞察**、**异常与风控中心**、**销售数据服务与开放**五个新模块，突出「目标可追踪、利润可归因、异常可处置、数据可复用」的价值，支撑销售系统从执行工具向「执行 + 分析 + 风控 + 数据服务」一体化平台演进。
