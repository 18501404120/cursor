### 智岩科技（Govee）ERP 产品经理核心工作内容

---

### 一、整体定位

你是**跨境电商 + 智能硬件企业**的 ERP 产品经理，负责支撑公司：  
`研发 → 采购 → 生产 → 仓储 → 销售 → 售后 → 财务` **全链路数字化**。

智岩是 **高增长、多品类、全球发货、亚马逊为主** 的业务模式，你负责的 ERP 必须支持：

- **多仓库**：深圳本地仓、海外仓、FBA 仓、中转仓  
- **多平台**：亚马逊、独立站、沃尔玛、TikTok 等  
- **多币种**：美元、欧元、英镑等  
- **多 SKU**：多版本、多属性、多套装  
- **大促爆单**：黑五、网一、Prime Day 等高峰场景  
- **全球供应链**：跨区域采购、生产、发货与售后

---

### 二、核心业务模块（你要负责的事情）

#### 1. 商品与 BOM 管理（智能硬件行业必备）

- 维护：SKU、物料、BOM、版本、替代料、EC 变更  
- 支撑：智能灯带、氛围灯、小家电等产品的  
  - 多版本  
  - 多配件  
  - 多组合
- 确保：研发、采购、生产、销售 **使用同一套物料主数据**  
- **输出**：  
  - 物料主数据模块  
  - BOM 管理  
  - EC 工程变更管理

#### 2. 采购与供应商管理

- 管理采购流程：`请购 → 询价 → 下单 → 到货 → 质检 → 入库`  
- 支持：  
  - 委外加工  
  - 贴片（SMT）  
  - 组装  
  - 包材采购
- 行业特点：  
  - 电子料交期长  
  - 价格波动大  
  - 替代料使用频繁
- **输出**：  
  - 采购管理  
  - 供应商管理  
  - 价格管理  
  - 来料质检

#### 3. 生产与委外管理（智岩核心业务）

- 管理流程：  
  - 生产订单  
  - 领料 / 补料  
  - 入库  
  - 报工  
  - 工单成本核算
- 支持：SMT、组装、包装、多产线、多工厂  
- 与：BOM、物料、库存、成本 **强关联联动**  
- **输出**：  
  - 生产管理  
  - 委外管理  
  - 工单执行  
  - 生产领料管理

#### 4. 库存与仓储管理（全球多仓）

- 覆盖：深圳总仓、海外仓、亚马逊仓、中转仓  
- 管理：  
  - 入库 / 出库  
  - 调拨  
  - 盘点  
  - 库位  
  - 批次  
  - 效期
- 支撑业务场景：  
  - 大促爆单  
  - 预售、预售锁库存  
  - 超卖控制
- **输出**：  
  - 库存中心  
  - 仓储 WMS 联动  
  - 批次管理  
  - 库存预警

#### 5. 销售与订单履约（跨境电商核心）

- 对接平台：亚马逊、独立站、沃尔玛、TikTok 等  
- 订单流程：`平台拉单 → 审单 → 拆单 / 合单 → 发货 → 物流追踪`  
- 关键能力：  
  - 多仓发货  
  - 路径与成本优化  
  - 超卖控制  
  - 关税处理  
  - 多币种结算
- **输出**：  
  - 订单中心  
  - 履约中心  
  - 物流单管理  
  - 渠道库存管理

#### 6. 售后与退换货管理（跨境高占比）

- 售后流程：`售后申请 → 质检 → 退换货 → 退款 → 补货 → 报废`  
- 海外退货特点：  
  - 退回难  
  - 维修难  
  - 二次销售困难
- **输出**：  
  - RMA 售后管理  
  - 退货入库  
  - 维修管理

#### 7. 成本与财务闭环（老板最关心）

- 实现自动核算：  
  - 采购成本  
  - 生产成本  
  - 履约成本  
  - 库存成本
- 对接财务软件：  
  - 凭证  
  - 应收 / 应付  
  - 成本结转
- **输出**：  
  - 成本模块  
  - 应收应付模块  
  - 财务凭证集成能力

#### 8. 数据与大屏（管理层强需求）

- 搭建数据看板：  
  - 销售  
  - 库存  
  - 采购  
  - 生产  
  - 履约  
  - 毛利
- 提供关键分析：  
  - 库存健康度  
  - 库存周转  
  - 缺货与超卖  
  - 呆滞料分析
- **输出**：  
  - 数据中心  
  - 经营大屏  
  - 预警中心

### 三、产品经理日常工作（你每天真正在做的）

#### 1. 需求调研与业务梳理

- 访谈对象：采购、生产、仓库、销售、财务、海外运营等角色  
- **输出**：  
  - 业务流程图  
  - 用例图、活动图  
  - 需求清单与优先级

#### 2. PRD 撰写与功能设计

- 编写：页面、字段、按钮、权限、业务逻辑、异常流程  
- 设计：原型、规则配置、审批流、角色与权限体系

#### 3. 跨部门协同（ERP PM 最重要能力）

- 对接：研发、测试、业务部门、供应链、财务、IT  
- 推动：方案对齐、问题解决、数据治理、流程规范落地

#### 4. 项目推进与上线

- 管理：排期、迭代、冒烟测试、UAT、上线、灰度、回滚预案  
- 负责：上线后系统稳定运行与问题闭环

#### 5. 持续优化（ERP 永远做不完）

- 优化方向：  
  - 大促保障  
  - 性能优化  
  - 流程简化  
  - 自动化、减少人工操作
- 提升指标：  
  - 发货速度  
  - 库存准确率  
  - 成本核算精准度

#### 6. 规则与配置中台化

- 目标：让业务**可配置、不发版**即可调整  
- 配置范围：  
  - 审批流  
  - 价格策略  
  - 库存策略  
  - 发货策略  
  - 权限策略
