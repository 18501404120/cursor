# 竞品分析：泛欧 / 多站点 MSKU 共享库存场景

> **关联背景**：见同目录 `需求背景.md`（亚马逊泛欧、多站点共用库存、MSKU 非唯一、预测分站点与备货归主店铺、库存重复展示、PSI/计划下推等）。  
> **分析目的**：对照主流跨境 ERP 的**公开功能说明**，归纳行业常见解法，为自研 ERP 的能力缺口与分期建设提供参考。  
> **信息来源**：各厂商官网帮助中心、产品介绍页及公开文章；**未**基于付费账号实测，具体以厂商当前版本与合同范围为准。

---

## 一、问题映射：背景诉求 vs 竞品常见能力维度

| 背景中的痛点 | 竞品侧常见对应能力 |
|-------------|-------------------|
| 同一批 FBA 实物在多国 listing 下重复计库存 | **FBA 层合并/去重**（按 Pan-EU、EFN 等规则合并相同库存行） |
| 多国共享一套库存做补货决策 | **补货按 ASIN/MSKU 维度汇总** + **可选纳入共享库存** |
| 运营需区分「本国可售」与「跨境/远程可售」 | 报表字段区分 **本地可售 / 远程可售**（与亚马逊报告字段对齐） |
| 多店铺、多 MSKU 对本地 SKU | **配对规则**、**按 MSKU/店铺同步库存**、**库存明细多维唯一键** |
| 计划/采购/FBA 在途一体决策 | **采购段+平台仓+在途** 同屏、**多国库存看板**、**补货试算/连续计划** |

以下按厂商展开；**领星**在公开文档中对 **Pan-EU / EU-EFN** 的表述最具体，**积加**在字段层对 **远程可售** 等与亚马逊对齐较细，**易仓**公开材料更偏 **供应链可视化与 FBA 计划流程**，对「泛欧合并行」的专项说明较少。

## 二、领星 ERP（Lingxing）

### 2.1 产品定位（与本文相关部分）

面向亚马逊卖家的 **FBA 库存、补货、多平台库存同步** 等；帮助文档对 **欧洲泛欧（Pan-EU）与欧洲远程配送（EU-EFN）** 有明确的产品层处理说明。

### 2.2 FBA 库存：泛欧 / 远程配送场景的「去重」逻辑（功能详情）

根据官方《FBA 库存》帮助文档：

- **数据范围**：展示店铺内 **FBA + FBM** 库存；聚合亚马逊多张报告与接口；更新间隔约 **20～60 分钟**，库龄 **每日**更新。
- **查询维度**：支持按仓库、分类、品牌、SKU、品名、**MSKU**、**FNSKU**、ASIN、父 ASIN、listing 负责人、**配送方式**等筛选（含模糊搜索）。
- **核心机制（与泛欧强相关）**：系统通过自动判断，**合并相同的库存数据行**，避免相同库存被重复计算。明确列出的情形包括：
  - **欧洲泛欧配送与远程配送（Pan-EU、EU-EFN）**
  - 北美远程配送（NARF）
  - 欧洲-英国远程配送（EU-EK EFN）
  - **使用供应商条码产生的相同 FNSKU** 等
- **展示配置**：支持隐藏 0 库存、父 ASIN 合并显示、显示已删除 listing、成本/数量维度切换等。
- **数据源（文档披露）**：如《Reserved inventory》《Manage FBA inventory》《FBA inventory（库龄）》等；并对可售、待调仓、在途、预留等字段给出与亚马逊字段的对应说明。

**与背景的对应关系**：贵司会议中「多国 MSKU 同显一份数量导致重复」——领星在 **FBA 库存列表层**采用 **合并行** 思路，直接对准 **重复计算** 问题；**不**等同于「店铺+MSKU 计划预测下推」的内部 ERP 全流程，更多是 **运营侧 FBA 视图与补货输入** 的去重。

### 2.3 补货策略：共享库存汇总补货（功能详情）

根据官方《如何制定科学的补货策略？》等文档：

- **补货维度**：可按 **ASIN、MSKU、SKU、父 ASIN** 补货。
- **与泛欧/北美共享库存的关系**：明确写出 **ASIN/MSKU 维度补货** 适配 **北美远程配送 / 欧洲统一配送 / 泛欧计划** 等场景，并支持 **北美/欧洲共享库存汇总补货**。
- **销量与规则**：可分时段日均权重、近 90 天历史、手动固定销量；可排除异常销量；可配置 **FBA 在途公式**、**是否包含共享库存**、FBA 库存计算方式等。
- **模式**：本地仓发 FBA、海外仓中转；支持 **连续补货计划**、**补货试算**（模拟库存走势、断货点）、**补货提醒**（消息中心、邮件等）。

**与背景的对应关系**：将 **多国销售与物理上一批货** 在 **补货计算** 上拉通，接近会议中「预测分站点、备货归主店铺/汇总」中的 **备货输入侧** 做法；**预测准确率按国拆分**、**内部 PSI 下推** 等仍需企业自建或与领星其他模块组合，公开文档未覆盖贵司内部计划闭环细节。

### 2.4 多店铺 MSKU 与库存同步（功能详情）

公开文档提及：

- **自动同步库存**：可在本地仓、FBA、海外仓与多平台店铺商品间按规则同步；可按 **店铺、MSKU 或 SKU** 指定目标；支持比例分配、0 库存策略等。
- **配对规则**：MSKU 与本地 SKU 的解析规则（截取位数、前后缀等）提升配对效率。
- **库存明细**：有材料称明细以 **「仓库 + SKU + 店铺 + FNSKU」** 等为维度统计（具体以当前产品版本说明为准）。

**小结（领星）**：在**可公开查证**的范围内，领星对 **Pan-EU / EU-EFN 重复库存行合并** 与 **MSKU/ASIN 级共享库存补货** 描述清晰，是跨境 ERP 中对该类问题 **产品化表述较直接** 的一例；贵司若对标，可重点对标 **FBA 展示层去重规则** 与 **补货是否纳入共享库存** 的配置化能力。

**参考链接**：

- [领星 ERP - FBA 库存（含 Pan-EU、EU-EFN 合并说明）](https://www.lingxing.com/help/article/fbaInventory)
- [领星 ERP - 补货策略（泛欧/欧洲统一配送/共享库存汇总）](https://www.lingxing.com/help/article/buhuocelue)

## 三、易仓 ERP（Eccang）

### 3.1 产品定位（与本文相关部分）

易仓集团产品线包含 **易仓 ERP（多平台 / 亚马逊专版）**、WMS、TMS 等。官网亚马逊专版强调 **FBA 库存管理、FBA 备货、头程、利润报表、多批次出库、客服邮件** 等。

### 3.2 FBA 与库存相关功能（公开信息归纳）

根据官网 FBA 专题页及社区文章等：

- **FBA 管理**：支持 **亚马逊 FBA 库存管理、FBA 备货**；**多维度创建 FBA 计划**（运营、销售均可参与），强调流程协作。
- **库存监控**：宣传 **「库存 AI」** 监控库存、采购、在途数量与状态；供应链模块强调 **多仓库、每产品库存透明**、**滞销/不足/正常** 等状态预测、异常预警（如采购已下单工厂未发货）。
- **仓配协同**：强调 **国内仓 + 海外仓 + FBA** 联动、出库模式灵活等。

### 3.3 与泛欧问题的对照说明

在已检索的 **易仓官网 FBA 页、新闻稿、社区文章** 中，**未发现** 与领星帮助文档同级别的 **「Pan-EU / EU-EFN 自动合并库存行」** 专项说明。易仓更突出：

- 多仓、多角色协作与 **补货/在途可视化**；
- **FBA 计划与头程** 流程效率；
- 与 **WMS** 一体的仓内作业能力（若卖家同时用易仓海外仓体系）。

**推断与建议**：易仓卖家在泛欧场景下，更多依赖 **亚马逊后台库存报告 + ERP 多仓视图 + FBA 备货流程** 组合；若贵司对标易仓，宜在 **调研/POC** 中 **单独追问**：FBA 列表是否对 EU 共享库存去重、补货公式是否支持「欧洲共享库存一口价」维度，避免仅根据营销文案对标。

**参考链接**：

- [易仓 - 亚马逊 ERP / FBA 管理介绍](https://www.eccang.com/fba.html)
- [易仓社区 - 供应链管理功能介绍](https://bbs.eccang.com/articles/1369)

## 四、积加 ERP（JiJia，补充竞品）

虽用户未点名，但 **积加在帮助文档中对 FBA 字段（含远程可售）与多国看板** 描述较细，可作为同类架构参考。

### 4.1 FBA 库存（功能详情）

根据官方《Amazon FBA 库存》帮助文档：

- **整合报表**：同步 FBA 多种库存报告，**字段与亚马逊卖家后台对齐**，并叠加 **产品信息、采购信息、销量、周转** 等系统计算指标。
- **与内部进销存衔接**：文档明确 FBA 展示中包含 **G+ERP 系统中的采购段锁仓/共享库存、非平台仓在途锁仓/共享库存、非平台仓库内可用锁仓/共享库存** 以及亚马逊店铺内库存、销量、周转天数等——即 **平台库存与采购/调拨/在途** 在同一决策界面拉通。
- **更新频率**：亚马逊库存约 **每小时**，库龄约 **每 8 小时**；**多国库存看板**在指定时间点批量更新（文档给出每日多次调度示例）。

### 4.2 「本地可售 + 远程可售」与泛欧/EFN 的对应

文档中 **库存信息** 部分：

- **可售** = **本地可售 + 远程可售**
- **本地可售**、**远程可售** 分别对应亚马逊报告中的 `afn-fulfillable-quantity` 与 **`afn-fulfillable-quantity-remote`**

该拆法与亚马逊 **跨境履约/远程可售** 语义一致，便于运营理解「本仓可发」与「依赖跨国调配的可售」差异，**从字段层减少误解**，但 **是否在 UI 上合并多国 MSKU 重复行** 需结合其实际列表交互（公开文档以字段说明为主）。

### 4.3 小结（积加）

优势在 **报表字段与亚马逊一致 + 采购/锁仓/共享库存与 FBA 同屏**，适合对标贵司 **「计划/采购/在途与 FBA 一体」** 的深度；**泛欧重复展示** 是否在列表层做合并，建议 POC 验证。

**参考链接**：

- [积加 - Amazon FBA 库存](https://help.jijiaerp.com/docs/v5Wl4W20)

## 六、综合对比与对自建系统的启示

### 6.1 竞品常见三层解法（抽象）

1. **展示层**：识别 **Pan-EU / EFN / 同 FNSKU** 等导致的 **重复行**，合并或标注，避免运营/计划 **double count**。  
2. **字段层**：与亚马逊报告对齐 **本地可售、远程可售、预留** 等，减少「看起来每个国家都有货」的歧义。  
3. **决策层（补货）**：在 **ASIN/MSKU** 粒度上 **汇总多国需求**，并允许配置 **是否计入共享库存 / 在途公式**，生成采购或发货建议。

### 6.2 与贵司《需求背景》的差距与可借鉴点

- **库存重复**：领星公开的 **合并相同库存行** 是直接可借鉴的产品规则；贵司还可叠加 **店铺+MSKU 主从、主店铺配置**（会议已提「SKU 库存归属」）。  
- **预测分站点 vs 备货归主店铺**：竞品 **补货模块** 多解决 **备货数量** 汇总；**分站点 forecast 准确率、PSI 前置、计划下推只显主站** 属于 **企业内部计划体系**，需自建规则引擎/配置表，较少在对外帮助文档中完整披露。  
- **周转天数**：积加、领星均强调 **周转、销量、库龄** 等扩展指标；泛欧下 **总库存对单国预测** 的偏差，竞品多用 **汇总补货** 或 **指标说明** 缓解，**不一定**解决财务/管理会计口径的分摊问题。

### 6.3 使用本竞品分析时的注意点

- 厂商功能迭代快，**以演示环境、合同附件、API/报表说明为准**。  
- **泛欧 + 无欧盟税号店铺** 属合规与运营策略组合，ERP 主要解决 **数量与流程**，**税号与开票** 需另列专题。  
- 若需 **强制对标** 某一竞品，建议列出 **POC 清单**：FBA 列表是否合并 Pan-EU 行、补货是否支持欧洲共享库存、是否区分 remote fulfillable、主从 MSKU 配置方式等。
