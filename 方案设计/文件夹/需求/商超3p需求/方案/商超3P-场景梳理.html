商超 3P · 场景梳理

WFS 库存 · 多平台上架 · 促销规划 · 全渠道管报 · 约 12 分钟阅读

草案 · 含 8 条待确认（见文末）

一句话：成本驱动下主货盘转向 WFS 一池多店，需在 ERP 侧解决 品牌/平台逻辑库存、借调台账与超卖防控；同时补齐 Listing 主数据与 Mirakl 对接、亚马逊→沃尔玛促销规划效率，销售成本并入 全渠道管报。

1 · 背景
备货策略转向测算后 WFS 头尾成本最低，主货盘（含后续更多商超 3P 平台）倾向集中备入 WFS。
平台约束WFS 不能像 FBA 按店铺分仓；实物与账面多集中在沃尔玛侧 WFS，多品牌、多平台共卖同一池。
渠道扩张BBY 由 Reason 迁回 Mirakl/MySQL；Lowes 等新店洽谈中，Listing 需重复维护。
促销节奏沃尔玛促销规则相对固定（如 Best Deal 窗口），但规划仍依赖亚马逊促销日历手工对照。
2 · 痛点
超卖风险WM 占满 WFS 可售；BBY/Lowes 可售需手工配且扣减非实时，10 分钟拉单窗口内可能卖穿。
品牌难区分三品牌共 WFS，无法像 FBA 按店隔离，缺逻辑库存与借调消耗追溯。
借调低效日常小批量借调依赖人工找仓储同事，缺自助与额度校验。
上架重复百款级 SKU 在 Mirakl 后台逐条建品；跨平台字段名不一致，无法「拷店」。
促销费时每月从亚马逊营销日历扒价再排沃尔玛表，划线价 / Coupon / Promotion 难区分，Lowes 等平台还不能分段预排。

4 · 业务价值
控超卖共享池 + 预测砍量 / 切补仓，降低多平台共卖 WFS 的断货与赔付风险。
算清账借调台账 + 订单履约标识，支撑多品牌 WFS 消耗与头尾成本归因。
提人效借调自助、Listing 主数据一次维护多平台上架、促销试算省约 1～2 天/月。
统一看数商超 3P 销售成本纳入全渠道管报，与亚马逊等同一套营收规则。

Lowes 等（扩店）

同上；拉单盲区内 WM 可能卖穿 → 超卖风险点。

目标能力（三块）

区分与台账多品牌逻辑库存；借调面板展示借调量与消耗；订单可识别 WFS 履约消耗（含借调货）。
共享与防控沿用共享库存主库存=沃尔玛；加消耗预测：连续多个 10 分钟窗口评估 WM 增速，风险时砍 BBY/Lowes 可售或切 FBM/谷仓补仓。
借调自助实时查 WFS 仓库存；扣减已借未还；可选比例上限（如 < 实查 30%）；无法 100% 防超卖但减人工。
10 分钟拉单 · 风险示意

T0：WFS 实查 200，BBY 配可售 100。T0～T10：沃尔玛热卖 200 台，ERP 尚未感知 → BBY 仍可能再卖 → 逻辑超卖。

短期订单量不大可人工兜底；旺季前需预测砍量或切自发货（自发货库存数据在己方）。

轻量演算：借调额度（草案规则）

可借上限 ≈ min(实查×30%, 实查−已借) → 示例 70 台
7 · Listing：ERP 主数据 · 多平台上架
现状
  • Mirakl 后台逐条建品；CSV 导入仅文字，图片 URL 易失败
  • BBY 无法导出再导入 Lowes；字段名按平台各异（item / name…）
  • ERP 无长宽高等 Listing 主数据历史
目标
  • ERP 维护商超 Listing 主数据（尺寸、描述、认证、图链等）
  • 按类目模板映射 Mirakl 必填项；新店走导入或 API 创建
  • 源数据变更可同步多平台，避免逐店手工刷
先调研 Mirakl API 试单类目 CSV 导入 图片：公网 URL 或平台托管

Lowes 开店紧迫：可先 Excel/模板导入跑通，再迭代 API；亚马逊资料可作补充来源但 ERP 需沉淀副本。

8 · 促销：亚马逊日历 → 沃尔玛规划
三类促销Coupon（复控）、划线价、Promotion（灵活时段）；Flash Deal 固定月内窗口。
近期交付营销日历增强：导出区分 Coupon 与划线价（或同色标单元格）；约 6 月。
中期目标全渠道资源计划加「沃尔玛试算」：读亚马逊分段价 + 业务成文规则 → 高亮可报 Flash / Promotion / Coupon。
体验补强Lowes 等：同价不能两段预排 → 促销结束次日提醒设下一段；调研 Mirakl 是否支持创建 Promotion。
色块含义（业务表习惯）沃尔玛侧动作
标 Coupon → 复控价报 Coupon
仅标价、无 Coupon → 划线划线价 / Best Deal 窗口
与 Flash 窗口重叠的低价段试算高亮「可报 Flash」

沃尔玛可整月多段预排；仍须人工到 Mirakl 后台报名，系统先解决「看清该报什么」再考虑 API 自动写价。

9 · 全渠道管报（不单独立项）

商超 3P 销售成本 / 营收不单独做「销售成本面板」，纳入在研全渠道管报，与各渠道同一套呈现规则；出货授权成本等由管报项目一并交付。

10 · 角色与职责

商超运营（3P）

  • 备货策略、各平台可售配置、促销排期
  • 提供沃尔玛促销成文规则与 Excel 模板样例
  • 复核 WFS 扣减时点；对接沃尔玛平台方

ERP / 产品 · 研发

  • 共享库存、借调自助、Listing 主数据、营销日历与试算
  • Mirakl API / 导入能力矩阵调研

仓储 / 库存协作

  • 过渡期 WFS 手工借调；配合实查口径
  • 借调自助上线后转为规则内自助

全渠道管报项目

  • 商超 3P 渠道指标与销售成本口径验收
