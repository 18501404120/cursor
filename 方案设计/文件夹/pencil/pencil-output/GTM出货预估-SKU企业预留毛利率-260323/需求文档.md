# 需求文档（改动点说明）

**需求名称**：GTM 出货预估 — SKU 维度企业预留毛利率维护与继承  
**文档版本**：v1.2（精简表述）  
**关联评估**：本需求为独立说明，可与业务方补充确认后定稿

---

## 一、需求概述

- **一句话**：在 `GTM看板 → 出货预估` 的 **MSKU 列表** 中，于「企业预留毛利率（%）」**左侧** 增加 **「SKU 维度企业预留毛利率（%）」**；该字段逻辑归属 **SKU**（列表多行同 SKU 展示一致），**默认空**；**单行 / 批量 / 导入** 修改规则与权限和现网「企业预留毛利率」一致。**改 SKU 维度**（含任一 MSKU 行上改该列）→ 更新 SKU 主数据，且该 SKU 下 **全部 MSKU** 的 **SKU 维度列** 与 **行级企业预留毛利率（%）** 均 **覆盖为同一取值**。**仅改行级企业预留毛利率** → 不回写 SKU 维度、不影响同 SKU 其他行。**导入/导出模板** 增加 SKU 维度列；**历史数据** 在 MSKU 行级取值可唯一确定时回填 SKU 维度。
- **涉及模块**：GTM 出货预估、SKU-MSKU 主数据、成本/价格相关配置。
- **角色/场景**：运营维护 SKU 默认毛利率；与现有行级编辑、批量、导入导出共用。

---

## 二、改动范围总览

| 类型 | 说明 |
|------|------|
| 新增 | 列表列 **SKU 维度企业预留毛利率（%）**；后台 **SKU（或期间+SKU，待确认）** 存主数据；**导入/导出** 模板增列。 |
| 修改 | 列表支持该列 **行内编辑**；**批量编辑、导入** 支持该列；文案提示「改 SKU 维度将覆盖整 SKU 下所有 MSKU 的 SKU 维度与行级毛利率」。可选 **SKU 维护 Tab**（与列表同源，**待确认**是否本期交付）。 |
| 删除/下线 | 无。计算公式不变，仍以 **MSKU 行级「企业预留毛利率（%）」** 参与出货预估相关计算。 |

## 三、具体改动点

### 3.1 页面 / 功能入口

- **位置**：`GTM看板 → 出货预估`（MSKU 列表）。
- **改动**：列顺序为 **SKU 维度企业预留毛利率（%）** → **企业预留毛利率（%）** → 其余列不变；工具栏 **批量编辑 / 导入 / 导出** 覆盖上述两列（导出仅多列、不改数）。

### 3.2 字段 / 数据项

| 字段 | 层级 | 含义 | 规则摘要 |
|------|------|------|----------|
| SKU 维度企业预留毛利率（%） | SKU | 与行级字段同口径 | 默认空；**单条 / 批量 / 导入** 写入即 **SKU 维度变更**；权限、校验对齐现网「企业预留毛利率」。写入以 **SKU 主数据为真理源**，列表可主表读取或冗余存储须一致。 |
| 企业预留毛利率（%） | MSKU | 行级，参与计算 | **新建 MSKU**：默认 = 当前 SKU 维度（SKU 侧空则按现网默认）。**可单独改行**；不改 SKU 维度及其他行。**SKU 维度变更** 时本 SKU 下 **全部行覆盖** 为 SKU 取值。 |
| 一致/覆盖标识（可选） | MSKU 展示 | 行级是否与 SKU 维度相同 | 仅展示；**SKU 维度覆盖全 SKU** 后应更新为一致。 |

### 3.3 筛选 / 查询条件

- **MSKU 列表**：沿用现有筛选；本期不强制新增筛选项（可选「仅看行级与 SKU 维度不一致」**待确认**）。
- **若有 SKU Tab**：筛选项与主列表域对齐（月份、国家、店铺、SKU 等），**待确认**。

### 3.4 业务逻辑与规则

1. **层级**：SKU 父、MSKU 子；一 SKU 多 MSKU。
2. **SKU 维度变更**（来源：**单行、批量、导入**及接口若存在）：更新 **SKU 主数据** → 该 SKU 下 **所有 MSKU** 的 **SKU 维度列** 统一为新值 → **所有 MSKU** 的 **行级企业预留毛利率（%）** 同步为该值（**覆盖式**，含曾手工改过的行）。任一行上改 SKU 维度列 **等同** 改该 SKU 的 SKU 维度。
3. **仅行级变更**：只更新当前 MSKU 行；**不** 动 SKU 维度及其他行。
4. **新建 MSKU**：SKU 维度列 = 所属 SKU 当前值；行级默认 = 当前 SKU 维度（或现网空值规则）。
5. **历史数据处理**：按 **SKU** 遍历其下 **全部 MSKU** 的 **行级企业预留毛利率（%）** — 若 **均非空且取值完全相同**（去重仅 1 个数值），则写入 **SKU 维度企业预留毛利率（%）**；若多值、空值混用、全空则 **不写** SKU 维度（或后续人工/导入补录，**待确认**众数等策略）。
6. **导入/导出**：模板 **增加列「SKU 维度企业预留毛利率（%）」**；导入该列有值时按 **本条第 2 款** 做 **整 SKU** 同步；导出带出 SKU 维度与行级两列（同 SKU 多行可重复 SKU 维度值）。
7. **权限**：与现网企业预留毛利率一致或同套可配置（是否拆分「仅行级」**待确认**）。

### 3.5 数据来源与依赖

- **依赖**：SKU/MSKU 关联、出货预估期间与店铺等国家维度（与现网一致）。
- **存储**：SKU 维度存配置主表；行级存 MSKU 行表；保存后 **即时** 生效列表与计算链。

### 3.6 异常与边界

- SKU 维度未配置时的默认与提示对齐现网。
- 导入 **同 SKU 多行 SKU 维度列不一致** → 拒识/首行/末行等规则 **见第六节**。
- 比例与币种/站点关系、是否拆「期间+SKU+国家」键 **见第六节**。

## 四、验收要点

- [ ] 列顺序正确；同 SKU 多行 **SKU 维度列一致**。
- [ ] **单行 / 批量 / 导入** 改 SKU 维度后，该 SKU 下全部 MSKU **两列** 均为新值；**仅改行级** 时 SKU 维度及其它行不变。
- [ ] 导入/导出模板含 **SKU 维度** 列，校验与失败行提示正确。
- [ ] 新建 MSKU 默认符合 3.2、3.4 第 4 款。
- [ ] 历史迁移：仅 **全非空且唯一行级取值** 的 SKU 写入 SKU 维度。
- [ ] 权限、日志与现网对齐。

---

## 五、与现有能力的关系

- **依赖**：出货预估列表、毛利率/毛利额/出货预估价链路、批量与导入、操作日志。
- **不改**：其它列口径与计算公式（除行级毛利率默认值与覆盖来源变化外）。

---

## 六、待与业务确认的不明确点

1. SKU 维度 **唯一键**：是否仅「月份+SKU」或含国家/店铺。  
2. **清空 SKU 维度** 时行级是否同步清空。  
3. **历史迁移** 是否必须全非空；含空行但其余相同是否回填。  
4. **导入** 同 SKU 多行 SKU 维度冲突处理规则。  
5. **本期** 是否交付独立 SKU 维护 Tab。  
6. **补录 MSKU** 取历史快照还是当前 SKU 维度。
