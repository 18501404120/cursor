原型标注1 本页标注口径：以“历史导入费用”为主，按“导入/新增 → 状态流转 → 是否纳入管报计算”进行验收。

原型标注1｜页面说明（业务视角）

  • 这是「业务费用导入管理」页，核心目标是把新增/导入的费用批次管理清楚，并明确哪些批次会进入管报。
  • 批次默认是“待生效”，只有变成“已生效”后才参与管报；“失效”批次不参与，且仅失效批次可删除。
  • 列表和明细要保持口径一致：列表显示什么状态，明细里的“是否纳入管报计算”就应显示同样结论。
  • 新增/导入只是“写入数据”，不是“直接生效”；业务确认动作在生效/失效操作里完成。

一、前提

  • 本页维护需补充导入的业务费用批次（手工新增弹窗 + 文件导入解析）。
  • 批次通过状态决定是否进入全渠道管报的业务费用导入结果池及按 MSKU 分摊。
  • 列表「明细」弹窗中的纳入管报计算与行状态一致，便于验收。

二、本页在做什么

  • 筛选：按归属月范围、费用项、部门、状态、备注等条件筛选，点击「查询」后刷新列表。
  • 行操作：生效 / 失效 / 删除 / 明细；批量：批量生效、批量失效、批量删除（均带状态校验）。
  • 新增 / 导入：写入的新批次默认待生效，需人工「生效」后才参与管报。

三、状态定义与默认值

状态含义
待生效新建或导入成功后的初始状态；不参与管报计算。
已生效人工确认后；参与管报分摊与汇总。
失效业务作废；不参与计算；仅此时允许删除。

四、状态流转（图形）

单条与批量按钮遵循同一套状态迁移规则；非法组合操作时页面会弹出提示，且不改数据。

待生效与已生效均可操作「失效」进入失效状态。删除仅允许针对已为「失效」的批次（见下文规则表）。

  • 生效：仅支持“待生效”变为“已生效”。
  • 失效：支持“待生效”或“已生效”变为“失效”。
  • 删除：仅“失效”批次可删除；删除后会从列表移除并清除对应明细记录。

五、列表操作与批量规则

当前状态行内操作
待生效明细、生效、失效
已生效明细、失效
失效明细、删除
批量按钮允许勾选的行结果
批量生效全部为待生效一律变为已生效；混入其它状态则报错不执行。
批量失效全部为待生效或已生效（可混）一律变为失效；若含已失效行则报错不执行。
批量删除全部为失效删除；混入非失效则报错不执行。

表头「全选」仅作用于当前筛选结果中的可见行。

六、纳入管报计算

  • 仅已生效批次进入业务费用导入结果池及按 MSKU 分摊；待生效与失效均不参与。

七、筛选与多选下拉

  • 全部筛选条件（归属月范围、费用项、部门、状态、备注）须点击「查询」后生效并刷新列表。
  • MSKU、零售商及弹窗内渠道/店铺等：遵循《多选下拉筛选》— 默认点击展开后再加载选项；面板内搜索与多选；MSKU/SKU 弹窗内无「全部」；历史区零售商在「查询」左侧。

八、弹窗入口

  • 新增导入费用：配置后预览 → 确认写入 → 新增一条待生效批次及明细占位。
  • 导入：按钉钉《业务费用导入模版》填写（含数据字典页）；下载 CSV 或打开在线模版后上传；正式环境解析后批量待生效；原型可用「模拟：生成一条待生效批次」。

九、测试建议（验收清单）

  1. 状态筛选：待生效 / 已生效 / 失效 / 全部 与列表一致。
  2. 待生效 → 生效 → 已生效；明细中「纳入管报计算」为是。
  3. 已生效 → 失效；明细中为否。
  4. 失效 → 删除确认后行消失。
  5. 批量生效：混入已生效行应报错；仅待生效应全部已生效。
  6. 批量失效：待生效+已生效混合应全部失效；含失效行应报错。
  7. 批量删除：仅失效成功；混入待生效应报错。
  8. 全选 + 批量：仅处理当前筛选可见行。

模版结构

  • 费用信息：费用项、归属月、金额、币种、分摊模式、部门、备注
  • 渠道范围：区域 / 国家 / 渠道 / 店铺 / 零售商

分摊规则

  • 分摊：渠道与产品范围分别取交后，按权重月营收占比分摊至各 MSKU，剔除回款为负数据；部门可留空（按店铺映射）
  • 不分摊：渠道/产品每列仅可单选或不填，填写字段为 AND 条件，全空即全公司通用费用；部门必填
  • 解析成功生成待生效批次，规则与「新增导入费用」一致
在线模版与数据字典： 打开钉钉文档 · 业务费用导入模版 含「导入模版」示例行与「数据字典」各列合法取值；正式环境以此版本为准。

正式环境支持 Excel / CSV；校验失败时返回错误明细文件。

填写要求

  1. 费用项、币种及渠道/产品各列取值须与钉钉模版「数据字典」页一致；店铺、SKU、MSKU 等与系统主数据二次校验。
  2. 同一单元格内多个选项仅用英文逗号分隔，勿用分号或中文逗号。
  3. 分摊模式：从本月营收明细筛选「渠道范围 AND 产品范围」都匹配的记录，空字段视为不限，营收 < 0 的记录剔除不参与分摊；按匹配记录营收占比分摊金额（保留2位小数，末行舍入调整），结果归属到明细级（如具体店铺）。部门可留空（按店铺映射归属），填了则按填的部门归属；订单号、DL批次号可填。
  4. 不分摊模式：渠道/产品范围每列仅可单选或不填，不可多选；填写字段作为费用归属的 AND 条件，全部为空即「全公司通用费用」；查询时填写字段精确匹配、空字段为通配。部门必填，由用户填金蝶部门。
  5. 解析失败行写入错误文件回传；成功行生成待生效批次。
