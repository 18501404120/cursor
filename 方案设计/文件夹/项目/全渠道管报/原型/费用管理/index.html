费用管理 · 费用来源与商超计提

本模块含费用来源定义、费用填报（导入分摊 + 手工填报）、商超客户计提规则（比例/销费规则）、退款与扣款台账，以及统一的费用项主数据（名称、备注，浏览器本地持久化，各页下拉同步）。

费用来源定义

筛选 + 列表；弹窗维护来源规则。工具栏可维护费用部门（组织→部门树，中间层可选，对金蝶 BM）与费用项主数据。

 费用填报管理

嵌入完整业务费用导入管理；支持按部门维度筛选与分摊。费用项下拉引用主数据。

 商超费用计提口径说明

按费用项查看计提逻辑、Excel公式、数据来源、冲销规则与校验点，可直接用于系统落地与对账复核。

 客户计提规则管理

按零售商维护促销扣款、销售折扣、现金折扣比例及销售费用计提规则；支持按客户「部门管理」与扣款管理联动。

 退款管理

按客户+月份维护退款数据，展示期初余额、实际退款（用户录入）、当月计提退款、期末余额。

 扣款管理

按客户+月份+费用项维护实际扣款与计提扣款金额，自动输出差异与匹配状态。

 项目立项 · 预算

PMP 项目预算填报：营销类型 / 类型 / 场景品类 / 区域渠道与费用规划。支持 GitHub Pages 预览入口。

系统组件（本目录）

  • fee-dept-master.js + fee-dept-master.css — 费用部门树（组织→层级→部门）、金蝶 BM 对照、增删改导出（在「费用来源定义」页维护）
  • fee-item-master.js + fee-item-master-data.json — 费用项主数据（树形只读 + 备注）、localStorage、各页下拉同步末级节点
  • fee-mgmt-op-log.js — 操作日志（localStorage，退款/规则页共用）
  • fee-mgmt-common.js — 筛选区可清除、弹窗、CSV 导出
  • 商超费用计提口径说明.js — 费用项口径规则引擎（筛选、检索、公式与取数口径展示）
  • supermarket-accrual-store.js — 客户计提规则、退款记录、扣款记录共享数据层（localStorage）
