# 全渠道管报 · 原型（HTML）

本目录为静态 HTML 原型，按编号子目录组织。

## 目录结构

| 目录 | 说明 |
|------|------|
| `00-方案与规划/` | 项目规划、用户故事、业务口径、竞品 |
| `01-经营分析/` | 经营分析看板与明细 |
| `02-费用管理/` | 费用来源、填报、商超计提、海外仓费率等 |
| `03-BP管理/` | 渠道 BP 分发与填报 |
| `04-管报二期/` | 费用分析与来源追溯 |
| `_archive/` | 历史稿与 v1 页面 |

## 本地预览

在 `方案设计` 根目录执行：

```bash
python3 -m http.server 8765
```

浏览器打开：`http://localhost:8765/文件夹/项目/全渠道管报/原型/index.html`
