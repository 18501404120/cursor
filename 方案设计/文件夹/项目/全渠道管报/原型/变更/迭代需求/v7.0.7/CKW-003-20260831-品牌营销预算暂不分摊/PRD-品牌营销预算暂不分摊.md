【预算模块】品牌营销预算暂不分摊

公开原型：[在线访问](https://18501404120.github.io/cursor/文件夹/项目/全渠道管报/原型/02-费用管理/项目立项-创建项目.html)

改动位置：项目平台 → 项目 → 预算页签

原型（与知识库共用一份，不再另做独立页）：
`本地/方案设计/文件夹/项目/全渠道管报/原型/02-费用管理/项目立项-创建项目.html`

本次改动：
1. 去掉「分摊模式」字段。本页所有预算行不再展示、也不再让用户选择分摊或不分摊。
2. 本页费用一律挂全公司，暂不执行分摊。不论品牌费用项选到品牌营销、产品营销还是基础固定花费，金额都不拆到商品。11 月分摊规则与按记录回算不在本次范围。
3. 场景品类、model、SKU、区域、国家、渠道、店铺改为均可多选，系统只做记录，供后续分摊规则确定后再用。范围可全空。不再按「不分摊时每列最多选 1 个」裁减。
4. 费用部门仍必填，继续记承担部门。挂全公司指分摊对象，不是取消部门。
5. 品牌费用项改为树形单选，交互对齐费用项主数据下拉：支持展开/收起、按名称或编码搜索；选项为整棵营销投入树（自主营销 / 联合营销 → 产品营销 / 品牌营销 / 基础固定花费 → 下级末级）。只能选末级，父级点击只展开不选中。选中后展示短路径。替换旧版「营销类型 + 类型」。
6. 新品标签仍按现有年份单选，不改。

异常处理：
- 未选品牌费用项：提示「第 N 行：请选择品牌费用项」
- 未选费用部门：提示「第 N 行：请填写费用部门」
