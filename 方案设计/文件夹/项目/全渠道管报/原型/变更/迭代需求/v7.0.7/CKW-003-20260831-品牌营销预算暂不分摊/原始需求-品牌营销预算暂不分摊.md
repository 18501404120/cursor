目标系统：全渠道管报

需求描述（原文）：
昨天业务试用项目平台预算管理时提了一下变更点：
1、针对品牌营销费用，暂时都不分摊，但是允许业务选到多个sku/场景品类/国家，系统先做记录（让用户先填写），费用挂到整个公司，等到分摊规则确定后（预计11月份提供），根据记录的信息再执行分摊。因此当前去掉“分摊模式”字段，下面字段允许业务多选；2、业务调整了品牌营销费用的分类
--将这个变更梳理成PRD和原型，先和我对齐

确认结果：
- 「去掉分摊模式」作用范围 → 用户选择：都不要分摊模式；本次只改项目预算页，整页去掉分摊模式；费用导入等其它费用项仍保留现有分摊模式
- 去掉分摊模式后如何判断挂全公司还是分摊 → 用户选择：本页所有行都挂全公司、暂不分摊（含选了产品营销、基础固定花费的行）
- 范围字段多选范围 → 用户选择：全部范围字段都可多选（场景品类 / model / SKU / 区域 / 国家 / 渠道 / 店铺）
- 「费用挂到整个公司」时费用部门怎么处理 → 用户选择：费用部门仍必填（记录承担部门）；分摊对象挂全公司，不拆到 SKU
- 品牌营销费用分类口径 → 用户选择：整棵营销投入树（含产品营销、品牌营销、基础固定花费）
- 对齐方案五条 → 用户选择：确认
