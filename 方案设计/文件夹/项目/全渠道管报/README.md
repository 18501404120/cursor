## 本地预览（推荐）

部分原型依赖脚本与 `fetch` 读同仓 JSON，请在 **`方案设计` 根目录** 起 HTTP 服务（不要用 `file://`，也不要只在本项目子目录起服务）：

```bash
cd /Users/ckw/Documents/erp/本地/方案设计
python3 -m http.server 8765
```

建议入口：

- 项目总导航：`http://localhost:8765/文件夹/项目/index.html`
- 本项目原型目录：`http://localhost:8765/文件夹/项目/全渠道管报/原型/index.html`
- 费用管理：`http://localhost:8765/文件夹/项目/全渠道管报/原型/费用管理/index.html`
- BP 管理：`http://localhost:8765/文件夹/项目/全渠道管报/原型/BP管理/index.html`
- 经营分析看板：`http://localhost:8765/文件夹/项目/全渠道管报/原型/全渠道管报-经营分析看板.html`
- 经营分析明细：`http://localhost:8765/文件夹/项目/全渠道管报/原型/经营分析明细.html`
- 终版方案入口：`http://localhost:8765/文件夹/项目/全渠道管报/终版方案/原型/index.html`
- 归档原型：`http://localhost:8765/文件夹/项目/全渠道管报/原型/暂时不需要/index.html`

局域网分享也可用：

```bash
cd /Users/ckw/Documents/erp/本地/方案设计/原型分享服务
./start.sh
```
