# 亚马逊费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 亚马逊利润报表（SKU 页签为主；月度/年度/国家为同一套底层结果的不同展示）
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（交易明细入账、费用拆分、SKU 报表查询与展示）

---

## 1. 先看结论

亚马逊各费用项**不是页面即时现算**，而是：

1. 先把亚马逊后台 **交易明细报告**（以及广告、仓储、线下导入、采购/头程成本）按店铺、月份拆成「费用子项」；
2. 再按 **店铺 + MSKU + 月份 + 币种** 汇总；
3. 页面查询时按筛选条件聚合，换汇后展示。

SKU 页看到的是「发货 / 退货拆开」的明细；月度页、全渠道经营报表看到的是「同一套子项按管报科目合并、并统一正负号」后的结果。

管报初始化时，**以月度/全渠道经营报表那一套科目口径为准**更稳；SKU 页适合追查「这笔钱从哪类亚马逊交易来」。

## 2. 数据从哪来

| 来源 | 用在哪些费用 | 说明 |
|------|----------------|------|
| 亚马逊交易明细报告 | 销售额、退款、折扣、运费/包装收入、税金、平台代扣税、佣金、FBA 配送费、服务费、调整费、店铺侧仓储/广告总额 | 主数据源。按交易类型、描述、金额列拆分 |
| 亚马逊广告花费报表 | 广告费（SKU 可定位部分） | 按 SKU 汇总广告花费 |
| FBA 仓储报表 | 仓储费里的「长期仓储」「月度仓储」 | 长期按当月；月度取**上月**仓储报表 |
| 线下/站外费用导入 | 推广费、销售广告费、站外服务费、品牌广告（SB） | 财务导入表；能定位到 MSKU/SKU/ASIN 则分摊，否则落到空 MSKU 或店铺 |
| 采购价快照 | 发货成本、退货成本 | Listing / MSKU / SKU 兜底取采购单价 |
| 头程物流单价 | 头程运费、关税 | 物流侧维护的单件头程、单件关税 × 数量 |
| 进销存数量 | 进销存成本、退货成本差额 | 用于「销售口径成本」与「进销存口径成本」对照 |
| MSKU 关系快照 | 所有 SKU 归属 | 决定 team、sales、品线、以及无法直接带 SKU 的费用如何分摊 |

**主链路**：交易明细入库 → 按店铺/月份拆费用子项 → 写入 SKU 结果表 → 页面按维度查询、换汇、取整展示。

## 3. 通用口径（所有费用项共用）

### 3.1 统计粒度

- 明细落库：**店铺 + MSKU + 月份**。
- 页面 SKU 行：再带出品线、小品线、team、sales、SKU、币种。
- 匹配不到具体商品时，金额进 **MSKU 为空的承接行**，保证店铺合计不断层。

### 3.2 交易类型怎么理解

下文「发货订单」不是业务上所有已发货单，而是交易明细里归为 **订单** 的行；部分费用还会并入 **清算**。

「退货」也不是只看退货单，还包括：

| 业务口径 | 交易明细中的类型 | 主要用在 |
|----------|------------------|----------|
| 发货主交易 | 订单 | 销售额、销量、运费收入、包装收入、折扣、佣金、FBA 配送费 |
| 发货补充 | 清算 | 销售额、销量、部分税费 |
| 发货补税 | 订单补收/补税 | 发货税金、发货平台代扣税 |
| 退款主交易 | 退款 | 退货销售额、数量、运费、包装、折扣、佣金、FBA |
| 拒付退款 | 原单退回退款 | 退货销售额、数量、佣金、部分税费 |
| 退款补税 | 退款补收/补税 | 退货税金、退货平台代扣税 |
| 费用调整 | 调整费 | FBA 配送费按正负分流到发货或退货 |
| 平台调整 | 调整 | 页面「调整费用 / 平台赔偿」 |
| 服务费类 | 服务费、优惠券、秒杀/Deal 费等 | 服务费、店铺侧广告、店铺侧仓储 |

Govee 店铺多数场景还会再过滤「订单归类 = 亚马逊订单」；GoveeLife 店铺一般不过这层过滤。

### 3.3 币种、精度、展示

- 内部按 **4 位小数** 计算。
- 页面默认四舍五入取整；换汇后绝对值小于 0.5 的金额会显示成 0。
- 可按选定币种展示，或勾选「显示原币」按站点原币展示。
- 数量类不换汇。
- 占比分母：SKU 页可选「营收」或「发货销售额」。

### 3.4 正负号（非常重要）

交易明细里，平台扣费通常是负数，退款冲回通常是正数。

页面有两套展示习惯：

| 页面 | 习惯 |
|------|------|
| SKU / 国家明细 | 尽量保留交易明细原方向：发货扣费为负、退货冲回为正 |
| 月度 / 年度 / 全渠道经营报表 | 把费用项翻成「费用为正、收入按科目定义」的管报口径 |

管报对表时，不要用 SKU 明细某一列的正负号直接去对月度科目。

### 3.5 分摊规则（店铺费用落到 SKU）

能直接带商品编码的，按商品落。落不到时：

1. 能解析出 SKU / ASIN：按当月该商品对应各 MSKU 的 **发货销售额占比** 分摊；
2. 仍匹配不到：进空 MSKU 行；
3. 线下导入可指定 MSKU、SKU、ASIN、品线或店铺。

## 4. 收入与折扣

### 4.1 发货销售额

- **来源**：交易明细，交易类型 = 订单（另含清算）。
- **取值**：商品销售额列合计。
- **SKU 页**：当月发货 → 销售额。
- **月度 / 全渠道「销售额」**：**发货销售额 + 发货运费收入 + 发货包装收入**（不含退货）。

### 4.2 发货数量

- **来源**：同上，数量列合计。
- **SKU 页**：当月发货 → 数量；销售成本组里的数量也用发货数量。

### 4.3 退货销售额

- **来源**：退款、原单退回退款、清算调整。
- **取值**：
  - 退款：商品销售额 + 其他金额；
  - 原单退回退款、清算调整：商品销售额。
- **月度 / 全渠道「销售退款」**：把退货销售额、退货运费收入、退货包装收入合计后取反，展示为退款金额。

### 4.4 运费收入、包装收入

- **来源**：订单 / 退款对应列（运费积分、包装费）。
- **关键规则（运费优惠重分类）**：同一行里「运费收入」与「促销折扣」正负几乎完全抵消时，视为买家运费被促销全额减免。系统把该行的运费收入和折扣**同时剔除**，避免销售额、折扣双计。
- 日本站折扣还会并入亚马逊积分成本。

### 4.5 折扣、优惠合计、销售收款

- **折扣来源**：订单 / 退款的促销折扣列；已剔除上面的全额运费优惠。
- **SKU 页**：发货折扣、退货折扣分开。
- **月度 / 全渠道**：
  - 折扣 = −发货折扣 − 退货折扣（翻成费用/冲减口径）；
  - 优惠合计 = 折扣；
  - 销售收款 = 销售额 − 优惠合计。

### 4.6 税金、平台代扣税

**发货税金**（订单 + 清算 + 订单补税）：

商品销售税 + 运费税 + 包装税 + 促销折扣税 + 监管费税 + 补收税费；非土耳其站点还加「合计与理论合计的差额」。

**退货税金**：退款、退款补税、原单退回退款，口径对称。

**平台代扣税**：对应列合计；发货含订单补税，退货含退款补税和拒付退款。

**月度页**：税金、平台代扣税分两行。

**全渠道「销售税 / VAT」**：发货税金 + 退货税金 + 发货代扣税 + 退货代扣税（四项直接加总，不再拆行）。

亚马逊月度「收入净额」口径：**收入净额 = 销售净额**（税金与代扣税不从销售净额里再扣一遍）。全渠道经营报表对亚马逊也按「销售净额」作为收入净额。

### 4.7 销售净额、营收

- **销售净额** = 销售收款 − 销售退款。
- **SKU 营收** = 发货（销售额 + 运费收入 + 包装收入 + 折扣）+ 退货（销售额 + 运费收入 + 包装收入 + 折扣）。
- SKU 页营收提示不含佣金、FBA；利润才会继续扣费用和成本。

## 5. 平台费用（佣金、FBA、仓储、服务费）

### 5.1 平台佣金（全渠道列名常为「FBA 佣金」）

| 方向 | 取值 |
|------|------|
| 发货 | 交易类型 = 订单，销售费用（佣金）列合计 |
| 退货 | 退款 + 原单退回退款，销售费用列合计 |

- **SKU 页**：发货佣金、退货佣金分开，保留原符号。
- **月度 / 全渠道**：−（发货佣金 + 退货佣金），把净佣金展示为费用。

### 5.2 FBA 配送费（全渠道列名常为「尾程运费 / FBA 物流」）

**发货 FBA** 由四块相加：

1. **订单且有 SKU**：FBA 费用列 + 其他交易费用列。Govee 店铺只计「订单归类 = 亚马逊订单」；GoveeLife 店铺直接计。
2. **描述 = 代发尾程 FBA 配送费**：取其他金额列。
3. **交易类型 = 调整费**，FBA 费用列为**负数**：计入发货 FBA。
4. **调整费且描述含 FBA 客户退货费用**：FBA 费用计入发货 FBA。

**退货 FBA**：

1. 退款、原单退回退款：FBA 费用 + 其他交易费用；
2. 调整费中 FBA 费用列为**正数**（且不是「FBA 客户退货费用」）：计入退货 FBA。

- **SKU 页**：发货 / 退货分开。
- **月度 / 全渠道**：−（发货 FBA + 退货 FBA）。

说明：部分订单的 FBA 费用里会夹带「运费扣回」（与运费收入成对）。现网仍计在 FBA 配送费里，没有单独拆成运费抵扣科目。对账时 FBA 可能比「纯配送费」偏大。

### 5.3 仓储费（页面不拆长期 / 月度，底层可拆）

现网利润报表、全渠道经营报表都只有一列 **仓储费**，不单独展示「长期仓储费」。长期仓储是仓储费的构成，不是独立科目。

**SKU 侧构成（相加）**：

| 构成 | 取数 | 归属方式 |
|------|------|----------|
| 长期仓储 | 当月长期仓储报表：6 个月库龄费 + 12 个月库龄费 | 按报表上的 SKU 直接归属 |
| 月度仓储 | **上月**月度仓储报表的预计月度仓储费 | 按 ASIN 找到对应 MSKU，再按当月发货销售额占比分摊；ASIN 匹配不到则进空 MSKU |
| 与店铺总额的差额 | 见下 | 进空 MSKU，保证 SKU 合计与店铺一致 |

**店铺侧总额（用于卡总额、算差额）**：

- 交易类型 = 服务费，且描述属于仓储费 / 仓储处理费 / 仓储运输费，取合计金额；
- 交易类型 = FBA 库存仓储费，取合计金额。

**差额**：店铺侧仓储总额取反后，减去 SKU 已分摊合计，差额写入 SKU 结果。SKU 页仓储费 = SKU 分摊额 + 该差额。月度 / 全渠道再对合计取绝对值，展示为费用。

产品方案里还有「移仓费、其他仓储费按移除订单 / 发货报告分摊到 SKU」以及 UK 站点部分 FBA 库存费改记仓储费。**现网利润主计算仍按上表（仓储报表 + 交易明细店铺总额差额）**；管报初始化不要按尚未并入主链路的方案去套现网数。

### 5.4 服务费

服务费不是「交易类型 = 服务费」的简单合计，而是多来源归集后再做净额。

**可分到 SKU 的部分**：

- 优惠券：描述末 8 位当 SKU，按发货销售额占比分摊；服务费里描述含 Coupon 的也按优惠券处理。
- Deal / 闪电 Deal：描述前 8 位当 SKU，同样分摊。
- 订单、退款、清算、清算调整上的「其他交易费用」。
- 解析不到 SKU 的，先进入「待匹配」；财务补全 MSKU 对应关系后再分摊。未分摊前，金额暂挂在待分摊合计里，避免店铺总额丢失。

**店铺固定服务费**：交易类型 = 服务费，但要挖掉已归到别的科目的描述：

- 广告费、广告退款 → 广告；
- 仓储相关描述 → 仓储；
- FBA 国际运费及税费 → 不进服务费。

剩下的合计进服务费（常落在空 MSKU / 店铺层）。无订单号的店铺固定费（如部分站点 Premium services fee）本来就不分到 SKU。

**SKU 页「服务费」** = 已分摊服务费 + 待分摊服务费。

**月度 / 全渠道「服务费」** = 站外服务费 −（平台服务费 + 待分摊服务费）。这是净额，不能只用交易明细「服务费」类型去复算。

### 5.5 调整费用 / 平台赔偿

- **来源**：交易类型 = 调整，取合计金额。
- **SKU 页**：调整费用（+）。
- **月度 / 全渠道「平台赔偿」**：同一笔调整金额。匹配不到 MSKU 的进空 MSKU 行。

## 6. 广告与推广

### 6.1 广告费

由三块合成：

1. **广告花费报表**按 SKU 汇总；
2. **交易明细服务费**中描述为广告费、广告退款的店铺总额；
3. SKU 合计与店铺广告总额的差额（保证不断层）；
4. 另加线下导入的 **销售广告费**、品牌广告（SB）。

- **SKU 页**：其他费用里的「广告费」= 报表广告 + 差额 + SB；线下「销售广告费」单列。
- **月度 / 全渠道「广告费」** = |广告费 + 广告差额 + SB| + 销售广告费。

### 6.2 推广费

- **来源**：线下 / 站外费用导入，类型为销售推广。
- **归属**：指定了 MSKU 则直接记；只给了 SKU/ASIN 则按发货销售额分摊；只给了品线或店铺则挂在对应维度；换汇到站点币种。
- **SKU 页**：线下/站外费用 → 销售推广费。
- **月度 / 全渠道「推广费」**：同一金额，不与广告费合并（广告宣传小计才合并）。

## 7. 货值与物流成本

### 7.1 发货成本（采购成本）

1. 取当月采购单价：优先 Listing 采购快照，没有则用 MSKU、再没有则用 SKU（含截前 8 位、按「-」前缀兜底）。
2. **发货成本** = 发货数量 × 采购单价。
3. 采购币种默认人民币，再换到展示币种。
4. 德国站以 X00 开头的 MSKU 不算采购/头程/关税单价。
5. 特殊结构商品（如找回货）会先还原到真实商品再取价。

### 7.2 退货成本

对同一 MSKU：**发货采购成本 − 进销存采购成本**。进销存采购成本 = 进销存数量 × 采购单价。

SKU 页同时展示「当月销售成本」（参与 SKU 利润）和「当月进销存成本」（对照，不直接当 SKU 利润扣项）。

### 7.3 头程运费、关税

1. 物流侧取该月该商品的 **单件头程**、**单件关税**。
2. SKU 页「销售成本」：发货数量 × 单件。
3. 月度 / 全渠道「头程运费」「关税」：用 **进销存数量 × 单件**（进销存口径）。
4. 进销存合计与销售口径合计的差额会单独记下，便于对账。

### 7.4 货值净额、物流成本小计（仅汇总页）

- **货值净额** = 发货成本 − 退货成本 − 平台赔偿。
- **物流成本小计** = 头程 + 关税 + FBA 配送费 + 仓储费。  
  全渠道经营报表同口径，只是 FBA 列名叫「尾程运费 / FBA 物流」。

## 8. SKU 页怎么展示、利润怎么算

SKU 页分组如下（自定义列可隐藏子列）：

| 分组 | 子项 |
|------|------|
| 固定列 | 期间月、国家、品线、小品线、team、sales、SKU、MSKU、币种、营收、利润、利润率 |
| 当月发货 | 销售额、数量、税费、运费收入、包装收入、平台代扣税费、折扣、平台佣金、FBA 配送费 |
| 当月退货 | 同上结构 |
| 其他费用 | 广告费、仓储费、服务费、调整费用 |
| 线下 / 站外 | 销售推广费、销售广告费、站外服务费 |
| 销售成本（参与利润） | 数量、采购成本、头程、关税 |
| 进销存成本（对照） | 数量、采购成本、头程、关税 |
| 占比 | 退货占比、折扣占比、广告费占比 |

**SKU 利润**（参与项用销售口径成本，不用进销存口径）：

营收相关（发货销售额、运费、包装、折扣 + 退货对应项）  
+ 发货/退货佣金  
+ 发货/退货 FBA  
− 广告费  
− 仓储费  
+ 服务费  
+ 调整费用  
− 站外服务费 − 销售广告费 − 销售推广费  
− 发货采购成本 − 销售头程 − 销售关税

利润率 = 利润 ÷ 营收（或发货销售额，取决于占比类型），符号与利润一致。

国家页利润扣的是 **进销存采购 / 头程 / 关税**，与 SKU 页不完全相同。对利润不要跨页签直接加总。

## 9. 月度科目与全渠道 / 管报列对照

同一套底层子项，汇总页合并如下。管报初始化建议按下表取亚马逊渠道。

| 管报 / 月度科目 | 亚马逊取值（产品口径） | 符号处理 |
|-----------------|------------------------|----------|
| 销售额 | 发货销售额 + 发货运费收入 + 发货包装收入 | 收入为正 |
| 折扣 | −发货折扣 − 退货折扣 | 冲减/费用口径 |
| 优惠合计 | 等于折扣 | — |
| 销售收款 | 销售额 − 优惠合计 | — |
| 销售退款 | −（退货销售额 + 退货运费 + 退货包装） | 退款为正 |
| 销售净额 | 销售收款 − 销售退款 | — |
| 税金 | 发货税金 + 退货税金 | 月度单列 |
| 平台代扣税 | 发货代扣 + 退货代扣 | 月度单列 |
| 销售税 / VAT（全渠道） | 税金 + 平台代扣税 四项合计 | 全渠道合并为一列 |
| 收入净额 | 等于销售净额 | 亚马逊不从净额再扣税 |
| 发货成本 | 发货数量 × 采购单价 | — |
| 退货成本 | 发货采购 − 进销存采购 | — |
| 平台赔偿 | 调整类合计 | — |
| 货值净额 | 发货成本 − 退货成本 − 平台赔偿 | — |
| 广告费 | \|SKU 广告 + 差额 + SB\| + 线下销售广告 | 费用为正 |
| 推广费 | 线下销售推广 | 费用为正 |
| 广告宣传小计 | 广告费 + 推广费 | 全渠道还加样品费，亚马逊样品费为 0 |
| 头程运费 | 进销存数量 × 单件头程 | — |
| 关税 | 进销存数量 × 单件关税 | — |
| FBA 配送费 / 尾程 | −（发货 FBA + 退货 FBA） | 费用为正 |
| 仓储费 | \|SKU 仓储 + 与店铺差额\| | 含长期 + 月度，不拆列 |
| 物流成本小计 | 头程 + 关税 + FBA + 仓储 | — |
| 平台佣金 | −（发货佣金 + 退货佣金） | 费用为正 |
| 服务费 | 站外服务费 − 平台服务费（含待分摊） | 净额 |
| 平台费用小计 | 佣金 + 服务费 | — |
| 边际贡献 / 销售毛利 | 销售净额 − 货值净额 − 广告宣传 − 物流 − 平台费用 | 全渠道毛利公式与此对齐 |

亚马逊渠道在全渠道表上的「样品费、退货运费、收单费用、店铺费用、Commission Fee」一般为 0；佣金走「FBA 佣金」，FBA 物流走「尾程运费 / FBA 物流」，服务费走「平台服务费」。

## 10. 必须记住的特殊规则

1. **运费与折扣成对抵消**：全额运费优惠从运费收入和折扣里同时剔除。
2. **FBA 调整费按正负分流**：负的进发货 FBA，正的进退货 FBA；「FBA 客户退货费用」固定进发货。
3. **月度仓储错月**：算本月仓储费时，月度仓储报表取 **上月**。
4. **长期仓储在仓储费内**：6 个月 + 12 个月库龄费，页面不单列。
5. **广告、仓储都有「店铺总额 − SKU 已分摊」差额行**，只对店铺合计、不对单 SKU 业务含义。
6. **服务费月度是净额**：站外服务费减平台服务费，不能按交易类型「服务费」单表加总。
7. **日本折扣含积分**；**土耳其税金不含合计差额**。
8. **德国 X00 开头 MSKU** 不算采购/头程/关税。
9. **Govee / GoveeLife** 是否过滤「亚马逊订单归类」不同，FBA 等费用会受影响。
10. **SKU 利润用销售口径成本，国家页利润用进销存口径成本**。
11. **空 MSKU 行是故意设计**，用来承接分摊剩余，删掉会对不上店铺合计。

## 11. 给管报初始化的用法

1. 亚马逊渠道初始化，优先对 **月度科目 / 全渠道经营报表** 的合并结果，不要直接拷贝 SKU 页「当月发货 / 当月退货」原值（正负号和合并方式不同）。
2. 仓储费按 **一列合并值** 接入；若管报产品上要单列长期仓储，现网利润报表没有现成列，只能回到仓储报表的 6 个月 / 12 个月库龄费，且与利润报表「仓储费」不会自动相等（后者还含月度仓储和差额）。
3. 推广费只来自 **线下导入**，不是交易明细里的促销折扣。促销折扣在「折扣」。
4. 广告费同时含广告报表、交易明细广告描述、差额和线下销售广告。
5. 对账时允许 SKU 明细与交易明细有小差额：特殊 SKU 映射、四舍五入、清算过滤、空 MSKU 承接都会造成尾差。
6. 刷新顺序：交易明细进系统并完成当月费用拆分后，报表才是准的；只导交易明细文件、不跑拆分，页面不会变。

## 12. 费用项速查

| 页面名称 | 一句话取值 |
|----------|------------|
| 销售额（汇总） | 发货商品额 + 发货运费 + 发货包装 |
| 发货销售额（SKU） | 订单（+清算）商品销售额 |
| 折扣 | 促销折扣，剔除与运费完全抵消的行；日本加积分 |
| 销售收款 | 销售额 − 折扣 |
| 销售退款 | 退货商品额 + 退货运费 + 退货包装（汇总时取反） |
| 税金 / 代扣税 | 多税列合计 + 补税类型；土耳其税金不含合计差额 |
| 平台佣金 | 订单 / 退款 / 拒付退款的销售费用列 |
| FBA 配送费 | 订单 FBA+其他交易费 + 代发尾程 + 调整费按正负分流 |
| 仓储费 | 长期仓储（当月）+ 月度仓储（上月分摊）+ 与交易明细店铺仓储总额的差额，汇总取绝对值 |
| 广告费 | 广告报表 + 服务费中的广告描述 + 差额 + SB；汇总再加线下销售广告并取绝对值 |
| 推广费 | 线下导入的销售推广，按 MSKU/SKU/ASIN/品线/店铺归属 |
| 服务费 | 优惠券/Deal/其他交易费 + 剔除广告仓储后的剩余服务费；汇总再与站外服务费轧差 |
| 调整 / 平台赔偿 | 交易类型 = 调整的合计 |
| 发货成本 | 发货数量 × 采购单价 |
| 退货成本 | 发货采购 − 进销存采购 |
| 头程 / 关税（SKU 利润） | 发货数量 × 单件 |
| 头程 / 关税（月度管报） | 进销存数量 × 单件 |
| 利润 / 边际贡献 | 收入轧差后退货与费用、按上文章节公式扣成本 |
