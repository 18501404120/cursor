# Shopify（独立站）费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 自营利润报表（筛选平台 = 独立站）
- **页签**：年度 / 月度 / 店铺 / SKU；底层是同一套费用子项
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（金蝶销售/退货、收单账单、海外仓、站外导入、自营利润报表查询与展示）

---

## 1. 先看结论

Shopify 各费用项**不是页面即时现算**，而是：

1. 先把 **金蝶销售订单**（独立站店铺）拆成销售额、税费、数量、采购、头程、关税；
2. 再叠加 **自营退货账单、线下退款导入、收单账单、风控账单、海外仓账单、站外导入**；
3. 按 **店铺 + MSKU + 月份 + 币种** 汇总；
4. 页面查询时按筛选条件聚合，换汇后展示。

独立站与 App 商城共用「自营利润报表」和同一套自营费用结构，**靠店铺所属平台区分**。管报初始化时，Shopify 渠道只取独立站店铺。

SKU 页适合追查到商品；月度页、全渠道经营报表是同一套子项按管报科目合并后的结果。管报初始化**以月度 / 全渠道那一套为准**更稳。

## 2. 数据从哪来

| 来源 | 用在哪些费用 | 说明 |
|------|----------------|------|
| 金蝶销售订单（独立站店铺） | 销售额、税费、销售数量、收入 | 本位币含税销售额扣运费补贴；收入 = 销售额 − 税费 |
| 自营退货账单（对齐金蝶退货） | 退款金额、退款税额、退款收入、退货数量 | 退款收入 = 退款金额 − 退款税额 |
| 线下退款导入 | 退款金额 / 税额 / 收入 的线下部分 | 页面上并进退款三列，不单列 |
| 采购价快照 | 采购成本、退货采购成本 | 数量 × 采购单价；采购币种默认人民币再换汇 |
| 头程物流单价 | 头程运费、关税、退货头程、退货关税 | 单件 × 对应数量 |
| 海外仓账单 | 尾程运费、仓储费、海外仓费用 | 按店铺 / MSKU 归属；MSKU 含独立站标识时落到独立站 |
| 收单账单 | 收单成本 | Shopify Payment、PayPal、Adyen、Seel 等，按订单落到 MSKU |
| 风控账单 | 风控费 | 风控明细按订单商品分摊 |
| 站外费用导入 | 平台服务费、推广费、额外风控费 | 指定 MSKU 直接记；否则按当月 **净额占比** 分摊 |
| MSKU 关系快照 | 所有 SKU 归属 | team、sales、品线；匹配不到进空 MSKU 行 |

**主链路**：金蝶销售/退货入账 → 拆费用子项 → 叠加收单/仓/导入 → 写入 SKU 结果表 → 页面换汇展示。

## 3. 通用口径

### 3.1 统计粒度

- 明细落库：**店铺 + MSKU + 月份**。
- 页面 SKU 行再带出品线、team、sales、SKU、币种。
- 匹配不到商品时，金额进 **MSKU 为空的承接行**，保证店铺合计不断层。

### 3.2 店铺怎么划到 Shopify

- 店铺所属平台 = 独立站。
- 店铺名含「独立站」会归到独立站；海外仓历史分摊里，MSKU 含独立站标识也会落到独立站店铺。
- 自营利润报表店铺下拉同时含独立站和 App 商城；**取 Shopify 渠道时必须过滤独立站店铺**。

### 3.3 币种、精度、展示

- 内部按 **4 位小数** 计算。
- 页面默认四舍五入取整；可按选定币种，或勾选「显示原币种」。
- 数量类不换汇。
- 月度费用行带「净额占比」：费用 ÷ 净额。

### 3.4 正负号

自营报表习惯是：**收入类为正、费用类为正、退款列展示退款金额**。毛利公式里对费用取反、对退货采购/退货头程/退货关税加回。

SKU 页与月度页公式一致，不像亚马逊那样「SKU 保留交易原方向、月度再翻符号」。

### 3.5 分摊规则（站外费用落到 SKU）

1. 导入时指定了 MSKU：直接记到该商品；
2. 未指定：按该店铺当月各 MSKU 的 **净额占比** 分摊；
3. 仍匹配不到：进空 MSKU 行。

## 4. 收入与退款

### 4.1 销售额

- **来源**：金蝶销售订单，独立站店铺。
- **取值**：本位币含税销售额 − **运费补贴**。
- 原币销售额单独保留，勾选「显示原币种」时用原币。
- **全渠道「销售额 / 销售收款」**：等于本列（独立站没有运费收入、包装收入、折扣列）。

### 4.2 税费、收入

- **税费**：金蝶销售订单税额（本位币）。
- **收入** = 销售额 − 税费。
- 页面提示：收入 = 销售额 − 税费。

### 4.3 销售数量

- 金蝶销售订单数量合计。

### 4.4 退款金额、退款税额、退款收入、退货数量

退款由两块相加，页面**合并成一列**，不拆「线上 / 线下」：

| 构成 | 取值 |
|------|------|
| 自营退货账单 | 金蝶退货含税合计、税额；退款收入 = 含税合计 − 税额 |
| 线下退款导入 | 导入的退款金额、税额、收入 |

- 页面提示：**退款收入 = 退款金额 − 退款税费**。
- **全渠道「销售退款」**：退款金额（含线下）。
- **全渠道「销售税 / VAT」**：发货税费 − 退款税额 − 线下退款税额。

### 4.5 净额

- **净额** = 收入 − 退款收入。
- 页面提示与现网计算一致。
- **全渠道「收入净额」**：直接取本列净额（不是「销售净额再减税」；税已在收入/退款收入里处理过）。

独立站没有「折扣 / 优惠合计」列；促销已含在金蝶销售额里，不再单拆。

## 5. 货值与物流

### 5.1 采购成本、退货采购成本

- **采购成本** = 销售数量 × 采购单价（优先当月采购快照，没有则兜底价；人民币再换到展示币种）。
- **退货采购成本** = 退货数量 × 采购单价，毛利公式里**加回**（冲减货值）。
- **全渠道**：发货成本 = 采购成本；退货成本 = 退货采购成本。

### 5.2 头程运费、关税、退货头程、退货关税

- 物流侧单件头程、单件关税 × 对应数量。
- 退货方向在毛利里加回。
- **全渠道「关税」**：发货关税 − 退货关税。
- **全渠道「退货运费」**：退货头程运费。

### 5.3 尾程运费

- **来源**：海外仓出库 / 尾程账单，按店铺、MSKU 归属到独立站。
- **全渠道「尾程运费 / FBA 物流」**：本列。独立站没有 FBA 配送费。

### 5.4 仓储费、海外仓费用

自营利润报表 **分两列**：

| 列 | 含义 |
|----|------|
| 仓储费 | 仓储类账单合计 |
| 海外仓费用 | 海外仓操作等费用 |

**全渠道「仓储费」** = 仓储费 + 海外仓费用，不再分列。

---

## 6. 平台、收单、推广、风控

### 6.1 平台服务费

- **来源**：站外费用导入，类型为平台服务费。
- **归属**：指定 MSKU 或按净额分摊。
- **全渠道「平台服务费」**：本列。独立站没有佣金列。

### 6.2 推广费

- **来源**：站外费用导入，类型为推广费。
- 按净额分摊规则同上。
- **全渠道「推广费」**：本列。独立站样品费为 0；广告费列也为 0（推广不并进广告费）。

### 6.3 收单成本

由多路收单账单归集到同一列「收单成本」：

| 账单 | 典型场景 |
|------|----------|
| Shopify Payment | 独立站主收单；含手续费、汇率损失 |
| PayPal | 收单及提现相关费用 |
| Adyen | 收单、已结算、提现 |
| Seel | 延保 / 收单类账单 |
| 退款侧收单 | 退款冲回的收单费用 |

按订单落到 MSKU；落到独立站店铺的计入 Shopify。

**全渠道「收单费用 / Payment Discount」**：本列。

### 6.4 风控费

由两块相加，页面合并为一列：

1. **风控账单**：按独立站 / Shopify 订单商品分摊；
2. **站外额外风控费**：导入后按净额分摊。

**全渠道「店铺费用」**：风控费 + 额外风控费。

---

## 7. SKU / 店铺页怎么展示、毛利怎么算

SKU 列（店铺页少品线 / SKU / 数量）：

| 分组 | 子项 |
|------|------|
| 固定列 | 期间月、店铺、品线、team、sales、SKU、MSKU、币种、销售毛利、毛利率 |
| 收入 | 销售额、销售数量、税费、收入 |
| 退款 | 退款金额、退款税费、退款收入、退货数量 |
| 净额 | 净额 |
| 货值物流 | 采购成本、退货采购成本、头程、退货头程、关税、退货关税、尾程 |
| 仓与费用 | 仓储费、海外仓费用、平台服务费、推广费、收单成本、风控费 |

**销售毛利**：

净额  
− 采购成本 + 退货采购成本  
− 头程 + 退货头程  
− 关税 + 退货关税  
− 尾程 − 仓储费 − 海外仓费用  
− 平台服务费 − 推广费 − 收单成本 − 风控费（含额外风控）

毛利率 = 销售毛利 ÷ 净额。

月度 / 年度科目名称与上表一致，只是把店铺/SKU 压成期间列。

## 9. 必须记住的特殊规则

1. **销售额已扣运费补贴**，不要再用金蝶含税原值去对。
2. **收入已经扣税**，净额 = 收入 − 退款收入；全渠道收入净额直接用净额。
3. **线下退款并进退款三列**，对账时不要漏导入表。
4. **毛利加回退货采购 / 退货头程 / 退货关税**，不要把退货成本当成再扣一次。
5. **仓储费与海外仓费用在利润报表分列，全渠道合并**。
6. **空 MSKU 行承接分摊剩余**，删掉会对不上店铺合计。
7. 独立站与 App 商城同页，初始化必须按店铺平台切开。

---

## 10. 给管报初始化的用法

1. 优先对 **月度科目 / 全渠道经营报表**，不要把 SKU 明细当管报入账原值去拆正负号（本渠道 SKU 与月度符号已对齐，但仍有空 MSKU、四舍五入尾差）。
2. 仓储按全渠道合并值接入；若产品要分列仓储 / 海外仓，回到自营利润报表两列。
3. 推广费、平台服务费只来自 **站外导入**，不是金蝶折扣。
4. 收单必须等各收单账单跑完分摊，页面才会变。
5. 刷新顺序：金蝶销售/退货进系统并完成当月费用拆分、收单与仓账单入账后，报表才准。

## 11. 费用项速查

| 页面名称 | 一句话取值 |
|----------|------------|
| 销售额 | 金蝶本位币含税销售 − 运费补贴 |
| 税费 | 金蝶销售税额 |
| 收入 | 销售额 − 税费 |
| 退款金额 | 自营退货含税合计 + 线下退款 |
| 退款收入 | 退款金额 − 退款税额 |
| 净额 | 收入 − 退款收入 |
| 采购成本 | 销售数量 × 采购单价 |
| 退货采购成本 | 退货数量 × 采购单价（毛利加回） |
| 头程 / 关税 | 单件 × 数量；退货方向毛利加回 |
| 尾程运费 | 海外仓尾程账单 |

| 平台服务费 / 推广费 | 站外导入，按净额分摊 |
| 收单成本 | Shopify Payment / PayPal / Adyen / Seel 等合计 |
| 风控费 | 风控账单 + 站外额外风控 |
| 销售毛利 | 净额扣货值物流仓费用后加回退货成本项 |
