# App 商城费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 自营利润报表（筛选平台 = App 商城）
- **页签**：年度 / 月度 / 店铺 / SKU；与独立站同一张表、同一套自营费用结构
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（金蝶销售/退货、收单账单、海外仓、站外导入、自营利润报表）

---

## 1. 先看结论

App 商城**不是另一套利润引擎**。它和 Shopify 共用：

- 同一张「自营利润报表」；
- 同一套费用子项（销售额、税费、收入、退款、净额、采购/头程/关税、尾程、仓储、海外仓、平台服务费、推广费、收单、风控）；
- 同一套毛利公式。

差别只在 **店铺所属平台 = App 商城**，以及收单账单、尾程归属、风控会多几路 App 专用来源。

管报初始化时，App 商城渠道只取 App 商城店铺，不要和独立站加总后再拆。

**不要把「App 走 FBA 发货」的费用当成 App 商城利润报表的一列。** App 订单走亚马逊 FBA 的履约费在亚马逊交易里核算，进销存会剔除这部分数量；App 商城损益本身仍按金蝶销售订单 + 自营费用项。

---

## 2. 和 Shopify 完全相同的部分

下列口径与《Shopify费用项取值逻辑》一致，本文不重复展开计算细节：

| 科目 | 口径摘要 |
|------|----------|
| 销售额 | 金蝶本位币含税销售 − 运费补贴 |
| 税费 / 收入 | 收入 = 销售额 − 税费 |
| 退款三列 | 自营退货账单 + 线下退款导入；退款收入 = 退款金额 − 退款税额 |
| 净额 | 收入 − 退款收入 |
| 采购 / 退货采购 | 数量 × 采购单价；毛利加回退货采购 |
| 头程 / 关税及退货方向 | 单件 × 数量；毛利加回退货头程、退货关税 |
| 仓储费、海外仓费用 | 利润报表分列；全渠道合并 |
| 平台服务费、推广费 | 站外导入，按净额分摊 |
| 销售毛利 | 净额 − 采购 + 退货采购 − 头程 + 退货头程 − 关税 + 退货关税 − 尾程 − 仓储 − 海外仓 − 平台服务费 − 推广 − 收单 − 风控 |

币种精度、空 MSKU 承接、4 位小数内部计算、页面取整，也与独立站相同。

---

## 3. App 商城特有：店铺怎么划

- 店铺所属平台 = App 商城。
- 店铺名含「app商城」会归到 App 商城。
- 海外仓历史尾程分摊里，MSKU 含 App 标识会落到 App 商城店铺（独立站标识落到 Shopify）。
- 自营利润报表店铺下拉同时含独立站和 App；**取 App 渠道必须过滤 App 商城店铺**。

---

## 4. App 商城特有：收单成本构成更多

页面仍只有一列 **收单成本**，但底层账单比独立站多。落到 App 店铺的全部计入本渠道。

| 账单 | 说明 |
|------|------|
| Shopify Payment | 部分 App 店铺仍可能走该通道 |
| PayPal（含提现） | 收单及提现 |
| Adyen（收单 / 已结算 / 提现） | 与独立站同类 |
| Seel | 延保 / 收单类 |
| **Pingpong** | 采购、退款、拒付、其他费、提现；App 更常见 |
| **Klarna** | 分期收单 |
| **Afterpay** | 分期收单 |
| 退款侧收单 | 退款冲回收单费 |

**全渠道「收单费用 / Payment Discount」**：上述合计。对账时不能只用 Shopify Payment 一张账单去复算 App 收单。

---

## 5. App 商城特有：风控与尾程

### 5.1 风控费

同样由「风控账单 + 站外额外风控」合并。风控账单会按 **App 商城订单** 的商品行分摊，与 Shopify 订单分摊相互独立。

额外风控费走站外导入、按净额分摊，独立站和 App 按店铺平台分开。

### 5.2 尾程运费

海外仓出库 / 尾程挂到 App 商城店铺。历史规则还会看 MSKU 是否带 App 标识。不要把亚马逊 FBA 配送费并进本列。

### 5.3 App FBA（不进本报表）

亚马逊侧会单独算「App FBA 费用」，用于进销存数量剔除（App / App 商城 FBA 发货不进亚马逊销售口径成本）。**App 商城利润报表没有「App FBA」列**，管报 App 渠道也不要从亚马逊 FBA 再抄一笔。

---

## 6. SKU 页与毛利

列结构与独立站相同（销售毛利、毛利率、销售额、数量、税费、收入、退款三列、净额、采购及退货采购、头程/关税及退货方向、尾程、仓储、海外仓、平台服务费、推广费、收单成本、风控费）。

毛利率提示：**销售毛利 / 净额**。

公式见第 2 节，与独立站、全渠道自营毛利一致。

---

## 7. 月度科目与全渠道 / 管报列对照

全渠道把独立站和 App 商城标成同一套「自营」映射，科目对照与 Shopify 文档第 8 节相同。差别只是**店铺范围**：

| 管报 / 全渠道科目 | App 商城取值 |
|-------------------|--------------|
| 销售额 / 销售收款 | App 店铺销售额 |
| 折扣 / 优惠合计 | 0 |
| 销售退款 | 退款金额（含线下） |
| 销售税 / VAT | 发货税费 − 退款税额 − 线下退款税额 |
| 收入净额 | 净额 |
| 发货成本 / 退货成本 | 采购成本 / 退货采购成本 |
| 推广费 | 站外推广 |
| 样品费 / 广告费 | 0 |
| 头程 / 尾程 / 退货运费 | 头程、尾程、退货头程 |
| 仓储费 | 仓储费 + 海外仓费用 |
| 关税 | 发货关税 − 退货关税 |
| 平台服务费 | 站外平台服务费 |
| 收单费用 | 多通道收单合计（含 Pingpong / Klarna / Afterpay） |
| 店铺费用 | 风控 + 额外风控 |
| FBA 佣金 / Commission Fee | 0 |
| 边际贡献 | 与自营毛利公式一致 |

---

## 8. 必须记住的特殊规则

1. **与 Shopify 同页同公式**，渠道切分只看店铺平台。
2. **收单通道比独立站多**，Pingpong / Klarna / Afterpay 漏计会少收单成本、虚高毛利。
3. **App FBA 不属于本渠道损益列**。
4. 销售额同样要扣 **运费补贴**；收入已扣税。
5. 毛利加回退货采购 / 退货头程 / 退货关税。
6. 空 MSKU 行承接分摊剩余。

---

## 9. 给管报初始化的用法

1. 从自营利润报表或全渠道表取 **平台 = App 商城** 的结果，不要用「自营合计 − 独立站」的差当作定义（可以拿来核对，但不能当唯一算法）。
2. 仓储按全渠道合并值接入。
3. 收单、风控、尾程必须等 App 店铺对应账单跑完。
4. 与独立站对账时，先确认店铺有没有被两边各记一次（店铺名、MSKU 标识、平台字段不一致时会发生）。

## 10. 费用项速查

| 页面名称 | 一句话取值 |
|----------|------------|
| 销售额 | 金蝶本位币含税销售 − 运费补贴（App 店铺） |
| 收入 | 销售额 − 税费 |
| 退款收入 | 退款金额 − 退款税额（含线下导入） |
| 净额 | 收入 − 退款收入 |
| 采购 / 头程 / 关税 | 与独立站相同算法，限 App 店铺 |
| 尾程 | 海外仓尾程，归属 App 店铺；不含亚马逊 FBA |
| 仓储 / 海外仓 | 分列；全渠道合并 |
| 平台服务费 / 推广费 | 站外导入，按净额分摊 |
| 收单成本 | Shopify Payment / PayPal / Adyen / Seel / Pingpong / Klarna / Afterpay 等 |
| 风控费 | App 订单风控账单 + 站外额外风控 |
| 销售毛利 | 与独立站同一公式 |
