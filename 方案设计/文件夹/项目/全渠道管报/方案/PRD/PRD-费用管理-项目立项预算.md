## 1. 需求背景与目标

### 1.1 背景

营销类项目在 PMP 立项时，需要提前规划各收益周期内的营销费用预算，明确：

1. 费用覆盖的收益日期范围；
2. 营销类型与活动类型；
3. 商品范围（场景品类 / model / SKU / 新品标签）；
4. 地理与渠道范围（区域 / 国家 / 渠道 / 店铺）；
5. 费用承担部门；
6. 后续实际费用导入时的**分摊处理方式**（分摊 / 不分摊）。

当前原型阶段，预算页用于在立项流程中录入、校验、汇总营销费用规划行，并为后续费用导入提供**规划口径**参考。

### 1.2 建设目标

1. 在项目「预算」页签提供**行级预算维护**能力：新增、编辑、复制、删除、批量删除、保存。
2. 支持**行级分摊模式**选择（下拉单选、必填、无默认值），记录该笔预算后续费用的处理方式（仅规划，不生成 MSKU 分摊结果）。
3. 建立与费用导入页**口径一致**的范围填写规则（分摊 / 不分摊两套校验）。
4. 与费用部门主数据、销售主数据、区域国家渠道店铺主数据联动。
5. 实时汇总预算合计，支撑立项评审与后续预算使用对比。

### 1.3 目标用户

| 角色 | 主要场景 |
|------|----------|
| 项目经理 / 立项发起人 | 录入项目营销预算、选择分摊模式、提交立项 |
| 营销负责人 | 审核预算范围与金额合理性 |
| 财务 BP | 核对费用部门、币种与规划口径 |
| 管报运营 | 了解项目预算规划，为后续费用导入对账提供基准 |

### 1.4 上下游

| 方向 | 说明 |
|------|------|
| 上游 | PMP 项目主数据、费用部门主数据、销售主数据（model/SKU）、区域国家渠道店铺主数据、场景品类主数据 |
| 下游 | 项目立项评审、营销费用规划/使用看板、费用填报管理（实际导入时参考预算行分摊模式与范围规划） |

### 1.5 与费用导入的关系（重要）

| 环节 | 项目预算页 | 费用填报管理（导入） |
|------|------------|----------------------|
| 业务阶段 | 立项规划 | 实际费用发生与入账 |
| 分摊模式 | **行级**，仅记录规划口径 | **批次级**，决定实际分摊/归属 |
| MSKU 分摊 | **不生成** | 分摊模式下生成并落库 |
| 部门 | 规划参考；不分摊时必填 | 不分摊时必填；分摊时可空按店铺映射 |
| 状态 | 编辑中 / 已保存（原型本地） | 待生效 / 已生效 / 失效 |

**核心原则：预算页只做规划记录，实际 MSKU 分摊在费用导入生效后执行。**

### 2.1 本 PRD 覆盖

## 4. 全局业务规则

### 4.1 立项约束

1. **立项提交前至少须有一行校验通过的预算。**
2. 空表点击「保存预算」须拦截，提示：`预算为必填：请至少新增一行并填写营销费用规划`。
3. 每行「营销费用规划」须 **> 0**。

### 4.2 分摊模式（行级 · 仅记录规划）

| 属性 | 规则 |
|------|------|
| 粒度 | **行级**，每行独立选择分摊模式 |
| 位置 | 表格列，位于「类型」之后、「费用部门」之前 |
| 组件 | 下拉单选框 |
| 可选值 | `分摊` / `不分摊` |
| 必填 | **是** |
| 默认值 | **无**（须用户手工选择，首项为「请选择」） |
| 存储 | 作为预算行字段 `allocMode` 落库 |
| 业务含义 | **仅记录规划口径**，说明该笔预算后续实际费用导入时的处理方式 |
| 是否生成 MSKU 分摊 | **否**，本页不预览、不保存 MSKU 分摊明细 |

**字段注释（问号说明）：**

> 行级规划口径，记录该笔预算后续费用的处理方式，不在预算页生成实际分摊结果。必填，无默认值。
>
> - **分摊**：记录后续将按渠道/产品范围拆分至各商品；范围可全空（=全产品分摊）；费用部门可不填。
> - **不分摊**：记录后续将整笔挂到指定维度；范围可全空（全公司通用预算），费用部门必填；渠道/产品范围每列仅可单选或不填。

**切换该行分摊模式时：**
1. 立即按该行新模式执行范围填写约束（不分摊时多选裁减为每列最多 1 项）；
2. 不影响其他行；
3. 不影响本行已填金额与日期等基础字段；
4. 正式环境建议：若裁减会导致数据丢失，可增加二次确认（原型未实现）。

### 4.3 预算行状态（原型）

| 状态 | 含义 |
|------|------|
| 编辑中 | 可新增、修改、复制、删除；尚未通过保存校验或尚未点击保存 |
| 已保存 | 校验通过并持久化；可继续编辑后再次保存 |

```
编辑中 ──保存预算/行内保存且校验通过──→ 已保存
已保存 ──修改任意字段或增删行──→ 编辑中
```

正式环境须与项目状态（草稿 / 审批中 / 已立项）联动，立项通过后是否允许修改预算另行定义。

### 4.4 预算合计

1. 实时汇总当前表格各行「营销费用规划」数值；
2. **不按币种折算**，各币种金额直接相加（展示层约定，正式环境可改为分币种展示）；
3. 新增、修改金额、删除行后自动刷新；
4. 保存成功 Toast 中的合计与标题区合计一致。

## 5. 分摊模式规则（完整对照）

### 5.1 总览

| 维度 | 分摊模式 | 不分摊模式 |
|------|----------|------------|
| 规划对象（场景品类 / SKU / 新品标签） | **可全空**（=全产品分摊） | **可全空**（全公司通用预算） |
| 费用部门 | 可不填 | **必填** |
| 范围多选 | 各列可多选 | 每列**仅可单选或不填** |
| 列间关系 | AND 交集 | AND 条件 |
| 区域/国家/渠道/店铺/model 全空 | 表示该维度不限 | 表示通配 |
| 产品范围全空含义 | 全产品参与分摊 | 全公司通用（不限产品） |
| MSKU 分摊预览 | 无（仅规划） | 无（仅规划） |

### 5.2 范围全空含义

| 模式 | 渠道/产品范围全空时的业务含义 |
|------|-------------------------------|
| 分摊 | 不限定商品范围，后续按命中范围内的**全部产品（MSKU）**做营收权重分摊 |
| 不分摊 | **全公司通用预算**，整笔按指定部门归属，不拆到 MSKU |

### 5.3 不分摊模式特殊规则

1. **范围可全空**：场景品类、model、SKU、新品标签、区域、国家、渠道、店铺均可不填，表示全公司通用预算。
2. **费用部门必填**：每行须选择费用部门，否则保存拦截。
3. **单选限制**：场景品类、model、SKU、区域、国家、渠道、店铺在不分摊模式下，每列最多保留 1 个值；用户多选时自动保留最后选择的值。

**拦截提示（部门为空）：** `第 N 行：不分摊模式下费用部门为必填项`

### 5.4 与费用导入规则的对齐说明

预算页规则与 `PRD-费用管理-费用填报管理.md` 中分摊/不分摊的范围口径**保持一致**，差异仅在于：

| 差异点 | 预算页 | 费用导入页 |
|--------|--------|------------|
| 分摊模式粒度 | 行级 | 批次级 |
| 是否执行分摊 | 否 | 是（分摊模式预览并落库） |
| 费用项 / 归属月 | 无（用收益日期范围代替） | 有 |
| 批次状态机 | 无 | 待生效 / 已生效 / 失效 |

## 6. 字段详细规则

### 6.1 收益日期范围

| 属性 | 规则 |
|------|------|
| 必填 | 是 |
| 组件 | 日期范围选择器（开始日 + 结束日） |
| 含义 | 该笔预算对应的收益起止周期 |
| 校验 | 开始日与结束日均须填写 |
| 拦截提示 | `第 N 行：请完整选择收益日期范围` |
| 数据字段 | `revenueDateStart`、`revenueDateEnd`（YYYY-MM-DD） |
| 兼容 | 历史 `monthStart` / `monthEnd`（YYYY-MM）加载时自动转换为日期范围 |

### 6.2 营销类型

| 属性 | 规则 |
|------|------|
| 必填 | 是 |
| 组件 | 下拉单选 |
| 枚举值 | 自主营销-产品营销、自主营销-品牌营销、联合营销-产品营销、联合营销-品牌营销 |
| 含义 | 决定后续管报中的营销费用归类口径 |
| 拦截提示 | `第 N 行：请选择营销类型` |

### 6.3 类型（活动类型）

| 属性 | 规则 |
|------|------|
| 必填 | 是 |
| 组件 | 下拉单选 |
| 枚举值 | 海外社媒投放、红人营销（KOL）、媒体公关（PR）、视觉素材制作、地标广告、大型展会、代言与赞助、发布会 |
| 含义 | 与营销类型组合描述活动形态 |
| 拦截提示 | `第 N 行：请选择类型` |

### 6.4 分摊模式

| 属性 | 规则 |
|------|------|
| 必填 | **是** |
| 默认值 | **无**（下拉首项为「请选择」） |
| 组件 | 下拉单选 |
| 位置 | 类型列之后、费用部门列之前 |
| 枚举值 | 分摊、不分摊 |
| 含义 | 行级规划口径，记录该笔预算后续费用处理方式；本页不生成实际 MSKU 分摊结果 |
| 拦截提示 | `第 N 行：请选择分摊模式` |
| 数据字段 | `allocMode: "分摊" \| "不分摊" \| ""` |
| 联动 | 选「不分摊」时：该行范围多选裁减为每列最多 1 项；费用部门变为必填。分摊 / 不分摊时范围均可全空（分摊=全产品分摊） |

### 6.5 费用部门

| 属性 | 规则 |
|------|------|
| 必填 | 该行选「不分摊」时必填；选「分摊」时可不填 |
| 组件 | 树形下拉单选 + 清除按钮 |
| 数据来源 | 费用部门主数据（`FeeDeptMaster`） |
| 展示格式 | 选中后展示「组织·组织名 / 管报部门」（如 `102·Govee / APP商城`），与费用导入页一致；存储 `deptCode` + `dept`（完整展示名） |
| 搜索 | 支持按部门名称、财务部门简称（BM）、组织代码搜索 |
| 树形交互 | 支持展开/收拢；首次打开默认展开根节点；搜索时全展开 |
| 可选范围 | 仅 `selectable !== false` 的节点；禁选节点及其下级不展示 |
| 可选层级 | 可选中间层级或末级部门 |
| 清除 | 点击 × 清空已选部门 |
| 历史兼容 | 旧版 BP 部门名（智能照明、智能家电）加载时自动清空 |
| 主数据变更 | 费用部门管理变更后，本页下拉自动同步 |

### 6.6 场景品类

|------|------|

### 6.12 渠道

### 6.13 店铺

## 7. 操作与交互

### 7.1 新增一行

1. 在表尾插入一行；
2. 默认值：

| 字段 | 默认值 |
|------|--------|
| 收益日期范围 | 当年 1/1 ～ 12/31（原型：2025-01-01 ～ 2025-12-31） |
| 营销类型 | 空（须手工选择） |
| 类型 | 空（须手工选择） |
| 分摊模式 | 空（须手工选择，无默认值） |
| 费用部门 | 空 |
| 场景品类 | 默认「观影 / TV灯带」一组 |
| model / SKU | 空 |
| 新品标签 | 空 |
| 区域 | NA（北美区） |
| 国家 / 渠道 / 店铺 | 空 |
| 营销费用规划 | 0（保存前须改为 >0） |
| 币种 | USD |

3. Toast：`已新增一行，请填写后保存`

### 7.2 行内保存

1. 仅校验并保存**当前行**；
2. 校验规则同「保存预算」单行规则；
3. 通过后更新本地存储中该行数据；
4. Toast：`已保存该行预算`

### 7.3 保存预算（顶部）

1. 校验**全部行**；
2. 至少一行；
3. 全部行通过后，以当前 DOM 同步列表并持久化；
4. Toast：`预算已保存（合计 {合计值}）`

### 7.4 复制

1. 复制源行全部字段，生成新 `id`；
2. 插入列表末尾并重新渲染；
3. Toast：`已复制该行`

### 7.5 删除（单行）

1. 二次确认：`确定删除该预算行？`
2. 从存储移除并刷新表格与合计；
3. Toast：`已删除`

### 7.6 批量删除

| 规则 | 说明 |
|------|------|
| 启用条件 | 至少勾选 1 行 |
| 未勾选 | 按钮禁用 |
| 全选 | 表头复选框可全选/半选当前全部行 |
| 确认 | `确定删除选中的 N 行预算？` |
| 结果 | 批量移除并刷新；Toast：`已删除 N 行` |

### 7.7 示例数据（首次进入）

原型首次进入（无本地缓存）时预置 3 行示例预算，用于演示不同区域/类型组合。示例行 id 固定，避免删除与 DOM 不同步。

## 9. 校验规则汇总

### 9.1 保存前校验顺序

对每一行依次校验：

1. 收益日期范围完整；
2. 营销类型已选；
3. 类型已选；
4. 分摊模式已选；
5. 该行选「不分摊」→ 费用部门已选；
6. 营销费用规划 > 0。

> 注：分摊 / 不分摊下场景品类、SKU、新品标签等范围字段**均可全空**，不做「至少填一类」校验。

### 9.2 校验场景矩阵

| 场景 | 分摊模式 | 规划对象 | 部门 | 预期 |
|------|----------|----------|------|------|
| 未选分摊模式 | 空 | 任意 | 任意 | 拦截 |
| 分摊 + 范围全空 | 分摊 | 全空 | 可空 | 通过（全产品分摊） |
| 正常分摊行 | 分摊 | 有场景品类等 | 可空 | 通过 |
| 不分摊全空范围 | 不分摊 | 全空 | 已填 | 通过 |
| 不分摊缺部门 | 不分摊 | 任意 | 空 | 拦截 |
| 金额为 0 | 已选 | 满足 | 满足 | 拦截 |
| 空表保存 | — | — | — | 拦截 |

### 9.3 级联清空矩阵

| 变更字段 | 联动行为 |
|----------|----------|
| 区域 | 清空国家；刷新国家选项 |
| 渠道 | 清空店铺；刷新店铺选项 |
| 该行分摊模式 → 不分摊 | 该行各范围多选列裁减为最多 1 项 |

## 10. 异常与边界

| 场景 | 处理 |
|------|------|
| 费用部门主数据未加载 | 下拉显示「费用部门主数据未加载」；保存时若不分摊且部门为空则拦截 |
| 销售主数据索引加载失败 | 使用内置 model 子集，不影响保存 |
| 切换分摊模式导致多选裁减 | 原型静默保留最后值；正式环境可增加确认弹窗 |
| 历史数据字段迁移 | 自动处理 monthStart/monthEnd、model 字符串、npTag 旧格式、BP 部门名 |
| 浏览器缓存清除 | 原型数据丢失，恢复示例数据；正式环境走服务端 |

## 12. 测试验收要点

### 12.1 基础校验

1. 空表点「保存预算」→ 提示至少新增一行。
2. 金额为 0 或空 → 拦截并提示。
3. 收益日期、营销类型、类型、分摊模式缺任一 → 按行号提示。

### 12.2 分摊模式

4. 分摊模式为行级下拉，位于费用部门前；必填，无默认值（显示「请选择」）。
5. 表头「分摊模式」有字段注释，说明分摊/不分摊规划口径。
6. 该行选「分摊」且场景品类 / SKU / 新品标签等范围全空 → **可保存**（全产品分摊）。
7. 该行选「不分摊」且范围全空、部门已填 → 可保存。
8. 该行选「不分摊」且部门为空 → 拦截。
9. 该行切换为「不分摊」时，范围多选自动裁减为每列最多 1 项；不影响其他行。
10. 同一项目可同时存在「分摊」行与「不分摊」行。

### 12.3 级联与组件

11. 修改区域后，国家被清空。
12. 修改渠道后，店铺被清空。
13. 场景品类级联：hover 切换右列、父级全选子级、半选态正确。
14. 新品标签下拉显示当前年 ±3 年共 7 项。
15. 费用部门树形下拉：搜索、展开收拢、清除、禁选节点不可见。

### 12.4 操作

16. 新增一行：分摊模式为空（须手工选择）；保存前须补齐必填项。
17. 复制行生成新 id，含分摊模式在内的字段全部带出。
18. 批量删除：未勾选禁用；勾选后可删；全选生效。
19. 行内保存仅校验当前行；顶部保存校验全部行。
20. 保存后刷新页面，数据仍在，合计正确。

### 12.5 与费用导入口径一致性（联调）

21. 预算行分摊模式为「不分摊」时，后续费用导入可参考该口径，但导入页仍独立校验。
22. 预算页不出现 MSKU 分摊预览、分摊明细弹窗、批次状态等导入页专属能力。
