## 1. 需求背景与目标

### 1.1 背景

全渠道管报中，除系统自动取数、规则计提外，还存在大量需**人工补充导入**的业务费用（品牌联合投放、临时推广、样品、物流调整等）。这类费用需要：

1. 按批次录入或导入，明确费用项、归属月、金额、范围与分摊方式；
2. 经业务确认后纳入管报，避免未审核数据污染报表；
3. 分摊模式下按 MSKU 维度拆分；不分摊模式下按维度组合整笔归属。

### 1.2 建设目标

1. 提供**业务费用批次**的统一管理入口：筛选、新增、导入、预览、生效、失效、删除。
2. 建立清晰的状态机：**待生效 → 已生效 → 失效**，仅已生效批次参与管报。
3. 支持**分摊**与**不分摊**两种模式，规则与预览口径一致。
4. 部门展示与归属遵循统一标准：`组织·组织名 / 管报部门`（如 `102·Govee / APP商城`）。
5. 与费用项主数据、费用部门主数据、渠道/产品主数据联动。

### 1.3 目标用户

| 角色 | 主要场景 |
|------|----------|
| 费用/财务运营 | 录入、导入、预览、生效/失效批次 |
| 管报分析人员 | 查看明细、核对分摊结果与纳入口径 |
| 财务主管 | 审核待生效批次、批量生效 |

### 1.4 上下游

| 方向 | 说明 |
|------|------|
| 上游 | 费用项主数据、费用部门主数据、渠道/店铺/场景/品类/SKU/MSKU 主数据、营收权重数据、钉钉导入模版 |
| 下游 | 全渠道管报业务费用导入结果池、按 MSKU 分摊展示、费用汇总 |

## 4. 全局业务规则

### 4.1 批次状态与管报纳入

| 状态 | 含义 | 纳入管报计算 |
|------|------|--------------|
| 待生效 | 新增/导入后的初始状态 | **否** |
| 已生效 | 人工确认后 | **是** |
| 失效 | 业务作废 | **否** |

**核心原则：**
- 新增/导入仅写入数据，**不等于**纳入管报；
- 列表状态与明细弹窗「纳入管报计算」字段必须一致；
- 失效批次不可重新生效（需新建批次）；
- 仅失效批次允许删除。

### 4.2 状态流转

```
新增/导入 ──→ 待生效
待生效 ──生效──→ 已生效
待生效 ──失效──→ 失效
已生效 ──失效──→ 失效
失效 ──删除──→ 从系统移除
```

### 4.3 筛选规则（点击查询生效）

**修改筛选条件后，须点击「查询」按钮才刷新列表**；未点查询前列表保持上一次结果。

| 筛选项 | 控件 | 默认 | 匹配规则 |
|--------|------|------|----------|
| 归属月范围 | 月份范围选择器 | 空（不限） | 闭区间，格式 YYYY-MM |
| 费用项 | 树形下拉 | 全部 | 精确匹配费用项名称 |
| 部门 | 树形下拉 | 全部 | 按部门展示名等价匹配 |
| 状态 | 下拉 | 全部 | 精确匹配 |
| 备注 | 文本 | 空 | 关键词模糊匹配（包含、不区分大小写） |

**全选规则：** 表头全选仅作用于**当前查询结果可见行**，不跨查询、不跨页。

### 4.4 部门展示与归属

#### 展示格式（统一标准）

`{组织编码}·{组织名} / {管报部门名}`

示例：
- `102·Govee / APP商城`
- `109·Trading / 品牌中心`

组织节点仅展示组织部分，如 `102·Govee`。

#### 归属优先级（引用映射方案）

1. **用户指定管报部门** → 直接按指定部门归属，带出金蝶组织与金蝶部门；
2. **未指定部门，有店铺** → 按店铺映射表自动归属；
3. **未指定部门，无店铺** → 先按分摊规则拆到店铺，再映射；无法拆分则进入**待确认**；
4. **借货场景** → 按实际销售店铺归属，不按 MSKU 来源归属。

#### 部门必填规则

| 场景 | 部门 |
|------|------|
| 分摊模式 | **非必填**；不填按店铺映射；无店铺 → 待确认 |
| 不分摊模式 | **必填**；由用户指定金蝶部门 |

### 4.5 批次号规则

格式：`IMP-{YYYYMMDD}-{3位序号}`

示例：`IMP-202604-001`

### 4.6 历史归属月调整（已确认）

本页用于**手工补充导入**类费用（品牌投放、临时推广、样品等），与《费用来源定义》中的**规则计提**相互独立，但在管报层合并展示。

**核心约定：不做导入模式（追加/覆盖）。** 每次新增/导入均生成独立批次；用户认为需要「覆盖」时，须**主动失效**原批次后重录。

#### 4.6.1 归属月 vs 操作月

| 概念 | 说明 |
|------|------|
| **归属月** | 费用计入管报的月份（`YYYY-MM`）；补录历史月时须填**目标归属月**，非当前操作月 |
| **操作月** | 用户实际录入/导入的自然月；记入创建时间、操作人，用于审计 |
| **权重月** | 分摊模式下 = 归属月的**上月**；7 月重录 6 月费用时，仍按 5 月营收占比分摊 |

#### 4.6.2 标准纠错流程

| 场景 | 操作 |
|------|------|
| 金额/范围/分摊模式填错 | 筛选目标归属月 → **失效**错误批次 → 重新新增/导入（归属月不变）→ 预览 → **生效** |
| 漏录一笔 | 直接新增/导入，归属月填目标月 → 生效（与已有批次并存，管报累加） |
| 多录一笔 | 仅失效多录批次 |
| 要在原费用上再加 | 再新增一条批次并生效（不做同键合并） |

失效后不可重新生效，须新建批次（§4.1）。

#### 4.6.3 关账分层

与《费用来源定义》§4.7、《全渠道管报-费用录入三选一-页面设计》进库锁定规则对齐：

| 归属月状态 | 批次层（本页） | 管报层 |
|------------|----------------|--------|
| **未进库 / 未关账** | 允许失效已生效批次并重录 | 新生效批次纳入管报 |
| **已进库 / 已关账** | 建议拦截对已生效批次的失效，或须财务角色二次确认 | 默认不回溯；失效后须配合管报侧重算或差额说明 |

**已关账月硬差额：** 若不允许失效，可通过新增**调整批次**（备注标明「关账后差额调整」）录入正负金额；正式环境须受权限与审计约束。

#### 4.6.4 可选弱提示（非阻断）

写入前若存在「同费用项 + 同归属月 + 已生效」批次，可 Toast 提示：

> 已存在同费用项、同归属月的已生效批次 {批次号}，请确认是否需要追加新批次。

不拦截写入，不要求选择导入模式。

### 4.7 与费用来源定义、管报进库的协同（已确认）

| 费用类型 | 维护入口 | 历史月纠错 |
|----------|----------|------------|
| 规则计提（固定金额/比例、历史滚动占比等） | 费用来源定义 + 月度费用运行 | 修正规则 → 未关账月重跑（见对方 PRD §4.9） |
| 手工补充导入 | 本页 | 失效 + 重录（§4.6.2） |
| 自动取数 | 数据源同步 | 不在本页修改；同步失败后重新同步或联系数据方 |

**分工原则：**

1. 规则计提问题**优先**在来源定义/月度运行处理，避免用本页重复录入抵销；
2. 本页仅承担**规则无法覆盖**或**关账后差额**的手工补充；
3. P4「确认并进库」后，该归属月费用池锁定；更正须先在来源页（规则类）或本页（手工类）作废，再视关账状态决定是否允许重进库。

## 6. 新增导入费用弹窗

### 6.1 费用信息

| 字段 | 必填 | 默认值 | 校验与说明 |
|------|------|--------|------------|
| 分摊模式 | 是 | 分摊 | 分摊 / 不分摊 |
| 费用项 | 是 | 品牌营销费 | 仅末级费用项，不可自由输入 |
| 部门 | 条件必填 | 空 | 不分摊必填；分摊可空 |
| 归属月 | 是 | 当前月 | YYYY-MM |
| 金额 | 是 | — | 须 > 0，两位小数 |
| 币种 | 是 | USD | 见枚举 |
| 备注 | 否 | 空 | 补充背景/审批备注 |

**分摊模式联动：**
- 不分摊：部门字段显示必填标识；渠道/产品每列仅可单选或不填；
- 分摊：部门非必填；渠道/产品各列可多选。

**关键字段变更后**（费用项、金额、归属月、币种、备注、部门、分摊模式、任意范围字段）须**重新预览**，确认写入按钮恢复禁用。

### 6.2 渠道范围（5 列）

| 字段 | 分摊模式 | 不分摊模式 |
|------|----------|------------|
| 区域 | 多选，可空 | 单选或不填 |
| 国家 | 多选，可空 | 单选或不填 |
| 渠道 | 多选，可空 | 单选或不填 |
| 店铺 | 多选，可空 | 单选或不填 |
| 零售商 | 多选，可空 | 单选或不填 |

**空值语义：**
- 分摊：该列不填 = 该维度不限（通配）；
- 不分摊：该列不填 = 通配；填写字段之间为 **AND** 条件；全空 = 全公司通用费用。

**列间关系：** 各列之间取 **AND（交集）**。

### 6.3 产品范围（9 列）

| 字段 | 分摊模式 | 不分摊模式 |
|------|----------|------------|
| 场景 | 多选，可空 | 单选或不填 |
| 品类 | 多选，可空 | 单选或不填 |
| MODEL | 多选，可空 | 单选或不填 |
| SKU | 多选，可空 | 单选或不填 |
| MSKU | 多选，可空 | 单选或不填 |
| ASIN | 多选，可空 | 单选或不填 |
| 新品标签 | 文本，英文逗号分隔 | 同左，不分摊时仅取第一个值 |
| 订单号 | 文本，英文逗号分隔 | 同左 |
| DL批次号 | 文本，英文逗号分隔 | 同左 |

规则同渠道范围。

### 6.4 分摊规则摘要

实时展示当前录入的费用项、归属月、金额、币种、范围口径、分摊模式说明。

**不分摊且未选部门时**，摘要须明确提示：**未填写（必填，请选择金蝶部门）**，不得出现「按店铺映射」类误导文案。

### 6.5 预览分摊

#### 前置校验

| 校验项 | 错误提示 |
|--------|----------|
| 未选费用项 | 请选择费用项 |
| 未填归属月 | 请填写归属月 |
| 金额 ≤ 0 或非数字 | 金额必须为大于 0 的数字 |
| 不分摊未选部门 | 不分摊模式下部门为必填项，请先选择部门 |

#### 分摊模式预览逻辑

1. 从归属月对应营收明细中，筛选「渠道范围 AND 产品范围」均匹配的记录；
2. **剔除营收 < 0 的记录**，不参与分摊；
3. 权重月 = 归属月的**上月**（如归属月 2026-04 → 权重月 2026-03）；
4. 按匹配记录权重月营收占比分摊总金额；
5. 分摊金额保留 2 位小数；前 n-1 行四舍五入，**末行 = 总额 - 前序之和**（舍入补差）；
6. 预览表展示：店铺、MSKU、新品标签、零售商、权重月营收、权重占比、分摊金额；
7. 预览总额须与录入金额一致。

**无命中时：**
- 有新品标签条件：`当前范围与「新品标签」条件下无 MSKU 可分摊，请放宽范围或清空新品标签`
- 其他：`当前范围交集为空，无法预览分摊`

#### 不分摊模式预览

- 不生成 MSKU 分摊表；
- 展示汇总卡片：模式、归属维度、部门、金额；
- 归属维度按 AND 条件组合展示。

#### 预览与写入关系

- 必须先预览成功，才能点击「确认写入」；
- 预览后修改关键字段，确认写入自动禁用，须重新预览。

### 6.6 确认写入

写入后：
- 生成一条**待生效**批次；
- 保存渠道/产品范围摘要（不分摊时按渠道列、产品列分别生成摘要）；
- 保存部门（完整展示格式）、费用项、归属月、金额、币种、备注、分摊模式；
- 分摊模式同时保存预览分摊明细；不分摊模式明细为空。

成功提示须说明：须再点「生效」后才纳入管报计算。

## 7. 分摊 vs 不分摊 — 完整规则对照

| 维度 | 分摊模式 | 不分摊模式 |
|------|----------|------------|
| 范围多选 | 各列可多选 | 每列仅单选或不填 |
| 列间关系 | AND 交集 | AND 条件 |
| 全空含义 | 全渠道 + 全产品 | 全公司通用费用 |
| 空列含义 | 该维度不限 | 通配 |
| 分摊方式 | 按 MSKU 营收占比拆分 | 整笔归属到维度组合 |
| 部门 | 非必填（店铺映射/待确认） | **必填** |
| 明细弹窗 | 展示 MSKU 分摊表 | 隐藏 MSKU 表，展示归属维度 |
| 列表渠道摘要 | `区域:xx；国家:xx` 或 `全渠道（各列空）` | `不分摊 · 国家=美国 (US)` 等 |
| 列表产品摘要 | `MODEL:xx` 或 `全产品（各列空）` | `不分摊 · MODEL=H6071` 等 |

### 7.1 查询口径（不分摊）

未填字段视为通配；**仅当业务查询条件命中该维度组合时，此笔费用才显示**。

## 10. 主数据依赖

### 10.1 费用项主数据

> 与《费用来源定义》PRD §12.1、§19 一致。

- 树形结构，**仅末级节点**可选；
- 层级仅含：总类、大类、子类、管报场景 L1、管报场景 L2、管报场景 L3、管报下级费用项；**「线上/线下」不进入费用项树**；
- 编码为连续串（无 `-`，如 `T040301010102`）；列表/明细展示可用名称全称（根→末级，` / ` 连接）+ 编码；
- 费用来源页「费用项管理」**仅可维护备注**，不提供新增/编辑/删除节点；树由初始化主数据维护；
- 费用项变更后刷新本页下拉与列表。

### 10.2 费用部门主数据

> 与《费用来源定义》PRD §12.2、§19.3 一致。

- 组织 → 部门树，含金蝶 BM 对照；
- **不使用节点编码、属性类型**作为业务字段；下拉与列表按名称 + 组织/BM 识别；
- 仅可选节点可作为费用归属；
- 禁用节点不在下拉中显示；
- 展示统一为标准格式：`组织编码·组织名 / 管报部门名`。

### 10.3 渠道/店铺/场景/品类

- **渠道列（管报口径）固定六类：** 亚马逊、shopify、App商城、线下商超、商超3P、线下分销（与费用来源定义、项目立项一致）；
- 店铺随所选渠道展开；区域国家、场景品类来自主数据 JSON/服务；
- 正式环境须与钉钉数据字典二次校验。

## 13. 验收清单

1. 设置筛选条件后点击「查询」，列表按条件刷新。
2. 待生效 → 生效后，明细「纳入管报计算」= 是。
3. 已生效 → 失效后，明细 = 否。
4. 失效 → 删除后行消失。
5. 批量操作状态校验与单行一致，无部分成功。
6. 全选仅作用于当前筛选可见行。
7. 不分摊未选部门时，摘要、预览、写入均拦截并提示必填。
8. 分摊预览剔除负营收，各行分摊之和 = 录入金额。
9. 部门展示统一为 `102·Govee / APP商城` 格式。
10. 不分摊列表渠道/产品摘要分列展示，与示例数据格式一致。
11. 导入模版部门列示例为标准格式。
12. 列表状态与明细纳入口径始终一致。
13. 7 月补录 6 月费用：归属月填 2026-06，权重月自动取 2026-05。
14. 纠错流程：失效 → 重录 → 生效；不做导入模式字段。
15. 已关账月失效拦截或须财务确认（按环境配置）。

4. 导入文件大小、行数上限与异步任务机制。

## 15. 已确认事项

1. **不做导入模式**：不建设追加/覆盖；纠错采用失效 + 重录（§4.6）。
2. **历史归属月**：补录时归属月填目标月；与操作月分离（§4.6.1）。
3. **关账分层**：未关账可失效重录；已关账默认不回溯，差额走调整批次或解锁流程（§4.6.3）。
4. **与费用来源定义分工**：规则计提走来源定义+月度运行；本页负责手工补充（§4.7）。
