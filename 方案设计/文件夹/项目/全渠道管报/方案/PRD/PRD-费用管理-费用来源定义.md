## 1. 需求背景与目标

### 1.1 背景

全渠道管报月度费用运行前，需预先定义每个费用项在各渠道下的**取数/计提规则**。规则配置是后续自动取数、固定金额/比例计提、历史滚动占比、同期占比预估等能力的**主数据基础**。

### 1.2 建设目标

1. 提供费用来源配置的增删改查、启停管理能力；
2. 支持五种费用来源类型，覆盖自动取数与四类手工维护规则；
3. 按口径范围自动展开明细组合，支持逐行维护、批量编辑、导入导出；
4. 列表摘要按**明细维护值汇总**展示，而非仅取顶部默认值；
5. **启用**配置占用渠道、参与计提；**停用**配置保留但不占渠道、不参与新计提。

### 1.3 目标用户

| 角色 | 主要场景 |
|------|----------|
| GTM/财务运营 | 维护各费用项在各渠道下的计提规则 |
| 财务主管 | 审核规则、启停配置 |
| 管报分析 | 查看规则摘要，理解费用取数口径 |

### 1.4 上下游

| 方向 | 说明 |
|------|------|
| 上游 | 费用项主数据、渠道/国家/场景/零售商主数据、历史费用与比例基数 |
| 下游 | 月度费用运行、管报费用汇总、费用填报对账 |

## 4. 全局业务规则

### 4.1 配置对象定义

一条**费用来源配置** = 

```
一个费用项 + 一种费用来源类型 + 一组适用渠道
+（非自动取数时）口径范围 + 明细维护值
```

### 4.2 启用/停用与渠道占用

| 状态 | 参与月度计提 | 占用渠道 |
|------|--------------|----------|
| 启用 | 是 | **是**（同费用项下渠道互斥） |
| 停用 | 否 | **否** |

**关键规则（已确认）：**
- 仅**启用**配置占用渠道；
- 编辑**停用**配置保存时，**不**做渠道冲突校验；
- 列表「启用」操作前须校验渠道占用；
- 启停、规则修改后：**已运行月份与历史报表保留快照，不回溯重算**；仅未运行月份按新规则生效。

### 4.3 渠道互斥

- 粒度：**同一费用项**下，一个渠道只能被**一条启用配置**占用；
- UI：已被占用的渠道在下拉中置灰；
- 切换费用项时，自动剔除新费用项下已被占用的已选渠道。

### 4.4 筛选规则（点击查询生效）

**修改筛选项后，须点击「查询」按钮才刷新列表**；未点查询前列表保持上一次结果。导出与列表一致，按上一次查询的筛选条件取数。

| 筛选项 | 选项 |
|--------|------|
| 费用项 | 全部 + 末级费用项（树形，按编码） |
| 费用来源 | 全部、自动取数、固定金额、固定比例、历史滚动占比、同期占比预估 |
| 渠道 | 全部、亚马逊、独立站、线下商超、分销 |
| 状态 | 全部、启用、停用 |

**导出规则：** 导出**上一次查询的筛选结果**（须与列表展示一致）；仅配置摘要，不含明细维护值。

### 4.5 列表摘要生成规则（已确认：明细汇总）

保存时 `来源摘要` 按**明细维护值汇总**生成，非仅取弹窗顶部默认值。

| 来源类型 | 摘要格式 |
|----------|----------|
| 自动取数 | 列表展示「系统自动取数」 |
| 固定金额 | `¥{min}–{max} / 月（均值 ¥{avg}）· {口径} · {N} 条明细`；全部相同则只展示单值 |
| 固定比例 | `{min}%–{max}%（均值 {avg}%）× {比例基数} · {口径} · {N} 条明细` |
| 历史滚动占比 | `{历史窗口} 滚动 · {比例基数} · {口径} · {N} 条明细` |
| 同期占比预估 | `同比月占比 · {比例基数} · {口径} · {N} 条明细` |

### 4.6 同费用项多来源类型并存（已确认）

| 场景 | 是否允许 |
|------|----------|
| 同费用项 + **不同渠道** + 不同来源类型 | ✅ 允许 |
| 同费用项 + **同渠道** + 不同来源类型（均启用） | ❌ 不允许（渠道占用互斥，与来源类型无关） |
| 同费用项 + 多条停用配置 | ✅ 允许（不占渠道） |

同一费用项可按渠道拆分不同计提方式（如亚马逊用历史滚动占比、独立站用同期占比预估），但同一渠道在启用状态下只能归属一条配置。

## 6. 五种费用来源类型

### 6.1 类型枚举

| 内部值 | 展示名 | 需口径明细 |
|--------|--------|------------|
| auto | 自动取数 | 否 |
| fixedAmount | 固定金额 | 是 |
| fixedRate | 固定比例 | 是 |
| rollingRate | 历史滚动占比 | 是 |
| yoyMonthRate | 同期占比预估 | 是 |

### 6.2 自动取数

**参数：** 无额外规则参数。

**行为：**
- 显示提示：系统从既有数据源自动同步，仅需确认费用项与适用渠道；
- 隐藏口径范围与明细区；
- 保存提示：`已保存：自动取数 · 渠道「…」`

**本期不展开：** 数据源、同步频率、失败补数、对账口径。

### 6.3 固定金额

| 参数 | 必填 | 说明 |
|------|------|------|
| 默认月固定金额 | 是 | > 0，顶部默认值为批量编辑参考 |
| 币种 | 否 | CNY/USD/EUR，默认 CNY |
| 适用周期 | — | 固定「每月」 |

**明细维护值列名：** 月固定金额

**计算：** 按各明细行维护的金额直接参与计提。

### 6.4 固定比例

| 参数 | 必填 | 说明 |
|------|------|------|
| 默认比例值（%） | 是 | 0–100，步长 0.01 |
| 比例基数 | 是 | 当月实际营收 / 当月销售额；须持久化 |

**明细维护值列名：** 比例值（%）

**计算：** `本月费用 = 当月比例基数 × 明细比例值`

### 6.5 历史滚动占比

| 参数 | 必填 | 说明 |
|------|------|------|
| 历史窗口 | 是 | 近 12/6/3 个月 |
| 比例基数 | 是 | 当月实际营收 / 当月销售额 |

**计算公式：**
```
滚动占比 = AVG(历史各月费用 ÷ 历史各月基数)   // 仅对有效月求平均
本月费用 = 当月比例基数 × 滚动占比
```

**有效月判定与缺数处理（已确认）：**

| 场景 | 处理规则 |
|------|----------|
| **缺数月份**（费用或基数为空） | 不参与滚动窗口计算 |
| **有效月不足**（如窗口 12 个月但仅 2 个月有数） | 按**实际有效月数**求平均，不设最低月数门槛、不阻断启用/运行 |
| **异常月**（基数 ≤ 0） | 剔除该月，不参与均值 |
| **极端占比 / 负值月份** | 按原公式 `费用÷基数` 正常计入均值，**不告警**；财务场景允许负数，拉会整年均值不受影响 |
| **补录后** | 已关账/已出报表月份保留快照、不回溯；当前开放月及未来月用补录后数据重算 |

**明细维护值：** 滚动占比（%），**系统计算、只读**，不可手工编辑、不可批量编辑、不可导入。

### 6.6 同期占比预估

| 参数 | 必填 | 说明 |
|------|------|------|
| 比例基数 | 是 | 当月实际营收 / 当月销售额 |
| 历史参考窗口 | — | 固定近 12 个月（用于校验） |
| 缺数处理 | — | 固定取近 12 个月滚动均值 |

**计算公式：**
```
本月预估占比 = 去年同月费用 ÷ 去年同月基数
缺数时 = 过去 N 个月有效占比算术平均（N ≤ 12，仅含基数 > 0 的月份）
本月费用 = 当月比例基数 × 本月预估占比
```

**补录与重算（已确认）：**

| 数据状态 | 是否重算 |
|----------|----------|
| 已月度运行 / 已出管报 | ❌ 不回溯，保留快照 |
| 当月运行中、未关账 | ✅ 用补录后参考数据重算 |
| 未来月预估 | ✅ 随最新参考数据更新 |

**明细维护值：** 预估占比（%），可手工维护、批量编辑、导入。

## 7. 口径范围

### 7.1 选项

| 内部值 | 展示名 | 明细维度 |
|--------|--------|----------|
| channelCountry | 渠道+国家 | 渠道、国家 |
| channelCountryScene | 渠道+国家+场景 | + 场景 |
| channelCountryRetailer | 渠道+国家+零售商 | + 零售商 |
| channelCountrySceneRetailer | 渠道+国家+场景+零售商 | 全部四维 |

### 7.2 规则

1. 决定明细表列与筛选器显隐；
2. 切换口径范围 → 按新维度重建明细行，清空不再适用的筛选；
3. 尽量保留同 key 的旧维护值（见下表）；
4. 切换来源类型且类型变化时，清空已有明细后重建。

**口径变更迁移策略（已确认）：**

| 变更类型 | 迁移策略 |
|----------|----------|
| **扩口径**（如 渠道+国家 → +场景） | 原 `渠道|国家` 匹配的行，维护值复制到所有新展开子行 |
| **缩口径**（如 +场景 → 渠道+国家） | 同 `渠道|国家` 多行值不一致时，取**最近一次维护值**；UI 标黄冲突行 |
| **无法匹配** | 新行留空，保存时走必填校验 |
| **已保存规则修改** | 保存前展示「保留 X 条 / 丢失 Y 条 / 新增 Z 条」预览，用户确认后写入 |

### 7.3 维度主数据

| 维度 | 来源 |
|------|------|
| 国家 | 区域国家基础数据 |
| 场景 | 场景品类基础数据（排除「未分类」） |
| 零售商 | 按页面渠道映射（零售商 = 具体客户） |
| 渠道下店铺 | 渠道店铺基础数据 |

### 7.4 页面渠道与主数据映射

| 页面渠道 | 主数据渠道 |
|----------|------------|
| 亚马逊 | Govee、Govee EU、GoveeLife、Govee_VC、TTS |
| 独立站 | 独立站、APP商城 |
| 线下商超 | Offline、Wayfair-US、WM 3P、BBY 3P、Lowes 3P |
| 分销 | 线下分销、京东 |

## 9. 口径明细

### 9.1 展开规则

1. 选择适用渠道后，按口径范围自动生成全部可维护组合（笛卡尔积）；
2. 组合键：`渠道|国家|场景|零售商`（按口径范围取子集）；
3. 未选渠道 → 提示先选择渠道；
4. 切换渠道/口径/来源类型 → 重建明细，保留可匹配 key 的值。

### 9.2 明细表结构

| 元素 | 说明 |
|------|------|
| 勾选列 | 全选/单选（查看模式隐藏） |
| 维度列 | 随口径范围动态 |
| 维护值列 | 随来源类型变化 |
| 摘要行 | 已展开 X 条，当前显示 Y 条 |

### 9.3 明细筛选（仅影响展示）

| 筛选项 | 显隐 |
|--------|------|
| 渠道 | 始终 |
| 国家 | 始终 |
| 场景 | 口径含场景时 |
| 零售商 | 口径含零售商时 |

**不改变**已展开的全部明细集合及保存范围。

### 9.4 维护值校验

| 类型 | 规则 |
|------|------|
| 固定金额 | > 0 |
| 固定比例 / 同期占比 | 0 ≤ 值 ≤ 100 |

保存时**全部明细行**须通过校验（非自动取数）。

### 9.5 批量编辑

**入口：** 明细工具栏「批量编辑」

**前置：** 须先勾选明细行；查看模式、历史滚动占比不可用。

**流程：**
1. 弹窗展示已选 N 条；
2. 填写统一维护值；
3. 预览维度 + 当前值；
4. 确认后仅更新已勾选行。

### 9.6 导出明细

- 按钮文案建议：**导出全部明细**
- 范围：弹窗内**全部已展开明细**（非仅筛选可见行）
- 查看模式下仍可用

### 9.7 导入明细

| 项 | 内容 |
|----|------|
| 适用类型 | 固定金额、固定比例、同期占比预估 |
| 不支持 | 历史滚动占比 |
| 模版列 | 渠道*、国家*、场景（口径含时必填）、零售商（口径含时必填）、维护值* |
| 匹配键 | 渠道 + 国家 + 场景 + 零售商 |
| 覆盖策略 | 按维度匹配覆盖同组合值 |
| 失败策略 | 整批回滚；文件内重复维度 → 失败 |

## 10. 编辑弹窗

### 10.1 弹窗模式

| 模式 | 标题 | 保存 |
|------|------|------|
| 新增 | 新增费用来源 | 可保存 |
| 编辑 | 编辑费用来源 · {id} | 可保存 |
| 查看 | 查看费用来源 · {id} | 不可保存 |

### 10.2 字段清单

| 区块 | 字段 | 必填 |
|------|------|------|
| 基础 | 费用项 | 是（仅末级） |
| 基础 | 费用来源 | 是 |
| 基础 | 启用状态 | 否，默认启用 |
| 适用范围 | 渠道（多选） | 是 |
| 规则 | 口径范围 | 非 auto 必填 |
| 规则 | 类型参数 | 随类型 |
| 明细 | 口径明细表 | 非 auto 必填 |
| 其它 | 说明 | 否 |

### 10.3 表单重置规则

打开弹窗时须**先重置**全部类型参数字段为默认值，再按编辑数据覆盖，避免切换记录时残留上一条的固定金额/比例等。

### 10.4 说明字段

- 字段：说明（textarea）
- 须持久化至 `remark`，编辑时回显
- 与费用项主数据的「备注」为不同字段

### 10.5 保存校验

1. 至少选择一个适用渠道；
2. **仅启用状态**校验渠道占用；
3. 非自动取数：
   - 固定金额默认金额 > 0；
   - 固定比例默认比例 0–100；
   - 全部明细维护值合法；
4. 费用项须为有效末级节点。

### 10.6 启停：列表 vs 弹窗

| 路径 | 生效时机 |
|------|----------|

## 13. 状态机

```
┌─────────┐  列表停用 / 保存为停用   ┌─────────┐
│  启用   │ ──────────────────────► │  停用   │
│         │ ◄────────────────────── │         │
└─────────┘  列表启用 / 保存为启用   └─────────┘
     │ 参与计提、占用渠道                  │ 保留配置、不占渠道
     └────────────────────────────────────┘
```

**转换约束：**
- 停用 → 启用：须通过渠道占用校验；
- 规则修改或启停：仅影响未运行月份。

## 16. 验收清单

1. 设置筛选项后点击「查询」，列表按条件刷新；导出与列表筛选结果一致。
2. 列表摘要按明细汇总展示区间/均值，与明细实际值一致。
3. 启用配置占用渠道；停用配置不占渠道、编辑保存不被渠道冲突拦截。
4. 列表启用前校验渠道冲突；弹窗保存仅启用状态校验。
5. 说明字段保存后可回显。
6. 切换编辑不同记录时，不适用字段不残留上一条值。
7. 固定比例的比例基数（rateBase）保存后可回显。
8. 历史滚动占比明细只读，不可编辑/导入。
9. 查看模式：表单只读，筛选与导出仍可用。
10. 自动取数不展示口径明细，保存仅需费用项+渠道。
11. 启停后已运行月份不重算，未运行月份按新规则。
12. 费用项被启用来源引用时不可删除。
13. 同费用项可在不同渠道配置不同来源类型；同渠道启用配置仍互斥。
14. 历史滚动占比：缺数/基数≤0 月剔除；有效月按实际月数均值；负值月正常计入、不告警。
15. 同期占比补录后不回溯关账月；导出含停用（筛全部时）、CSV UTF-8 BOM。
16. 切换来源类型、移除渠道、缩口径等破坏性操作须二次确认。

---

## 17. 已确认事项

1. **同费用项多来源类型**：允许在不同渠道并存；同渠道启用配置互斥（§4.6）。
2. **口径范围变更迁移**：按 key 尽量保留；缩口径取最近维护值；保存前预览确认（§7.2）。
3. **历史滚动占比缺数/异常/补录**：缺数月、基数≤0 月剔除；有效月按实际月数求均；负值/极端占比正常计入不告警；补录不回溯关账月（§6.5）。
4. **同期占比补录重算**：已关账月不回溯；开放月与未来月重算（§6.6）。
5. **费用项改名**：历史报表保留 `fee_name_snapshot`，编码不变、不触发重算（§12.1）。
6. **列表导出**：跟随查询筛选；状态「全部」含停用；CSV UTF-8 BOM；字段顺序见 §5.3。
7. **破坏性操作确认**：切换来源类型强确认；移除渠道、缩口径中确认（§14）。
