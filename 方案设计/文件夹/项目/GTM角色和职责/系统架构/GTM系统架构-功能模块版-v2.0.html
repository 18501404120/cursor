建设顺序建议（不改前版本，仅补充模块化视图）
P0：`PSI中枢 + 价格管理平台 + 产品信息库 + 经营看板/管报`；
P1：`PCT流程数字化 + 项目里程碑 + PD↔GTM事件接口 + 渠道SO自动回流`；
P2：`预测优化 + 价格弹性/利润模拟 + 经营归因智能 + 售后问题自动回流`。
本版本为“功能模块架构图”，用于系统方案设计与评审。与角色职责版并行保留，不覆盖旧版本。
