## 一、项目背景

EOM 已由阶段性的停产确认工作，转变为**常态化的产品退市运营工作**：LBU 按月评审、实时发起，ABU 月度预排查、季度统一发起。业务需要管理的是一个完整过程——退市触发 → 核料 → 清库及 Last Buy 方案 → 正式 EOM → 库存/物料清理 → 反 EOM → S&OP 复盘 → EOL 闭环。

而当前 GTM 系统本质仍是"核料测算 + 附件审批"：**计划确认后系统即显示"完结"**，后续清库、Last Buy、物料清理和 EOL 闭环全部依赖 Excel 台账、钉钉群聊和人工催办。由此产生四类核心问题：

1. **状态失真**：系统显示"完结"时，业务才刚进入正式 EOM 执行，清库超期、物料未清等风险被隐藏。
2. **台账线下化**：产品、预测、库存、Last Buy、物料数据分散在多系统和线下表格，需求计划反复导数拼表，口径不一致、无法复盘。
3. **协同无责任链**：销售、计划、PMC、采购等角色任务在线下分配，靠人催办，无留痕、无预警。
4. **无真实闭环**：没有以"成品全链路库存清零"自动判定 EOL，关单靠人工跨系统核对。

## 二、项目价值

### 2.1 核心价值：把钱省下来

- **降低库存损失**：对新品延期、老品断货、库存积压、呆滞库存、专用料未清等风险提前预警，让 Last Buy 与清库方案可以及时调整，直接减少报废和积压金额。
- **保障新老品平稳切换**：新品里程碑、老品库存、预测联动管理，避免"老品断货丢销售"和"新品上市老品积压"两头受损。

### 2.2 效率价值：把人解放出来

- **退市全程在线化**：从发起到 EOL 全程可视，节点完成自动通知下一处理人，替代群聊催办，缩短 EOM 周期。
- **需求计划不再拼表**：在线台账自动汇聚预测、库存、Last Buy、物料数据，需求计划从"导数、拼表、核对、催办"转向风险分析和业务推动。
- **各角色任务清晰**：每个节点有明确责任人、完成时限和完成标准，"何时、为哪个产品、做什么"一目了然。

### 2.3 管理价值：让经营看得见

- **统一口径**：流程、角色职责、数据口径、闭环标准全部统一，页面、导出、复盘同一套数。
- **决策可追溯**：清库方案、Last Buy、报废决策、反 EOM 全程留痕，关键节点保存不可变快照，审计链完整。
- **复盘有依据**：管理层可直接查看进度、风险、金额和超期原因，支持按组织、品类、区域、退市原因复盘，为产品组合和库存策略优化提供数据基础。

### 2.4 可衡量的预期收益

上线后持续观测：线下台账替代率、节点按时完成率、平均 EOM 周期、清库达成率、专用料关闭率、呆滞库存金额变化、人工催办次数及台账整理工时变化、EOL 自动闭环率。基准值与目标值上线前由业务确认。

## 三、项目 OKR

OKR：O 指项目希望达成的目标；Kr 指关键结果，是考核 O 是否达成的依据，一般 3～5 个。

|  | 内容 |
| --- | --- |
| O | 实现 EOM 全生命周期在线管理，以及销售 PSI、采购计划对退市产品状态的同步适配 |
| Kr 1 | 完成 GTM 工单阶段重构与主动 / 被动退市分流，计划确认后进入 EOM 执行，不再显示业务完结 |
| Kr 2 | 上线以 8 位 SKU 为单元的在线台账，以及结构化清库 / Last Buy 方案（含导入、发起人与计划双会签），替代线下 Excel 拼表 |
| Kr 3 | 实现成品全链路库存清零自动判定 EOL；反 EOM 走钉钉 OA「反EOL流程审批」并回写关单 |
| Kr 4 | 完成 PSI 管理 / 审核适配（展示产品状态与预计 EOL，Sell out 超全链路库存硬拦）及采购计划 Last Buy 提示、EOM 后禁下单 |

## 四、挑战

Challenges：项目推进中必须面对、且会直接影响验收的难点。

|  | 内容 |
| --- | --- |
| Challenge 1 | 现网把计划确认当成完结，工单阶段、产品状态、任务状态混用，要改成全生命周期且不影响现网下单拦截 |
| Challenge 2 | 退市数据分散在 GTM、PSI、采购计划与库存 / 物料多套系统，口径不一，台账汇聚和状态写回必须对齐 |
| Challenge 3 | Last Buy 方案数量与采购实单并行、不互相校验，PSI 又要硬拦全链路库存，跨系统规则容易打架 |

## 五、改动点

本期不只改 GTM：产品状态写回后，销售系统 PSI、采购计划同步适配。**Forecast / Forecast 审核本期不改**。Last Buy 在 GTM 清库方案按渠道填写，计划在采购计划自行下最后一单，两套并行、**不互相校验数量**。
