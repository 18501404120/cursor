# 标注发布（本地编辑 → Pages 全员可见）

## 协作约定

| 场景 | 能力 |
|------|------|
| 本地 `http://127.0.0.1:8787/` | 可新增/编辑标注；点 **「发布到预览」** 推送到 Git |
| GitHub Pages 在线预览 | **只读**：只看标注与「查看页面说明」，无「新增标注 / 发布到预览」 |

## 使用步骤

1. 双击启动 `启动原型分享服务.command`（保持 8787 运行）
2. 本机打开原型页面，完成标注
3. 点右上角 **「发布到预览」** → 自动写入 HTML 并 `git push`
4. 约 **1～2 分钟** 后，同事刷新同一 Pages 链接即可看到

## 说明

- 不需要 Cloudflare。
- Pages 上即使用户强行调用接口也会被 runtime 拒绝（`pagesForceReadonly`）。
- 局域网分享给同事查看时，仍用 Pages 链接最省事；本机 8787 主要用于你自己编辑发布。
