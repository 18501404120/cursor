# 日期范围选择框 — 全局 UI 规范

> **适用范围**：凡需选择「起止日期」的筛选、表单、弹窗（非单月、非单点时刻），应使用本规范中的 **日期范围选择器**（对标 Ant Design `RangePicker` / Element Plus `daterange`）。  
> **技术实现**：原型阶段推荐使用仓库内脚本 **`文件夹/规范/assets/date-range-picker.js`**（`DateRangePicker.mount`），与设计稿交互一致。  
> **配套规则**：项目根目录 `.cursor/rules/date-range-picker.mdc`。

---

## 1. 触发器（收起态）

| 项目 | 要求 |
|------|------|
| 外框 | 白底、浅灰描边 `#d9d9d9`、小圆角（约 4px），高度与筛选项内其他控件一致（建议 28px）。 |
| 左侧图标 | **日历图标**（线框日历），灰色，与文案垂直居中。 |
| 展示文案 | 已选时：`YYYY-MM-DD 至 YYYY-MM-DD`，**严格**使用 **半角连字符日期** 与中文 **「至」** 作为分隔，中间有空格与否须全站统一（推荐：`2026-01-01 至 2026-01-31`）。 |
| 未选 | 占位提示，如「请选择日期范围」，浅灰字色。 |
| 右侧 | 有值时显示 **清空（×）**，点击清空起止日期并触发变更。 |
| 聚焦/展开 | 描边使用品牌主色（如 `#1677ff` / `#1890ff`），可带浅外发光，与 Ant Design 一致。 |

参考图：**`日期范围选择框-参考图-收起态.png`**

## 2. 下拉面板（展开态）

| 项目 | 要求 |
|------|------|
| 结构 | **左右双月历**并排，中间 **竖向浅灰分隔线**；面板白底、圆角、轻阴影。 |
| 月份标题 | 中文：**`YYYY 年 M 月`**（如 `2026 年 1 月`）。 |
| 导航 | 左面板：**上一年 «**、**上一月 ‹**；右面板：**下一月 ›**、**下一年 »**（与常见 Ant Design 双面板一致）。 |
| 星期表头 | **`日 一 二 三 四 五 六`**（日起始）。 |
| 非本月日期 | 浅灰显示，可点击以扩大范围。 |
| 选中范围 | 起止日为 **实心主色圆角/圆形**，中间日期为 **浅蓝背景**（建议范围色 `#e6f7ff`，主色 `#1677ff` / `#1890ff`）。 |
| 层级 | 面板 `z-index` 须高于同区域筛选条、表格，在弹窗内使用时高于蒙层内容区（如 `400+`）。 |

参考图：**`日期范围选择框-参考图-双月历展开.png`**

## 3. 交互与数据格式

- **点击**触发器展开面板；再次点击触发器或点击页面其他区域收起（原型脚本已实现）。  
- **选择顺序**：先选开始日期，再选结束日期；若第二次早于第一次，按组件惯例交换或重选（以当前 `date-range-picker.js` 为准）。  
- **清空**：清除起止日期。  
- **传参与展示**：接口与存储建议使用 **`YYYY-MM-DD`** 字符串；禁止用 `MM/DD/YYYY` 等混排作为默认。  

---

## 4. 与「单月」「单日」「月份范围」的区别

| 场景 | 控件 |
|------|------|
| **起止均为自然月**（标签常为「月份范围」） | 使用 **《月份范围选择框-全局UI规范》** + `month-range-picker.js`（`YYYY-MM - YYYY-MM`），**禁止**用本日期范围控件冒充。 |
| 仅选一个月（如 YYYYMM） | 使用 **月份选择** 或 **月份范围**（见上），**不**强制用本按日范围框。 |
| 仅选某一天 | 使用 **单日期** 选择器，不用双历日期范围。 |

---

## 5. 前端工程（非原型）

- **Ant Design**：`DatePicker.RangePicker`，`format="YYYY-MM-DD"`。  
- **Element Plus**：`el-date-picker`，`type="daterange"`，`value-format="YYYY-MM-DD"`。  

---

## 6. 跨项目复用

1. 复制本目录下 **`assets/date-range-picker.js`** 与参考图。  
2. 复制 `.cursor/rules/date-range-picker.mdc`。  
3. HTML 中：`<script src="（相对路径）/date-range-picker.js"></script>` 后调用 `DateRangePicker.mount`。
