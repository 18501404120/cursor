# 币种 — 全局业务规范

> **适用范围**：ERP / 管报 / 费用 / 仓储等涉及**金额币种**录入、展示与接口传参的场景。  
> **唯一数据源**：`文件夹/规范/基础数据/币种基础数据_v1.json`  
> **配套控件**：`文件夹/规范/assets/searchable-select.js`（`SearchableSelect.mount`，可搜索单选下拉）

---

## 1. 币种字典（强制）

页面与接口使用的币种代码须来自基础数据 JSON 的 `currencies[].code`，当前支持：

| 代码 | 中文名 |
|------|--------|

| CNY | 人民币 |
| CAD | 加元 |
| GBP | 英镑 |
| EUR | 欧元 |
| JPY | 日元 |
| AUD | 澳元 |
| SGD | 新加坡元 |
| SEK | 瑞典克朗 |
| PLN | 波兰兹罗提 |
| MXN | 墨西哥比索 |
| TRY | 土耳其里拉 |
| HKD | 港币 |
| AED | 阿联酋迪拉姆 |

## 2. 展示口径

| 场景 | 格式 |
|------|------|
| 列表 / 日志金额 | `{code} {amount}`，如 `USD 2.13`、`CNY 18.50`；金额保留 2 位小数（JPY 等零小数币种实现层可按 ISO 4217 扩展，原型默认 2 位） |
| 费率单位后缀 | `（{code} / 立方 / 天）` |
| 下拉选项 | 主文案 `{code}`；可选副文案 `{name}`（如 `USD · 美元`） |

---

## 3. 交互（强制）

1. 币种选择须为**可搜索单选下拉**（输入代码或中文名过滤），不得使用不可搜索的原生 `<select>` 作为最终形态（选项 ≤3 且明确标注极简草稿除外）。
2. 浮层在弹窗、表格等可能被裁切场景下，须启用 **`useBodyPortal: true`**（见《下拉与浮层-防遮挡-全局UI规范》）。
3. 默认值：无历史数据时 **USD**；编辑时回显该行已保存币种。

---

## 4. 引用方式

```html
<script src="…/规范/assets/searchable-select.js"></script>
```

```javascript
fetch('…/规范/基础数据/币种基础数据_v1.json')
  .then(function (r) { return r.json(); })
  .then(function (data) {
    var options = data.currencies.map(function (c) {
      return { value: c.code, label: c.code, hint: c.name };
    });
    SearchableSelect.mount('#currencyMount', {
      options: options,
      placeholder: '币种',
      initialValue: 'USD',
      useBodyPortal: true,
      onChange: function (code) { /* … */ }
    });
  });
```
