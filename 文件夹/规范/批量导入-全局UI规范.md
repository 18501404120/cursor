# 批量导入 · 全局 UI 规范

- 生效日期：2026-06-05
- 适用范围：本仓库内所有含 **Excel/CSV 批量导入** 的 HTML 原型、Vue/React 页面及需求说明
- 参考实现：`文件夹/规范/assets/import-modal-kit.js`；业务示例见 `文件夹/项目/全渠道管报/原型/暂时不需要/补充费用导入与分摊-系统原型.html` 批量导入弹窗
- 关联规则：`.cursor/rules/batch-import-global.mdc`

---

## 1. 原则

凡页面提供「导入」能力，**必须**同时提供：

1. **可下载的导入模版**（CSV 或 Excel，列结构与线上一致）
2. **填写说明**（弹窗正文 +「查看模版填写要求」二级弹窗/抽屉）
3. **上传区**（选择文件，正式环境支持拖拽）
4. **校验反馈**（成功/失败行数；失败可下载错误明细）

禁止仅放一个 `<input type="file">` 而无模版与说明。

---

## 2. 交互结构（必须）

```
列表页 [导入] 按钮
    └── 批量导入弹窗（主）
            ├── 说明正文（业务口径、三部分/字段分组、写入规则）
            ├── 模版下载区
            │     ├── 主按钮：下载导入模版（CSV/Excel）
            │     └── 链接：查看模版填写要求
            ├── 上传区（已填写的模版文件）
            └── 底部：取消 | 确认导入
    └── 填写要求弹窗（次，由「查看模版填写要求」打开）
            ├── 列结构表（分组 | 列名 | 必填 | 说明）
            └── 填写要求有序列表
```

### 2.1 主弹窗标题

统一为 **「批量导入」** 或 **「导入 {业务对象名}」**（如「导入 BP 数据」），副标题可不写。

### 2.2 说明正文（MUST）

- 用业务语言说明模版包含哪些信息块、如何与系统匹配
- 说明导入后数据状态（如：草稿 / 待生效 / 直接写入）
- 说明必填项与常见错误（字典取值、主数据校验等）
- **禁止**仅写「请选择文件」

### 2.3 模版下载（MUST）

- 提供 **「下载导入模版」** 按钮，文件名含业务含义，如 `BP填报导入模版.csv`
- 若有在线文档，提供可点击外链（遵守《HTML 原型外链规范》）
- 模版列结构与页面/接口字段一一对应

### 2.4 填写要求（MUST）

- **「查看模版填写要求」** 链接或按钮，打开二级弹窗
- 二级弹窗含 **列说明表** + **填写要求列表**（≥3 条）

### 2.5 上传与确认

- 支持 `.xlsx`、`.xls`、`.csv`（按业务约定）
- 原型可禁用真实解析，但须保留 UI 与「确认导入」按钮
- 导入结果 Toast 或弹内提示：成功 N 行、失败 M 行

---

## 3. 视觉（对齐 Ant Design / 现网后台）

| 元素 | 要求 |
| --- | --- |
| 弹窗宽度 | 主弹窗 `min(560px, 96vw)`；填写要求 `min(720px, 96vw)` |
| 关闭钮 | 标题栏右上角 ×（见《弹层与对话框-关闭按钮》） |
| 说明区 | 浅底 `#fafafa` 或正文 13px `#475569` |
| 主按钮 | 下载模版可用主色；确认导入在 footer 右侧 |
| 上传区 | 虚线框 +「上传已填写的模版文件」文案 |

---

## 4. 原型落地

- 优先使用 **`ImportModalKit.mount(config)`**（`文件夹/规范/assets/import-modal-kit.js`）
- 每个业务的 `config` 须包含：`title`、`introHtml`、`templateFileName`、`columns`、`requirements`、`downloadCsvRows`（可选，用于原型生成 CSV）

## 6. BP 管理专用说明（示例）

**BP 填报导入模版** 建议列：

| 分组 | 列 | 必填 |
| --- | --- | --- |
| 主键 | 年份、区域、渠道、SKU | 是 |
| 人员 | Sales（多人英文逗号分隔） | 否 |
| 全年 | 全年销量、全年销售额、全年毛利 | 是 |
| 1–12 月 | 每月销量、销售额、毛利（列名如 `1月销量`） | 是 |

导入后：更新当前用户有权限的 SKU 行；已提报行是否可覆盖由业务规则说明。
