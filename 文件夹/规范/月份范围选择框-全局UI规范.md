# 月份范围选择框 — 全局 UI 规范

> **适用范围**：业务按 **自然月** 聚合、筛选、列展示时（如 **销量预测** 主工作台「月份范围」、预测配置「月份范围」），须使用本规范控件，**不得**用「日期范围（按日）」组件代替（避免 `YYYY-MM-DD 至 YYYY-MM-DD` 与标签「月份范围」不一致）。  
> **与日期范围的关系**：视觉与交互 **对齐**《日期范围选择框-全局UI规范》（日历前缀、清空、主色描边、双面板、阴影），但 **数据粒度为月**，展示与存储为 **`YYYY-MM`**。  
> **技术实现**：原型阶段使用 **`文件夹/规范/assets/month-range-picker.js`**（`MonthRangePicker.mount`）。  
> **配套规则**：`.cursor/rules/month-range-picker.mdc`。

---

## 1. 触发器（收起态）

| 项目 | 要求 |
|------|------|
| 外框 | 白底、浅灰描边；聚焦/展开时主色描边（如 `#1677ff`）及浅外发光，与日期范围一致。 |
| 左侧图标 | **日历图标**（线框），灰色。 |
| 展示文案 | 已选：**`YYYY-MM - YYYY-MM`**（中间为 **半角连字符 `-`**，两侧 **空格**，与参考图一致，如 `2026-01 - 2026-04`）。 |
| 选择过程中 | 可先显示 **`YYYY-MM - …`**，直至选满结束月。 |
| 未选 | 占位如「请选择月份范围」，浅灰字。 |
| 右侧 | 有值或部分选择时显示 **清空（×）**。 |

参考图：**`月份范围选择框-参考图-收起态.png`**、**`月份范围选择框-参考图-销量预测场景.png`**（红框处应对齐为月份格式，而非按日；图示页面为 **销量预测** 主工作台场景）

---

## 2. 下拉面板（展开态）

| 项目 | 要求 |
|------|------|
| 结构 | **左右双面板**，中间 **竖向浅灰分隔线**；整体白底、圆角、轻阴影。 |
| 左/右标题 | **`YYYY 年`**（如 `2026 年`、`2027 年`），默认展示 **连续两个自然年**（左年、右年 = 左年+1）。 |
| 导航 | **左面板左侧 `«`**：两个年份同时 **减 1**；**右面板右侧 `»`**：两个年份同时 **加 1**（与 Ant Design 月份范围双年视图一致）。 |
| 月格 | 每年 **3 行 × 4 列**，文案 **`一月`～`十二月`**（或团队统一简称，须全站一致）。 |
| 选中态 | **起止月**可用 **实心主色块**（白字）；中间月可用 **主色字** 或浅底表示范围内（与参考图一致即可）。 |
| 交互 | **第一次点击**定起始月，**第二次点击**定结束月；若第二次早于第一次则自动交换。选满后收起并触发变更。 |
| 层级 | 面板 `z-index` 高于同区筛选条；在弹窗内时使用 `400+`。 |

参考图：**`月份范围选择框-参考图-双年展开.png`**

## 3. 数据格式与接口

- 展示与组件回传：**`YYYY-MM`**（字符串）。  
- 与后端/老字段 **`YYYYMM`** 互转：去掉或补上中间 `-` 即可（脚本提供 `ymToYyyyMm` / `yyyyMmToYm`）。  
- **禁止**在「月份范围」标签下以 **`YYYY-MM-DD`** 作为默认展示格式。

---

## 4. 何时用「日期范围」、何时用「月份范围」

| 场景 | 控件 |
|------|------|
| 按自然日（合同日、发货日、生效日） | 《日期范围选择框-全局UI规范》+ `date-range-picker.js` |
| 按自然月（预测月、财务月、报表月） | 本规范 + `month-range-picker.js` |

---

## 5. 前端工程（非原型）

- **Ant Design**：`DatePicker.RangePicker`，`picker="month"`，`format="YYYY-MM"`。  
- **Element Plus**：`el-date-picker`，`type="monthrange"`，`value-format="YYYY-MM"`。

---

## 6. 跨项目复用

1. 复制 `assets/month-range-picker.js` 与本规范、参考图。  
2. 复制 `.cursor/rules/month-range-picker.mdc`。  
3. HTML 中先引入脚本，再 `MonthRangePicker.mount`。
