# 弹层与对话框 · 关闭按钮（全局 UI 规范）

适用于：本仓库内 **HTML 原型**、**说明版原型**、以及后续生成的单页需求原型中，一切带蒙层或浮层的 **Modal / Dialog / Drawer 标题栏**。

## 1. 图标关闭（×）位置（强制）

- **必须**将「仅图标、无文案」的关闭控件（`×` / `close` icon）放在 **标题栏最右侧**（视觉上右上角），与顶栏、右内边距对齐。
- **禁止**因布局原因将 × 置于标题栏水平居中或标题与右边缘之间漂浮。
- 若标题栏使用 `display: flex` 且需在关闭钮旁挂载 **红点说明**等额外节点，**必须**将「× + 附属说明控件」包在同一容器内（例如 `.xxx-hd-actions` / `.mh-close-group`），与标题分列：**左侧标题区（可 `flex:1`）**、**右侧操作组（`margin-left: auto` 或等价）**，避免 `justify-content: space-between` 下出现 **三个平级 flex 子项** 导致 × 被挤到中间。

## 2. 文案按钮「关闭」（建议）

- 底部或页脚的 **「关闭」「取消」** 可与顶部 × **并存**；顶部 × 负责快速退出，底部按钮负责取消未保存操作等语义时，须在需求中区分。
- 仅底部有「关闭」、无顶部 × 时，适用于极简弹层；若弹层较高或表单较长，**仍建议**保留标题栏 ×，以符合用户习惯。

## 3. 无障碍与热区

- 图标关闭须具备 `aria-label="关闭"`（或等价文案）。
- 建议可点击区域不小于 **32×32px**（或通过 padding 扩大热区）。

## 4. 与红点说明（prototype-anno-kit）的关系

- 使用 `initProtoAnnos` 且对关闭按钮采用 `attach: "afterend"` 挂载红点时，**必须**保证红点与 × 同属上述「右侧操作组」容器，不得作为标题栏的第三个平级 flex 子项单独排列。
