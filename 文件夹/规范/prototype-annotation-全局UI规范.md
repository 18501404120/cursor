# Prototype Annotation 全局 UI 规范

> **适用范围**：所有需要给评审、开发、测试说明页面逻辑的 HTML 原型页。  
> **目标**：统一“页面说明”与“红点标注”的交互、文案结构和视觉样式，避免每个页面各写各的。  
> **核心原则**：页面说明默认收起；红点说明面向开发/测试；文案只描述当前页面真实存在的能力。

---

## 1. 页面说明区

- 页面说明必须通过一个明确按钮触发，例如 `查看页面说明`。
- 默认状态必须为**不展示**，点击后展开，再次点击可收起。
- 页面说明内容建议放在页首或首屏第一个面板内，避免与主业务内容混杂。
- 页面说明分两层：
  - `原型标注1｜页面说明`：给业务/评审看，解释这个页面是干什么的。
  - `原型标注1｜智能标注`：给开发/测试看，拆解页面模块、联动逻辑、验收点。

---

## 2. 红点标注交互

- 红点标注用于**开发/测试逻辑说明**，不要和业务字段提示混用。
- 触发方式统一使用**数字红点**，例如 `1 / 2 / 3`，点击后展示说明浮层。
- 浮层默认隐藏，点击红点后显示；点击空白区域后关闭。
- 同一时刻仅展示一个红点说明浮层。
- 红点说明要挂在真实需要解释的字段、分组标题、图例说明、明细表标题等位置。
- 每个红点说明都必须带**编辑**、**删除**功能；删除需二次确认。
- 截图示例只用于参考浮层里的文字大小、排版节奏和逻辑描述方式，不改变红点必须显示数字的规则。

---

## 3. 红点标注视觉样式

- 红点：红底白字、圆形、尺寸小、紧贴标题或字段名右侧，内容始终为数字编号。
- 浮层：
  - 淡红背景
  - 红色边框
  - 12px 左右圆角
  - 有阴影
  - 标题深红色加粗
  - 正文使用编号列表，行距舒展，便于测试逐条核对

推荐视觉特征：

- 红点尺寸：`14px ~ 16px`
- 浮层宽度：`420px ~ 460px`
- 标题字号：`12px`，加粗
- 正文字号：`12px`
- 行距：`1.65 ~ 1.8`

---

## 4. 红点文案结构

每个红点说明都应尽量使用同一结构：

1. 第一行写**标题**，格式建议：`XX逻辑：` / `XX筛选逻辑：` / `XX展开逻辑：`
2. 后续使用**编号列表**逐条描述规则。
3. 一条规则只讲一件事，避免一条里塞多个条件。
4. 文案必须是“可验证”的，便于测试据此核对。

推荐写法：

```text
日期范围筛选逻辑：
1. 默认值为“上月开始日期 ~ 上月结束日期”。
2. 日期控件为范围选择，不允许结束日期早于开始日期。
3. 若跨月，财务维度行在时间与结账粒度上的拆分与展示规则见明细表「财务维度」说明。
```

不推荐写法：

- “这里是日期筛选，支持按条件过滤数据。”
- “大概会跟别的图表联动。”
- “后面再补逻辑。”

---

## 5. 页面说明文案要求

- 先讲页面定位，再讲模块分工，再讲联动关系。
- 不要把开发实现细节直接塞给业务视角页面说明。
- 页面说明必须贴合当前页面真实能力。
- **页面没有的能力不要写**。

强制要求：

- 没有编辑功能的页面，不得写“编辑”。
- 没有删除功能的页面，不得写“删除”。
- 没有新增入口的页面，不得写“新增”。
- 没有导出能力的页面，不得写“导出”。
- 上述限制只针对**业务页面真实功能**；标注系统自身的“编辑/删除说明”能力必须保留。

---

## 6. 智能标注表建议结构

智能标注建议用表格承载，列建议如下：

- `标注位`
- `页面区域`
- `当前作用`
- `联动逻辑`
- `验收点`

如果页面更偏流程型，也可替换为：

- `标注位`
- `触发动作`
- `系统行为`
- `异常/拦截提示`
- `验收点`

---

## 7. 适配建议

- **看板页**：重点写筛选、指标卡、图表、结构分析、下钻明细之间的联动。
- **列表页**：重点写筛选、列表字段、操作列、批量操作、状态流转。
- **表单/配置页**：重点写字段规则、校验、保存、发布、生效逻辑。
- **汇报型页面**：重点写页面定位、章节作用、汇报结构、管理层关注点。

---

## 8. HTML 原型建议实现

推荐最小结构：

```html
<div class="panel-head">
  <div class="panel-title">页面说明</div>
  <button type="button" class="anno-toggle">查看页面说明</button>
</div>
<div class="anno-panel" hidden>
  <!-- 页面说明 -->
</div>
```

红点说明推荐最小结构：

```html
<span class="req-dot" data-req-key="filter-date-range">1</span>
<div class="req-popover" id="reqPopover"></div>
```

---

## 9. 验收清单

1. 页面说明默认隐藏，点击按钮才展开。
2. 红点点击后能展示说明，点击空白能关闭。
3. 红点说明标题清晰、正文为编号列表。
4. 每个红点说明都能编辑、删除，删除后当前版本不再显示。
5. 文案与当前页面真实能力一致。
6. 智能标注能支持开发和测试直接据此验收。
