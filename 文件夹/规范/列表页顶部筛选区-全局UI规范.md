# 列表页顶部筛选区 — 全局 UI 规范

> **适用范围**：ERP / 管报 / 主数据 / 配置类页面的**列表、看板**顶部筛选条（含地理、渠道、场景品类、产品、销售、时间等维度）。  
> **默认强制**：在本仓库内**生成或改版 HTML / Vue / React 原型**时，**须默认遵循本规范**；仅当需求说明或用户**明确标注为特殊场景**时可偏离，且须在页面或 PRD 中注明例外项。  
> **唯一参考实现**：**`文件夹/规范/全局筛选与列表示范页.html`**（样式类名、交互逻辑以该页为准，勿另起一套视觉）。  
> **配套 Cursor 规则**：`.cursor/rules/list-page-filter-bar.mdc`（`alwaysApply: true`）。

## 2. 整体布局（强制）

| 项目 | 要求 |
|------|------|
| 结构 | 筛选项**单行横向**排布（可 `flex-wrap` 换行）；**标签在左、控件在右**；垂直居中 |
| 背景 | 筛选区白底 `#fff` |
| 分隔 | 筛选区底部 **1px 浅灰线**（如 `#f0f0f0`），与下方表格/工具栏分区 |
| 项间距 | 行内 `gap`：**12px**（纵）× **16px**（横）；不得使用过大横向间距（如 24px）导致单行过稀 |
| 查询 | **「查询」主按钮**放在筛选项行末（对比范围、日期范围之后），右对齐习惯与示范页一致 |
| 默认值 | 枚举类下拉默认选项文案 **「全部」**（`value=""`），不得省略空选项 |

## 3. 控件宽度（强制 · 禁止过宽）

筛选项须**紧凑**，避免单行只能放下少量字段。下列为示范页实测 token，实现时允许 ±8px，但**不得**明显宽于下表。

| 控件类型 | 宽度要求 | 说明 |
|----------|----------|------|
| **普通单选下拉**（区域、国家、渠道、店铺、TL、Sales 等） | `min-width: 88px`；`max-width: 120px` | 外包 `.ctl-wrap`，右侧留清除钮空间 |
| **SKU 模式**（组合框左侧） | **固定 `68px`**（`flex: 0 0 68px`） | 仅容纳「模糊」「精确」「8位搜索」 |
| **SKU 输入**（组合框右侧） | **约 `112px`** | 占位「请输入SKU」；精确模式语义仍为 MSKU |
| **场景品类**触发器 | `min-width: 140px`；`max-width: 168px` | 文案过长 `ellipsis` |
| **场景品类**浮层左列（场景） | **约 `132px`** | 右列品类 **约 `168px`** |
| **品线** Tag 触发区 | `min-width: 120px`；`max-width: 200px` | 见《产品信息筛选区》§2.3 |
| **月份范围 / 对比范围** | 触发器 `min-width: 168px`；`max-width: 180px` | 使用 `month-range-picker.js` |

**禁止**：无上限 `min-width: 200px` 的筛选项；SKU 模式下拉随文案自动撑到 100px 以上。

## 4. 可清除单选下拉（强制）

凡 **`<select>` 类单选筛选**（含区域、国家、渠道、店铺、TL、Sales 及业务扩展枚举），须支持**一键清除已选值**（回到「全部」）。

### 4.1 结构

```html
<span class="ctl-wrap">
  <select id="fltRegion" class="ctl">…</select>
  <button type="button" class="ctl-clear" hidden aria-label="清除区域">×</button>
</span>
```

### 4.2 样式

| 项目 | 要求 |
|------|------|
| 清除钮 | **透明背景**；字色 `rgba(0,0,0,.25)`；悬停 `.45`；字号约 `12px` |
| 位置 | 位于下拉**右侧、系统箭头左侧**（`right: 22px` 量级） |
| 显示 | **仅当 `select.value !== ""` 时显示**；未选时 `hidden` |
| 下拉内边距 | `select` 增加 `padding-right: 36px`，避免文字与 × 重叠 |

### 4.3 行为

1. 点击 ×：`select.value = ""` → 触发 **`change` 事件**（须 `bubbles: true`），以驱动区域↔国家、渠道↔店铺等联动。  
2. 选项变更后同步清除钮显隐（示范页函数 `syncClearableSelect` / `wireClearableSelects`）。  
3. **`fillSelect` 刷新选项列表后**须再次同步清除钮状态。

### 4.4 场景品类触发器

场景品类为**自定义组合控件**，须在触发器行使用 **`.sc-cat-clear`**，规则同 §4.2；有任意已选叶子时显示 ×，点击清空**全部场景**下的品类选择（`selectedByScene = {}`）。

**不要求**：SKU 右侧文本框、月份范围控件上的 ×（除非 PRD 单独要求）；本规范默认仅覆盖**下拉类**与**场景品类触发器**。

## 5. 场景 × 品类组合控件（强制）

当页面同时筛选**场景**与**品类**且支持**跨场景多选记忆**时，须使用**双列浮层**（非两个独立下拉）。

| 项目 | 要求 |
|------|------|
| 布局 | 左列场景列表；右列当前场景的品类复选框 |
| **「全部」行** | 右列**顶部**固定一行 **「全部」** 复选框（`.sc-cat-all`）；勾选=当前场景下品类全选；取消=全不选 |
| 半选 | 部分品类选中时，「全部」为 **indeterminate** |
| 单选品类 | 勾选/取消后刷新「全部」状态（可 `renderCatCol()`） |
| 触发器文案 | 未选：「请选择」；≤2 项：`场景/品类` 拼接；更多：「已选 N 项」 |
| 清除 | 触发器 × 清空所有场景已选（见 §4.4） |
| 业务 | 跨场景勾选记忆、与列表过滤关系见《销售主数据-全局业务规范》§12.2 |

## 6. SKU 组合与其它产品维度

- **SKU 模式 + 输入**：形态、模式语义、与 model 不级联等，以 **`产品信息筛选区-全局UI规范.md` §2.2** 为准；**宽度**以本文 §3 为准（模式 **68px**）。  
- **品线多选**：§2.3 Tag + 下拉勾选。  
- **区域↔国家、渠道↔店铺**：§2.4、§2.5 + 基础数据 JSON。

## 7. 原型生成检查清单（Agent / 人工）

生成或改版带筛选区的原型前，逐项自检：

- [ ] 已阅读本文档 + 《产品信息筛选区》+ 相关业务规范 §12  
- [ ] 单选下拉均包 `.ctl-wrap` + `.ctl-clear`，选中后可清除  
- [ ] 下拉宽度在 §3 范围内；SKU 模式 **68px**  
- [ ] 场景品类含右列 **「全部」** 与触发器清除  
- [ ] 筛选项横向间距 **16px**；底部分隔线存在  
- [ ] 月份/日期控件用规范 assets，宽度约 **168～180px**  
- [ ] 浮层不被表格 `overflow` 裁切（必要时 `document.body` portal）  
- [ ] 特殊场景偏离已在 PRD/页面说明中**显式写出**
