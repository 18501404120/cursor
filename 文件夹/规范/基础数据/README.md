# 规范基础数据

本目录为**全局主数据** JSON/CSV，供原型、需求与实现引用；业务含义见 **`../销售主数据-全局业务规范.md`**。

| 文件 | 用途 |
|------|------|
| `销售基础信息_v1.json` | MSKU×店铺明细（主键：`msku` + `店铺名称`；来源 Excel 导出） |
| `销售基础信息_原型子集_v1.json` | 上述宽表的子集，供营销费用等原型 fetch 失败时兜底 |
| `销售主数据索引_v1.json` | model（SKU 前 5 位）、SKU 去重列表 |
| `全局筛选示范数据_v1.json` | 《全局筛选与列表示范页》100 条列表数据 |
| `店铺国家映射_v1.json` | 店铺 → 国家/区域（独立站-EU、Govee_DE_1 → DE） |
| `场景品类基础数据_v1.json` | 场景 → 品类树 |
| `渠道店铺基础数据_v1.json` | 渠道 → 店铺树（GoveeLife 店铺为 `Goveelife_*`） |
| `区域国家基础数据_v1.json` | 区域 → 国家树 |
| `新品标签基础数据_v1.json` | 新品标签枚举 |

更新销售宽表后请同步修订 `销售主数据索引_v1.json`，并在主规范文档中递增版本说明。
