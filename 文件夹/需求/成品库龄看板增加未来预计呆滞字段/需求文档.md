# 需求文档（改动点说明）

**需求名称**：成品库龄看板增加未来预计呆滞字段  
**文档版本**：v1.0  
**关联评估**：见同目录下 `需求评估.md`

---

## 一、需求概述

- **一句话**：在 ERP 成品库龄看板中新增「未来某日预计呆滞」及占比（D/G）的展示与计算，并支持按未来日期、forecast 类型（已审核/待审核）、负责人筛选。
- **涉及 ERP 模块**：库存与仓储管理、数据与大屏（呆滞料分析 / 库存健康度）
- **使用角色/场景**：计划、供应链、仓库等查看成品未来呆滞风险，用于调仓、促销、清仓决策；使用频率建议为每日或按周查看。

---

## 二、改动范围总览

| 类型 | 说明 |
|------|------|
| 新增 | ① 筛选条件：未来某日、forecast 类型（已审核/待审核）、负责人；② 展示字段：当前呆滞 A、预计转呆滞 B、预计可消耗 C、未来剩余呆滞 D、当前库存 E、预计可入库 F、未来总库存 G、预计未来呆滞 D/G；③ 上述字段对应的计算与取数逻辑 |
| 修改 | 成品库龄看板页面的筛选区与表格列配置，在现有库龄/呆滞能力上扩展，不改变原有字段含义与口径 |
| 删除/下线 | 无 |

---

## 三、具体改动点

### 3.1 页面 / 功能入口

- **位置**：数据中心（或库存分析）→ 成品库龄看板（现有入口不变）
- **改动**：  
  - 在现有看板**筛选区**增加：未来日期选择器、forecast 类型（已审核 / 待审核）切换、负责人下拉/搜索。  
  - 在现有**表格区**增加一列或一块「未来预计呆滞」相关字段（见 3.2）；若采用 Tab 或折叠区，需在文档中说明展示形式。

### 3.2 字段 / 数据项

- **新增字段**（均为「未来某日」视角，日期由筛选条件决定）：

| 字段名 | 含义 | 计算/取数逻辑 | 展示格式 | 是否可筛选/排序 |
|--------|------|----------------|----------|------------------|
| 当前呆滞 A | 当前时点已呆滞库存 | 沿用现有呆滞口径与取数 | 数量 | 可与现有看板一致 |
| 预计未来某日会转呆滞 B | 到未来某日前会转为呆滞的量 | 待确认：若无现成数据可首期 B=0 或简单规则 | 数量 | 否 |
| 预计到未来某日可消耗 C | 按 forecast 累计消耗 | 依赖 forecast（已审核/待审核按筛选） | 数量 | 否 |
| 预计未来某日剩余呆滞 D | A+B−C | 计算项 | 数量 | 否 |
| 当前库存 E | 当前可售/在库库存 | 沿用现有库存口径 | 数量 | 可与现有一致 |
| 预计未来某日可入库 F | 在途/计划入库到该日 | 依赖在途或采购计划数据 | 数量 | 否 |
| 未来某日总库存 G | E+F−C | 计算项 | 数量 | 否 |
| 预计未来呆滞占比 | D/G | 计算项，G=0 时展示规则见 3.6 | 百分比 | 可排序 |

- **修改字段**：无（现有库龄、呆滞等字段不改动）。

### 3.3 筛选 / 查询条件

- **新增筛选**：  
  - **筛选日期（未来某日）**：日期选择器，可选范围待确认（建议如未来 7/30/90 天内）；默认值待确认（如当前日+7 天）。  
  - **Forecast 类型**：单选或 Tab「已审核 forecast / 待审核 forecast」，决定 C 的取数来源。  
  - **负责人**：下拉/搜索，可选值来源于组织架构或库存责任人主数据；与现有看板「负责人」一致则复用，否则新增并明确数据来源。
- **修改筛选**：若现有看板已有「负责人」，需确认是否与本需求为同一口径；若有差异需在需求文档中说明。

### 3.4 业务逻辑与规则

- **计算逻辑**：  
  - D = A + B − C；G = E + F − C；预计未来呆滞占比 = D / G（按筛选的「未来某日」与 forecast 类型、负责人维度计算）。  
  - 计算粒度：与现有成品库龄看板一致（如按 SKU+仓，或按品类/负责人聚合）；若 B 首期无数据，则 B=0，D=A−C，需在界面或评估中说明「未含预计转呆滞」。
- **权限与可见性**：按负责人筛选时，是否仅能看到本人负责的数据（与现有成品库龄看板权限一致，待确认）。

### 3.5 数据来源与依赖

- **依赖数据**：  
  - 当前呆滞 A、当前库存 E：现有库存/呆滞口径与表。  
  - 预计可消耗 C：**Forecast**（已审核/待审核来源与取数逻辑待与数据/业务确认）。  
  - 预计可入库 F：在途或采购/生产计划（具体表或接口待确认）。  
  - 预计转呆滞 B：待确认；首期可为 0 或简单规则。  
  - 负责人：组织架构或库存责任人主数据。
- **接口或表**：forecast 来源、在途/计划入库来源、负责人主数据来源待与数据/研发确认后补充。
- **刷新频率/时效**：待确认（如 T+1 或准实时）；影响展示与性能方案。

### 3.6 异常与边界

- **无数据时**：某 SKU/仓无 forecast 或无可入库时，C 或 F 为 0 按公式计算；D、G 为 0 或负数时展示规则待定（如展示「-」或 0，并提示「无有效预测」）。  
- **G=0**：预计未来呆滞占比 D/G 不计算，展示「-」或「N/A」，避免除零。  
- **多仓/多 SKU**：与现有成品库龄看板一致，覆盖成品维度；是否先上部分仓或全仓待与业务确认。

- [ ] 切换「待审核 forecast」后，C 及 D、G、D/G 随数据源变化。

- [ ] G=0 或数据缺失时无报错、展示符合 3.6。
- [ ] 性能：在约定数据量级下加载时间可接受（具体指标待与业务确认）。
