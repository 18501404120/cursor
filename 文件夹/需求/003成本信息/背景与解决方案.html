全渠道成本口径 · 思路与方案

依据 《msku成本信息表逻辑》 · 覆盖亚马逊、Shopify、APP 商城、商超 3P 及后续管报 / DP

一句话：全渠道共用同一套费用项名字和计算公式，定义落在 MSKU 成本信息。各渠道看板、经营分析、管报只读该月快照做滚动。渠道差异只换取值来源；没有的项记 0，不另起名字、不另写公式。

底表逻辑见钉钉表（2026-08-18 起维护）。本页把表内口径与落地路径写成可评审的方案说明。

1 · 现状

各渠道已经在看利润，但底层不是同一套成本定义。

MSKU 成本信息偏旧 页面现网主要按亚马逊单件公式算毛利：售价 − 出货授权价 − 头程 − FBA − 佣金 − 其他 − VAT − 退货。仓储、收单、营销、海外仓操作未进公式，费用项不全。
看板各自滚动 大促、日利润、自营经营分析各自扣项。自营经营分析（Shopify）现网为：净销售 − 其他 − 采购 − 头程 − 尾程 − 提现 − 广告 − 预留 − 关税，汇总再减 Seel×6%。货值拆成采购 / 关税 / 预留，不直接读底表出货授权价。
渠道缺项表现为 0 或手填 Shopify / 商城在本页仍走亚马逊公式，内部账号常无 FBA、佣金预测，对应列多为 0。业务侧用线下 Excel 补尾程、收单、仓储等，才能估毛利。
后续消费方要对齐 管报上线后利润逻辑按标准费用项看齐；明年 DP 模板按同一套释放。定价、折扣、促销预估需要和全渠道同一指标对得上。

财报是滞后约半个月的结果分类，不是指标定义。预估利润点对齐的是底表费用项，不是财报分类差异。

2 · 全渠道思路

先锁定义，再换取值，最后让看板消费。

1. 公共字段同一口径
出货授权价、头程、RP / Baseline、还价折扣等全渠道都有的字段，名字和公式锁定。分类差异可以存在，指标定义不能各写一套。
2. 渠道差异只换数据源
某渠道多出来的项可以加，并写清口径；某渠道没有的项保留列、记 0。例如亚马逊无收单、自营无 FBA。
3. 底表算单件，看板滚期间
MSKU 成本信息存 Listing × 渠道 × 自然月的完整成本。看板用单件 × 销量或发货、费率 × 净销售。折扣 / Deal / Seel 跟订单走，不进底表标准单件。
4. 预估与关账同一结构
未关账用预估或上一关账月结转；关账后用财务 / 物流实际覆盖该月。来源打标，不另做第二套公式。
  • 面向使用：定价、调价、促销时，在 MSKU 成本信息按该月快照试算毛利；经营分析等看板展示期间利润。
  • 面向系统：经营分析、大促、广告、管报、明年 DP 复用同一费用项，只换各自数据源。

5 · 关键口径

数量、仓库、新品都不改变字段定义，只改变取值或滚动方式。

规则 口径
出货授权价是单 PCS 价格 公式见上表，不含头程。期间出货总成本 = 单价 × 出货数量（或锁定的销量口径）。发货减退货属于看板滚动，不改字段本身。
头程与授权价分列 沿用公司头程分摊逻辑。底层已按仓库、物流方式分开算。渠道差异换仓库 / 账单，不换「头程」这个费用项。
新品无 12 个月物流历史 在底表该月快照写入预估头程 / 尾程。有货件或关账后覆盖。看板只读结果。US / CA、EU 取值不同时在底表标注，不另开公式。
月份快照 每个 Listing × 渠道 × 自然月存一份完整成本。进入新月先复制上月，再回写可刷新项。历史月读落存，当月可刷新。
试算与看板怎么配合： 调价、促销时在 MSKU 成本信息选所属月，按售价减标准费用项得到单 PCS 毛利。经营分析把该月单件按销量或发货滚成期间利润，与管报费用项一一对应。
6 · 落地步骤

按层推进。渠道看板改造发生在底表字段就绪之后。

阶段 内容 结果
A. 锁口径 确认标准费用项、锁定公式、分渠道取值表。公共字段跟《msku成本信息表逻辑》走。 各渠道评审用同一张表
B. 补底表 MSKU 成本信息增加所属月；补尾程、仓储、海外仓、收单、营销等列。新品建档写预估。无则 0。 单 PCS 试算可用，定价 / 促销可先离开纯 Excel
C. 看板改读底表 经营分析、进销销售、大促 / 广告等改为读该月快照滚动。财务关账回写后重算对应月。 各渠道看板利润点可对齐
D. 管报 / DP 复用 管报与明年 DP 模板使用同一费用项，只换数据源或补 0 项。 B / C 不因后续释放作废
历史月： 上线后按月重算可回溯月；未关账月用预估或上月结转。只从改完当天生效会造成年内口径断裂，默认不采用。
7 · 待确认

下列项只影响取值，不改变「先底表、后看板」和「公共字段同一公式」。

  1. 滚动驱动：出货授权价、头程在看板乘销量还是发货件数，全渠道锁一种。
  2. 费率分母：收单、营销、海外仓用净销售还是含税销售额；EU 0.8% 覆盖哪些欧洲站。
  3. 仓储分母：亚马逊是否锁定为大促看板销量；销量为 0 时单件记 0。
  4. 新品头程预估：各渠道线下估算规则写入底表，并与物流对齐。
  5. 尾程关账：财务实际、上月结转、新品预估的最终取数页。
  6. 自营平台佣金：是否独立保留，或由收单覆盖。
  7. 范围：TTS、商超 3P 是否同期进底表；3P 仓储 / 海外仓取值。
