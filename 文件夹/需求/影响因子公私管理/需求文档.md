# 需求文档（改动点说明）

**需求名称**：影响因子（超参数因子）公私管理  
**文档版本**：v1.0  
**关联评估**：见同目录下 `需求评估.md`

---

## 一、需求概述

- **一句话**：在销量预测相关的**超参数因子（影响因子）**管理中，支持因子分为**公有**与**私有**：私有仅创建人可见与选用；公有全员（或约定范围）可见但仅指定角色可创建/编辑，并与现有「批量应用到 MSKU、已应用不可删、可改时间范围」等能力打通，解决因子库混乱与重复建设问题。
- **涉及 ERP 模块**：数据与大屏 / 预测与配置中心（规则与配置中台）；与商品多 SKU、多店铺/国家筛选相关，不直接改动订单履约与库存事务。
- **使用角色/场景**：运营/计划人员日常为 MSKU 批量挂载调整因子；TL/STR（或品线负责人，**待确认**）维护标准公有因子；个人临时事件用私有因子，避免污染公共库。

---

## 二、改动范围总览

| 类型 | 说明 |
|------|------|
| 新增 | 因子主数据维度：**因子类型（公有 / 私有）**；新建时的类型选择与校验；列表/选择器上的**类型筛选、权限过滤**；公有因子的**创建/编辑权限**（与现有角色体系绑定，细则待确认） |
| 修改 | **超参数因子管理页**：列表列字段、筛选项、新建/编辑表单；**批量设置参数因子**弹窗中的因子选择列表数据源与过滤规则；可选：**因子库时间范围筛选**（会议提及用于减少历史噪声） |
| 删除/下线 | 无整体下线；**已应用到 MSKU 的因子仍不可物理删除**（沿用会议结论），是否增加「归档/停用」待确认 |

## 三、具体改动点

### 3.1 页面 / 功能入口

- **位置**：配置中心 → 超参数因子管理（名称以系统现有菜单为准）；以及 MSKU 维度的「批量设置参数因子」等入口中的因子选择器。
- **改动**：
  - 因子**新建**：增加必选字段 **因子类型**：`公有` / `私有`。
    - 选 **私有**：保存后仅创建人在列表与选择器中可见（**他人不可见他人私有因子**）。
    - 选 **公有**：保存后进入公有池，对可见范围内的用户展示；**仅具备「公有因子维护」权限的角色可创建/编辑**（具体角色名与录音对齐：**待确认** TL/STR/品线负责人）。
  - 因子列表：增加 **类型**、**创建人**（私有尤其需要）、**生效时间范围** 等展示；支持 **按类型 / 关键词 / 时间范围** 筛选（时间筛选逻辑待与业务定：默认是否「仅未来生效」）。
  - 「批量设置参数因子」：因子下拉/勾选列表**仅展示当前用户有权查看的因子**（公有 + 本人的私有）。

### 3.2 字段 / 数据项

| 字段名（建议） | 含义 | 计算/取数逻辑 | 展示格式 | 筛选/排序 |
|----------------|------|----------------|----------|-----------|
| 因子类型 | 公有 / 私有 | 用户新建时选择；私有记录创建人 ID | 标签 | 是 |
| 创建人 | 私有因子归属 | 登录用户 | 姓名/账号 | 可选 |
| 系数 | 对预测销量乘法系数 | 现有逻辑 | 小数 | 否 |
| 作用时间范围 | 生效起止 | 现有逻辑；允许修改时间（会议确认可改时间） | 日期区间 | 是 |
| 是否已应用 | 是否已被任意 MSKU 引用 | 关联应用表非空则 true | 是/否 | 可选 |
| 因子名称/说明 | 业务描述 | 手工录入 | 文本 | 关键词搜索 |

### 3.3 筛选 / 查询条件

- **新增筛选**：
  - **因子类型**：全部 / 公有 / 我的私有（或「私有」且仅本人，**待确认**是否需「本组私有」）。
  - **关键词**：名称/说明模糊搜索（公有池与私有池各自范围内搜索）。
  - **时间范围**：如「生效结束日期 ≥ 今天」或自定义区间，用于缩小因子库（会议提出的治理手段）。
- **默认值**：建议默认「类型=全部（在权限过滤后）」或「仅未来生效」之一，**待与业务确认**。

### 3.4 业务逻辑与规则

- **可见性**：
  - **公有因子**：对系统约定的可见范围用户可见（默认全公司或按组织，**待确认**）。
  - **私有因子**：仅创建人可见、可选、可编辑（是否允许管理员代管，**待确认**）。
- **创建权限**：
  - 所有具备因子管理入口权限的用户：可创建 **私有** 因子（**待确认**是否全员或仅计划角色）。
  - **公有** 因子：仅 **公有因子维护角色** 可创建；无权限用户界面隐藏「公有」选项或选择后提示无权限（具体交互待 UX 定）。
- **编辑权限**：
  - 公有因子：全员可见但 **仅维护角色可编辑**（会议：不是大家都能编辑）。
  - 私有因子：仅创建人可编辑。
- **删除规则**（延续会议）：
  - **已被应用到 MSKU 的因子**：不允许删除（保留历史可追溯）。
  - **未应用过的因子**：允许删除（如建错）。
- **时间范围**：允许修改已有因子作用时间，不必强制新建；若审计要求保留痕迹，可考虑变更日志或重大变更时复制新因子——**待与业务确认**。

**计算逻辑**：因子对预测的影响仍为会议所述**多因子连乘**（与现有一致），本需求不改变乘法规则，仅改变因子库的治理与可见性。

### 3.5 数据来源与依赖

- **依赖数据**：用户账号与角色/品线负责人关系（权限系统）；MSKU 与因子应用关系表；现有预测/详情中对因子的引用方式。
- **接口或表**：在现有因子表增加类型、创建人、可见性策略字段；列表与选择器接口增加过滤参数。**表名/接口名待研发确认**。
- **刷新频率**：配置类数据，保存后实时生效；预测重算规则沿用现有任务/调度。

### 3.6 异常与边界

- **无权限建公有**：提示「无公有因子维护权限，已为您切换为私有」或禁用选项。
- **他人私有因子**：在任何列表、搜索、批量选择中均不可见。
- **已应用因子删除**：按钮禁用 + Tooltip「已应用于 MSKU，不可删除」。
- **多仓/多平台/多 SKU**：因子仍通过 MSKU/店铺/国家等现有维度批量应用；公私类型不区分渠道，**若业务要求按站点拆分公有池，待确认后单独列需求**。

## 四、验收要点（可与提需方对齐后补充）

- [ ] 新建因子：可选公有/私有；无权限用户无法创建公有或收到明确提示。
- [ ] 用户 A 的私有因子：用户 B 在因子管理列表与「批量设置参数因子」中均不可见。
- [ ] 公有因子：可见范围内的用户可见；非维护角色不可编辑他人建的公有因子。
- [ ] 已应用到 MSKU 的因子：删除操作不可用；未应用的可删除。
- [ ] 修改因子作用时间后，已引用该因子的 MSKU 预测行为符合产品规则（与研发确认是否即时重算）。
- [ ] 时间范围/类型组合筛选后，列表结果符合预期，无越权数据。

## 五、与现有能力的关系

- **依赖的现有能力**：超参数因子管理、时间作用范围、系数、批量应用到 MSKU、预测详情中的因子说明、配置中心按 MQ 批量系数等（会议描述的现状）。
- **不影响的功能**：订单履约、仓储出入库、采购单流转；**P0/P1 预警阈值与月销量分档**若独立立项，与本需求文档可并行但验收分离。
- **会议中相关但非本子需求核心**：批量备注与达成率剔除区间、规则计算详情页、关联 SKU 手动维护等——若同一迭代交付，建议在项目计划中拆分为多个需求单便于测试。
