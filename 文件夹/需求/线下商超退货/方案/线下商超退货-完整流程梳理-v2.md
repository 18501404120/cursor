## 1. v2.1 分类口径（重要）

同一批 C 端 RMA 实物回仓后，按**货况与处置**区分，而非笼统「返修可入库」：

| 签收后处置 | 分类 | 销售退货单 | 其他入库单 |
|------------|------|------------|------------|
| **损坏报废**（无法再售） | **A-1** | ❌ 一般无 | ❌ |
| **拆配件给售后用** | **A-1** | ❌ | ✅ |
| **无瑕疵，按原 SKU 重新上架售卖** | **A-2** | ✅ | ❌ |
| 无实物、仅走账 | **A-3** | ❌ | ❌ |
| KA 季末批量滞销（全新未拆箱） | **B** | ✅ | ❌ |

**要点**

- **A-2**：退回来的商品**没有瑕疵**，可正常售卖，按**原 SKU** 重新上架 → 物流邮件同步财务 → **销售退货单**（流程与 B 类相近，制单相同）。
- **拆配件给售后**：属于 **A-1**，物流建 **其他入库单**（不是 A-2，B 类也不涉及）。
- 原 v1「A-2 仅退款」→ **A-3**。

|------|---------------|---------------|------------|------------|
| **业务动因** | C 端 RMA | C 端 RMA（无瑕疵可售） | C 端 RMA，无实物 | KA 季末滞销 |

## 3. A 类流程

### 3.1 A-1 · 退款 + 退货

**适用**

1. 签收后**损坏报废**，无法再售 → 一般**无**销售退货单、无其他入库单。  
2. **拆配件给售后用**（如灯带拆配件）→ 物流建 **其他入库单**。

**流程要点**

- 前置与 v1 相同：对账系统 / 钉钉登记 → 通知物流 → 猫头鹰仓签收。  
- 处置分支：报废 **或** 拆配件 → **其他入库单**（仅后者有 ERP 入库）。  
- 财务：核对扣款 → 货款抵扣 → 季度对账。

### 3.2 A-2 · 退款 + 退货 + 入库

**适用**：实物回仓，货品**无瑕疵**，可按**原 SKU** 正常售卖、重新上架。

**流程**（与 **B 类** 协作链一致，货况不同）

1. RMA 扣款凭证 + 商务登记，邮件通知物流。  
2. WMS 建单、签收（无瑕疵品）。  
3. 按**原 SKU** 重新上架。  
4. 物流邮件通知财务（原 SKU、数量）→ 财务手工 **销售退货单**（按签收月入账）。  
5. 货款抵扣 + 季度对账；扣款文件可能跨月陆续到达（同 B）。

**制单**：仅 **销售退货单**；**不**使用其他入库单。

### 3.3 A-3 · 仅退款

同 v2.0：沃尔玛等，无实物，只核金额，货款抵扣。

---

## 4. B 类 · 批量滞销退货

同 v1/v2.0：全新未拆箱 → **销售退货单**；与 A-2 流程相近，差异在触发原因与货况（B 为 KA 批量滞销全新品，A-2 为 C 端退回无瑕疵品）。

---

## 5. A-2 与 B 对比

| 对比项 | A-2 | B |
|--------|-----|---|
| 触发 | C 端 RMA | KA 季末滞销 |
| 货况 | 退回品**无瑕疵** | **全新未拆箱** |
| 协作 | 邮件 + WMS + 物流确认财务 | 相同 |
| 销售退货单 | ✅ 原 SKU | ✅ 原 SKU |
| 其他入库单 | ❌ | ❌ |

## 6. 管报对比摘要

```text
A-1：损坏报废（无单）| 拆配件（其他入库单）
A-2：无瑕疵原 SKU（销售退货单）— 流程同 B，货况不同
A-3：仅退款
B：全新批量（销售退货单）
```

---

## 7. 术语（v2.1）

| 术语 | 含义 |
|------|------|
| **A-1** | 损坏报废；或拆配件售后 → **其他入库单** |
| **A-2** | 无瑕疵，**原 SKU** 重新上架 → **销售退货单** |
| **A-3** | 仅退款（原 v1 A-2） |
| **销售退货单** | 原 SKU 退货入库时财务单据（A-2、B） |
| **其他入库单** | 拆配件等非原 SKU 成品入库（**A-1**） |
