## 1. v2 分类调整说明

v1 将「有实物回仓」的常规 RMA 统一归为 **A-1**，并标注「无规范 ERP 入库单」。实际业务中，同一批 C 端传导退货在签收后存在**两条处置路径**：

| 签收后处置 | v2 分类 | ERP 入库 |
|------------|---------|----------|
| 损坏无法再用 → 报废 / 仅返修不可用 | **A-1** 退款 + 退货 | ❌ 无规范入库单 |
| 返修后**可正常使用** → 需入账库存 | **A-2** 退款 + 退货 + 入库 | ✅ 有单据（见下表） |
| 无实物、仅走账 | **A-3** 仅退款（原 v1 A-2） | ❌ 无 |
| KA 季末批量滞销退回 | **B** 批量滞销退货 | ✅ 销售退货单（原 SKU 全新） |

**A-2 与 B 类**：协作流程（邮件预告 → WMS 签收 → 物流确认 → 财务制单）**基本一致**，差异主要在**货物状态**与**制单类型**；A-2 多出「拆成其他 SKU 入库」一种制单情形。

## 2. 四类场景速查对比

| 维度 | A-1 退款+退货 | A-2 退款+退货+入库 | A-3 仅退款 | B 批量滞销 |
|------|---------------|-------------------|------------|------------|
| **业务动因** | C 端 RMA，实物回仓后报废等 | C 端 RMA，返修后可再用 | C 端 RMA，无实物 | KA 未卖完协商退回 |
| **典型客户** | Costco 等高价值品 | Costco 等（返修可售分支） | 沃尔玛等多数 KA | Costco、山姆 |
| **实物回仓** | ✅ 猫头鹰仓等 | ✅ 同上 | ❌ 无 | ✅ 指定海外仓 |
| **货物状态** | 损坏为主 | 返修后可用 / 拆配件 | — | **全新未拆箱** |
| **退款方式** | 货款抵扣 | 货款抵扣 | 货款抵扣 | 货款抵扣（MA 陆续） |
| **ERP 入库** | ❌ 无规范单据 | ✅ 见 §3.2 | ❌ 无 | ✅ **销售退货单** |
| **能否再售** | ❌ 报废为主 | ✅ 原 SKU 或配件 SKU | — | ✅ 上架再售 |
| **信息入口** | KA 对账系统 + 钉钉 | 对账系统 + 邮件（同 B） | KA 导出 + Excel | 邮件预告总量 |

### 2.1 A-2 入库制单（相对 B 的差异）

| 入库情形 | 财务单据 | 谁发起 | B 类是否有 |
|----------|----------|--------|------------|
| 返修后按**原 SKU** 入库 | **销售退货单** | 物流邮件同步财务，财务手工建单 | ✅ 有（B 均为原 SKU 全新品） |
| 返修后拆成**其他 SKU** 入库 | **其他入库单** | 物流制单 / 协同财务 | ❌ **无**（B 不涉及拆 SKU） |

## 3. A 类 · 常规 RMA

> C 端消费者退货传导至 KA，KA 向供应商索赔。货权已至 KA；门店本地消化则不挂供应商。

### 3.1 A-1 · 退款 + 退货（无可用入库）

**适用**：签收后判定**无法正常使用**——报废，或返修后仍不可作为成品/配件再售（与 A-2 分支互斥）。

**流程要点**（与 v1 一致）：

1. Costco 等对账系统审批 → 下载凭证 → 钉钉登记  
2. 钉钉/邮件通知物流 → 猫头鹰仓签收  
3. 处置：报废 / 不可售返修  
4. 财务核对扣款 → **货款抵扣** → 季度对账  

**ERP**：目前**无规范销售退货单/其他入库单**；管报侧退货数量、库存不可见。

### 3.2 A-2 · 退款 + 退货 + 入库（返修可正常使用）

**适用**：与 A-1 **同源**（C 端 RMA、实物回仓），签收后判定**返修可正常使用**，需将库存拉回账面。

**流程骨架**（与 **B 类** 对齐）：

```text
  KA 扣款/RMA 凭证          商务/业务              物流 / 海外仓              财务
       │                        │                        │                      │
  ① 对账/扣款通知      →  ② 登记 + 通知退货      →  ③ WMS 建单/跟踪签收      │
       │                        │                        │                      │
       │                        │                   ④ 质检/返修判定            │
       │                        │                        │                      │
       │                        │              ┌─────────┴─────────┐            │
       │                        │         ⑤a 原SKU可入库    ⑤b 拆其他SKU入库   │
       │                        │              │                 │            │
       │                        │         邮件通知财务      物流其他入库单      │
       │                        │              ↓                 ↓            │
       │                        │         ⑥a 销售退货单    ⑥b 其他入库单     │
       │                        │                        │                      │
       └────────────────────────┴────────────────────────┴──→ ⑦ 货款抵扣、对账
```

**分支 ① · 原 SKU 入库（与 B 类制单相同）**

- 返修完成后仍按**退货原 SKU** 入账。  
- **物流**邮件告知财务签收数量、SKU。  
- **财务**手工建 **销售退货单**，按**确认签收月**挂客户/渠道。  

**分支 ② · 拆成其他 SKU 入库（A-2 特有，B 类无）**

- 例：灯带整机返修后拆为**配件 SKU** 入库。  
- **物流**在 ERP 建 **其他入库单**（非销售退货单）。  
- 财务按扣款/RMA 仍做**货款抵扣**；库存与收入口径需与管报约定配件 SKU 归属。

**与 B 类对比**

| 对比项 | A-2 | B |
|--------|-----|---|
| 触发 | C 端 RMA | KA 批量滞销 |
| 货况 | 返修后可用 / 拆配件 | 全新未拆箱 |
| 销售退货单 | 原 SKU 分支 | 整批原 SKU |
| 其他入库单 | **有**（拆 SKU 分支） | 无 |
| 上架 | 原 SKU 可售或配件再售 | 直接上架 |

### 3.3 A-3 · 仅退款（原 v1「A-2」）

**适用**：沃尔玛等多数 KA——**仅退款不退货**，无实物。

- KA 导出 RMA → 钉钉/Excel 登记 → 财务**只核金额**  
- 录入回款明细（目前多仅金额级）→ 货款抵扣 → 季度对账  
- 沃尔玛等可能有 **10% 手续费**，分摊至 SKU  

---

## 4. B 类 · 批量滞销退货

定义与 v1 相同：KA 季末/项目结束未卖完，整批退回；**全新未拆箱**；财务建**销售退货单**；MA 扣款可跨月陆续到达。

详见 v1 §5 及 HTML v2「B 批量滞销」Tab。

## 5. 四条链路对比（管报视角）

```text
┌────────────┬──────────────────┬────────────────────┬─────────────┬─────────────────┐
│            │ A-1 退款+退货     │ A-2 退货+入库       │ A-3 仅退款   │ B 批量滞销       │
├────────────┼──────────────────┼────────────────────┼─────────────┼─────────────────┤
│ 实物       │ ✅                │ ✅                  │ ❌           │ ✅               │
│ 库存入账   │ ❌                │ ✅ 销售退货/其他入库 │ ❌           │ ✅ 销售退货单     │
│ 拆其他SKU  │ —                 │ ✅ 其他入库单        │ —           │ —               │
│ 管报痛点   │ 退货量不可见      │ 需区分 A-1/A-2 标签  │ 仅金额      │ RMA率可能被拉高  │
└────────────┴──────────────────┴────────────────────┴─────────────┴─────────────────┘
```

## 6. 参与角色（v2 补充）

| 角色 | A-2 补充职责 |
|------|----------------|
| **物流** | 返修判定后通知财务：**原 SKU** 走销售退货单路径，**其他 SKU** 走其他入库单 |
| **财务** | 除扣款外，按分支建**销售退货单**或核对**其他入库单**；入账月=确认签收月 |
| **海外仓** | 签收、返修、上架或配件入库 |

---

## 7. 系统缺口（v2）

| 缺口 | 说明 |
|------|------|
| A-1 / A-2 未系统区分 | 同一 Costco 退货可能在签收后才分流，系统无「处置结果」字段 |
| A-2 其他入库单 | 与 RMA 扣款、客户、原 SKU 的关联靠邮件/人工 |
| A-3 扣款无 SKU | 同 v1 |
| B / A-2 扣款与入库不同步 | 同 v1 |

**系统化建议（v2）**

- 签收节点增加：**报废 / 原 SKU 入库 / 其他 SKU 入库** 三分支  
- A-2 与 B 共用「物流确认 → 财务制单」模板，制单类型可配置  
- 管报：A-2 与 B 分标签；A-1 仍记扣款与估算退货量  

---

## 8. 术语（v2）

| 术语 | 含义 |
|------|------|
| **A-1** | C 端 RMA，实物回仓，**无**规范 ERP 入库（报废等） |
| **A-2** | C 端 RMA，实物回仓，返修**可入库**；含销售退货单 / 其他入库单 |
| **A-3** | C 端 RMA，**仅退款**（原 v1 A-2） |
| **其他入库单** | 拆成非原 SKU 时的 ERP 入库单据 |
| **销售退货单** | 按原 SKU 退货入库时财务手工单据（B、A-2 分支①） |
