4. 计算公式（已定口径）
// ① 唯一总量：仅用 WFS 接口实查，不用各店库存相加
可分配池 = WFS实查可用 − Σ(各参与店安全库存)

// ② 各店目标（配平后应达到的逻辑可售 / 平台可售）
应有i = 可分配池 × 共享比例i + 安全库存i

// ③ 触发：当前 = 该店该 SKU 逻辑可售（含已同步平台可售、含已虚拟借入）
若 ∃ 店：当前 < 安全库存 → 触发一次自动配平

// ④ 缺料 / 富余（用于配平排序）
缺料 = max(0, 应有 − 当前)　　富余 = max(0, 当前 − 应有)

// ⑤ 配平结果：各店当前 := 应有；平台可售 := 应有（<1 则停售）

6. 一次配平规则
  1. 检测到任一参与店 当前 < 安全库存，对本 SKU 启动一次配平（非循环多轮）。
  2. 用 WFS 实查计算可分配池与各店应有。
  3. 富余店 → 缺料店虚拟调剂；缺料店按缺料量从大到小排队分配富余份额。
  4. 配平后：各店当前逻辑可售 = 应有；已借货体现在借入店可售中。
  5. 同步 WM、BBY 平台可售 = 应有；可售 < 1 → 停售。
当前可售 应有（配平目标） 安全库存线
7. 平台可售同步
店铺是否回写可售写入值停售规则
WM 3P-US 是 配平后的应有（逻辑可售） 可售 < 1 → 停售
BBY 3P-US 是 同上 可售 < 1 → 停售

所有平台可售均为计算结果，不是人工在 Mirakl 后台单独维护。与需求 02「主库存 = WFS、子店闸门」一致，且 WM 同样纳入回写（业务已确认）。

8. 订单推单与消耗

推单门禁

拦截 若逻辑分货 / 借货后仍不足以发货（无有效借货、可售不足），则不允许向 WFS 或谷仓推单。

出单消耗（示意）

与需求 01：订单行需能标识消耗的是本店份额或共享池中的借调份额。
