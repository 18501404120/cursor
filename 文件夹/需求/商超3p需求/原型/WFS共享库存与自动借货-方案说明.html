    5 WFS 仓共享 vs 谷仓共享 · 二选一
    WFS 仓共享
    本方案
    ✕
    谷仓共享
    不可同时

    硬性规则 同一 8 位 SKU 只能启用一种共享模式

    WFS 仓共享（本方案）

    • 总量 = WFS 接口实查
    • 参与店：WM / BBY / Lowes 3P-US
    • 自动配平、待推预占、超卖扫描

    谷仓共享（既有模块）

    • 总量 = 谷仓库存
    • 沿用「谷仓共享库存设置」
    • 与 WFS 共享 互斥
    操作系统行为
    保存 WFS 共享，但该 SKU 已启用谷仓共享 拒绝 提示：请先停用谷仓共享
    保存谷仓共享，但该 SKU 已启用 WFS 共享 拒绝 提示：请先停用 WFS 仓共享
    切换模式 先删除/停用当前模式全部配置 → 再启用另一模式（记 MODE_SWITCH 日志）

    与订单履约区分：订单在 WFS 库存不足时改推谷仓发货属于履约兜底，不等于同时开启「谷仓共享配置」。共享模式仍二选一。 详见 MD §5.5。

    6 计算公式（图示 + 代码）
    // ① 先扣订单锁定合计 L，再扣安全库存
    Q_eff = max(0, Q_wfs − L)
    可分配池 P = max(0, Q_eff − S_wm − S_bby − S_lowes)
    // L = 各店「订单锁定库存」之和（待推 WFS 预占）

    // ② 各店配平目标（整数舍入规则见 MD §9.3）
    应有_i = round(P × 比例_i) + 安全库存_i

    // ③ 触发
    ∃店：当前_i < 安全库存_i → 告警 + 整 SKU 一次配平

    // ④ 缺料 / 富余
    缺料_i = max(0, 应有_i − 当前_i)　富余_i = max(0, 当前_i − 应有_i)

    // ⑤ 配平后
    当前_i := 应有_i ；平台可售 := 应有_i（<1 → 停售）
