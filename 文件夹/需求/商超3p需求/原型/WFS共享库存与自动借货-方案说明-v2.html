WFS 共享库存与自动借货 · 方案说明 v2

易懂版 v2.1 · 触发 C < S + L · 2026-05-22 业务确认

一句话：WM / BBY / Lowes 共卖 同一 WFS 仓；拉单时同步平台可售，用本批销量作锁定；若 可售 < 安全 + 锁定 则虚拟配平，应有 = 比例份额 + 安全 + 锁定。

确认示例（BBY）：上次可售 100、上轮销量 10；本次拉单可售 80、安全 70、本批锁定 20 → 80 < 70+20=90 → 触发配平

解决什么 四句话 怎么分货 锁定与10分钟 主流程与演算 池耗尽 约束附录
1 · 我们要解决什么？
实物一份三店共用一个 WFS 池，容易超卖或分配不均。
拉单不实时BBY/Lowes 约每 10 分钟才拉一批单进 ERP，拉单前系统不知道平台又卖了多少。
要自动配平某店低于安全库存时，从富余店「借」数字，并同步三店平台可售。
不做真调拨只改逻辑份额和平台展示，不产生 WFS 调拨单。
2 · 先记住四句话
① 只信 WFS 实查总数 ② 三店卖的是「份额」不是三堆货 ③ 先扣锁定，再分可卖池 ④ 低于安全 → 一次虚拟配平

另：同一 SKU 的 WFS 仓共享 与 谷仓共享 只能开一种。

4 · 订单锁定 + 10 分钟拉单（BBY 示例）

平台可售：顾客下单当场减少；拉单时读到的数写入 ERP。本批锁定 L = 本 10 分钟销量。待拉单预占 = 上轮销量（拉单前占池用）。

拉单前
平台在卖，ERP 可售可能旧；预占 = 上轮销量（如 10）。
拉单时
同步可售（如 80），算本批 L（如 20）；若 C < S + L → 触发。

易错 没有 10:03、10:07 逐笔进单——只有 10:00、10:10 定时拉单 才知道本批合计。

单笔订单：进 ERP → 待推 +N、当前 −N；推 WFS 成功 → 待推 −实际成功件数。

6 · 池耗尽（极端情况）
何时：虚拟配平之后，三店仍全部 C < S + L（或仍无法满足应有）。
做什么：BBY、Lowes 平台可售 → 0；WM 不置 0；该 8 位 SKU 关闭 WFS 仓共享（WM 也不再与子店共享）。
恢复：需运营人工确认后重新开启共享。
7 · 约束与边界（文字附录）
  1. 参与店：WM / BBY / Lowes 3P-US；8 位生产 SKU。
  2. 只信 WFS 接口实查；失败时不静默用旧值做配平。
  3. WFS 仓共享与谷仓共享同一 SKU 二选一。
  4. 自动配平不产生调拨单、不搬实物。
  5. 触发（已定）：C < S + L（L = 本批销量）；应有 T = 比例份额 + S + L。
  6. 可售以拉单时平台同步为准；待拉单预占 = 上轮销量；禁止按 10:03 等逐笔建账。
  7. 10 分钟窗口无法 100% 消除超卖；依赖预占 + 风险扫描 + 配平。
  8. 池耗尽关共享后不自动恢复。
  9. 接口、表结构、验收、非功能见 详细方案 v1。

待确认：上轮销量为 0 时预占是否严格为 0；拉单与推 WFS 是否同一任务。
