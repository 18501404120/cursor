# 需求文档（改动点说明）

**需求名称**：促销-SKU  
**文档版本**：v1.0  
**关联评估**：见同目录下 `需求评估.md`

---

## 一、需求概述

- **一句话**：在促销-SKU 看板中，趋势图按日/周/月切换时浮窗展示「当日促销类型」或「该周/月促销次数」且仅在选择单个 MSKU 时展示，新增 MSKU 筛选；日期明细表标注表头来源与公式、T-CR 前提、原价与 RRP 仅保留 RRP（AMZ 后台）、表冻结至 MSKU 列、促销类型列置于 MSKU 之后。
- **涉及 ERP 模块**：数据与大屏（销售分析、经营看板）
- **使用角色/场景**：运营、计划等按 MSKU/国家/店铺分析促销与销量、转化；每日或按周查看。

---

## 二、改动范围总览

| 类型 | 说明 |
|------|------|
| 新增 | ① MSKU 筛选框；② 趋势图浮窗：按日显示「做了什么促销」（促销类型），按周/月显示「做了几次促销」；③ 明细表表头数据来源与计算公式标注；④ 促销类型列（置于 MSKU 后） |

| 删除/下线 | 原价列（仅保留 RRP，逻辑为抓取 AMZ 后台 RRP） |

## 三、具体改动点

### 3.1 页面 / 功能入口

- **位置**：数据中心（或销售分析）→ 促销-SKU 看板（现有入口不变）
- **改动**：  
  - **筛选区**：新增 **MSKU 筛选框**（支持搜索/下拉，可选单条或多条）；趋势图促销浮窗**仅在 MSKU 限定为单个时**展示。  
  - **趋势图区**：保留日/周/月切换；鼠标移入某日/周/月数据点时，浮窗内容按粒度变化（见 3.2）。  
  - **日期明细表区**：表头增加来源与计算公式标注；列顺序与冻结见 3.2、3.3。

### 3.2 趋势图浮窗逻辑

- **按「日」**：浮窗显示**当日促销类型**（做了什么促销）—— 文案为具体促销类型名称或枚举值，可多条。  
- **按「周」/「月」**：浮窗显示**该周/月做了几次促销**—— 数字为促销次数（口径需与数据侧确认：按活动数或按发生订单的促销类型去重次数）。  
- **展示条件**：仅当筛选区 **MSKU 为单选一条** 时，上述浮窗才出现；多选或未选 MSKU 时不展示促销浮窗（避免汇总维度下口径歧义）。

### 3.3 日期明细表列顺序与冻结

- **冻结列**：左侧冻结至 **MSKU 列**（即日期、国家、店铺、MSKU 四列固定），横向滚动时其余列滚动。  
- **列顺序**：**促销类型** 列置于 **MSKU 列之后**（第 5 列），顺序为：日期、国家、店铺、MSKU、**促销类型**、RRP（原「原价」与「RRP」仅保留 RRP）、折扣价、折扣力度、销量、折后销售额、Total Sessions、Browser Sessions、T-CR、B-CR 等（T-CR 前提，具体顺序可与现有表头对齐后微调）。  
- **原价与 RRP**：删除「原价」列或与 RRP 合并为仅保留 **RRP**，取数逻辑为**抓取 AMZ 后台 RRP 价格**；若 RRP 缺失，展示规则待确认（空或占位）。

### 3.4 表头来源与计算公式标注

- **改动**：在日期明细表表头处标注**数据来源**与**计算公式**（如 T-CR、B-CR、Sessions 等）。  
- **实现方式**：可为表头 title/tooltip 展示，或表头下方常驻一行小字；具体文案需与数据/业务确认后配置。

### 3.5 T-CR 前提

- **改动**：将 **T-CR** 列在表格中的位置**前提**（靠前），与 B-CR、Sessions 等流量与转化指标相邻，便于对比查看。

### 3.6 数据来源与依赖

- **促销类型 / 促销次数**：依赖促销活动或订单关联数据，需明确表或接口、按日/周/月聚合规则。  
- **RRP**：AMZ 后台 RRP，需确认接口或同步方式、更新频率。  
- **表头公式**：T-CR、B-CR、Sessions 等取数逻辑与公式需数据侧提供或已有文档对接。

### 3.7 异常与边界

- **无促销数据**：浮窗可展示「无促销」或 0 次；明细表促销类型列可为空。  
- **RRP 缺失**：展示「-」或占位，需与业务约定。  
- **多选 MSKU**：趋势图不展示促销浮窗，避免汇总口径混淆。

## 四、验收要点（可与提需方对齐后补充）

- [ ] 趋势图按「日」时，单选 MSKU 后移入某日，浮窗展示当日促销类型文案。
- [ ] 趋势图按「周」/「月」时，单选 MSKU 后移入某周/月，浮窗展示该周期促销次数。
- [ ] 未选 MSKU 或多选 MSKU 时，趋势图不展示促销浮窗。
- [ ] 明细表前四列（日期、国家、店铺、MSKU）横向滚动时固定；促销类型列紧跟在 MSKU 后。
- [ ] 明细表仅保留 RRP 列（取 AMZ 后台），T-CR 列前提；表头有来源/公式标注。
- [ ] MSKU 筛选框可单选、可搜索，与趋势图及明细表联动。

## 五、与现有能力的关系

- **依赖的现有能力**：促销-SKU 看板、趋势图与明细表组件、销售/流量/促销数据源；AMZ 后台或对接的 RRP 数据。
- **不影响的功能**：其他销售看板、订单与履约模块不变；仅本看板内交互与列配置调整。
