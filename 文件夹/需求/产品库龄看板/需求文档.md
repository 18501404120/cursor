# 需求文档（改动点说明）

**需求名称**：成品未来呆滞看板（产品库龄看板 - 预计呆滞库存信息）  
**文档版本**：v1.1  
**关联评估**：见同目录下 `需求评估.md`

---

## 一、需求概述

- **一句话**：新增/扩展「成品未来呆滞看板」独立页面，通过全局筛选与日期筛选，展示总览统计（数量/金额按节点拆分的呆滞）、趋势图（呆滞/呆滞金额/销量/呆滞率），以及明细表（当前与预计未来呆滞库存与货值、可用清算库存、30 天 Forecast、未来总库存与未来预计呆滞率），供销售与计划预判年终考核达成与库存健康。
- **涉及 ERP 模块**：数据与大屏（成品库龄看板/成品未来呆滞看板）、库存与仓储管理、销售预测（Forecast）
- **使用角色/场景**：销售、计划等按区域/国家/店铺/品线等筛选，查看当前与未来某日的呆滞数量与货值、各节点分布及趋势，预判考核达标与清库节奏。

## 三、具体改动点

### 3.1 页面 / 功能入口

- **位置**：物流系统（或数据中心/库存分析）→ 看板 → **成品未来呆滞看板**；或 产品库龄看板 内 Tab「未来呆滞」。
- **改动**：  
  - **全局筛选区**（作用于整页）：**区域、国家、店铺**（地理/销售组织）；**结算品类、战线、产品定位、model 查询、细分**（产品属性）；**SKU**（输入框）；**库存位置**（国内/海外在途/在库、FBA 等）；**日期**（当前/历史与未来日期，未来日期仅能选≥当前日，用于预计未来相关指标）；**TL、sales**（负责人）；**查询** 按钮。  
  - **页面结构**：顶部筛选 → 总览统计表（含数据更新时间）→ 趋势图 → 明细表；三者共用上述筛选条件。

### 3.2 字段 / 数据项

#### 3.2.1 总览统计表（数量 / 金额）

- **展示形式**：两行——**数量**、**金额**；列对应同一指标的数量与货值，便于同时看规模与货值。
- **列**（均按当前筛选条件汇总）：**总库存**、**总呆滞库存**、**国内在库呆滞**、**海外在途呆滞**、**海外在库呆滞**、**FBA 在途呆滞**、**FBA 在库呆滞**、**物流站调拨呆滞**、**不良品呆滞**、**呆滞比例**（总呆滞/总库存，G=0 时 N/A）。
- **数据更新时间**：在总览表旁展示最近一次跑数/刷新时间（如 2024-03-15 08:00:00），便于用户判断数据时效。

#### 3.2.2 趋势图

- **标题**：趋势图。
- **维度**：X 轴为时间（如按月 2023/01、2023/02… 或按日，与筛选日期范围一致）；Y 轴可双轴：数量/金额 + 比例。
- **图例**：**呆滞**（数量）、**呆滞金额**、**销量**、**呆滞率**；支持按筛选条件汇总后绘制，便于看趋势与对比。

#### 3.2.3 明细表（SKU 级）

- **列**（均支持按所选日期与未来日期推算，未来相关列在选择了「未来日期」时才有意义）：

| 列名 | 含义 | 计算/取数逻辑 | 备注 |
|------|------|----------------|------|
| 店铺 | 店铺名称 | 主数据 | 维度 |
| SKU | SKU 编码 | 主数据 | 维度 |
| ASIN | 平台 ASIN | 主数据 | 维度 |
| 当前实物库存 | 所选日期的实物库存数量 | 按日滚动得到的该日库存 | 当前 |
| 当前呆滞货值 | 所选日期的呆滞数量×单价 | 库龄>180 天部分货值；单价待定（如出货原价） | 当前 |
| 预计未来呆滞库存 | 未来某日的呆滞数量 | 按日滚动+库龄>180 天得到该日呆滞数量 | 未来 |
| 预计未来呆滞货值 | 预计未来呆滞库存×单价 | 同上，货值 | 未来 |
| 预计未来可用清算库存 | 未来可用于清算的库存数量/货值 | 业务口径与清算策略相关，待与业务确认 | 未来 |
| 预计未来可用清算货值 | 同上，货值 | — | 未来 |
| 30 天 Forecast | 未来 30 天预测销量（或选定未来区间内的 Forecast 汇总） | 已审核 Forecast 汇总 | 辅助 |
| 预计未来剩余呆滞货值 | 未来某日剩余呆滞×单价 | D（未来剩余呆滞）×单价；D=当前呆滞+预计转呆滞−预计可消耗 | 核心 |
| 当前库存 | 所选日期的总库存（数量/货值） | 按日滚动总库存 | 当前 |
| 当前库存货值 | 同上，货值 | 数量×单价 | 当前 |
| 预计未来可入库 | 到未来某日预计入库数量/货值 | 采购在途+Forecast 覆盖部分（待确认） | 未来 |
| 预计未来可入库货值 | 同上，货值 | — | 未来 |
| 未来总库存 | 未来某日总库存（数量/货值） | G = 当前库存 + 预计可入库 − 预计可消耗 | 未来 |
| 未来总库存货值 | 同上，货值 | — | 未来 |
| 未来预计呆滞率 | 未来剩余呆滞/未来总库存 | D/G；G=0 时 N/A | 核心 |

- **数量与货值**：明细表同时展示数量与货值列，与总览表「数量/金额」两行一致，便于对照。
- **汇总**：总览与趋势可按区域/店铺/战线等汇总；明细表按 SKU，支持导出与排序。

### 3.3 筛选 / 查询条件

- **全局筛选**（作用于总览、趋势图、明细表）：  
  - **地理/组织**：区域、国家、店铺。  
  - **产品**：结算品类、战线、产品定位、model 查询、细分、SKU（输入框）。  
  - **库存与时间**：库存位置（国内在库、海外在途/在库、FBA 在途/在库、物流站调拨、不良品等）、日期（当前/历史日期；未来日期仅可选≥当前日，用于预计未来相关列）。  
  - **人员**：TL、sales。  
  - **操作**：查询按钮；可选「重置」。
- **逻辑**：点击查询后，总览统计表、趋势图、明细表统一按上述条件刷新；未来日期不选时，仅「当前」相关列与总览/趋势中的当前口径有值，预计未来相关列可置空或隐藏。

### 3.4 业务逻辑与规则

- **计算逻辑**：  
  - 与**智能发货/红绿灯**一致：按**日**滚动，每日「入库」+「出库（Forecast 消耗）」得到当日库存；再根据**库龄>180 天**判定呆滞数量（按入库时间/调拨时间算库龄）。  
  - 呆滞相关：当前呆滞 = 该日已有库存中库龄>180 天的数量；预计转呆滞 = 到该日过程中新进入呆滞的数量；预计可消耗 = 到该日为止 Forecast 消耗；未来剩余呆滞 D = 当前呆滞 + 预计转呆滞 − 预计可消耗。  
  - 库存相关：当前库存 E = 该日总库存；预计可入库 F = 采购在途/计划到该日可入库 + 超出部分按 Forecast 覆盖（待确认）；未来总库存 G = E + F − 预计可消耗；占比 = D/G（G=0 显示 N/A）。  
- **粒度**：先按 **SKU** 计算，再汇总品线、店铺；FBA、海外仓均支持（与红绿灯一致）。
- **权限与可见性**：与现有产品库龄看板一致（按负责人/组织数据范围）。

### 3.5 数据来源与依赖

- **依赖数据**：  
  - 已审核 **Forecast**（日销，用于消耗与部分「预计可入库」口径）；  
  - **采购计划/在途**（到货日、状态），用于预计可入库；  
  - 各节点**库存与库龄**（国内仓、海外仓在途/在库、FBA 在途/在库），口径与现有库龄看板及红绿灯一致；  
  - 库龄起算：国内入库时间、调拨出库时间等（与红绿灯一致）。  
- **接口或表**：与智能发货/红绿灯、成品库龄看板、Forecast 共用数据源；具体表/接口与研发确认。  
- **刷新频率**：建议每日定时跑批生成「未来预计呆滞」结果（与讨论中「每天刷一版」一致）；具体 T+0/T+1 与数据时效待确认。

### 3.6 异常与边界

- **无数据时**：无 Forecast 或无可选未来日期时，板块不展示或表格为空并提示「请选择未来日期」或「暂无 Forecast 覆盖」。  
- **G=0**：预计未来呆滞占比显示「N/A」或「-」。  
- **未来日期超出 Forecast/采购覆盖**：按约定展示或提示「预计可入库/消耗超出覆盖范围，仅供参考」。  
- **多仓/多平台**：与现有看板一致，支持 FBA、海外仓、商超等；维度与权限保持一致。

## 五、与现有能力的关系

- **依赖的现有能力**：产品库龄看板、智能发货/红绿灯（计算逻辑与数据）、Forecast、采购计划/在途、各节点库存与库龄。
- **不影响的功能**：上方产品库龄看板的现有逻辑、筛选与展示不改动；仅新增独立板块与独立未来日期筛选。
