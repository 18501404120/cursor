不能直接双击打开本页

本工具需要先启动后端服务，再用浏览器访问下面地址（不要用本地文件方式打开）。

  1. 打开终端，进入项目目录：截图识别工具
  2. 执行：npm install（只需第一次）
  3. 执行：npm start
  4. 在浏览器地址栏输入：http://127.0.0.1:3789

若本机未安装 Node.js，请先从 nodejs.org 安装 LTS 版本。

截图识别

上传图片或粘贴截图，文字将保存到本地表格（按时间倒序）

拖拽截图到此处，或

在页面任意处按 Ctrl+V / ⌘+V 粘贴截图

输入框：点击聚焦此处，然后粘贴截图（与页面任意处粘贴效果相同）
