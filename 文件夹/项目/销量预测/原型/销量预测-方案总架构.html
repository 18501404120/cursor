销量预测原型 / 方案总架构

销量预测系统一期 · 方案总架构

从原始数据到主工作台复盘的完整链路：规则、机器学习与大促补充并行产出，融合后形成客观三线与 R1/R2/R3 锁定，再进入展示与反馈闭环。

数据准备 规则 机器学习 大促补充 锁定展示
产品方案总架构 一张图看清完整链路
A
原始数据层
销量、订单、广告、价格、流量、转化、商品主数据、开售时间、品类、库存、评价、排名等
部分字段为当前快照或低方差字段，不能直接当作时间序列输入
B
数据清洗与特征工程
缺失处理、常量剔除、异常 SKU 剔除、日期特征、生命周期、促销标识、移动平均等
先按主力稳定品过滤，再按字段分类决定是否进入模型
C1
规则预测引擎
基准销量 × 流量/价格/转化/广告/竞争力/超参等系数
可解释基线，准确率低于机器学习
C2
机器学习预测引擎
历史样本学习字段权重并预测未来销量
主预测轨：定位 1/3/5，月均销量 ≥100，历史天数 ≥365
C3
大促 / 特殊场景补充
大模型替换层：仅替换 7 / 10 / 11 / 12 月机器学习结果
这些月份大模型达成率更高；其它月份保持机器学习结果
D
预测结果融合与选择
规则基线对照 + 机器学习主轨 + 指定月份大模型修正
决定进入客观三线与锁定快照的最终预测版本
E
客观中值 / 下限 / 上限
同构销量合成公式下的中值路径与悲观 / 乐观情景
表达客观潜力区间，不读取经营目标类输入
F
R1 / R2 / R3 锁定快照
按目标月最后一天剩余天数锁定预测版本
默认 30 / 60 / 90 天，可配置；须满足 R1 < R2 < R3 且为正整数
G
销量预测主工作台
KPI、趋势图、明细、达成率、异常备注、导出
查看预测、切换预测方式、查看达成率并做复盘
H
达成率复盘 / 异常备注 / 导出
窗口聚合达成率、异常备注排除、导出对账
统一口径识别偏差，沉淀特殊事件与复盘证据
I→B
业务反馈与模型调优
使用反馈、准确率分层、字段质量问题回流清洗与特征工程
形成「预测 → 使用 → 复盘 → 调优」闭环
主预测轨：机器学习；规则作为可解释基线；大模型仅修正 7/10/11/12 月。
展示口径：客观三线 + R1/R2/R3 锁定 + 达成率复盘，统一时间窗对照。
