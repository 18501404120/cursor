## 1. 文档概述

### 1.1 页面名称与定位

- **页面标题**：**销量预测**（主工作台）  
- **定位**：销售、供应链与运营在统一界面完成「筛选 → **达成率筛选** → **KPI 汇总** → **销量预测与达成** 趋势图 → MSKU 明细（含 **R1/R2/R3 达成率列**）→ 异常备注与导出」；支持在 **机器学习预测** 与 **系统预测** 两种结果源之间切换查看。

### 1.2 名词（与主 PRD v4.0、《预测销量上下限规则-终版》《R1至R3规则说明》一致）

| 名词 | 说明 |
|------|------|
| **目标 R1 / R2 / R3** | M−1 / M−2 / M−3 月锁定的预测快照（件）。 |
| **下限 / 上限** | 与各目标点预测同构销量合成下的情景边界（件）。 |
| **达成率** | 100% − \|A−P\| / max(A,P)；未关账或无实际时不展示。 |
| **实际销量** | 与财务/运营约定的出库或结算口径实际值。 |

### 1.3 信息架构总览

```
应用壳（左侧图标导航 + 顶栏）
└── 主内容区（可滚动）
    ├── 筛选面板（多条件 + 月份范围 + 达成率筛选 + 搜索）
    ├── 预测模式单选（机器学习 / 系统预测）
    ├── KPI 条（R1 / R2 / R3 预测准确率汇总）
    ├── 勾选：显示人工预测 R1～R3 达成率（演示）
    ├── 图表区「销量预测与达成」（三目标柱+区间带、实际折线、三达成率右轴）
    ├── 明细表（工具栏「预测选择」+ 多行预测堆叠 + 趋势 + R1～R3达成率列 + 操作）
    └── 浮动：「趋势图」弹层；模态：详情 / 异常备注
```

### 1.4 交互原型

请以同目录 **销量预测管理-原型说明.html** 为准：内嵌完整工作台与筛选、达成率筛选、KPI、预测方式、主图与明细表，并对字段、按钮、筛选与图表逻辑逐项红点注释。

## 3. 筛选区

### 3.1 筛选字段（第一块白卡片）

| 字段 | 类型 | 说明 |
|------|------|------|
| 区域 / 国家 / 店铺 等 | 下拉 | 与主数据一致。 |
| 场景品类、品线、SKU 等 | 下拉/搜索 | 与现网一致。 |
| 月份范围 | 月份范围控件 | 控制图表横轴与表格月度列。 |
| **预测选择** | 下拉 | **R1 / R2 / R3**，与 **达成率** 比较符、**阈值(%)** 组合，用于列表行过滤（演示为当前月份窗口内已关账月的平均达成率）。 |
| **达成率** | 比较符 | 大于 / 大于等于 / 等于 / 小于 / 小于等于。 |
| **阈值(%)** | 数字 | 与上栏「预测选择」所指 R 档的汇总达成率比较。 |
| 搜索 | 主按钮 | 触发列表、图表、KPI 刷新。 |

### 3.2 预测模式单选

| 选项 | 说明 |
|------|------|
| 机器学习 | 列表主行与详情以 ML 管线输出为主。 |
| 系统预测 | 列表主行与详情以规则/系统基线为主。 |

## 4. 图表：销量预测与达成

### 4.1 模块标题

- 固定文案：**销量预测与达成**。

### 4.2 图表类型与坐标轴

| 项目 | 说明 |
|------|------|
| 类型 | **分组柱状**（目标 R1、R2、R3）+ **浅色区间带**（各柱对应下限～上限）+ **实际销量折线** + **R1/R2/R3 达成率折线**。 |
| X 轴 | 月份类目。 |
| Y 轴 | **左轴**：销量件数；**右轴**：达成率 0%～100%。 |

### 4.3 图例与系列

| 系列名 | 说明 |
|--------|------|
| 目标R1 / 目标R2 / 目标R3 | 锁定阶梯下的点预测柱；各带演示上下限带。 |
| 实际销量 | 已关账月折线。 |
| R1达成率 / R2达成率 / R3达成率 | 右轴百分比。 |
| 人工预测达成率（演示） | 由勾选「显示人工预测 R1～R3 达成率」控制。 |

### 4.4 交互

- Tooltip：轴触发；目标柱附当月演示下限/上限文案。  
- 图例：可点击隐藏/显示；`resize` 自适应。

## 5. 明细表区域

### 5.1 工具栏

| 控件 | 类型 | 说明 |
|------|------|------|
| **预测选择** | 下拉 | **R1 / R2 / R3**：高亮对应达成率列（演示）。 |
| 导出 / 新增异常备注 | 按钮 | 与 v3 一致。 |
| 系统规则销量预测 / forecast填写销量 | 复选框 | 与 v3 一致。 |

### 5.2 表格列定义

| 列组 | 列名（原型） | 说明 |
|------|--------------|------|
| 维度 | 区域/国家/店铺、场景/品类/品线、销售团队、SKU、MSKU | 与主数据一致。 |
| 月度 | 动态月份列 | 主行为当前预测方式下的系统预测数字；可展开系统规则行、forecast 行。 |
| 可视化 | 历史销量趋势 | Sparkline。 |
| **R1达成率 / R2达成率 / R3达成率** | 数值+% | 行级汇总达成率（演示算法与主 PRD 一致）。 |
| 操作 | 详情、异常备注 | 行内「异常备注」不依赖勾选。 |

## 9. 验收要点（UAT）

1. 筛选 +「搜索」后，主图、KPI、表格数据同源同切片。  
2. **达成率筛选** 生效，列表行与 KPI 一致变化。  
3. 主图含**左轴销量、右轴达成率**，三档目标柱与三达成率线齐全。  
4. 表格含 **R1/R2/R3 达成率** 列；工具栏「预测选择」切换高亮列。  
5. 详情表含三档目标、下限、上限、达成率列。
