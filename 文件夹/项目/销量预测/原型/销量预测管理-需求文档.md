## 1. 文档概述

### 1.1 页面名称与定位

- **页面标题**：**销量预测**（主工作台）  
- **定位**：销售、供应链与运营在统一界面完成「筛选（含 **预测选择 + 达成率阈值**）→ **KPI 汇总** → **销量预测与达成** 趋势图 → MSKU 明细（**当前 R 档单列预测达成率**）→ 异常备注与导出」；支持在 **机器学习预测** 与 **系统预测** 两种结果源之间切换查看。

### 1.2 名词（与主 PRD v4.1、《预测销量上下限规则-终版》《R1至R3规则说明》一致）

| 名词 | 说明 |
|------|------|
| **目标 R1 / R2 / R3** | 距目标月 1 号剩余天数分别 **≤** 各档配置天数时锁定的预测快照（件）；**默认 30 / 60 / 90 天**（可配置）。 |
| **下限 / 上限** | 与各目标点预测同构销量合成下的情景边界（件）。 |
| **预测达成率（单月）** | 100% − \|A−P\| / max(A,P)；未关账或无实际时不展示。 |
| **预测达成率（行 / KPI 汇总）** | **100% − Σ\|A−P\| / Σ max(A,P)**（窗口内参与月；被异常备注排除的自然月剔除）。 |
| **实际销量** | 与财务/运营约定的出库或结算口径实际值。 |

### 1.3 信息架构总览

```
应用壳（左侧图标导航 + 顶栏）
└── 主内容区（可滚动）
    ├── 筛选面板（多条件 … 可售状态 + 顶部预测选择 + 达成率 + 阈值 + 月份范围 + 搜索）
    ├── 预测模式单选（机器学习 / 系统预测）
    ├── KPI 条（R1 / R2 / R3 预测达成率）
    ├── 勾选：显示人工预测 R1～R3 达成率（演示）
    ├── 图表区「销量预测与达成」（三目标柱+区间带、实际柱、三档预测达成率右轴折线）
    ├── 明细表（工具栏预测选择 + 多行预测堆叠 + 趋势 + 单列 R*预测达成率 + 操作 + 导出）
    └── 浮动：「趋势图」弹层；模态：详情 / 异常备注
```

### 1.4 交互原型

请以同目录 **销量预测管理-原型说明.html** 为准：内嵌完整工作台与筛选、达成率筛选、KPI、预测方式、主图与明细表，并对字段、按钮、筛选与图表逻辑逐项红点注释。

## 3. 筛选区

### 3.1 筛选字段（第一块白卡片，同一 `.filter-grid`）

| 字段 | 类型 | 说明 |
|------|------|------|
| 区域 / 国家 / 店铺 … / 可售状态 | 下拉等 | 与主数据一致。 |
| **预测选择（#fltPredR）** | 下拉 | **R1 / R2 / R3**：**仅**用于与「达成率」「阈值」比较时的 R 档（行过滤）；**不**控制表格预测达成率列、详情列。 |
| **达成率** | 比较符 | 大于 / 大于等于 / 等于 / 小于 / 小于等于。 |
| **阈值(%)** | 数字 | 与 **#fltPredR** 所指 R 档的**行级窗口聚合预测达成率**比较。 |
| 月份范围 | 月份范围控件 | 控制图表横轴与表格月度列。 |
| 搜索 | 主按钮 | 触发列表、图表、KPI 刷新。 |

**布局**：**#fltPredR、达成率、阈值**紧挨 **月份范围** 左侧，整体位于 **「搜索」** 之前；**无**虚线分隔第二筛选行。

### 3.2 预测模式单选

| 选项 | 说明 |
|------|------|
| 机器学习 | 列表主行与详情以 ML 管线输出为主。 |
| 系统预测 | 列表主行与详情以规则/系统基线为主。 |

## 4. 图表：销量预测与达成

### 4.1 模块标题

- 固定文案：**销量预测与达成**。

### 4.2 图表类型与坐标轴

| 项目 | 说明 |
|------|------|
| 类型 | **分组柱状**（目标 R1、R2、R3）+ **浅色区间带**（各柱对应下限～上限）+ **实际销量柱状** + **R1/R2/R3 预测达成率折线**。 |
| X 轴 | 月份类目。 |
| Y 轴 | **左轴**：销量件数；**右轴**：预测达成率 0%～100%。 |

### 4.3 图例与系列

| 系列名 | 说明 |
|--------|------|
| 目标R1 / 目标R2 / 目标R3 | 锁定阶梯下的点预测柱；各带演示上下限带。 |
| 实际销量 | 已关账月 **柱状**。 |
| R1预测达成率 / R2预测达成率 / R3预测达成率 | 右轴百分比（折线）。 |
| 人工预测达成率（演示） | 由勾选「显示人工预测 R1～R3 达成率」控制。 |

### 4.4 交互

- Tooltip：轴触发；目标柱附当月演示下限/上限文案。  
- 图例：可点击隐藏/显示；`resize` 自适应。

## 5. 明细表区域

### 5.1 工具栏

| 控件 | 类型 | 说明 |
|------|------|------|
| **预测选择（#tablePredR）** | 下拉 | **R1 / R2 / R3**：控制表头「R*预测达成率」列与行内值、**详情**下钻列集；与顶部 `#fltPredR` **独立**。 |
| 导出 / 新增异常备注 | 按钮 | 导出列与当前表头一致，见《导出模板说明》。 |
| 系统规则销量预测 / forecast填写销量 | 复选框 | 与 v3 一致。 |

### 5.2 表格列定义

| 列组 | 列名（原型） | 说明 |
|------|--------------|------|
| 维度 | 区域/国家/店铺、场景/品类/品线、销售团队、SKU、MSKU | 与主数据一致。 |
| 月度 | 动态月份列 | 主行为当前预测方式下的系统预测数字；可展开系统规则行、forecast 行。 |
| 可视化 | 历史销量趋势 | Sparkline。 |
| **R*预测达成率** | 数值+% | **单列**，表头随 `#tablePredR` 变化（如 R1预测达成率）；行级窗口聚合。 |
| 操作 | 详情、异常备注 | 行内「异常备注」不依赖勾选。 |

## 7. 弹窗与模态

### 7.1 详情

- **触发**：行内「详情」。  
- **内容**：按月展示基准销量、弹性系数、影响因子、**仅当前 #tablePredR 对应档**的目标/下限/上限/**预测达成率**、forecast 等；**不**并列展示三档 R1～R3 全量列。表上方不要求大段说明段落。

### 7.2 异常备注

- **新增 / 编辑 / 批量**：表单含复选框 **「生效区间内月份不参与预测达成率计算」**，默认**不勾选**；勾选则生效范围内**每个自然月**均不计入该行预测达成率窗口聚合；不勾选则本备注不影响预测达成率。  
- 行内入口始终可点；批量需先勾选行。

## 9. 验收要点（UAT）

1. 筛选 +「搜索」后，主图、KPI、表格数据同源同切片。  
2. **达成率筛选** 生效，列表行与 KPI 一致变化。  
3. 主图 **实际销量为柱**；左轴销量、右轴预测达成率，三档目标柱与三达成率折线齐全。  
4. 表格为 **单列 R*预测达成率**，随 **#tablePredR** 切换列名与数值；顶部 **#fltPredR** 仅影响行是否在阈值过滤后展示。  
5. 详情仅展示当前 R 档列集。  
6. 导出列与当前可见表头一致，并对照《导出模板说明》。  
7. 异常备注勾选状态影响该行预测达成率汇总。
