## 1. 文档概述

### 1.1 页面名称与定位

- **页面标题**：**目标助手**（主工作台）  
- **定位**：销售、供应链与运营在统一界面完成「筛选 → **预测与目标**趋势图 → MSKU 维度预测明细 → 异常备注与导出」；支持在 **机器学习预测** 与 **系统预测** 两种结果源之间切换查看（原型为单选切换，实际数据流由后端决定）。

### 1.2 名词（与主 PRD v2.8、《预测销量上下限规则-终版》一致）

| 名词 | 说明 |
|------|------|
| **BP 目标** | 业务在 **业务系统**中维护的全年销售目标拆解到本页粒度；图表中「BP 目标」系列与此同源。 |
| **预测目标** | 当前任务下，按**规则引擎与/或机器学习**计算得到的预测销量（单月点值）；**非**「锁定版最后一版预测」等业务快照表述。 |
| **实际销量** | 与财务/运营约定的出库或结算口径实际值。 |

### 1.3 信息架构总览

```
应用壳（左侧图标导航 + 顶栏）
└── 主内容区（可滚动）
    ├── 筛选面板（多条件 + 月份范围 + 搜索）
    ├── 预测模式单选（机器学习 / 系统预测）
    ├── 图表区「预测与目标」（含人工预测值柱，图例可关显；无页面勾选开关）
    ├── 明细表（工具栏 + 多行预测堆叠 + 趋势 + 操作）
    └── 浮动：「趋势图」弹层；模态：详情 / 异常备注（列表+新增/编辑表单）
```

**不包含**：预测准确率 KPI 卡、达成率折线、右侧百分比轴、表格「预测准确率」列、R1～R3 达成类着色与列。

### 1.4 交互原型

请以同目录 **销量预测管理-原型说明.html** 为准：内嵌完整工作台与筛选、预测方式、主图与明细表，并对字段、按钮、筛选与图表逻辑逐项红点注释。主图不展示达成率折线与右侧百分比轴，与主 PRD v2.8 一致。

## 3. 筛选区

### 3.1 筛选字段（第一块白卡片）

| 字段 | 类型 | 说明 |
|------|------|------|
| 区域 / 国家 / 店铺 等 | 下拉 | 与主数据一致；支持「全部」。 |
| 场景品类、品线、产品定位 | 下拉 | 商品与运营分类维度。 |
| model 查询 | 下拉 | 模型或模板选择（枚举由算法/配置侧提供）。 |
| SKU | 组合控件 | 搜索方式（模糊/精确/8 位）+ 输入框，占位「请输入 SKU」。 |
| TL、Sales、可售状态 | 下拉 | 组织与状态过滤（以主数据为准）。 |
| 月份范围 | 月份范围控件 | 与全局规范《月份范围选择框》一致；控制图表横轴与表格月度列。 |
| 搜索 | 主按钮 | 触发列表、图表等数据刷新；需 Loading 与失败提示。 |

**交互规则（建议）**：默认「点搜索再刷新」，避免大数据量下每次改选就请求。

### 3.2 预测模式单选

| 选项 | 说明 |
|------|------|
| 机器学习 | 展示 ML 管线输出的**预测目标**序列。 |
| 系统预测 | 展示规则/系统基线输出的**预测目标**序列。 |

正式版需明确：切换后哪些组件刷新、是否共用同一套筛选与月份范围。

## 4. 图表：预测与目标

### 4.1 模块标题

- 固定文案：**预测与目标**（与主 PRD 一致）。

### 4.2 图表类型与坐标轴

| 项目 | 说明 |
|------|------|
| 类型 | 分组柱状图（可选叠加区间带）；**无**达成率折线。 |
| X 轴 | 月份类目；与筛选「月份范围」一致。 |
| Y 轴 | **仅左轴**：**数量**（销量）；**不**设右侧百分比轴。 |

### 4.3 图例与系列

| 系列名 | 说明 |
|--------|------|
| BP 目标 | 业务侧销量目标（BP）拆解到当前粒度（演示数为模拟）。 |
| 预测目标值 | 当前规则/模型输出的系统预测（单月点值）。 |
| 实际销量 | 已关账月的实际销量。 |
| 人工预测值 | 主图默认纳入该序列；用户可通过 **图例** 隐藏/显示（无单独页面勾选框）。 |

**上下限（原型演示）**：**仅**对 **预测目标值**（机器学习/系统预测行）在柱后叠加浅色区间带，口径见《预测销量上下限规则-终版》；Tooltip 仅在该系列行展示当月演示下限/上限。**BP 目标**、**人工预测值**为固定点值，无区间带与无区间 Tooltip。

### 4.4 交互

- Tooltip：轴触发；无达成率百分比行。  
- 图例：可点击隐藏/显示系列；随窗口 `resize` 自适应。

## 5. 明细表区域

### 5.1 工具栏

| 控件 | 类型 | 说明 |
|------|------|------|
| 导出 | 按钮 | 导出当前筛选结果。 |
| 新增异常备注 | 按钮 | **批量**：需先勾选至少一行方可点击。行内「异常备注」链接**不依赖**勾选，始终可点。 |
| 系统规则销量预测 | 复选框 | 勾选后在每月单元格主行下追加与当前主预测方式互斥的另一套预测行。 |
| forecast填写销量 | 复选框 | 勾选后追加 forecast 填报行。 |

### 5.2 表格列定义

| 列组 | 列名（原型） | 说明 |
|------|--------------|------|
| 维度 | 区域/国家/店铺、场景/品类/品线、销售团队、SKU、MSKU | 与主数据一致；销售团队列可拖拽调宽。 |
| 月度 | 动态月份列 | 主行展示当前预测方式下的**预测目标**；勾选后展开系统规则行、forecast 行。 |
| 可视化 | 历史销量趋势 | Sparkline 或「查看」打开趋势弹窗。 |
| 操作 | 详情、异常备注 | 无「预测准确率」列；**异常备注**不依赖行勾选即可打开。 |

### 5.3 表格交互与性能

- 表头纵向滚动时 **sticky**；大数据量：**分页或虚拟滚动**。  
- 单元格失焦或批量保存：需校验数字格式、权限与冲突提示。

## 7. 弹窗与模态

### 7.1 详情

- **触发**：行内「详情」。  
- **内容**：按月展示基准销量、弹性系数、影响因子、市场预测值、**BP 目标**（目标输入）、客观中值、系统推荐、客观下限/上限、forecast 等；规则与《预测销量上下限规则-终版》及主 PRD 一致。

### 7.2 异常备注（行内 / 批量）

- **历史列表表头**：调整人、调整时间、备注内容、生效时间、操作。  
- **表单字段**：备注内容、生效时间（范围）；**仅记录与展示**，不参与预测或达成率类自动计算。

## 8. 非功能需求

| 类别 | 要求 |
|------|------|

## 9. 验收要点（UAT）

1. 筛选条件 +「搜索」后，主图、表格数据 **同源同切片**。  
2. 切换「机器学习 / 系统预测」后，各模块展示对应**预测目标**数据集。  
3. 主图**仅数量轴**，无达成率折线与右轴。  
4. 表格无「预测准确率」列；异常备注仅记录与展示，不参与预测或达成率计算。  
5. 导出字段与当前表格列一致（或按导出模板）。
