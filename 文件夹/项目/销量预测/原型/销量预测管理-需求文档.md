> **对应原型**：[销量预测管理-原型.html](./销量预测管理-原型.html)（同目录，浏览器直接打开预览）  
> **关联背景**：[../项目背景.md](../项目背景.md)、[../销量预测项目方案.md](../销量预测项目方案.md)

> **说明**：本文档按当前可交互原型的模块、控件与交互逐项拆解；后端口径、权限矩阵与接口字段需在开发阶段另附《接口说明》补全。

## 1. 文档概述

### 1.1 页面名称与定位

- **页面标题**：销量预测管理  
- **定位**：供应链/运营侧在统一界面完成「筛选 → 看 KPI → 看预测与达成趋势 → 维护 MSKU 维度预测明细 → 异常备注与导出」；支持在 **机器学习预测** 与 **系统预测** 两种结果源之间切换查看（原型为单选切换，实际数据流由后端决定）。

### 1.2 信息架构总览

```
应用壳（左侧图标导航 + 顶栏）
└── 主内容区（可滚动）
    ├── 筛选面板（多条件 + 月份范围角标 + 搜索）
    ├── 预测模式单选（机器学习 / 系统预测）
    ├── KPI（R1～R3 准确率 + MSKU 待处理）
    ├── 图表区「销量预测与达成」+ 右侧/下方业务说明便签
    ├── 明细表（工具栏 + 预测选择 R1～R3 + 多行预测堆叠 + 趋势 + R 列 + 操作）
    ├── 页脚外链 + 红黑字误差说明
    └── 浮动：右下角「趋势图」弹层；模态：详情 / 异常备注（列表+新增/编辑表单）/ 工具栏新增异常备注
```

## 3. 筛选区

### 3.1 筛选字段（第一块白卡片）

| 字段 | 类型 | 说明 |
|------|------|------|
| 区域 | 下拉 | 与主数据一致；支持「全部」。 |
| 国家 | 下拉 | 可与区域联动。 |
| 店铺 | 下拉 | 店铺维度过滤。 |
| 场景品类 | 下拉 | 业务品类维度。 |
| 品线 | 下拉 | 产品线维度。 |
| 产品定位 | 下拉 | 如主推/新品等。 |
| model 查询 | 下拉 | 模型或模板选择（枚举由算法/配置侧提供）。 |
| TL | 下拉 | 团队/线别等业务字段，枚举待定。 |
| Sales | 下拉 | 销售归属维度，枚举待定。 |
| 可售状态 | 下拉 | 过滤不可售/在售等状态。 |
| SKU | 搜索框 | 占位「请输入 SKU」；支持精确或模糊策略（产品定义）。 |
| 预测选择 | 下拉 | 选项 **R1～R3**，与后方「比较」「数值」组合为过滤条件（筛选区可切换 R，非写死 R1）。 |
| 比较 | 下拉 | 大于 / 小于。 |
| 数值 | 文本/数字 | 与所选预测轮次、比较符组合过滤（具体过滤对象：误差率或预测值，需业务确认）。 |
| 月份范围 | 只读展示 + 角标 | 展示当前选中的起止月份（原型：`202501 ~ 202512`）；右上角 **黄色数字角标**（原型为 `6`）表示待处理事项数量或选中跨度等含义，**需业务定义**。 |
| 搜索 | 主按钮 | 触发列表、KPI、图表等数据刷新；需 Loading 与失败提示。 |

**交互规则（建议）**

- 默认「点搜索再刷新」，避免大数据量下每次改选就请求（可选二期「自动查询」开关）。

## 4. KPI 指标卡（六张）

横向排列（窄屏原型为 3×2 栅格），每张包含 **标题（含提前期天数）** 与 **主数值**。

| 卡片 | 标题文案（原型） | 主指标 | 展示说明 |
|------|------------------|--------|----------|
| 1 | R1（提前1个月）预测准确率 | 如 78% | 聚合口径需在数仓定义（如按销量加权）。 |
| 2 | R2（提前2个月）预测准确率 | 如 66% | 同上。 |
| 3 | R3（提前3个月）预测准确率 | 如 58% | 同上。 |
| 4 | MSKU待处理（偏差过大） | 如 1024 | 待处理口径需定义（如偏差阈值、去重维度）。 |
| 6 | MSKU待处理（偏差过大） | 如 1024 | 计数规则：超过阈值的 MSKU/SKU 数量；**点击可下钻**到表格过滤（建议增强）。 |

**视觉**：各卡渐变底色与主色不同（蓝/绿/青/橄榄/靛/粉），与原型一致即可。

## 5. 图表：销量预测与达成

### 5.1 模块标题

- 固定文案：**销量预测与达成**。

### 5.2 图表类型与坐标轴

| 项目 | 说明 |
|------|------|
| 类型 | 分组柱状图 + 折线图组合。 |
| X 轴 | 月份类目（默认展示 **未来 12 个月**，从下个月起；与筛选「月份范围」一致）。 |
| 左 Y 轴 | **数量**，范围原型为 0～250（正式版按真实量级自适应或配置上限）。 |
| 右 Y 轴 | **达成率**，0～100% 展示（原型数据为 0～1 映射百分比）。 |

### 5.3 图例与系列

| 系列名 | 类型 | 轴 | 说明 |
|--------|------|-----|------|
| 目标R1 / 目标R2 / 目标R3 | 柱 | 左 | 不同提前期或版本下的目标/预测销量（口径由业务定义）。 |
| 实际销量 | 柱 | 左 | 实际达成销量。 |
| R1达成率 / R2达成率 / R3达成率 | 线 | 右 | 达成率 = f(实际, 对应目标)，上限原型截断为 100%。 |

**默认展示（原型）**：图例中默认仅勾选 **目标R1**、**实际销量** 与 **R1达成率**；**目标R2/R3**、**人工R1～R3** 及 **R2/R3达成率**、**人工达成率** 默认收起，用户可通过图例点击展开。勾选「显示人工预测…」后，默认仅展开 **人工R1**（及对应达成率），R2/R3 仍由图例控制。

**上下限（原型演示）**：对 **目标R1～R3、人工R1～R3** 柱状系列，柱顶标签与轴 Tooltip 中附带与列表一致的演示区间（预测值×50% / ×150%，四舍五入）；**实际销量** 不展示区间。**详情**弹窗按月展示当前预测方式下的预测值、下限、上限及 forecast 填写列，口径与图表一致。

### 5.4 交互

- Tooltip：轴触发，展示各系列数值；对目标/人工 R 系列在提示中追加一行「上下限」说明（与柱顶标签一致）。  
- 图例：可滚动；支持点击隐藏/显示系列。  
- 随窗口 `resize` 自适应。

### 5.5 业务说明便签（Sticky Note）

- 位置：宽屏下叠在图表区域右上；窄屏下排到图表下方。  
- 样式：黄色便签风，轻微旋转（原型 `-0.5deg`）。  
- 内容：**可配置富文本**，原型示例为 ASIN 下多 MSKU 合并预测逻辑说明（含示例 SKU）。  
- 正式版：建议后台配置或帮助文档链接，避免写死。

## 6. 明细表区域

### 6.1 工具栏

| 控件 | 类型 | 说明 |
|------|------|------|
| 导出 | 按钮 | 导出当前筛选结果（格式：Excel/CSV，字段与表格列一致）。 |
| 批量异常备注 | 按钮 | 打开批量备注弹窗（见 §8.3）。 |
| 系统规则销量预测 | 复选框 | **默认不勾选**。勾选后，在每月单元格内**主行下方**追加一行，展示与筛选区当前主预测方式**互斥的另一套**销量：主选「机器学习」时该行展示**系统规则预测销量**；主选「系统预测」时该行展示**机器学习预测销量**。 |
| forecast填写销量 | 复选框 | **默认不勾选**。勾选后，在每月单元格最下方追加 **forecast填写销量** 行（有值才展示）；与权限、填报入口联动。 |
| 预测选择 | 下拉 | 选项 **R1～R3**，**默认 R1**；与列表/图表当前查看的提前期口径联动。 |

**与筛选区「机器学习 / 系统预测」关系**：列表**主行**始终展示当前单选所选方式的预测数值；两个勾选框仅控制是否在主行下**按序**展开第二、三行及对应小标题。

### 6.2 表格列定义

| 列组 | 列名（原型） | 说明 |
|------|--------------|------|
| 维度 | 区域/国家/店铺 | 左冻结列。 |
| 维度 | 场景/品类/品线 | 第二左冻结列。 |
| 维度 | 销售团队 | 可含 `sales` / `TL` 等；**默认列宽约 240px**，内容 **在 `/TL:` 处换行** 展示。**列宽可拖拽调整**（表头右缘拖拽条，原型约 **160～640px**），宽度可 **写入本地存储** 以便同浏览器下次打开保持（正式版可改为服务端用户偏好）。 |
| 商品 | SKU信息 | 两行：sku / 定位。 |
| 商品 | MSKU信息 | 两行：平台 / MSKU。 |
| 表头通栏 | 机器学习销量预测 / 系统规则销量预测 / forecast填写销量 | 双行表头；下列为 **202601～202612**。 |
| 预测/销量 | 月度格（多行） | 默认仅**一行**（当前主预测方式）。勾选后依次向下展示：② 另一套预测（系统规则或机器学习，与主行互斥展示）③ forecast填写销量。**forecast 填写行仅展示最终填报数值**，不展示上下限区间（与 ML/系统预测行的区间演示规则区分）。 |
| 可视化 | 历史销量趋势 | Sparkline，默认取主行序列。 |
| 指标 | R1～R3 | 百分比；可按误差规则着色（红/黄/黑，见 §9）。 |
| 操作 | 操作 | **异常备注**、**详情**。 |

### 6.3 表格交互与性能

- 表头纵向滚动时 **sticky**；左侧两列 **横向冻结**。  
- **销售团队列**：支持 **列宽拖拽调节**（`col-resize` 热区），与表体同列同步；默认宽度保证两行 `sales` / `TL` 文案完整可见。  
- 大数据量：**分页或虚拟滚动**（二选一，必选）。  
- 单元格失焦或批量保存：需校验数字格式、权限与冲突提示。

## 8. 弹窗与模态

### 8.1 详情

- **触发**：行内「详情」。  
- **内容**：展示当前行 SKU/MSKU/平台及可扩展字段（因子分解、版本号等，原型为占位文案）。  

### 8.2 异常备注（行内）

- **触发**：行内「异常备注」。  
- **首屏**：弹窗标题为 **「异常备注 — {SKU}」**，含 **「新增异常备注」** 按钮及历史列表表头：**调整人、调整时间、备注内容、生效时间、参与达成率计算、操作（编辑/删除）**。  
- **新增 / 编辑**：均打开同一套表单弹窗，标题分别为 **「新增异常备注」**、**「编辑异常备注」**；字段含 **修改人（只读）、修改时间（只读）、备注内容、生效时间（日期范围起止，必填）、是否参与达成率计算**；底部 **取消 / 确定**。  
- **原型**：演示数据与交互，无持久化。

### 8.3 新增异常备注（工具栏 / 批量）

- **触发**：工具栏 **「新增异常备注」**（原「批量异常备注」能力，与表单一致）。  
- **表单**：与 §8.2 相同，标题为 **「新增异常备注」**；说明区提示对当前筛选范围/所选 MSKU 批量生效（正式版需多选与权限）。  
- **规则**：生效时间必须为 **日期范围**；确定后正式环境应写入备注服务并可选返回列表。

## 9. 误差与预警展示（页脚说明对齐）

- **主行预测数字**（与当前所选「机器学习/系统预测」对应）：以行为粒度使用 **近一年 R2 指标**（口径由数仓定义）：  
  - **R2 ≥ 80%**：主行数字标**红**（高偏差预警）；  
  - **70% ≤ R2 < 80%**：主行数字标**黄**；  
  - 其余：默认色。  
- **forecast填写销量** 行：若某月填报值触发业务异常规则，可单独标红（原型对 202606、202612 等示例值演示）。  
- **R1～R3 列**：可按各列误差阈值标红/黑等（原型演示规则）。

## 13. 验收要点（UAT）

1. 筛选条件 +「搜索」后，KPI、主图、表格数据 **同源同切片**，无逻辑矛盾。  
2. 切换「机器学习 / 系统预测」后，各模块展示对应数据集（若一期仅一侧有数，需空态说明）。  
3. 主图左轴「数量」、右轴「达成率」与图例系列一致；月份范围与筛选一致。  
4. 表格 202601～202612：主行随「机器学习/系统预测」切换；勾选「系统规则销量预测」「forecast填写销量」后多行展示与 §6 一致。  
5. R 列与主行 R2 预警色（红/黄）与 §9 一致。  
6. 导出字段与当前表格列一致（或按导出模板）。
