## 1. 文档概述

### 1.1 页面名称与定位

- **页面标题**：超参数因子管理  
- **定位**：维护影响 **销量预测** 内规则/预测模型的超参数因子（事件说明、因子值、生效时间段、状态）；支持筛选查询、新增与行内编辑、批量生效/失效/删除；右侧展示单条因子的操作日志（**仅记录发生变更的字段**）。

### 1.2 信息架构

```
应用壳（左侧图标导航 + 顶栏）
├── 主内容区（可滚动）
│   ├── 筛选区（编号 / 事件 / 状态 + 搜索；**无顶栏时间范围控件**）
│   ├── 工具栏（新增 / 生效 / 失效 / 删除）
│   └── 主表（勾选、编号、事件、因子、时间范围、状态、操作）
└── 右栏：日志（点击行内「日志」展示该编号变更记录）
```

---

## 2. 筛选区

| 字段 | 类型 | 说明 |
|------|------|------|
| 超参数编号 | 文本 | 按 **5 位流水号** 匹配：取输入中的数字部分与 `00001` 形式编号 **全等** 对齐比较（见 §3 编号规则）。 |
| 超参数事件 | 文本 | 对「超参数事件说明」做 **包含** 匹配。 |
| 状态 | 下拉 | 全部 / 草稿 / 生效。 |
| 搜索 | 按钮 | 刷新列表。 |

**默认列表时间窗（隐式，无控件）**：列表始终仅展示「开始～结束」与 **以服务器当前日为锚点的 \[今天−12 个月, 今天+12 个月\]**（自然日闭区间）**存在交集** 的因子；再与上表显式筛选条件做 **且** 运算。若记录 **尚未填写完整起止日期**，可不参与上述交集过滤（仍可按其它条件展示，便于新建未完成行；正式环境是否允许以产品为准）。

## 3. 列表与字段

| 列 | 说明 |
|----|------|
| 勾选 | 批量生效 / 失效 / 删除。 |
| 超参数因子编号 | **5 位十进制流水号**（左补零），系统生成，**全局唯一、单调递增**；删除或作废后 **不回收** 旧号，避免与历史审计、外部引用冲突。 |
| 超参数事件说明、超参数因子、时间范围 | 可编辑（行内编辑 + 保存/取消）。 |
| 状态 | 草稿 / 生效。 |
| 操作 | **删除**（仅草稿）/ **编辑** / **日志**；编辑态下为 **保存** / **取消**。操作项之间保持统一间距。 |

**新增**：**不设默认值**（事件、因子、起止日期均为空），仅生成新编号；用户填写后保存。

## 4. 批量操作

### 4.1 生效（产品经理）

- 所选须 **全部为草稿**；否则提示，不执行。  
- 确认弹窗后，所选变为 **生效**，并记日志（仅记变更字段，如状态）。

### 4.2 失效（产品经理）

- 所选须 **全部为生效**；否则提示。  
- 若任一因子 **已应用到 MSKU**，则 **不可失效**，并列出编号。  
- 确认后变为 **草稿**，并记日志。

### 4.3 删除

- **仅草稿**可删；批量时若含非草稿则拦截。  
- **二次确认**后删除。

### 4.4 权限

- **生效、失效**：仅 **产品经理**（原型可用下拉模拟）。  
- 删除、编辑、查询等：按实际角色矩阵配置。

---

## 5. 日志（右栏）

- 列：**调整人**、**调整时间**、**调整前**、**调整后**。  
- **仅展示有变化的字段**；同一操作多字段变更可合并一条日志。
