# 销量预测（项目目录）

## 本地预览（推荐）

原型页会通过 `fetch` 加载仓库内 **`文件夹/规范/基础数据/*.json`** 及 **`文件夹/规范/assets/*.js`**。请在**本 Git 仓库根目录**（即包含 `.git` 的 `方案设计` 目录）启动静态服务，再访问下面地址，避免相对路径错误与浏览器对 `file://` 的限制。

```bash
cd "/path/to/方案设计"
npx --yes serve -p 5174
```

在浏览器中打开（端口以终端输出为准）：

| 说明 | URL 路径 |
|------|-----------|
| 原型导航入口 | `/文件夹/项目/销量预测/原型/index.html` |
| 主工作台（说明版） | `/文件夹/项目/销量预测/原型/销量预测管理-原型说明.html` |
| 预测配置中心 | `/文件夹/项目/销量预测/原型/销量预测配置中心-原型说明.html` |
| 超参数因子管理 | `/文件夹/项目/销量预测/原型/超参数因子管理-原型说明.html` |

示例：`http://127.0.0.1:5174/文件夹/项目/销量预测/原型/index.html`

## 目录说明（摘要）

- **`原型/`**：自包含 HTML + `prototype-anno-*.js` 红点说明脚本。
- **`需求文档/`**：PRD 与规则类 Markdown。
- **`scripts/`**：钉钉知识库同步等辅助脚本（若存在）。

将本目录变更推送到远程：`git add` 本目录下所需路径后 `git commit`，再在仓库根执行 `git push origin HEAD`。
