# R1～R3 规则说明（目标助手 · 预测准确率 / 达成口径）

> **读者**：销售、运营、计划及相关业务方  
> **目的**：用统一、好记的方式说明 **R1～R3 各自代表什么**、**和「前几个月」的关系**、**准确率怎么理解**，以及 **forecast 在什么情况下会更新 / 锁定**。  
> **说明**：本项目按「**提前一年开始预测，预测未来 12 个月**」执行；锁定按“**距离目标月还有几个月**”分段（3个月锁R3、2个月锁R2、1个月锁R1）。后续仍每日预测，但已锁定版本不再变化。

---

## 1. 一句话先记住

- **先选定要考核的「目标月」**（例如要算 3 月的准确率，目标月就是 3 月）。  
- **R1**：看的是 **前 1 个月** 那一侧、在规则允许范围内**最后一版**对「目标月」的预测，和 **目标月实际** 的关系。  
- **R2**：看的是 **前 2 个月** 那一侧的最后一版对目标月的预测 vs 目标月实际。  
- **R3**：看的是 **前 3 个月** 那一侧的最后一版对目标月的预测 vs 目标月实际。

可以记成：**R 后面的数字 n，就是「往前数第 n 个月」那一版预测，拿来和目标月真卖出去的数比。**

---

## 2. 时间轴怎么理解（和内部培训材料对齐）

下面用 **「目标月 = 3 月」** 举例（仅帮助建立直觉，具体月份可替换）：


| 说法（相对目标月 3 月） | 大约对应    | 在对比里扮演的角色                                   |
| ------------- | ------- | ------------------------------------------- |
| 前 1 个月        | 2 月     | **R1**：2 月时点上认定的「最后一版对 3 月的预测」vs **3 月实际**  |
| 前 2 个月        | 1 月     | **R2**：1 月时点上认定的「最后一版对 3 月的预测」vs **3 月实际**  |
| 前 3 个月        | 去年 12 月 | **R3**：12 月时点上认定的「最后一版对 3 月的预测」vs **3 月实际** |


**R2 预测准确率**（培训材料中的定义）：  
**本月（目标月）实际达成** 与 **两个月前那一版「最后一版预测」** 之间的匹配程度。  
R1、R3 只是把「两个月前」改成「一个月前 / 三个月前」。

## 3. 「销量目标达成率 / 准确率」怎么算（与系统公式一致）

以下 **「销量目标」** 指：对应 R1 / R2 / R3 口径下、该目标月在规则中认定的**最后一版预测（目标值）**；**「实际销量」** 指该目标月关账后的实际。

### 3.1 跨月汇总（多个月份 n₁、n₂、…、n 一起考核时）

**销量目标达成率**（亦可称汇总准确率）按下式计算：


\text{销量目标达成率} = 100 - \frac{\sum_i \lvert \text{实际销量}_i - \text{销量目标}_i \rvert}{\sum_i \max(\text{实际销量}_i,\ \text{销量目标}_i)}


- **分子**：各考核月份上，「实际 − 目标」的**绝对值之和**。  
- **分母**：各考核月份上，「实际」与「目标」**两者中的较大值之和**（避免单期分母过小带来的失真）。  
- 仅对**已有关账实际销量**的月份参与汇总；无实际或无法对齐目标的月份不计入分子分母。

**与单期的关系**：若只考核 **一个** 目标月，上式退化为下面的单期公式。

### 3.2 单个月份（仅看某一个目标月 n）


\text{准确率} = 100 - \frac{\lvert \text{实际} - \text{目标} \rvert}{\max(\text{实际},\ \text{目标})}



≈  


- 分子：该月实际与目标的绝对偏差。  
- 分母：该月实际与目标的较大者。

**例子（R2、仅目标月 3 月）**

- 3 月**实际**销量：500  
- **1 月时点上**、按规则认定的对 3 月的**最后一版目标**：2000

则：  
`100% − |500 − 2000| ÷ max(500, 2000) = 100% − 1500÷2000 = 25%`  

即：**该维度在 3 月的 R2 准确率可报为 25%**。

### 3.3 界面上的常见用法


| 位置                         | 建议口径                                                      |
| -------------------------- | --------------------------------------------------------- |
| **主图「R1/R2/R3 达成率」折线（按月）** | 每个目标月一个点：按 **3.2 单期公式** 计算（无实际销量的月份不画点）。                  |
| **顶部 KPI 卡片（R1/R2/R3 汇总）** | 在当前筛选的月份范围内，对**已有实际的各月**按 **3.1 汇总公式** 各算一条 R1 / R2 / R3。 |

## 4. 核心：R1/R2/R3 什么时候锁定？

业务上大家最关心：**我改了 forecast，R1 用的那个「目标值」到底变不变？**  
下面用“目标月 M”为锚点，按月说明（更贴近销售口径：R1=提前1个月、R2=提前2个月、R3=提前3个月）。

### 4.1 场景复述

- 以某个 **目标月** 为准。  
- **一开始**：系统提前一年开始预测，展示未来 12 个月；此阶段 **R1、R2、R3 对同一目标月的预测值相同**（都跟随每日预测滚动）。  
- **距离目标月还有 3 个月开始**：**R3 锁定**为当时那一刻的“最后一版预测”；之后每日预测仍会产生新值，但 **R3 不再变化**。  
- **距离目标月还有 2 个月开始**：**R2 锁定**；R1 继续随每日预测滚动。  
- **距离目标月还有 1 个月开始**：**R1 锁定**。

**一句话记**：  
**R3 先锁（3个月前），R2 再锁（2个月前），R1 最后锁（1个月前）；锁定后继续每日预测，但不回写已锁定版本。**

### 4.2 和「一个月」说法的关系

- **R1 = 前 1 个月**：是**统计口径上**「拿前一个月那一侧的最后一版预测，去对比目标月实际」。  
- 本项目锁定用“**月**”来表达（3/2/1 个月前锁），更符合销售定义；若后续要落到具体日期（例如每月1号/某个跑批日）由系统配置说明补充。

---

## 5. R2、R3 也怎么理解？


| 指标     | 含义（目标月记为 M）                           |
| ------ | ------------------------------------- |
| **R1** | **M 的实际** vs **M−1 月侧**认定的最后一版对 M 的预测 |
| **R2** | **M 的实际** vs **M−2 月侧**认定的最后一版对 M 的预测 |
| **R3** | **M 的实际** vs **M−3 月侧**认定的最后一版对 M 的预测 |


锁定原则与 R1 类似：核心是为了让同一目标月的指标可比，不被“越临近越改标准”影响。

## 6. FAQ

**Q：为什么临近目标月还不让改 R1 数字？**  
A：否则准确率会失去可比性（会越来越像“贴实际”）。

**Q：为什么一开始 R1/R2/R3 会一样？**  
A：因为在锁定节点到来之前，这三档都引用“每日滚动预测”的同一个值；只有进入 3/2/1 个月的锁定窗口后，才分别冻结为不同的版本快照。

**Q：KPI 卡片里出现「R1（按天数）」这类文案会冲突吗？**  
A：本项目以销售定义为准：R1=提前1个月、R2=提前2个月、R3=提前3个月；若界面历史上存在“按天数”展示，应同步改为“按月”表述，避免歧义。
