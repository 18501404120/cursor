# 产品需求文档（PRD）：预测销量上下限规则

> **关联文档**：[基于规则的销量预测设计说明.md](../基于规则的销量预测设计说明.md)、[销量预测管理-PRD.md](./销量预测管理-PRD.md)（**目标助手 · 主工作台**）  
> **适用范围**：点预测结果在列表、图表、详情中的**可解释区间**（下限～上限），与「点预测」并列展示，供计划评审与解释；**不作为**产品内「预警阈值」类告警能力（隶属 **目标助手**）。
> **文档版本**：v1.10  
> **状态**：草案  
> **最后更新**：2026-04-16

---

## 1. 背景与目标

### 1.1 背景

业务需要在「点预测」之外展示**合理波动区间**，支撑计划评审、库存安全量讨论与异常检测。区间应来自**可解释的驱动因子**（流量、转化率、竞争力、价格、广告花费等），而非简单按点预测乘常数，以便与运营认知对齐、便于审计。

### 1.2 目标

| 目标 | 说明 |
|------|------|
| **口径统一** | 下限、上限分别对应一套明确的因子取值规则（悲观情景 / 乐观情景）。 |
| **可复现** | 时间窗口、聚合方式（月均）、同比对齐规则在数据层可实现、可单测。 |
| **与规则预测一致** | 上下限由「因子极值 + 与点预测相同的销量合成公式」得出；若点预测为算法黑盒，需约定等价接口或近似路径（见 §4）。 |

### 1.3 非目标（本 PRD 不展开）

- 具体接口字段名、调度频率、存储表结构（由《接口说明》或技术设计补全）。  
- 非以下五类因子的其他因子（如生命周期、大促标签）是否纳入区间，默认**不改变点预测中已锁定部分**，仅替换下表所列因子取值。

## 2. 名词与范围

| 名词 | 定义 |
|------|------|
| **点预测** | 当前任务产出的单值预测销量（系统/规则/融合后的主结果）。 |
| **预测流量** | 与点预测同一任务、同一版本下使用的**流量输入**（或模型反推的流量假设）；用于与去年同期流量做比较。 |
| **去年同期流量** | 与**目标预测月**在公历上对齐的**去年同月**（或业务约定的「同比月」）内，按与点预测一致的粒度聚合后的流量。 |
| **近 3 个月** | **不含预测目标月本身**的、向前连续 3 个完整自然月的滚动窗口；各因子在该窗口内先按**自然月**聚合，再对三个月的月值取 min/max（见 §3）。 |
| **近 1 年** | **不含预测目标月本身**的、向前连续 12 个完整自然月的滚动窗口；价格取各月**月均价格**后再做极值（见 §3）。 |
| **转化率 / 竞争力** | 与《基于规则的销量预测设计说明》中定义一致；具体数据源（站内转化、类目排名等）以主数据与数仓字典为准。 |
| **广告花费** | 与点预测口径一致的渠道广告花费（币种、含税规则与财务/广告中台对齐）。 |

**粒度约定（待配置，默认推荐）**：同一 **MSKU（或 ASIN+渠道最小粒度）× 自然月** 计算一对上下限；跨店汇总需在规格中声明聚合顺序（建议先 SKU 再汇总，避免「均值之均值」偏差）。

### 2.1 预测销量 P 与市场预测值、BP 目标、BP目标融合权重（α）（与详情表一致）

| 名词 | 定义 |
|------|------|
| **市场预测值 M** | 未叠销售目标、未按 BP 规则修正前的**算法侧**预测量（与列表/模型输出同源）。 |
| **BP 目标 T** | **业务系统**中维护的全年销售目标拆解值（与主工作台图表「BP 目标」同源、同月、同 MSKU/渠道粒度）。 |
| **BP目标融合权重（α）** | 取值 **[0, 1]** 的权重，表示 **BP 目标**在加权合成中的占比。**仅当 T 有值（非空）时**配置并展示 α；**T 为空时 α 必须为空**，不参与加权。 |

**预测销量 P（点预测）计算规则**

1. **T 为空**：α 为空；**P = M**（原型演示；正式版可定义兜底策略如仅展示「不可算」）。**上下限**一律按 **§3** 因子悲观/乐观情景，在与点预测**同构的销量合成公式**下求得；无 T 时点预测即为 **M**，区间与详情/列表/图表一致地以 **M** 为合成路径上的点预测输入（而非对 M 做固定比例缩放）。  
2. **T 非空且 M ≤ T**：**P = T × 1.05**（将结果抬升至不低于 BP 目标的 5% 缓冲，业务称「市场预测修正为不低于目标×1.05」的落地口径）。
3. **T 非空且 M > T**：**P = T × α + M × (1 − α)**（在 BP 目标与市场预测之间按权重插值）。

**与上下限的关系**：在得到点预测 **P**（或 **T 空**时的 **P=M**）后，**下限、上限**仅通过 **§3** 五类因子的悲观/乐观取值代入**同一套销量公式**得到，**不再**使用对 P 或 M 套用单一全局乘数的旧演示区间。分支、公式与 **§2.3** 表格对照一致，便于评审时「一眼对齐」。

### 2.2 算法输出与 BP 目标对齐（与主工作台、§4 一致）

1. **算法侧**可先输出**市场预测值 M**，以及按因子极值情景得到的**原始下限、原始上限**（或等价中间量）；具体形态由数据/算法实现约定。  
2. **最终在本产品展示的「预测目标」（点预测 P）及推荐区间**：须与 **§2.1** 一致——在 **BP 目标 T** 与 **BP目标融合权重（α）** 下，将 M 调整为与业务规则一致的 **P** 后，再对 **P** 应用 **§3** 因子悲观/乐观情景得到**下限、上限**；**不得**与主工作台详情表、列表、图表出现两套互斥口径。  
3. 若算法管线**一步输出**已融合 BP 目标的推荐销量与区间，须在元数据或详情中可核对 **M、T、α、P** 与区间合成路径，保证与 **§2.1 / §2.3 / §3** 可追溯一致。

### 2.3 预测销量 P 与上下限：计算逻辑对照（表格）

下列表格将 **点预测 P** 与 **下限 / 上限** 放在同一视角下对比：**先**由 M、T、α 得到 **P**，**再**在「与 P 同构的销量合成公式」中仅替换 §3 五类因子的悲观/乐观取值，分别得到下限、上限。

#### 表 1：点预测 P 的分支与公式（同一 MSKU × 自然月）

| 分支条件 | 预测销量 **P**（点预测，与详情「预测销量」列一致） | **α** | 说明 |
|----------|------------------------------------------------------|--------|------|
| **T 为空**（无 BP 目标） | **P = M** | **必须为空**，不参与加权 | 无销售目标约束时，展示与合成路径上的点预测即市场预测 M；正式版可对「不可算」兜底策略另定。 |
| **T 非空且 M ≤ T** | **P = T × 1.05** | 有值，取值 **[0, 1]**（配置中心维护） | 市场预测不高于 BP 目标时，将结果抬升至不低于目标的 5% 缓冲（业务落地口径）。 |
| **T 非空且 M > T** | **P = T × α + M × (1 − α)** | 同上 | 在市场预测与 BP 目标之间按 α 线性插值；α 越大越偏向 T。 |

#### 表 2：点预测 P vs 下限 vs 上限（同一套销量公式下的差异）

| 对比项 | **预测销量 P**（点预测） | **下限**（悲观情景） | **上限**（乐观情景） |
|--------|--------------------------|----------------------|----------------------|
| **产出形态** | 单月 **一个点值**（列表主数字、柱图高度、详情「预测销量」） | 单月 **一个点值**（区间左端） | 单月 **一个点值**（区间右端） |
| **计算顺序** | **第一步**：由 M、T、α 按 **表 1** 得到 P（T 空时 **P=M**）。 | **第二步**：在「与点预测**相同**的销量合成公式」中，将 §3 五类因子替换为 **悲观**列取值，其余因子与点预测一致，求得销量结果即为 **下限**。 | **第二步**：同上，将五类因子替换为 **乐观**列取值，求得 **上限**。 |
| **是否依赖 P** | — | **依赖**：公式中的「点预测路径」在 **T 非空**时以已算出的 **P** 代入；**T 空**时与 §4 一致，以 **P=M** 与 §3 同构求区间（不对 M 做固定比例缩放）。 | 同左 |
| **因子角色** | 不直接套用 §3 的 min/max 表；M 本身已反映算法/规则侧多因子结果。 | 仅替换 **流量、转化率、竞争力、价格、广告花费** 五类因子为 §3「下限」列极值。 | 仅替换上述五类为 §3「上限」列极值。 |
| **与 BP/α 关系** | 直接由 **T、α、M** 按表 1 分支决定。 | 在已定的 **P**（及同构公式其余项）上换因子向量；**不**再单独改 T、α 的展示规则。 | 同左 |
| **典型用途** | 主指标、与 BP/实际对比、下游引用。 | 计划评审悲观边界、可解释「差情景卖多少」。 | 计划评审乐观边界、可解释「好情景卖多少」。 |
| **序关系（原则）** | — | 须满足 **下限 ≤ P ≤ 上限**（若非线性导致不成立则按 §4 单调修正并记日志）。 | 同左 |

#### 表 3：符号与数据流（与详情弹窗、主工作台对齐）

| 符号 | 含义 | 在计算中的位置 |
|------|------|----------------|
| **M** | 市场预测值（未叠 BP 规则前） | **P** 的输入；T 空时 **P=M**。 |
| **T** | BP 目标（业务系统拆解） | **P** 的分支条件与输入；T 空则 α 必空。 |
| **α** | BP目标融合权重（0～1） | **仅**在 **M > T** 分支参与 **P**；与配置中心列一致。 |
| **P** | 点预测（预测目标） | **上下限**同构公式的基准点（T 空时路径上为 M）。 |
| **下限 / 上限** | §3 因子极值 + 同构公式 | **在 P 确定之后**计算，与图表浅色带、Tooltip、列表括号区间一致。 |

## 3. 功能需求：因子取值规则（上下限规划逻辑）

**原则**：在**与点预测相同的销量合成公式**中，仅替换下表五类因子；**下限（悲观）**各因子取不利销量一侧极值，**上限（乐观）**取有利一侧；其余因子与点预测一致。

| 因子 | 下限（悲观） | 上限（乐观） | 窗口与聚合 |
|------|--------------|--------------|------------|
| **流量** | `min(去年同期流量, 点预测所用预测流量)` | `max(同上两项)` | 同粒度、与预测月对齐 |
| **转化率** | 近 3 个月各月转化率代表值的 **min** | 近 3 个月各月代表值的 **max** | 不含目标月；每月先定「月代表值」，再对 3 个月取极值（转化口径需统一） |
| **竞争力** | 近 3 个月月代表值的 **min**（指标越大越强时） | 近 3 个月月代表值的 **max** | 同上；方向以字典为准，反向指标则悲观/乐观对调 |
| **价格** | 近 1 年各月 **月均价** 的 **max**（价高偏悲观） | 近 1 年各月 **月均价** 的 **min**（价低偏乐观） | 不含目标月；有效月参与，无效月剔除 |
| **广告花费** | 近 3 个月月代表值的 **min** | 近 3 个月月代表值的 **max** | 与点预测币种/口径一致 |

**缺失与边界**：历史不足 3/12 个月时，窗口缩至可用月，仍不足则**该因子沿用点预测**并标注「历史不足」。无去年同期流量时，上下限流量均**取预测流量**（或 proxy，待确认）。价格/广告若 12 个月均无效则因子**与点预测一致**。竞争力方向须在指标字典配置，避免反号。

## 4. 销量合成（上下限数值如何得到）

1. **点预测 P**：优先按 **§2.1**（分支与公式见 **§2.3 表 1**）由市场预测值 M、BP 目标 T、**BP目标融合权重（α）** 得到；与详情弹窗「预测销量」列一致；算法原始输出须经 **§2.2** 与 BP 目标对齐后再作为展示与推荐的最终值。  
2. **上下限**（§3）：与点预测**同一套销量公式**；仅将 §3 表中悲观/乐观因子向量代入，分别得到 **销量下限、销量上限**；其余因子不变。**T 非空**时公式中的点预测取 **P**；**T 空**时取 **P=M**，区间仍由 §3 情景得出。  
3. **序关系**：原则上 **下限 ≤ 点预测 ≤ 上限**；若公式非线性导致不成立，后端做单调修正（阈值 **待业务确认**）并记日志。  
4. **点预测非规则可拆时**（立项二选一）：**A** 区间用固定比例/分位数 + 因子说明条；**B** 算法提供指定因子向量下的反事实预测，本 PRD 只定义因子向量。

## 5. 展示与交互（与主 PRD 对齐）

| 位置 | 需求 |
|------|------|
| 列表月度单元格 | 主数值为点预测；括号内展示 **下限～上限**（与图表浅色带口径一致）。 |
| 图表 | **预测目标值**：柱为点预测，可叠浅色带为上下限区间，Tooltip 可展示当月下限、上限。**BP 目标**、**人工/forecast 填报类点值**为固定单列，**不**展示区间带、**不**在 Tooltip 附下限/上限。 |
| 详情 | 可按月展示各因子在点预测 / 下限情景 / 上限情景下的取值对照表，便于解释。 |

## 6. 非功能需求（摘要）

| 类别 | 要求 |
|------|------|
| **性能** | 单次列表查询在约定数据量下返回时间目标由主 PRD/接口 SLA 继承；区间宜与点预测**同次请求**返回，避免二次往返。 |
| **审计** | 保存用于计算上下限的**原始月序列**版本号或数据日期，便于复盘「为何该月区间偏宽」。 |
| **权限** | 与点预测一致；无价格/广告权限的角色隐藏对应因子或整段区间（产品策略二选一）。 |

## 7. 待确认清单（评审前补齐）

1. 「近 3 个月 / 近 1 年」是否**必须不含预测目标月**，还是含当月已发生部分（月中预测场景）。  
2. 转化率、竞争力、广告花费的「月代表值」是**自然月整月**还是「截至锚定日的 MTD 年化」？  
3. 去年同期流量是否与**农历大促**或业务**活动周对齐**做同比（而非公历同月）。  
4. 多币种站点：价格与广告花费是否统一折 **USD** 再比极值。
