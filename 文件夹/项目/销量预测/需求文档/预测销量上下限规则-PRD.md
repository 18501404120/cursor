# 产品需求文档（PRD）：预测销量上下限规则

> **关联文档**：[基于规则的销量预测设计说明.md](../基于规则的销量预测设计说明.md)、[销量预测管理-PRD.md](./销量预测管理-PRD.md)  
> **适用范围**：销量预测结果在列表、图表、详情中的**可解释区间**（下限～上限），与「点预测」并列展示或用于预警阈值。  
> **文档版本**：v1.0  
> **状态**：草案  
> **最后更新**：2026-04-15

---

## 1. 背景与目标

### 1.1 背景

业务需要在「点预测」之外展示**合理波动区间**，支撑计划评审、库存安全量讨论与异常检测。区间应来自**可解释的驱动因子**（流量、转化率、竞争力、价格、广告花费等），而非简单按点预测乘常数，以便与运营认知对齐、便于审计。

### 1.2 目标

| 目标 | 说明 |
|------|------|
| **口径统一** | 下限、上限分别对应一套明确的因子取值规则（悲观情景 / 乐观情景）。 |
| **可复现** | 时间窗口、聚合方式（月均）、同比对齐规则在数据层可实现、可单测。 |
| **与规则预测一致** | 上下限由「因子极值 + 与点预测相同的销量合成公式」得出；若点预测为算法黑盒，需约定等价接口或近似路径（见 §5）。 |

### 1.3 非目标（本 PRD 不展开）

- 具体接口字段名、调度频率、存储表结构（由《接口说明》或技术设计补全）。  
- 非以下五类因子的其他因子（如生命周期、大促标签）是否纳入区间，默认**不改变点预测中已锁定部分**，仅替换下表所列因子取值。

## 2. 名词与范围

| 名词 | 定义 |
|------|------|
| **点预测** | 当前任务产出的单值预测销量（系统/规则/融合后的主结果）。 |
| **预测流量** | 与点预测同一任务、同一版本下使用的**流量输入**（或模型反推的流量假设）；用于与去年同期流量做比较。 |
| **去年同期流量** | 与**目标预测月**在公历上对齐的**去年同月**（或业务约定的「同比月」）内，按与点预测一致的粒度聚合后的流量。 |
| **近 3 个月** | **不含预测目标月本身**的、向前连续 3 个完整自然月的滚动窗口；各因子在该窗口内先按**自然月**聚合，再对三个月的月值取 min/max（见 §3.2）。 |
| **近 1 年** | **不含预测目标月本身**的、向前连续 12 个完整自然月的滚动窗口；价格取各月**月均价格**后再做极值（见 §3.3）。 |
| **转化率 / 竞争力** | 与《基于规则的销量预测设计说明》中定义一致；具体数据源（站内转化、类目排名等）以主数据与数仓字典为准。 |
| **广告花费** | 与点预测口径一致的渠道广告花费（币种、含税规则与财务/广告中台对齐）。 |

**粒度约定（待配置，默认推荐）**：同一 **MSKU（或 ASIN+渠道最小粒度）× 自然月** 计算一对上下限；跨店汇总需在规格中声明聚合顺序（建议先 SKU 再汇总，避免「均值之均值」偏差）。

## 3. 功能需求：因子取值规则

### 3.1 总原则

- **下限情景（悲观）**：在销量合成公式中，对下列因子代入**偏不利于销量**的一侧极值（流量取低、转化取低、竞争力取弱侧、价格取高压制需求侧、广告投入取低）。  
- **上限情景（乐观）**：代入**偏有利于销量**的一侧极值（与下限对称：流量取高、转化取高、竞争力取强侧、价格取低刺激需求侧、广告投入取高）。  
- 未在本表列出的因子：**与点预测保持一致**，除非业务另行要求「全因子极值组合」（可作为 P2 扩展）。

### 3.2 下限（悲观情景）— 各因子取值

| 因子 | 规则（业务描述） | 聚合说明 |
|------|------------------|----------|
| **流量** | 取 **去年同期流量** 与 **当前点预测所用预测流量** 中的 **较低值** | 同一粒度、同一时间对齐后的两个标量取 `min` |
| **转化率** | 取 **近 3 个月**内，各自然月转化率的 **月均**序列中 **最低**的一个月均值（即三个月月均值再取 **min**） | 每月先算当月日均或当月整体转化率（需统一一种）；再对三个月的「月代表值」取最小 |
| **竞争力** | 取 **近 3 个月**内，各月竞争力指标的 **月均**序列中的 **最低**值（含义上为「最弱竞争态势」对应取值，具体指标方向由字典定义：若数值越大表示越强，则下限情景取 min） | 与上类似：三个月月值取 min |
| **价格** | 取 **近 1 年**各自然月 **月均价格** 中 **最高**的一个月均价 | 「月均价格」= 当月有效成交或展示价的月均值；12 个月代表值取 **max**（高价抑制销量，属悲观侧） |
| **广告花费** | 取 **近 3 个月**内，各月广告花费的 **月均**（或月总额）序列中的 **最低**值 | 三个月月值取 **min**（投入少则偏悲观） |

### 3.3 上限（乐观情景）— 各因子取值

与下限**对称**：每一行改为取有利于销量一侧的 **max**（或与下限对偶的极值）。

| 因子 | 规则（业务描述） | 聚合说明 |
|------|------------------|----------|
| **流量** | 取 **去年同期流量** 与 **当前预测流量** 中的 **较高值** | `max(去年同期流量, 预测流量)` |
| **转化率** | 取 **近 3 个月**各月转化率代表值中的 **最高**值 | 三个月月值取 **max** |
| **竞争力** | 取 **近 3 个月**各月竞争力代表值中的 **最高**值 | 三个月月值取 **max**（若指标越大越强） |
| **价格** | 取 **近 1 年**各月 **月均价格** 中的 **最低**值 | 十二个月月值取 **min**（低价刺激销量，属乐观侧） |
| **广告花费** | 取 **近 3 个月**各月广告花费代表值中的 **最高**值 | 三个月月值取 **max** |

### 3.4 边界与缺失数据处理

| 场景 | 处理策略（建议） |
|------|------------------|
| 新上架不足 3 个月无历史 | 转化率/竞争力/广告花费的 min/max 窗口**不足时**：回退为「自上架首月起至预测月上月」的可用月数；仍不足则**该因子与点预测一致**并在 UI 标注「历史不足」。 |
| 无去年同期（新渠道/新站点） | 去年同期流量缺失时：**下限/上限流量均取预测流量**（或取类目/店铺层级 proxy，需业务确认）。 |
| 某月价格/广告全为空 | 该月不参与月均计算；若 12 个月均无效则该因子**与点预测一致**。 |
| 竞争力指标方向性 | 若业务定义「数值越小越强」，则下限情景取该指标的 **max**、上限情景取 **min**；须在指标字典中配置方向，避免反号。 |

## 4. 销量合成（上下限数值如何得到）

1. **与点预测同构**：采用与点预测相同的销量计算公式（连乘/加权规则以《基于规则的销量预测设计说明》及后台实现为准）。  
2. **仅替换因子向量**：点预测代入基准与各因子基准值；**下限**代入 §3.2 表格中的因子集合，其余因子不变，得到 **销量下限**；**上限**代入 §3.3，得到 **销量上限**。  
3. **序关系校验**：在默认规则下应满足 **销量下限 ≤ 点预测 ≤ 销量上限**；若因非线性或裁剪导致不成立，需在后端做 **单调修正**（例如将下限 capped 为点预测的 0.5×、上限 capped 为 1.5×）并打日志——具体阈值 **待业务确认**。  
4. **算法黑盒场景**：若点预测不由可拆解因子公式产生，可采用（二选一，立项时敲定）：  
   - **A**：仅对可观测因子展示「情景说明条」，区间仍用固定比例或分位数（与当前原型演示一致）；  
   - **B**：算法侧提供「在指定因子向量下的反事实预测」接口，本规则仅定义因子向量。

## 5. 展示与交互（与主 PRD 对齐）

| 位置 | 需求 |
|------|------|
| 列表月度单元格 | 主数值为点预测；括号内展示 **下限～上限**（与图表浅色带口径一致）。 |
| 图表 | 柱为点预测；浅色带为上下限区间；Tooltip 展示当月下限、上限数值。 |
| 详情 | 可按月展示各因子在点预测 / 下限情景 / 上限情景下的取值对照表，便于解释。 |

## 6. 非功能需求（摘要）

| 类别 | 要求 |
|------|------|
| **性能** | 单次列表查询在约定数据量下返回时间目标由主 PRD/接口 SLA 继承；区间宜与点预测**同次请求**返回，避免二次往返。 |
| **审计** | 保存用于计算上下限的**原始月序列**版本号或数据日期，便于复盘「为何该月区间偏宽」。 |
| **权限** | 与点预测一致；无价格/广告权限的角色隐藏对应因子或整段区间（产品策略二选一）。 |

## 7. 待确认清单（评审前补齐）

1. 「近 3 个月 / 近 1 年」是否**必须不含预测目标月**，还是含当月已发生部分（月中预测场景）。  
2. 转化率、竞争力、广告花费的「月代表值」是**自然月整月**还是「截至锚定日的 MTD 年化」？  
3. 去年同期流量是否与**农历大促**或业务**活动周对齐**做同比（而非公历同月）。  
4. 多币种站点：价格与广告花费是否统一折 **USD** 再比极值。  
5. 与 **MSKU 预计阈值规则** 中偏差告警的关系：区间宽度是否参与告警，避免重复或矛盾。
