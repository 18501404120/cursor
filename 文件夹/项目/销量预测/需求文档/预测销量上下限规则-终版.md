# 预测销量客观三线（终版）

**本文档为唯一口径**：描述每个货号、每个预测月的 **客观下限销量、客观中值销量、客观上限销量**（件数）的来源与计算顺序；与主工作台、配置中心、原型说明交叉引用时均以本文件为准。**产品内需求预测与汇总一律使用销量件数**，不引入「均价 × 销量」类营收折算。

---

## 一、在算什么

每个货号、每个预测月输出三条销量（件数）：

- **客观中值销量**：规则或模型在**中值路径**下得到的单月点预测，**仅**使用客观因子与约定统计窗口，**不**读取任何经营类「目标」输入（例如 BP、销售目标、人工填目标等）。
- **客观下限销量 / 客观上限销量**：与客观中值**同一套销量合成公式**，将流量、转化、竞争力、广告、价格等因子按**第三节**在悲观路径 / 乐观路径上取极值或缩放后代入求得；同样**与目标类输入无关**。

**汇总范围**：默认当前专员权限内负责的全部货号；若用户筛选子集，只计算子集并在界面标明。

---

## 二、怎么算（按顺序）

1. **客观中值销量**：由规则引擎与/或机器学习管线输出，输入侧**仅**客观因子与主数据，**不**含目标类字段。  
2. **客观下限、客观上限销量**：与中值同构公式，因子按第三节取悲观侧 / 乐观侧。  
3. **落地**：三档销量取整展示；**客观下限 ≤ 客观中值 ≤ 客观上限**；若因子窗口缺数导致边界异常，按引擎兜底策略并在日志留痕。

---

## 三、因子口径摘要（销量合成用）

在与客观中值**相同的销量合成公式**里，只替换下面五类因子；悲观取**不利销量**一侧，乐观取**有利销量**一侧；其余与中值一致。

| 因子 | 客观下限（悲观） | 客观上限（乐观） | 窗口与聚合 |
|------|------------------|------------------|------------|
| **流量** | 预测流量 × **0.5** | 预测流量 × **2** | 与预测月、同粒度对齐 |
| **转化率** | 近 3 个月各月代表值的 **min** | 近 3 个月各月代表值的 **max** | **不含**预测月 |
| **竞争力** | **与中值路径相同**（见下「竞争力与主链路一致」） | **与中值路径相同** | **不再**对竞争力单独取近 3 月 min/max；入参即 **`G_comp`**（与《销量预测-分步计算说明》**§3.5** 完全一致） |
| **价格**（进销量公式） | 近 1 年各月**月均价**的 **max**（价高偏悲观） | 近 1 年各月**月均价**的 **min**（价低偏乐观） | **不含**预测月 |
| **广告花费** | 近 3 个月月代表值的 **min** | 近 3 个月月代表值的 **max** | 与中值路径币种/口径一致 |

上表中的「价格」**仅**参与**销量**合成中的因子路径；**不得**再套一层「用另一套均价把销量折成营收」作为本产品的预测或上下限判定环节。

#### 竞争力与主链路一致（定稿）

1. **定义合并**：销量合成（客观中值、客观下限、客观上限）中所用的 **竞争力增长率**，与《销量预测-分步计算说明》**§3.5** 中的 **`G_comp`** **为同一变量、同一套计算**（小类/大类排名、预测月前两月相对前月的 **`R_sym`** 环比、月权 **0.45 / 0.55**、小类/大类权 **0.7 / 0.3**）。缺数时 **`G_comp = 0`**，竞争力项不对销量合成施加额外偏离（与系数链 **`C_comp = 1`** 语义对齐，由引擎统一实现）。  
2. **悲观 / 乐观路径**：**流量、转化率、广告、价格** 仍按上表取历史窗 **min / max** 或缩放；**竞争力** **不再**单独取「近 3 个月代表值 min/max」，**下限路径、上限路径与中值路径在竞争力因子处共用同一 `G_comp`**。  
3. **同源 ASIN 非承载 MSKU**（见《销量预测-分步计算说明》**§1.1**）：**客观下限销量 = 客观中值销量 = 客观上限销量 = 0**（件），**主工作台仍须展示**该三线与标签；**达成率**口径仍以《R1至R3规则说明》**§5.3** 为准。

## 四、数据示例（按步骤）

> **与定稿差异**：下表「步骤 1」中 **竞争力 g「悲观 min → 乐观 max」** 为**历史示意骨架**；**当前产品口径**下 **`g` 与 `G_comp` 同源**，且 **悲观/乐观/中值三线在竞争力上同值**（见第三节「竞争力与主链路一致」）。**流量、转化率、广告、价格** 仍按第三节取极值。**数仓与引擎落地后，本示例数值将整体替换。**

以下示例预测月为 **2026-05**，汇总 **MSKU A / B / C**，与第三节因子表一致。

## 六、与主工作台「目标 R1～R3」的衔接

- 规则引擎 / 机器学习管线输出的**点预测销量**，经《R1至R3规则说明》中的**时间阶梯锁定**后，形成对目标月的 **目标 R1、目标 R2、目标 R3**（件数）。  
- 对每一个 **目标 Rk** 的**点预测值**，可套用本文**第二节**所述**同一套销量合成公式**，在悲观 / 乐观情景下派生对应的**下限销量、上限销量**，用于主工作台图表中的浅色区间带与详情下钻；**因子口径与量纲仍以本文为准**，锁定规则以《R1至R3规则说明》为准。  
- **达成率** 不在本文展开，定义与筛选见《R1至R3规则说明》。
