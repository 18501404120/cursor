# 产品需求文档（PRD）：目标助手 · 主工作台

> **产品名称**：**目标助手**。本 PRD 描述主工作台（原「销量预测管理」单页）。  
> **关联文档**：[项目背景.md](../项目背景.md)、[预测销量上下限规则-终版.md](./预测销量上下限规则-终版.md)（**客观三线**；唯一口径）  
> **原型**：[../原型/销量预测管理-原型说明.html](../原型/销量预测管理-原型说明.html)（全局筛选 + 趋势图 + SKU 明细表等；说明版含红点）  
> **文档版本**：v3.0  
> **状态**：草案

## 1. 背景与目标

### 1.1 业务背景

与《项目背景》一致：行业进入精细化运营阶段，**可解释的需求预测**是库存与补货决策的重要输入。主工作台在同一时间切片下展示 **客观中值、客观区间、实际** 以及（若启用）**人工或 forecast 填报**，便于计划与运营对齐与留痕。产品**不承载**「预测准确率 / MAPE / 达成率」类考核与展示。

### 1.2 名词（与本页强相关）

| 名词 | 定义 |
|------|------|
| **客观中值** | 当前任务下，按**规则引擎与/或机器学习**、**仅基于客观因子**得到的单月主点预测；与《预测销量上下限规则-终版》一致。 |
| **客观下限 / 客观上限** | 与客观中值同构销量公式下，代入因子悲观/乐观极值得到的边界；**不因**任何经营类「目标」输入而改变。 |
| **实际销量** | 与财务/运营约定的**出库或结算口径**实际值，与《项目方案》中历史销量数据源一致。 |
| **人工预测值 / forecast** | 业务在流程中填报或修正的销量点值，用于对照与协同；**不参与**客观三线的自动计算。 |

### 1.3 本页产品目标

| 目标 | 说明 |
|------|------|
| **查看** | 按区域/渠道/SKU 等维度查看 **客观中值、客观区间、实际** 及（若启用）人工/forecast。 |
| **解释** | 支持从汇总到 SKU、从客观三值到因子下钻，提升业务信任度。 |
| **协同** | 支持异常备注、历史追溯、批量备注（**仅记录与展示**，不参与预测类自动计算）。 |

### 1.4 成功指标（本页可验收）

- 计划/运营能在**单一页面**完成：筛选 → 看趋势 → 查 SKU → 看计算明细 → 写/查备注。  
- 核心筛选条件下，列表与图表**口径与后台预测任务一致**（同源数据、同一时间切片）。  
- 详情面板展示的因子与**客观中值、客观下限、客观上限**来源字段**与后端可追溯一致**（允许展示粒度与权限裁剪，但不可逻辑矛盾）。  
- **不包含**：准确率、MAPE、达成率、R1～R3 达成、预测版本锁定与冻结快照对比类功能与文案。

## 2. 范围与名词

### 2.1 范围说明

- **纳入**：本 PRD 描述**目标助手 · 主工作台**主单页及其关联弹层（详情、异常备注历史、批量异常备注）。  
- **不包含**（可另起 PRD）：规则引擎配置后台、模型训练与发布流程、补货建议引擎全链路（本页仅消费预测结果与元数据）。

### 2.2 其他名词

| 名词 | 定义 |
|------|------|
| **系统预测** | 规则/基线或算法管线输出的标准结果，未经本条 SKU/该月的业务人工覆盖（若存在覆盖，需在详情或状态中区分）。 |
| **异常备注** | 业务对某 SKU 或批量 SKU 的说明与纠偏意图记录；**仅作追溯与协同说明**，不参与预测管线自动计算。 |

## 3. 用户角色与核心场景

| 角色 | 典型场景 |
|------|----------|
| **供应链计划 / 需求计划** | 按组织与渠道查看客观预测带，对大促 SKU 写异常备注并留档。 |
| **渠道运营** | 按国家/渠道筛选，对比客观中值与实际，点开单元格看因子分解。 |
| **销售** | 查看本人或本组 MSKU 的预测与实际，用于运营节奏协同（权限与数据范围另定）。 |
| **数据分析 / 算法** | 从因子与结果下钻驱动规则与模型迭代（**不以本页 MAPE/达成率为 KPI**）。 |
| **管理层（只读）** | 查看趋势与汇总，不做编辑。 |

## 4. 页面信息架构

```
顶部：全局筛选 + 查询/重置
├── 主图表区：客观中值（含客观下～上浅色带）、实际销量（及可选人工/forecast）
├── 明细表：维度列 + 月度列（客观中值为主数字，可附客观区间）+ 汇总行 + 迷你趋势 + 操作（详情/异常备注）
└── 弹层：详情（因子表）| 历史异常备注 | 批量异常备注
```

说明：**不**设「预测准确率 KPI 卡」「R1～R3 准确率列」「系统 vs 人工误差率」等区域。

## 5. 功能需求

### 5.1 全局筛选区

| 元素 | 类型 | 需求说明 |
|------|------|----------|
| 区域 | 下拉 | 单选或多选（与主数据一致）；影响下方所有组件。 |
| 国家 | 下拉 | 依赖区域可选；支持清空联动。 |
| 渠道 | 下拉 | 与 ERP/OMS 渠道主数据编码一致。 |
| 销售组织 | 下拉 | 权限过滤：用户仅能看到授权组织数据。 |
| 品牌 / 产品系列 | 下拉 | 可选。 |
| E-code/SKU 搜索 | 文本 | 支持精确/模糊（产品定义一种默认策略）；与查询按钮联动。 |
| 年、月 | 下拉/日期 | 定义**列表与图表的时间窗口基准**（与方案中滚动预测窗口对齐）。 |
| 预测状态 | 下拉 | 枚举值需与后台任务状态一致（如：待生成/已生成/失败等）。 |
| 审核状态 | 下拉 | 若业务流程含审核，与审核流状态一致。 |
| 查询 / 重置 | 按钮 | 触发全页数据刷新；重置为默认筛选。 |

**交互**：建议**默认点击查询刷新**，避免大数据量下频繁请求。

### 5.2 主图表区

| 元素 | 需求说明 |
|------|----------|
| 柱状图 | **客观中值**（规则/ML 客观输出）、**人工预测值**（默认进主图，可由图例隐藏）、**实际销量**（已关账月）。 |
| X 轴 | 月份时间序列，与筛选范围一致。 |
| Y 轴 | **销量数量**（单轴）；**不**展示达成率、百分比第二纵轴。 |
| 客观区间带 | **仅**绕 **客观中值**展示浅色带（客观下限～客观上限，见《预测销量上下限规则-终版》）及 Tooltip；**人工预测值**为点值，**无**该区间带、**不**附客观下/上限 Tooltip。 |
| 空状态 / 加载 | 无权限或无数据时明确提示。 |

### 5.3 明细表格

1. **维度列**：区域/国家/渠道、品牌/产品系列、SKU（E-code）/名称等。  
2. **月度数据列**：每月单元格以 **客观中值** 为主数字；可展示 **客观下限～客观上限**（括号或次行）；可选叠加系统规则行、forecast 行（与原型一致）；**不**展示「准确率%」。  
3. **汇总行**（验收要点）：当前筛选范围内，该月 **`SumLo`/`SumMid`/`SumHi`（三档销量合计）** 与《预测销量上下限规则-终版》算例逻辑一致。  
4. **历史趋势**：每行 Sparkline 为 **客观中值** 序列（若产品定义切换为其他序列须统一并注明）。  
5. **操作**：**详情**、**异常备注**。

**交互**：点击单元格打开详情；表头冻结、列宽、销售团队列换行规则与原型一致。

### 5.4 详情面板（计算分解）

用于回答「客观中值/客观带怎么来的」。

| 列/字段 | 说明 |
|---------|------|
| 月份 | 与表格所选单元格对应。 |
| 客观中值 / 客观下限 / 客观上限 | 与《预测销量上下限规则-终版》**因子与销量合成路径**及后台输出一致；**仅**由客观因子情景得出。 |
| 影响因子系数 | 流量、转化等（与可解释输出一致）。 |
| forecast 等 | 若流程启用，与填报源一致，**不参与**客观三线回算。 |

### 5.5～5.7 异常备注与批量备注

| 字段 | 说明 |
|------|------|
| 行内异常备注 | 操作列「异常备注」入口：**始终**可点击，打开该 SKU 的备注历史/新增；**不依赖**本行或全表勾选框。 |
| 批量异常备注 | 工具栏「新增异常备注」：**需**先勾选 **至少一行** 方可启用；写入范围与所选行一致（仅记录与展示）。 |
| 历史列表 | 调整人、时间、备注内容、生效期间。 |
| 批量备注校验 | 同主 PRD 既有校验；不参与任何「准确率」汇总（本页不提供该类汇总）。 |

## 6. 业务规则与数据口径

### 6.1 与预测服务的关系

- **客观中值 / 客观带** 以预测任务、规则引擎/算法服务及《预测销量上下限规则-终版》输出为准；**预测批次**（如 P1～P3）命名与含义以预测配置中心为准。

### 6.2 与下游补货的关系

- 本页展示层**不直接改补货单**；异常备注的展示与下游消费边界（若有）由接口与数据团队另行约定，**本 PRD 不将备注作为预测计算的输入**。

### 6.3 与《预测销量上下限规则-终版》对齐

- **客观中值** 与 **客观下限/上限** 仅由客观因子与终版规则得出。  
- 列表、图表、详情、导出与预测配置中心展示名须**同源**。

## 9. 验收标准（UAT 检查项示例）

1. 任意合法筛选组合下，图表与表格中 **客观中值、客观下限、客观上限、实际** 同源一致。  
2. 点击单元格打开详情，**客观三值**与表格一致（抽样核对）。  
3. **汇总行**试算与《预测销量上下限规则-终版》**第四节「数据示例」**中三档销量手算一致（抽 1 个月）。  
4. 页面**不出现**准确率、MAPE、达成率、R1～R3 达成类指标与列。  
5. 无权限用户看不到未授权组织/渠道数据。
