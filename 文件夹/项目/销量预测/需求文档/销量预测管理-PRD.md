# 产品需求文档（PRD）：目标助手 · 主工作台

> **产品名称**：**目标助手**。本 PRD 描述主工作台（原「销量预测管理」单页）。  
> **关联文档**：[项目背景.md](../项目背景.md)、[销量预测项目方案.md](../销量预测项目方案.md)（即《目标助手项目方案》）  
> **原型**：[../原型/销量预测管理-原型.html](../原型/销量预测管理-原型.html)（全局筛选 + 趋势图 + SKU 明细表等）  
> **文档版本**：v2.0  
> **状态**：草案

## 1. 背景与目标

### 1.1 业务背景

与《项目背景》一致：行业进入精细化运营阶段，**销量预测是库存与补货决策的重要输入**；销售与计划需要把 **GTM 中的销量目标（BP）**、**系统按规则/模型产出的预测目标**与**实际**放在同一页面查看与协同。产品**不承载**「预测准确率 / MAPE / 达成率」类考核与展示（含 R1～R3 口径的达成、锁定快照对比等均已不作为产品范围）。

### 1.2 名词（与本页强相关）

| 名词 | 定义 |
|------|------|
| **销量目标（BP）** | 业务在 **GTM 系统**中维护的**全年销售目标**拆解到 MSKU/渠道/月（或产品承接的粒度）；与本页图表中的「BP目标值」同源。 |
| **预测目标** | 当前任务下，按**规则引擎与/或机器学习**逻辑计算得到的**预测销量**（单月点值）；与详情中的因子分解、配置中心参数一致；**非**「锁定版最后一版预测」类快照概念。 |
| **实际销量** | 与财务/运营约定的**出库或结算口径**实际值，与《项目方案》中历史销量数据源一致。 |

### 1.3 本页产品目标

| 目标 | 说明 |
|------|------|
| **查看** | 按区域/渠道/SKU 等维度查看 **BP、预测目标、实际** 及（若启用）人工/forecast 与预测区间说明。 |
| **解释** | 支持从汇总到 SKU、从结果到因子（基量、调整系数、影响因子）的下钻，提升业务信任度。 |
| **协同** | 支持异常备注、历史追溯、批量备注及「是否参与预测计算」开关，与计划/运营/销售目标管理工作流对齐。 |

### 1.4 成功指标（本页可验收）

- 计划/运营能在**单一页面**完成：筛选 → 看趋势 → 查 SKU → 看计算明细 → 写/查备注。  
- 核心筛选条件下，列表与图表**口径与后台预测任务一致**（同源数据、同一时间切片）。  
- 详情面板展示的因子与**预测目标**及（若展示）**销量目标**来源字段**与后端可追溯一致**（允许展示粒度与权限裁剪，但不可逻辑矛盾）。  
- **不包含**：准确率、MAPE、达成率、R1～R3 达成、预测版本锁定与冻结快照对比类功能与文案。

## 2. 范围与名词

### 2.1 范围说明

- **纳入**：本 PRD 描述**目标助手 · 主工作台**主单页及其关联弹层（详情、异常备注历史、批量异常备注）。  
- **不包含**（可另起 PRD）：规则引擎配置后台、模型训练与发布流程、补货建议引擎全链路（本页仅消费预测结果与元数据）。

### 2.2 其他名词

| 名词 | 定义 |
|------|------|
| **系统预测** | 规则/基线或算法管线输出的标准结果，未经本条 SKU/该月的业务人工覆盖（若存在覆盖，需在详情或状态中区分）。 |
| **异常备注** | 业务对某 SKU 或批量 SKU 的说明与纠偏意图记录；可选**是否参与预测计算**（参与时应对后续滚动预测或融合层产生约束/覆盖，具体算法侧另表）。 |

## 3. 用户角色与核心场景

| 角色 | 典型场景 |
|------|----------|
| **供应链计划 / 需求计划** | 按组织与渠道查看 BP 与预测目标差异，对大促 SKU 写异常备注并标记是否参与计算。 |
| **渠道运营** | 按国家/渠道筛选，对比预测目标与实际，点开单元格看因子分解。 |
| **销售** | 查看本人或本组 MSKU 的 BP 与预测目标、实际，用于目标管理节奏（权限与数据范围另定）。 |
| **数据分析 / 算法** | 从因子与结果下钻驱动规则与模型迭代（**不以本页 MAPE/达成率为 KPI**）。 |
| **管理层（只读）** | 查看趋势与汇总，不做编辑。 |

## 4. 页面信息架构

```
顶部：全局筛选 + 查询/重置
├── 主图表区：BP目标值、预测目标值、实际销量（及可选人工/forecast）；可展示预测区间浅色带（见《预测销量上下限规则》）
├── 明细表：维度列 + 月度列 + 迷你趋势 + 操作（详情/异常备注）
└── 弹层：详情（因子表）| 历史异常备注 | 批量异常备注
```

说明：**不**设「预测准确率 KPI 卡」「R1～R3 准确率列」「系统 vs 人工误差率」等区域。

## 5. 功能需求

### 5.1 全局筛选区

| 元素 | 类型 | 需求说明 |
|------|------|----------|
| 区域 | 下拉 | 单选或多选（与主数据一致）；影响下方所有组件。 |
| 国家 | 下拉 | 依赖区域可选；支持清空联动。 |
| 渠道 | 下拉 | 与 ERP/OMS 渠道主数据编码一致。 |
| 销售组织 | 下拉 | 权限过滤：用户仅能看到授权组织数据。 |
| 品牌 / 产品系列 | 下拉 | 可选。 |
| E-code/SKU 搜索 | 文本 | 支持精确/模糊（产品定义一种默认策略）；与查询按钮联动。 |
| 年、月 | 下拉/日期 | 定义**列表与图表的时间窗口基准**（与方案中滚动预测窗口对齐）。 |
| 预测状态 | 下拉 | 枚举值需与后台任务状态一致（如：待生成/已生成/失败等）。 |
| 审核状态 | 下拉 | 若业务流程含审核，与审核流状态一致。 |
| 查询 / 重置 | 按钮 | 触发全页数据刷新；重置为默认筛选。 |

**交互**：建议**默认点击查询刷新**，避免大数据量下频繁请求。

### 5.2 主图表区

| 元素 | 需求说明 |
|------|----------|
| 柱状图 | **BP目标值**（来自 GTM 拆解）、**预测目标值**（当前规则/模型输出）、**实际销量**（已关账月）；可选 **人工预测值**（与原型勾选一致）。 |
| X 轴 | 月份时间序列，与筛选范围一致。 |
| Y 轴 | **销量数量**（单轴）；**不**展示达成率、百分比第二纵轴。 |
| 预测区间 | 若启用《预测销量上下限规则》，可在 BP/预测目标等点估计外展示浅色区间带；与点预测合成规则一致。 |
| 空状态 / 加载 | 无权限或无数据时明确提示。 |

### 5.3 明细表格

1. **维度列**：区域/国家/渠道、品牌/产品系列、SKU（E-code）/名称等。  
2. **月度数据列**：每月单元格展示**预测目标**为主数字；可选叠加系统规则行、forecast 行（与原型一致）；Tooltip 可展示 BP、实际等，**不**展示「准确率%」。  
3. **历史趋势**：每行 Sparkline（预测目标序列）。  
4. **操作**：**详情**、**异常备注**。

**交互**：点击单元格打开详情；表头冻结、列宽、销售团队列换行规则与原型一致。

### 5.4 详情面板（计算分解）

用于回答「预测目标怎么来的」及「与 BP 的关系」。

| 列/字段 | 说明 |
|---------|------|
| 月份 | 与表格所选单元格对应。 |
| 销量目标（BP） | 来自 **GTM**，与图表「BP目标值」同源（字段名以接口为准）。 |
| 市场预测值 M / 规则基量等 | 与《基于规则的销量预测设计说明》及后台输出一致。 |
| 影响因子系数 | 流量、转化等（与可解释输出一致）。 |
| **预测目标** | 当前规则/模型合成后的单月预测；与《预测销量上下限规则》§2.1 中 **P** 的关系以后台实现为准（若仍含 M/T/α 合成，须在详情可核对）。 |

### 5.5～5.7 异常备注与批量备注

| 字段 | 说明 |
|------|------|
| 历史列表 | 调整人、时间、备注内容、生效期间、**是否参与预测计算**（**不使用**「参与达成率计算」表述）。 |
| 批量备注 | 同主 PRD 既有校验；不参与任何「准确率」汇总（本页不提供该类汇总）。 |

## 6. 业务规则与数据口径

### 6.1 与 GTM、预测服务的关系

- **BP** 以 GTM 下发为准，本页只读展示与筛选消费。  
- **预测目标** 以预测任务/规则引擎/算法服务输出为准，每日或按任务版本刷新；**不做** R1/R2/R3 冻结快照用于考核。

### 6.2 与下游补货的关系

- 本页展示层**不直接改补货单**；「参与预测计算」的备注通过预测服务/数仓回流后，由既有补货链路消费（与《项目方案》接口约定一致）。

## 9. 验收标准（UAT 检查项示例）

1. 任意合法筛选组合下，图表与表格中 **BP、预测目标、实际** 同源一致。  
2. 点击单元格打开详情，**预测目标**与表格一致，**BP** 与 GTM 口径一致（抽样核对）。  
3. 页面**不出现**准确率、MAPE、达成率、R1～R3 达成类指标与列。  
4. 无权限用户看不到未授权组织/渠道数据。
