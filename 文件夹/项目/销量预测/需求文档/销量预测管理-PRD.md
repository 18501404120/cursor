# 产品需求文档（PRD）：销量预测管理

> **关联文档**：[项目背景.md](../项目背景.md)、[销量预测项目方案.md](../销量预测项目方案.md)  
> **原型**：[../原型/销量预测管理-原型.html](../原型/销量预测管理-原型.html)（全局筛选 + KPI + 趋势图 + SKU 明细表等）  
> **文档版本**：v1.0  
> **状态**：草案

## 1. 背景与目标

### 1.1 业务背景

与《项目背景》一致：行业进入精细化运营阶段，**销量预测是库存优化与补货决策的前提**；传统人工或简单统计预测准确率低，难以应对大促与动态市场；需采用「规则 + 算法」混合模式，并具备**可解释、可审计、可人工纠偏**能力，以支撑「预测 → 补货 → 调仓」闭环。

### 1.2 本页产品目标

| 目标 | 说明 |
|------|------|
| **监控** | 按区域/渠道/SKU 等维度查看系统预测与实际偏差，掌握 R1～R3 多提前期表现。 |
| **解释** | 支持从汇总到 SKU、从结果到因子（基量、调整系数、影响因子）的下钻，提升业务信任度。 |
| **协同** | 支持异常备注、历史追溯、批量备注及「是否参与预测计算」开关，与计划/运营工作流对齐。 |
| **度量** | 提供 MAPE 等准确率指标及「系统 vs 人工」对比视角，服务复盘与模型迭代。 |

### 1.3 成功指标（本页可验收）

- 计划/运营能在**单一页面**完成：筛选 → 看趋势 → 查 SKU → 看计算明细 → 写/查备注。  
- 核心筛选条件下，列表与图表**口径与后台预测任务一致**（同源数据、同一时间切片）。  
- 详情面板展示的因子与最终预测值**与后端计算日志可追溯一致**（允许展示粒度与权限裁剪，但不可逻辑矛盾）。

## 2. 范围与名词

### 2.1 范围说明

- **纳入**：本 PRD 描述**销量预测管理**主单页及其关联弹层（详情、异常备注历史、批量异常备注）。  
- **不包含**（可另起 PRD）：规则引擎配置后台、模型训练与发布流程、补货建议引擎全链路（本页仅消费预测结果与元数据）。

### 2.2 名词定义

| 名词 | 定义 |
|------|------|
| **预测提前期 R1～R3** | R1 表示**提前 1 个月**做出的预测，R2 为提前 2 个月，R3 为提前 3 个月。切换 R 用于对比不同「决策时点」上的预测质量。 |
| **MAPE（本页展示口径）** | 展示用公式：**MAPE = 1 − \|实际 − 预测\| / 实际**（即「准确率」型展示，非传统误差型 MAPE；分母为 0 或缺失时需定义保护策略，见 §6.2）。 |
| **系统预测** | 算法 + 规则融合后的标准输出，未经本条 SKU/该月的业务人工覆盖（若存在覆盖，需在详情或状态中区分）。 |
| **实际销量** | 与财务/运营约定的**出库或结算口径**实际值，与《项目方案》中历史销量数据源一致。 |
| **异常备注** | 业务对某 SKU 或批量 SKU 的说明与纠偏意图记录；可选**是否参与预测计算**（参与时应对后续滚动预测或融合层产生约束/覆盖，具体算法侧另表）。 |

## 3. 用户角色与核心场景

| 角色 | 典型场景 |
|------|----------|
| **供应链计划 / 需求计划** | 按组织与渠道查看 R1 准确率，对大促 SKU 写异常备注并标记是否参与计算。 |
| **渠道运营** | 按国家/渠道筛选，对比系统预测与实际，点开单元格看因子分解。 |
| **数据分析 / 算法** | 观察 MAPE 卡片与底部「系统误差率 vs 人工预测误差率」对比，驱动模型与规则迭代。 |
| **管理层（只读）** | 查看 KPI 与趋势，不做编辑。 |

## 5. 功能需求

### 5.1 全局筛选区

| 元素 | 类型 | 需求说明 |
|------|------|----------|
| 区域 | 下拉 | 单选或多选（与主数据一致）；影响下方所有组件。 |
| 国家 | 下拉 | 依赖区域可选；支持清空联动。 |
| 渠道 | 下拉 | 与 ERP/OMS 渠道主数据编码一致。 |
| 销售组织 | 下拉 | 权限过滤：用户仅能看到授权组织数据。 |
| 品牌 | 下拉 | 可选。 |
| 产品系列 | 下拉 | 可选。 |
| E-code/SKU 搜索 | 文本 | 支持精确/模糊（产品定义一种默认策略）；与查询按钮联动。 |
| 年、月 | 下拉/日期 | 定义**列表与图表的时间窗口基准**（与方案中滚动预测窗口对齐）。 |
| 预测状态 | 下拉 | 枚举值需与后台任务状态一致（如：待生成/已生成/失败等）。 |
| 审核状态 | 下拉 | 若业务流程含审核，与审核流状态一致。 |
| 查询 | 按钮 | 触发全页数据刷新；需防抖或 loading，避免重复提交。 |
| 重置 | 按钮 | 恢复默认筛选（默认值需在配置中定义，如当前财年、默认渠道）。 |

**交互**：筛选变更后，未点「查询」是否即时刷新——建议**默认点击查询刷新**，避免大数据量下频繁请求（可在高级设置中提供「自动查询」开关作为二期）。

### 5.2 KPI 卡片区

| 卡片 | 内容 | 规则 |
|------|------|------|
| R1～R3 MAPE | 各提前期下，当前筛选范围内的**聚合 MAPE**（§2.2 公式） | 聚合方式需定义：如按销量加权平均 vs 简单平均（建议**按销量加权**更贴近业务）。 |
| 预测调整 SKU 数 | 在筛选条件下，**存在人工调整或有效异常备注参与计算**的 SKU 数量（口径与后台一致） | 点击可下钻到表格过滤（可选增强）。 |

**展示**：保留原型中「多卡片并排」布局；数值保留合理小数位；无数据时显示占位与说明。

### 5.3 主图表区

| 元素 | 需求说明 |
|------|----------|
| 柱状图 | **实际销量**、**系统预测**按月对比（颜色区分图例）。 |
| 折线图 | 展示 **R1～R3 等不同版本或不同提前期**在同一时间轴上的预测曲线（与「预测提前期」筛选联动：可高亮当前 R，其余弱化或可选隐藏）。 |
| X 轴 | 月份时间序列，与筛选年月范围一致。 |
| Y 轴 | 销量数量，单位与主数据一致（件/套等）。 |
| 预测提前期 | 下拉（如 R1），切换后图表高亮对应曲线，且与表格中 R 列语义一致。 |
| 空状态 / 加载 | 无权限或无数据时明确提示。 |

### 5.4 明细表格

**列分组（与原型对齐）**

1. **维度列**：区域/国家/渠道、品牌/产品系列、SKU（E-code）/名称等。  
2. **月度数据列**：如 `202301`、`202302`… 单元格展示**该月实际、预测或合并展示策略**（需统一：建议 Tooltip 展示实际+预测+偏差）。  
3. **历史趋势**：每行 Sparkline，数据范围为当前筛选时间窗或固定近 N 月（产品二选一并写死）。  
4. **R1～R3 准确率列**：按 §2.2 公式在 SKU 层计算后的展示；颜色可分级（绿/蓝/橙等）表示优劣阈值（阈值可配置）。  
5. **操作**：**详情**、**编辑**（或「备注」）。

**交互**

- **点击某月单元格**：打开 **详情面板**（§5.5），展示该 SKU、该月（或该切片）的分解。  
- **新增异常备注**（工具栏）与行内 **异常备注**：见当前页面弹窗流程（列表 + 新增/编辑表单，含生效日期范围）。  
- 支持横向滚动、表头冻结、列宽自适应；**「销售团队」列**须 **默认宽度可完整展示** `sales` 与 `TL` 两行（在 `/TL:` 处换行），并提供 **表头拖拽调整列宽**（建议范围如 160px～640px）；用户偏好可 **持久化**（本地或账户设置）。  
- 分页或虚拟滚动：数据量大时必选一种，并给出默认 pageSize。

### 5.5 详情面板（计算分解）

用于回答「这个预测怎么来的」。

| 列/字段 | 说明 |
|---------|------|
| 月份 | 与表格所选单元格对应。 |
| 基量（Base Volume） | 规则/模型给出的基准销量。 |
| 调整系数 | 总体系数或业务调整。 |
| 影响因子系数 | 如：流量、转化、促销、竞品等（与《项目方案》5 类因子可映射；具体列以后台可解释输出为准）。 |
| 最终预估销量 | 与表格/图表展示的系统预测一致。 |

**权限**：敏感因子可对部分角色脱敏或合并为「其他因子」。

### 5.6 历史异常备注

| 字段 | 说明 |
|------|------|
| 调整人 | 操作者账号/姓名。 |
| 时间 | 操作时间，时区统一。 |
| 备注内容 | 文本。 |
| 影响期间 | 生效的起止月或滚动窗口描述。 |
| 是否参与预测计算 | 开关或标签展示；变更需留痕。 |

支持按时间倒序；与当前 SKU（及可选渠道维度）绑定。

### 5.7 批量异常备注弹窗

| 字段 | 校验 |
|------|------|
| 申请人 | 默认当前用户，可改（若允许代填需权限）。 |
| 备注内容 | 必填，长度上限。 |
| 生效期间 | 必填，合法时间范围。 |
| 是否参与预测计算 | 勾选；需二次确认文案（避免误操作大面积影响预测）。 |

**范围**：对表格**多选行**生效；未选时按钮 disabled 或提示先选择。提交后异步任务或同步返回需定义；失败时行级回滚提示。

### 5.8 系统 vs 人工误差对比（原型左下角小表）

| 指标 | 说明 |
|------|------|
| 系统误差率 | 基于系统预测与实际的偏差汇总指标（与 MAPE 家族一致，避免同一页多种口径冲突）。 |
| 人工预测误差率 | 基于人工覆盖或采纳后的预测与实际对比（口径需在数据层定义清楚）。 |

用于评估人工介入价值；刷新周期与主表一致。

## 6. 业务规则与数据口径

### 6.1 提前期 R 与数据对齐

- **提前一年开始预测，预测未来 12 个月**：系统每天滚动产出对未来 12 个月的预测。  
- **版本锁定（按销售口径）**：同一 SKU、同一目标月 M：  
  - **距离 M 还有 3 个月开始**：**R3 锁定**为当时那一刻的最后一版预测；之后每日预测仍跑，但 R3 不再变化。  
  - **距离 M 还有 2 个月开始**：**R2 锁定**。  
  - **距离 M 还有 1 个月开始**：**R1 锁定**。  
- 历史复盘计算准确率/达成时，必须使用对应 R 的**冻结版本快照**，而非最新重算值（若后台无版本库，需在 PRD 附录中说明 MVP 采用近似方案）。

### 6.2 MAPE 边界情况

- **实际为 0**：不计算或显示「N/A」，不参与聚合分母。  
- **预测缺失**：显示「—」，不参与聚合。  
- **负数销量**（退货冲销等）：与数据治理约定是否剔除或单独标记。

### 6.3 与下游补货的关系

- 本页展示层**不直接改补货单**；「参与预测计算」的备注通过预测服务/数仓回流后，由既有补货链路消费（与《项目方案》§5.4 接口约定一致）。

## 7. 非功能需求

| 类别 | 要求 |
|------|------|
| **性能** | 常规筛选下首屏可交互时间目标（如 P95 小于 3 秒，可按公司基线调整）；大表虚拟滚动。 |

## 8. 依赖与接口（概要）

- **预测结果服务**：按筛选条件返回汇总 KPI、序列数据、表格行数据。  
- **可解释因子服务**：按 SKU + 月返回详情面板字段。  
- **备注服务**：CRUD、历史列表、批量提交。  
- **主数据**：区域/国家/渠道/组织/品牌/系列/SKU 与 ERP 同源。

详细字段表与 API 可在《接口清单》子文档中展开。

## 9. 验收标准（UAT 检查项示例）

1. 任意合法筛选组合下，KPI、图表、表格**同一指标数值一致**（允许展示格式差异）。  
2. 点击单元格打开详情，**最终预估销量**与表格一致。  
3. 新增一条异常备注并勾选参与计算后，**预测调整 SKU 数**在规则生效后正确变化（或显示异步延迟说明）。  
4. R1～R3 切换时，图表与表格 R 列语义一致。
5. 无权限用户看不到未授权组织/渠道数据。
