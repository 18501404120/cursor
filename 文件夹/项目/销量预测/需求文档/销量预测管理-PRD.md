## 1. 背景与目标

### 1.1 业务背景

与《项目背景》一致：行业进入精细化运营阶段，**可解释的需求预测**是库存与补货决策的重要输入。主工作台在同一时间切片下展示 **目标 R1、目标 R2、目标 R3**（按**可配置锁定提前量**、默认 **30 / 60 / 90 天**相对目标月 1 号先后锁定的预测快照）、**各目标对应的销量下限～上限带**、**实际销量**、**预测达成率**（已关账月），以及（若启用）**人工或 forecast 填报**，便于计划与运营对齐、复盘与留痕。

### 1.2 名词（与本页强相关）

| 名词 | 定义 |
|------|------|
| **目标 R1 / R2 / R3** | 对目标月 M 的预测销量在距 M 月 1 号剩余天数分别 **≤ R1/R2/R3 配置天数** 时锁定的快照（件）；未进入任一锁定阈值前通常与当日滚动预测一致。默认配置 **30、60、90 天**。见《R1至R3规则说明》。 |
| **下限销量 / 上限销量** | 与《预测销量上下限规则-终版》**同一套销量合成公式**，在悲观 / 乐观情景下对每个**目标 Rk 点预测**派生的边界（件）；与锁定时点规则独立组合展示。 |
| **实际销量** | 与财务/运营约定的**出库或结算口径**实际值（件），用于预测达成率计算。 |
| **预测达成率（单月）** | 对某目标月、某锁定预测 P 与实际 A：**100% − \|A − P\| ÷ max(A, P)**；未关账或实际缺失时不计算。 |
| **预测达成率（列表 / KPI 窗口聚合）** | 与业务确认稿「图七」一致：**100% − Σ\|A − P\| ÷ Σ max(A, P)**，对窗口内参与汇总的已关账月求和；被异常备注规则排除的自然月不纳入分子分母。见《R1至R3规则说明》。 |
| **人工预测值 / forecast** | 业务在流程中填报或修正的销量点值，用于对照与协同；**不回写**已锁定的 R1/R2/R3 快照。 |

### 1.3 本页产品目标

| 目标 | 说明 |
|------|------|
| **查看** | 按区域/渠道/SKU 等维度查看 **目标 R1～R3、区间带、实际、预测达成率** 及（若启用）人工/forecast。 |
| **解释** | 支持从汇总到 SKU、从锁定目标到因子与上下限下钻，提升业务信任度。 |
| **筛选** | 支持按顶部 **预测选择（#fltPredR）+ 达成率比较符 + 阈值** 过滤列表行；汇总口径为当前月份窗口内、按上式聚合的**预测达成率**（并尊重异常备注排除规则）。 |
| **协同** | 支持异常备注、历史追溯、批量备注；备注中**勾选**「生效区间内月份不参与预测达成率计算」时，将覆盖到的各自然月排除出该行预测达成率汇总（默认不勾选，见 5.6）。 |

### 1.4 成功指标（本页可验收）

- 计划/运营能在**单一页面**完成：筛选 → 看趋势与 KPI → 查 SKU → 看计算明细 → 写/查备注。  
- 核心筛选条件下，列表与图表**口径与后台预测任务及锁定快照一致**（同源数据、同一时间切片）。  
- 详情面板展示的因子与各 **目标 Rk、下限、上限、预测达成率** 来源字段**与后端可追溯一致**（允许展示粒度与权限裁剪，但不可逻辑矛盾）。

## 2. 范围与名词

### 2.1 范围说明

- **纳入**：本 PRD 描述**销量预测 · 主工作台**主单页及其关联弹层（详情、异常备注历史、批量异常备注）。  
- **不包含**（可另起 PRD）：规则引擎配置后台、模型训练与发布流程、补货建议引擎全链路（本页仅消费预测结果、锁定快照与元数据）。

### 2.2 其他名词

| 名词 | 定义 |
|------|------|
| **系统预测 / 机器学习** | 规则/基线或算法管线输出的滚动预测结果源；切换后列表主数字行与详情中与预测方式相关的展示一致切换。 |
| **异常备注** | 业务对某 SKU 或批量 SKU 的说明与纠偏意图记录；可选**勾选**将生效区间内各自然月**排除**出预测达成率汇总（默认不勾选），详见 5.6。 |

## 3. 用户角色与核心场景

| 角色 | 典型场景 |
|------|----------|
| **供应链计划 / 需求计划** | 按组织与渠道查看三档锁定目标与区间带，对大促 SKU 写异常备注并留档。 |
| **渠道运营** | 按国家/渠道筛选，对比 **目标 R1～R3** 与实际及预测达成率，点开单元格看因子分解。 |
| **销售** | 查看本人或本组 MSKU 的预测、锁定目标与实际达成，用于运营节奏协同（权限与数据范围另定）。 |
| **数据分析 / 算法** | 从因子与结果下钻驱动规则与模型迭代；预测达成率用于**展示与筛选**，考核口径若不同由绩效系统承接。 |
| **管理层（只读）** | 查看趋势、KPI 卡与汇总，不做编辑。 |

## 4. 页面信息架构

```
顶部：全局筛选（含 SKU 等）+ 预测选择 + 达成率比较符 + 阈值 + 月份范围 + 搜索/重置
├── KPI 区：R1 / R2 / R3 预测达成率（当前筛选范围内窗口聚合）
├── 主图表区：目标 R1、目标 R2、目标 R3（各含下限～上限浅色带）+ 实际销量（柱）+ R1/R2/R3 预测达成率折线（右轴 %）；可选「人工预测达成率」
├── 明细表：工具栏「预测选择」+ 维度列 + 月度列 + 单列「R*预测达成率」+ 迷你趋势 + 操作（详情/异常备注/导出）
└── 弹层：详情（因子表 + 当前 R 档目标与区间及预测达成率）| 历史异常备注 | 批量异常备注
```

**布局说明**：顶部栅格内 **#fltPredR 预测选择、达成率、阈值** 位于**月份范围与「搜索」按钮之前**（**#fltPredR** 仅用于与阈值比较时的 R 档，不控制表格列/详情）；表格上方另有 **#tablePredR** 控制列表与详情展示的 R 档。

## 5. 功能需求

### 5.1 全局筛选区

| 元素 | 类型 | 需求说明 |
|------|------|----------|
| 区域 / 国家 / 店铺 等 | 下拉 | 与主数据一致；影响下方所有组件。 |
| 场景品类、品线、SKU 等 | 下拉/搜索 | 与现网一致。 |
| **预测选择（#fltPredR）** | 下拉 | **R1 / R2 / R3**：**仅**与「达成率」比较符、阈值组合，用于判断该行**哪一档**的窗口聚合预测达成率参与行过滤；**不**改变表格「R*预测达成率」列、表头及详情列集。 |
| **达成率** | 比较符下拉 | 大于 / 大于等于 / 等于 / 小于 / 小于等于；作用于 **#fltPredR** 所选 R 档的**行级窗口聚合预测达成率**。 |
| **阈值** | 数值 | 单位 **%**；与列表行汇总预测达成率比较，不满足的行不展示。 |
| 月份范围 | 控件 | 定义**列表与图表的时间窗口**。 |
| 查询 / 重置 | 按钮 | 触发全页数据刷新；重置为默认筛选。 |

**交互**：建议**默认点击查询刷新**，避免大数据量下频繁请求。

### 5.2 KPI 汇总区

| 元素 | 需求说明 |
|------|----------|
| **R1 预测达成率** | 当前筛选范围内、按 **5.1 名词** 窗口聚合公式的 **R1** 汇总展示。 |
| **R2 预测达成率** | 同上，**R2**。 |
| **R3 预测达成率** | 同上，**R3**。 |

卡片标题仅使用 **「R1/R2/R3 预测达成率」** 等简短文案，不出现「M−1 锁定」「当前筛选汇总（演示）」类说明性后缀（演示环境可在脚注或红点说明中标注数据来源）。

### 5.3 主图表区

| 元素 | 需求说明 |
|------|----------|
| 柱状图 | **目标 R1、目标 R2、目标 R3**（分组柱，各柱后叠**下限～上限**浅色带，口径见《预测销量上下限规则-终版》与终版文档第六节衔接说明）。 |
| 实际销量 | **柱状图**（按月一根柱），已关账月有值；**不使用折线表示实际销量**。 |
| **R1/R2/R3 预测达成率** | **折线**，绑定 **右侧 Y 轴（0%～100%）**；未关账月留空。图例命名建议 **「R*预测达成率」** 与列表列一致。 |
| **人工预测达成率**（可选） | 由配置或勾选控制；与人工点预测及实际按同一单月公式或展示约定计算。 |
| X 轴 | 月份时间序列，与筛选范围一致。 |
| Y 轴 | **左轴**：销量件数；**右轴**：预测达成率 %。 |
| Tooltip | 目标柱展示当月点值及**下限～上限**；达成率线展示百分比。 |

### 5.4 明细表格

1. **表格工具栏「预测选择」（#tablePredR）**：**R1 / R2 / R3**，控制表头「R*预测达成率」列名与单元格所用 R 档、以及行内「详情」弹窗展示的锁定目标/上下限/预测达成率列集；**与**顶部 **#fltPredR** 独立。  
2. **维度列**：区域/国家/店铺、场景/品类/品线、SKU、MSKU 等。  
3. **月度数据列**：每月单元格以当前预测方式下的**主预测数字**为主（与规则/ML 输出一致）；可展开系统规则行、forecast 行。  
4. **R*预测达成率**（单列）：列名随 **#tablePredR** 变化，展示行级**窗口聚合**结果（与 KPI 同公式、同排除规则）。  
5. **历史趋势**：Sparkline 与当前主预测序列一致。  
6. **操作**：**详情**、**异常备注**。  
7. **导出**：见 5.8。

### 5.5 详情面板（计算分解）

- **触发**：行内「详情」。  
- **列展示规则**：**仅展示**与表格工具栏 **#tablePredR** 一致的 **一档**：如选 R1，则展示 **目标R1、R1 下限、R1 上限、R1预测达成率** 等；**不**与 R2、R3 全量并列。切换 **#tablePredR** 后再次打开详情，列集随之变化。  
- **表上方长说明**：不要求展示大段测算说明文案（口径以《R1至R3规则说明》及本 PRD 为准，可在脚注或帮助链出）。  
- 其他列：月份、基准销量、弹性系数、影响因子、forecast 等与可解释输出一致。

### 5.6～5.7 异常备注与批量备注

- 行内入口**始终**可点；批量新增需先勾选至少一行。  
- **新增 / 编辑 / 批量新增**表单增加复选框：**「生效区间内月份不参与预测达成率计算」**（默认**不勾选**）。  
  - **勾选**：生效日期范围内**每个自然月**均**不纳入**该行「预测达成率」窗口聚合（分子分母均剔除该月）。  
  - **不勾选**：本条备注**不影响**预测达成率计算。  
- 历史列表展示修改人、时间、内容、生效区间及该选项状态（正式版字段以接口为准）。

### 5.8 导出

- 导出文件列与当前页表格**可见列**一致（含动态月份列、**#tablePredR** 对应的 **R*预测达成率** 单列）。  
- 字段顺序与含义以**主工作台原型「导出」红点说明**为验收对照；发布包可另附示例 xlsx（可选）。

## 6. 业务规则与数据口径

### 6.1 与预测服务的关系

- **滚动预测**、**R1/R2/R3 锁定快照** 以预测任务与《R1至R3规则说明》为准；**R1/R2/R3 提前锁定天数**可配置，默认 **30、60、90**。  
- **下限/上限** 以《预测销量上下限规则-终版》为准，作用于各目标点预测。

### 6.2 与下游补货的关系

- 本页展示层**不直接改补货单**；异常备注的下游消费边界由接口与数据团队另行约定。

### 6.3 文档对齐

- 预测达成率定义、筛选语义、聚合公式见《R1至R3规则说明》。  
- 三档销量合成见《预测销量上下限规则-终版》。  
- 导出列见主工作台原型「导出」红点说明。

## 9. 验收标准（UAT 检查项示例）

1. 任意合法筛选组合下，图表与表格中 **目标 R1/R2/R3、下限/上限、实际** 同源一致。  
2. **预测达成率** 手算与展示一致（抽 1 行：按窗口聚合公式；抽 1 月详情：按单月公式）。  
3. **达成率筛选** 改变阈值后，列表行集合随之变化且 KPI 卡与列表一致。  
4. 详情仅展示 **#tablePredR** 对应档的列，与主表抽样一致。  
5. 异常备注勾选/取消勾选后，该行预测达成率与 KPI 变化符合排除规则。  
6. 导出列与当前表头可见列一致，并与原型「导出」红点说明对照无矛盾。  
7. 无权限用户看不到未授权组织/渠道数据。
