> **产品名称**：**销量预测**。本 PRD 描述主工作台单页（目录与原型文件名仍多为「销量预测管理」）。  
> **关联文档**：[项目背景.md](../项目背景.md)、[预测销量上下限规则-终版.md](./预测销量上下限规则-终版.md)（客观三线销量合成；**上下限**与目标点预测组合展示）、[R1至R3规则说明.md](./R1至R3规则说明.md)（锁定阶梯与达成率）  
> **原型**：[../原型/销量预测管理-原型说明.html](../原型/销量预测管理-原型说明.html)（全局筛选 + 趋势图 + SKU 明细表等；说明版含红点）

> **状态**：草案

## 1. 背景与目标

### 1.1 业务背景

与《项目背景》一致：行业进入精细化运营阶段，**可解释的需求预测**是库存与补货决策的重要输入。主工作台在同一时间切片下展示 **目标 R1、目标 R2、目标 R3**（按 M−1/M−2/M−3 阶梯锁定的预测快照）、**各目标对应的销量下限～上限带**、**实际销量**、**达成率**（已关账月），以及（若启用）**人工或 forecast 填报**，便于计划与运营对齐、复盘与留痕。

### 1.2 名词（与本页强相关）

| 名词 | 定义 |
|------|------|
| **目标 R1 / R2 / R3** | 对目标月 M 的预测销量在 **M−1 / M−2 / M−3** 月分别锁定后的快照值（件）；未进入锁定点前通常与当日滚动预测一致。见《R1至R3规则说明》。 |
| **下限销量 / 上限销量** | 与《预测销量上下限规则-终版》**同一套销量合成公式**，在悲观 / 乐观情景下对每个**目标 Rk 点预测**派生的边界（件）；与锁定时点规则独立组合展示。 |
| **实际销量** | 与财务/运营约定的**出库或结算口径**实际值（件），用于达成率分子侧。 |
| **达成率（预测准确率展示）** | 对某目标月、某锁定预测 P 与实际 A：**100% − |A − P| ÷ max(A, P)**，以百分比展示；未关账或实际缺失时不计算。见《R1至R3规则说明》。 |
| **人工预测值 / forecast** | 业务在流程中填报或修正的销量点值，用于对照与协同；**不回写**已锁定的 R1/R2/R3 快照。 |

### 1.3 本页产品目标

| 目标 | 说明 |
|------|------|
| **查看** | 按区域/渠道/SKU 等维度查看 **目标 R1～R3、区间带、实际、达成率** 及（若启用）人工/forecast。 |
| **解释** | 支持从汇总到 SKU、从锁定目标到因子与上下限下钻，提升业务信任度。 |
| **筛选** | 支持按 **预测选择（R1/R2/R3）+ 达成率比较符 + 阈值** 过滤列表行（汇总口径由配置约定，如当前窗口内已关账月的平均达成率）。 |
| **协同** | 支持异常备注、历史追溯、批量备注（**仅记录与展示**，不参与预测类自动计算）。 |

### 1.4 成功指标（本页可验收）

- 计划/运营能在**单一页面**完成：筛选 → 看趋势与 KPI → 查 SKU → 看计算明细 → 写/查备注。  
- 核心筛选条件下，列表与图表**口径与后台预测任务及锁定快照一致**（同源数据、同一时间切片）。  
- 详情面板展示的因子与各 **目标 Rk、下限、上限、达成率** 来源字段**与后端可追溯一致**（允许展示粒度与权限裁剪，但不可逻辑矛盾）。

## 2. 范围与名词

### 2.1 范围说明

- **纳入**：本 PRD 描述**销量预测 · 主工作台**主单页及其关联弹层（详情、异常备注历史、批量异常备注）。  
- **不包含**（可另起 PRD）：规则引擎配置后台、模型训练与发布流程、补货建议引擎全链路（本页仅消费预测结果、锁定快照与元数据）。

### 2.2 其他名词

| 名词 | 定义 |
|------|------|
| **系统预测 / 机器学习** | 规则/基线或算法管线输出的滚动预测结果源；切换后列表主数字行与详情中与预测方式相关的展示一致切换。 |
| **异常备注** | 业务对某 SKU 或批量 SKU 的说明与纠偏意图记录；**仅作追溯与协同说明**，不参与预测管线自动计算。 |

## 3. 用户角色与核心场景

| 角色 | 典型场景 |
|------|----------|
| **供应链计划 / 需求计划** | 按组织与渠道查看三档锁定目标与区间带，对大促 SKU 写异常备注并留档。 |
| **渠道运营** | 按国家/渠道筛选，对比 **目标 R1～R3** 与实际及达成率，点开单元格看因子分解。 |
| **销售** | 查看本人或本组 MSKU 的预测、锁定目标与实际达成，用于运营节奏协同（权限与数据范围另定）。 |
| **数据分析 / 算法** | 从因子与结果下钻驱动规则与模型迭代；达成率用于**展示与筛选**，考核口径若不同由绩效系统承接。 |
| **管理层（只读）** | 查看趋势、KPI 卡与汇总，不做编辑。 |

## 4. 页面信息架构

```
顶部：全局筛选 + 达成率筛选（预测选择 R1/R2/R3 + 比较符 + 阈值）+ 查询/重置
├── KPI 区：R1 / R2 / R3 预测准确率（当前筛选范围内汇总，口径可配置）
├── 主图表区：目标 R1、目标 R2、目标 R3（各含下限～上限浅色带）+ 实际销量 + R1/R2/R3 达成率（右轴 %）；可选「人工预测达成率」
├── 明细表：工具栏「预测选择」+ 维度列 + 月度列 + R1/R2/R3 达成率列 + 迷你趋势 + 操作（详情/异常备注）
└── 弹层：详情（因子表 + 三档目标与区间及达成率）| 历史异常备注 | 批量异常备注
```

## 5. 功能需求

### 5.1 全局筛选区

| 元素 | 类型 | 需求说明 |
|------|------|----------|
| 区域 / 国家 / 店铺 等 | 下拉 | 与主数据一致；影响下方所有组件。 |
| 场景品类、品线、SKU 等 | 下拉/搜索 | 与现网一致。 |
| 月份范围 | 控件 | 定义**列表与图表的时间窗口**。 |
| **预测选择（达成率筛选）** | 下拉 | 取 **R1 / R2 / R3** 之一，表示以下「达成率」阈值作用于哪一档的达成率。 |
| **达成率** | 比较符下拉 | 大于 / 大于等于 / 等于 / 小于 / 小于等于。 |
| **阈值** | 数值 | 单位 **%**；与列表行汇总达成率比较，不满足的行不展示。 |
| 查询 / 重置 | 按钮 | 触发全页数据刷新；重置为默认筛选。 |

**交互**：建议**默认点击查询刷新**，避免大数据量下频繁请求。

### 5.2 KPI 汇总区

| 元素 | 需求说明 |
|------|----------|
| **R1（M−1 锁定）预测准确率** | 当前筛选范围内、按约定汇总口径聚合的 **R1 达成率** 展示（如简单平均或销量加权，以配置为准）。 |
| **R2（M−2 锁定）预测准确率** | 同上，**R2**。 |
| **R3（M−3 锁定）预测准确率** | 同上，**R3**。 |

### 5.3 主图表区

| 元素 | 需求说明 |
|------|----------|
| 柱状图 | **目标 R1、目标 R2、目标 R3**（分组柱，各柱后叠**下限～上限**浅色带，口径见《预测销量上下限规则-终版》与终版文档第六节衔接说明）。 |
| 实际销量 | **折线**（或产品统一为柱），已关账月有值。 |
| **R1/R2/R3 达成率** | **折线**，绑定 **右侧 Y 轴（0%～100%）**；未关账月不断线留空。 |
| **人工预测达成率**（可选） | 由配置或勾选控制；与人工点预测及实际按同一达成率公式计算。 |
| X 轴 | 月份时间序列，与筛选范围一致。 |
| Y 轴 | **左轴**：销量件数；**右轴**：达成率 %。 |
| Tooltip | 目标柱展示当月点值及**下限～上限**；达成率线展示百分比。 |

### 5.4 明细表格

1. **工具栏**：**预测选择**下拉（R1/R2/R3）用于高亮或主视角列（与筛选区「预测选择」可区分：一为列表视角、一为达成率筛选维度，若合并为一控件则以产品简化为准）。  
2. **维度列**：区域/国家/店铺、场景/品类/品线、SKU、MSKU 等。  
3. **月度数据列**：每月单元格以当前预测方式下的**主预测数字**为主（与规则/ML 输出一致）；可展开系统规则行、forecast 行。  
4. **R1 达成率 / R2 达成率 / R3 达成率** | 按约定汇总口径展示行级百分比（已关账月不足时可为「—」）。  
5. **历史趋势**：Sparkline 与当前主预测序列一致。  
6. **操作**：**详情**、**异常备注**。

### 5.5 详情面板（计算分解）

| 列/字段 | 说明 |
|---------|------|
| 月份 | 与表格时间窗一致。 |
| **目标 R1～R3** | 各月三档锁定点预测（件）。 |
| **各档下限、上限** | 与《预测销量上下限规则-终版》销量合成一致。 |
| **各档达成率** | 有实际时按《R1至R3规则说明》公式计算。 |
| 影响因子系数、forecast 等 | 与可解释输出、填报源一致。 |

### 5.6～5.7 异常备注与批量备注

与 v3.x 一致：行内入口始终可点；批量需勾选；不参与预测回算。

## 6. 业务规则与数据口径

### 6.1 与预测服务的关系

- **滚动预测**、**R1/R2/R3 锁定快照** 以预测任务与《R1至R3规则说明》为准。  
- **下限/上限** 以《预测销量上下限规则-终版》为准，作用于各目标点预测。

### 6.2 与下游补货的关系

- 本页展示层**不直接改补货单**；异常备注的下游消费边界由接口与数据团队另行约定。

### 6.3 文档对齐

- 达成率定义、筛选语义见《R1至R3规则说明》。  
- 三档销量合成见《预测销量上下限规则-终版》。

## 9. 验收标准（UAT 检查项示例）

1. 任意合法筛选组合下，图表与表格中 **目标 R1/R2/R3、下限/上限、实际** 同源一致。  
2. **达成率** 手算与展示一致（抽 1 行 1 个月，已关账）。  
3. **达成率筛选** 改变阈值后，列表行集合随之变化且 KPI 卡与列表一致。  
4. 详情中三档目标、区间与达成率与主表抽样一致。  
5. 无权限用户看不到未授权组织/渠道数据。
