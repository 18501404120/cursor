# 销量预测：如何一步一步算出来（计算链路说明）

> **文档目的**：把「从配置与原始数据到主工作台展示」的计算顺序写清楚；按配置中心各因子红点给出 **影响因子系数** 的计算规则，并附 **从基准销量起算的数值示例**。  
> **主要依据**：`会议/会议需求同步`、配置中心原型红点、《预测销量上下限规则-终版.md》《R1至R3规则说明.md》。  
> **量纲**：销量 **件数**；金额 **元**；比率、弹性为小数。

> **表述约定**：正文叙述、表格中的「名称」采用 **中文名（符号）** 形式，与下表一致；**算式、分步代入与连乘推导中只写符号**（不再在公式里夹写中文），便于实现与对账。

---

## 符号简表（中文名与符号对照）

| 中文名（符号） | 简要说明 |
|----------------|----------|
| 基准销量（Q_base） | 近一年总销量÷12，件/月 |
| 价格基准（P_base） | 近一年总销售额÷近一年总销量，元/件 |
| 价格基准价（P_ref） / 预估价（P_est） | 红点常用近 3 月均价；有规划用规划价 |
| 去年同月流量（T_ysm） | 去年与预测月同月的实际流量 |
| 预估流量（T_est） / 基准流量（T_base） | 由同比与 T_ysm 得到；近一年月均流量 |
| 流量同比增速（y1,y2,y3） | 预测月前三月相对去年同月，小数 |
| 流量综合增长率（G_flow） | 三月同比加权 |
| 流量倍数（M_flow） / 价格倍数（M_pri） / 转化倍数（M_cvr） / 广告倍数（M_ad） | 各因子「现值÷基准」类比值 |
| 流量弹性（E_flow） / 价格弹性（E_pri） / 转化弹性（E_cvr） / 广告弹性（E_ad） / 竞争力弹性（E_comp） | 配置中心下发 |
| 流量系数（C_flow） / 价格系数（C_pri） / 转化系数（C_cvr） / 广告系数（C_ad） / 竞争力系数（C_comp） | 按第三节公式计算 |
| 超参系数（C_hyp） | 配置绑定 |
| 总系数（C_tot） | 各系数连乘 |
| 点预测销量（Q_pred） | 目标推荐，件/月 |
| 转化环比增速（r1,r2） | 近两个月 |
| 转化综合增长率（G_cvr） | 两月加权 |
| 近30天转化（CR_d30） / 预估转化（CR_est） / 基准转化（CR_ref） | 转化链路透传 |
| 预估广告花费（A_est） / 基准广告花费（A_ref） | A_ref 常为近 3 月月均 |
| 竞争力综合增长率（G_comp） | 小类、大类同比等合成 |
| 预测自然月（M） | 时间粒度；MSKU 含店铺维度 |

## 一、先定范围：算什么、算到谁

| 项 | 说明（与会议对齐） |
|----|-------------------|
| **渠道** | 先做 **亚马逊**；在售 Listing。 |
| **时间粒度** | 预测到 **自然月**；滚动 **未来 12 个月**。 |
| **货号粒度** | 主工作台按 **MSKU** 展示与导出；配置中心维护系数与因子绑定。 |
| **新品** | 上架不足约 **3** 个月：可不产出预测/达成率，界面可为空。 |
| **数据规模** | 实现侧按性能分区、异步任务；不改变公式顺序。 |

## 二、全局基准定义（本文示例与对账用）

| 中文名（符号） | 含义（叙述） | 算式中仅用符号时 |
|----------------|--------------|------------------|
| 基准销量（Q_base） | 近一年总销量÷12，月均件数 | `Q_base = 年销量 / 12` |
| 价格基准（P_base） | 近一年均价，作部分示例分母 | `P_base = 年销售额 / 年销量` |

> **与红点差异**：配置中心「价格」红点里 **价格基准价（P_ref）** 常为 **近 3 个月** 成交均价。若与「近一年 **价格基准（P_base）**」不一致，**以上线配置为准**；下文 **第七章** 示例取 **P_base** 与 **Q_base** 同一窗口便于手算。

## 三、各影响因子系数——计算规则（按因子）

各因子：**先倍数或综合增长 → 再系数**；各弹性（E_*）由配置或算法下发。以下每条先一句话对齐中文（符号），**编号内的算式只写符号**。

### 3.1 流量（系数 C_flow）

1. 取预测月 **M** 前紧邻三个月，得 **流量同比增速（y1,y2,y3）**（小数，0.10 表示 +10%）。  
2. `G_flow = 0.2*y1 + 0.3*y2 + 0.5*y3`（权重以配置为准）。  
3. `T_est = T_ysm * (1 + G_flow)`，其中 **去年同月流量（T_ysm）** 为去年与 M 同月实际流量。  
4. `T_base = 年总流量 / 12`（近一年月均）。  
5. `M_flow = T_est / T_base`。  
6. `C_flow = M_flow * E_flow`。  
7. **降级取数**：去年同月 ASIN 无流量 → 关联 SKU → 品类 → 场景 → 渠道（以产品定义为准）。

### 3.2 价格（系数 C_pri）

1. **价格基准价（P_ref）**（红点）：近 3 个月成交均价；不足按品类。可与 **价格基准（P_base）** 二选一统一实现。  
2. **预估价（P_est）**：有下月价格规划用规划值；否则近 30 天均价外推。  
3. `M_pri = P_est / P_ref`。  
4. `C_pri = 1 + M_pri * E_pri`（**价格弹性（E_pri）** 可为负）。

### 3.3 转化（系数 C_cvr）

1. 取 **转化环比增速（r1,r2）**。  
2. `G_cvr = 0.4*r1 + 0.6*r2`。  
3. `CR_est = CR_d30 * (1 + G_cvr)`（若实现定义为「×综合增长因子」则按开发锁定）。  
4. **基准转化（CR_ref）**：优先 ASIN 近 12 月均转化；不足→关联 SKU→品类+场景。  
5. `M_cvr = CR_est / CR_ref`。  
6. `C_cvr = M_cvr * E_cvr`。

### 3.4 广告（系数 C_ad）

1. **基准广告花费（A_ref）**：近 3 月月均广告花费。  
2. **预估广告花费（A_est）**：有计划用规划值，否则近 30 天水平延续。  
3. `M_ad = A_est / A_ref`。  
4. `C_ad = 1 + M_ad * E_ad`（若业务改为无「1+」形态，以开发锁定为准）。

### 3.5 竞争力（系数 C_comp）

1. 小类、大类最近 2 个月同比等，月权 0.45/0.55，再小类 0.7 + 大类 0.3 合成 **竞争力综合增长率（G_comp）**。  
2. `C_comp = 1 + G_comp * E_comp`。

### 3.6 超参数（系数 C_hyp）

由配置绑定 **超参系数（C_hyp）**；与五因子独立，通常 **连乘** 进总系数。

### 3.7 总系数（C_tot）与点预测销量（Q_pred）

- `C_tot = C_flow * C_pri * C_cvr * C_ad * C_comp * C_hyp`（顺序以开发为准）。  
- `Q_pred = Q_base * C_tot`（取整与边界由引擎处理）。

## 六、会议与定稿不一致时的处理原则

1. **锁定、达成率、上下限因子表**：以《R1至R3规则说明》《预测销量上下限规则-终版》为准。  
2. **价格基准价（P_ref）** 用近 3 月还是 **价格基准（P_base）** 用近一年：以 **配置红点** 为准；本文第二节与第七章示例用 **P_base** 便于手算。  
3. **广告系数（C_ad）** 是否带「1+」形态：以业务+开发锁定为准。

## 七、数值示例（从基准销量与价格基准起算）

虚构演示数，不代表真实 SKU。下表「项」为 **中文名（符号）**；「算式/过程」列 **只用符号**。

### 7.1 全局基准

| 项 | 取值 | 算式（符号） |
|----|------|----------------|
| 近一年总销量 | 1 440 件 | — |
| 基准销量（Q_base） | 120 件/月 | `1440/12` |
| 近一年总销售额 | 14 400 元 | — |
| 价格基准（P_base） | 10 元/件 | `14400/1440` |

### 7.2 弹性与超参（配置假设）

| 因子 | 中文名（符号） | 取值（示例） |
|------|----------------|--------------|
| 流量 | 流量弹性（E_flow） | 1.0 |
| 价格 | 价格弹性（E_pri） | -0.5 |
| 转化 | 转化弹性（E_cvr） | 1.0 |
| 广告 | 广告弹性（E_ad） | 0.8 |
| 竞争力 | 竞争力弹性（E_comp） | 2.0 |
| 超参数 | 超参系数（C_hyp） | 1.02 |

### 7.3 各因子中间量与系数（过程只写符号）

**流量（见 3.1）**  
`y1=0.08, y2=0.10, y3=0.12` → `G_flow=0.106`。`T_ysm=10000` → `T_est=11060`。`T_base=10000` → `M_flow=1.106` → `C_flow=1.106*1.0=1.106`。

**价格（见 3.2）**（本例取 `P_ref=P_base=10`）  
`P_est=10.5` → `M_pri=1.05` → `C_pri=1+1.05*(-0.5)=0.475`。

**转化（见 3.3）**  
`r1=0.02, r2=0.03` → `G_cvr=0.026`。`CR_d30=0.10` → `CR_est=0.1026`。`CR_ref=0.10` → `M_cvr=1.026` → `C_cvr=1.026`。

**广告（见 3.4）**  
`A_ref=1000, A_est=1100` → `M_ad=1.1` → `C_ad=1+1.1*0.8=1.88`。

**竞争力（见 3.5）**  
`G_comp=0.05` → `C_comp=1+0.05*2.0=1.10`。

**超参（见 3.6）**  
`C_hyp=1.02`。

### 7.4 总系数与点预测销量

`C_tot ≈ 1.106 * 0.475 * 1.026 * 1.88 * 1.10 * 1.02 ≈ 1.201`

`Q_pred = Q_base * C_tot = 120 * 1.201 ≈ 144` 件/月（取整前约 144.1）。
