# 销量预测：如何一步一步算出来（计算链路说明）

> **文档目的**：把「从配置与原始数据到主工作台展示」的计算顺序写清楚；按配置中心各因子红点给出 **影响因子系数** 的计算规则，并附 **从基准销量起算的数值示例**。  
> **主要依据**：`会议/会议需求同步`、配置中心原型红点、《预测销量上下限规则-终版.md》《R1至R3规则说明.md》。  
> **量纲**：销量 **件数**；金额 **元**；比率、弹性为小数。

---

## 符号简表（全文统一用下列简写）

| 符号 | 含义 |
|------|------|
| **Q_base** | 基准销量（近一年总销量÷12，件/月） |
| **P_base** | 价格基准（近一年总销售额÷近一年总销量，元/件） |
| **P_ref** / **P_est** | 价格基准价（红点常用近 3 月）/ 预估价 |
| **T_ysm** | 去年与预测月「同月」的实际流量 |
| **T_est** / **T_base** | 预估流量 / 基准流量（近一年月均） |
| **y1,y2,y3** | 预测月前三月相对去年同月的流量同比增速（小数） |
| **G_flow** | 流量综合增长率（三月同比加权） |
| **M_flow** / **M_pri** / **M_cvr** / **M_ad** | 流量 / 价格 / 转化 / 广告 **倍数** |
| **E_flow** / **E_pri** / **E_cvr** / **E_ad** / **E_comp** | 各因子 **弹性系数**（配置中心） |
| **C_flow** / **C_pri** / **C_cvr** / **C_ad** / **C_comp** | 各因子 **影响系数**（按节公式算） |
| **C_hyp** | 超参数因子系数（配置） |
| **C_tot** | 总系数（连乘） |
| **Q_pred** | 点预测销量（目标推荐，件/月） |
| **r1,r2** | 近两个月转化率环比增速 |
| **G_cvr** | 转化综合增长率 |
| **CR_d30** / **CR_est** / **CR_ref** | 近 30 天均转化 / 预估转化 / 基准转化 |
| **A_est** / **A_ref** | 预估广告花费 / 基准广告花费（近 3 月均） |
| **G_comp** | 竞争力综合增长率 |
| **M** | 预测自然月；**MSKU** 含店铺维度 |

## 一、先定范围：算什么、算到谁

| 项 | 说明（与会议对齐） |
|----|-------------------|
| **渠道** | 先做 **亚马逊**；在售 Listing。 |
| **时间粒度** | 预测到 **自然月**；滚动 **未来 12 个月**。 |
| **货号粒度** | 主工作台按 **MSKU** 展示与导出；配置中心维护系数与因子绑定。 |
| **新品** | 上架不足约 **3** 个月：可不产出预测/达成率，界面可为空。 |
| **数据规模** | 实现侧按性能分区、异步任务；不改变公式顺序。 |

## 二、全局基准定义（本文示例与对账用）

| 名词 | 计算式 | 说明 |
|------|--------|------|
| **基准销量 Q_base** | 近一年总销量 ÷ 12 | 月均销量（件/月）。 |
| **价格基准 P_base** | 近一年总销售额 ÷ 近一年总销量 | 近一年均价（元/件），作示例里价格倍数分母。 |

> **与红点差异**：配置中心「价格」红点里 **P_ref** 常为 **近 3 个月** 成交均价。若与「近一年 P_base」不一致，**以上线配置为准**；下文 **第七章** 示例用 **P_base** 便于与 Q_base 同窗口手算。

## 三、各影响因子系数——计算规则（按因子）

各节：**先倍数或综合增长 → 再系数**；弹性 **E_*** 均由配置/算法下发。

### 3.1 流量 Traffic

1. 取预测月 **M** 前紧邻三个月 **m1,m2,m3**，各月相对去年同月的流量同比增速 **y1,y2,y3**（小数，0.10=+10%）。  
2. **G_flow** = `0.2*y1 + 0.3*y2 + 0.5*y3`（权重以配置为准）。  
3. **T_est** = **T_ysm** × `(1 + G_flow)`，**T_ysm**=去年与 M 同月的实际流量。  
4. **T_base** = 近一年月均流量（总流量÷12）。  
5. **M_flow** = **T_est** / **T_base**。  
6. **C_flow** = **M_flow** × **E_flow**。  
7. **降级取数**：去年同月 ASIN 无流量 → 关联 SKU → 品类 → 场景 → 渠道（以产品定义为准）。

### 3.2 价格 Price

1. **P_ref**（红点）：近 3 个月成交均价；不足按品类。可与 **P_base** 二选一统一实现。  
2. **P_est**：有下月价格规划用规划值；否则近 30 天均价外推。  
3. **M_pri** = **P_est** / **P_ref**。  
4. **C_pri** = `1 + M_pri × E_pri`（**E_pri** 可为负）。

### 3.3 转化率 Conversion

1. 近两个月转化环比增速 **r1,r2**。  
2. **G_cvr** = `0.4*r1 + 0.6*r2`。  
3. **CR_est** = **CR_d30** × `(1 + G_cvr)`（若实现定义为「×综合增长因子」则按开发锁定）。  
4. **CR_ref**：优先 ASIN 近 12 月均转化；不足→关联 SKU→品类+场景。  
5. **M_cvr** = **CR_est** / **CR_ref**。  
6. **C_cvr** = **M_cvr** × **E_cvr**。

### 3.4 广告花费 Ad

1. **A_ref**：近 3 月月均广告花费。  
2. **A_est**：有计划用规划值，否则近 30 天水平延续。  
3. **M_ad** = **A_est** / **A_ref**。  
4. **C_ad** = `1 + M_ad × E_ad`（若业务改为无「1+」形态，以开发锁定为准）。

### 3.5 竞争力 Comp

1. 小类、大类最近 2 个月同比等，月权 0.45/0.55，再小类 0.7 + 大类 0.3 合成 **G_comp**。  
2. **C_comp** = `1 + G_comp × E_comp`。

### 3.6 超参数 Hyper

由配置绑定 **C_hyp**；与五因子独立，通常 **连乘** 进总系数。

### 3.7 总系数与点预测

- **C_tot** = `C_flow × C_pri × C_cvr × C_ad × C_comp × C_hyp`（顺序以开发为准）。  
- **Q_pred** = **Q_base** × **C_tot**（取整与边界由引擎处理）。

## 四、分步总览（会议「详情」口述对齐）

| 步骤 | 内容 |
|------|------|
| 0 | 取预测月 M、MSKU；拉取各 **E_*** 与 **C_hyp**。 |
| 1 | 按 **第三节** 算 **C_flow … C_hyp**。 |
| 2 | **C_tot** → **Q_pred** = **Q_base** × **C_tot**。 |
| 3 | **R1/R2/R3** 锁定快照——《R1至R3规则说明.md》。 |
| 4 | **客观上下限**——《预测销量上下限规则-终版.md》。 |
| 5 | **达成率**——《R1至R3规则说明.md》。 |

## 五、页面与数据流（方便联调）

| 顺序 | 页面 / 模块 | 作用 |
|------|-------------|------|
| 1 | **超参数因子管理** | 因子库、编号、区间；与配置绑定。 |

## 六、会议与定稿不一致时的处理原则

1. **锁定、达成率、上下限因子表**：以《R1至R3规则说明》《预测销量上下限规则-终版》为准。  
2. **P_ref 用近 3 月还是 P_base 用近一年**：以 **配置红点** 为准；本文第二节与第七章示例用近一年 **P_base** 便于手算。  
3. **C_ad 是否带「1+」**：以业务+开发锁定为准。

## 七、数值示例（从基准销量与价格基准起算）

虚构演示数，不代表真实 SKU。

### 7.1 全局基准

| 项 | 取值 | 算式 |
|----|------|------|
| 近一年总销量 | 1 440 件 | — |
| **Q_base** | **120 件/月** | 1440 ÷ 12 |
| 近一年总销售额 | 14 400 元 | — |
| **P_base** | **10 元/件** | 14400 ÷ 1440 |

### 7.2 弹性系数（配置假设）

| 因子 | 符号 | 取值（示例） |
|------|------|--------------|
| 流量 | **E_flow** | 1.0 |
| 价格 | **E_pri** | -0.5 |
| 转化 | **E_cvr** | 1.0 |
| 广告 | **E_ad** | 0.8 |
| 竞争力 | **E_comp** | 2.0 |
| 超参数 | **C_hyp** | 1.02 |

### 7.3 各因子中间量与系数

**流量**  
y1=0.08, y2=0.10, y3=0.12 → **G_flow** = 0.106。T_ysm=10 000 → **T_est**=11 060。**T_base**=10 000 → **M_flow**=1.106 → **C_flow** = 1.106×1.0 = **1.106**。

**价格**（本例 **P_ref** 取 **P_base**=10）  
P_est=10.5 → **M_pri**=1.05 → **C_pri** = 1 + 1.05×(-0.5) = **0.475**。

**转化**  
r1=0.02, r2=0.03 → **G_cvr**=0.026。CR_d30=0.10 → **CR_est**=0.1026。**CR_ref**=0.10 → **M_cvr**=1.026 → **C_cvr** = **1.026**。

**广告**  
A_ref=1000, A_est=1100 → **M_ad**=1.1 → **C_ad** = 1 + 1.1×0.8 = **1.88**。

**竞争力**  
G_comp=0.05 → **C_comp** = 1 + 0.05×2.0 = **1.10**。

**超参**  
**C_hyp** = **1.02**。

### 7.4 总系数与预测销量

**C_tot** ≈ `1.106 × 0.475 × 1.026 × 1.88 × 1.10 × 1.02` ≈ **1.201**

**Q_pred** = **Q_base** × **C_tot** = 120 × 1.201 ≈ **144 件/月**（取整前约 144.1）。
