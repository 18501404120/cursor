# 销量预测：如何一步一步算出来（计算链路说明）

> **文档目的**：把「从配置与原始数据到主工作台展示」的计算顺序写清楚；按配置中心各因子红点给出 **影响因子系数** 的计算规则，并附 **从基准销量起算的数值示例**。  
> **主要依据**：`会议/会议需求同步`、配置中心原型红点、《预测销量上下限规则-终版.md》《R1至R3规则说明.md》。  
> **量纲**：销量 **件数**；金额 **元**；比率、弹性为小数。

> **表述约定**：正文叙述、表格中的「名称」采用 **中文名（符号）** 形式，与下表一致；**算式与代入中只写符号**（不在等式里夹写中文）。**数值示例（第七章）** 须与第三节公式一致：每一步先写 **公式原型**（符号关系），再 **代入数字** 写出等价变形与 **中间结果**，避免只给最终数。

## 一、先定范围：算什么、算到谁

| 项 | 说明（与会议对齐） |
|----|-------------------|
| **渠道与对象** | **亚马逊在售** Listing；**成品类型**；**成品定位**为 **P0、P1、P2**。不在该范围内的 SKU 是否展示/是否参与预测，以产品白名单或后续 PRD 为准。 |
| **时间粒度** | 预测到 **自然月**；滚动 **未来 12 个月**。 |
| **货号粒度** | 主工作台按 **MSKU** 展示与导出；配置中心维护系数与因子绑定。 |
| **新品** | 上架不足约 **3** 个月：可不产出预测/达成率，界面可为空。 |
| **数据规模** | 实现侧按性能分区、异步任务；不改变公式顺序。 |

### 1.1 同源 ASIN 多 MSKU（尾缀 -1、-2…）：训练合并、预测落点与达成率

**场景**：同一 ASIN（**按站点区分**）下，可能并存多个 MSKU，例如原链接 `H66411D1-US` 与后续新建的 `H66411D1-US-1`（尾缀 `-1`、`-2`… 表示同 ASIN 的衍生刊登）。评论或运营策略变化时常见「老链 + 新链」并行在售，**销量往往集中在较新的一侧**（新建链接、尾缀更大或 **MSKU 创建时间 / 开售时间** 更晚的一侧，以业务认定规则为准）。

**训练口径**：模型训练时，在 **站点 + ASIN** 维度将上述 MSKU 的**历史销量及相关特征按时间对齐后合并**，视为**一条样本序列**参与训练，避免同一 ASIN 被拆成多条弱相关序列导致学习不稳定。

**预测与展示口径**：推理仍按 **站点 + ASIN** 产出**一条**销量路径；将该路径得到的 **点预测销量（Q_pred）**（及经上下限、R1/R2/R3 锁定后的展示值，以开发为准）**全部写入「承载 MSKU」**——定义为：**同 ASIN 同站点下，尾缀序号最大**的 MSKU（实现上可与创建时间/开售时间校验一致）。**其余**同源 MSKU 行对同一预测月的 **Q_pred 固定为 0**（仅展示占位，不重复分摊销量）。

**达成率口径**：计算 **预测达成率**（单月或窗口聚合，见《R1至R3规则说明.md》）时，**Q_pred = 0** 的月份 / 行 **不参与**分子、分母（与「异常备注勾选排除月份」并列，均为排除类规则）。

## 二、全局基准定义（本文示例与对账用）

| 中文名（符号） | 含义（叙述） | 算式中仅用符号时 |
|----------------|--------------|------------------|
| 基准销量（Q_base） | 近一年总销量÷12，月均件数 | `Q_base = 年销量 / 12` |
| 价格基准（P_base） | 近一年成交均价（与 Q_base 同窗口） | `P_base = 年销售额 / 年销量` |

> **口径统一**：**价格基准（P_base）** 统一定为 **近一年成交均价**；与 **基准销量（Q_base）** 共用近一年滚动窗口。配置中心、引擎与本文 **第七章** 示例均按 **P_base** 计算 **价格倍数（M_pri）**。

## 三、各影响因子系数——计算规则（按因子）

各因子：**先倍数或综合增长 → 再系数**；各弹性（E_*）由配置或算法下发。以下每条先一句话对齐中文（符号），**编号内的算式只写符号**。

### 3.1 流量（系数 C_flow）

1. 取预测月 **M** 前紧邻三个月，得 **流量同比增速（y1,y2,y3）**（小数，0.10 表示 +10%）。  
2. `G_flow = 0.2*y1 + 0.3*y2 + 0.5*y3`（权重以配置为准）。  
3. `T_est = T_ysm * (1 + G_flow)`，其中 **去年同月流量（T_ysm）** 为去年与 M 同月实际流量。  
4. `T_base = 年总流量 / 12`（近一年月均）。  
5. `M_flow = T_est / T_base`。  
6. `C_flow = M_flow * E_flow`。  
7. **降级取数**：去年同月 ASIN 无流量 → 关联 SKU → 品类 → 场景 → 渠道（以产品定义为准）。

### 3.2 价格（系数 C_pri）

1. **价格基准（P_base）**：近一年成交均价（近一年总销售额÷近一年总销量）；不足或缺数时按品类等 **降级取数**（以产品定义为准），窗口与 **基准销量（Q_base）** 一致。  
2. **预估价（P_est）**：有下月价格规划用规划值；否则近 30 天均价外推。  
3. `M_pri = P_est / P_base`。  
4. `C_pri = 1 + M_pri * E_pri`（**价格弹性（E_pri）** 可为负）。

### 3.3 转化（系数 C_cvr）

1. 取 **转化环比增速（r1,r2）**。  
2. `G_cvr = 0.4*r1 + 0.6*r2`。  
3. `CR_est = CR_d30 * (1 + G_cvr)`（若实现定义为「×综合增长因子」则按开发锁定）。  
4. **基准转化（CR_ref）**：优先 ASIN 近 12 月均转化；不足→关联 SKU→品类+场景。  
5. `M_cvr = CR_est / CR_ref`。  
6. `C_cvr = M_cvr * E_cvr`。

### 3.4 广告（系数 C_ad）

1. **基准广告花费（A_ref）**：近 3 月月均广告花费。  
2. **预估广告花费（A_est）**：有计划用规划值，否则近 30 天水平延续。  
3. `M_ad = A_est / A_ref`。  
4. `C_ad = 1 + M_ad * E_ad`（若业务改为无「1+」形态，以开发锁定为准）。

### 3.5 竞争力（系数 C_comp）

以下 **算式仅用符号**。**竞争力只看「预测月前紧邻两个已满月」相对其前月的排名环比**，**不使用去年同期排名或同比**。数仓字段以映射表为准；文中 **`S(m)`** 表示 **小类排名**（自然月 **`m`**），**`B(m)`** 表示 **大类排名**（同 **`m`**）。排名数值方向（越大越差或越小越差）须全链统一，下列公式按「**相邻两月排名值**」直接代入 **`R_sym`**。

**时间记号（示例：预测 9 月）**  

- **`m0`**：**`m1`** 的前一月（如 **6 月**）  
- **`m1`、`m2`**：紧邻预测月的两个已满月（如 **7 月、8 月**）

**对称环比增速**：对相邻两月排名 **`a`（上月）、`b`（本月）**，定义  

`R_sym(b,a) = (b - a) / (a + b)`  

与业务写法一致：如 **7 月增速** = **`(S(m1)-S(m0)) / (S(m1)+S(m0))`**，**8 月** = **`(S(m2)-S(m1)) / (S(m2)+S(m1))`**。**若 `a+b=0`** 或 **任一端排名缺失**，则本条增速 **不可算**。

**月权**：**`w1 = 0.45`**（对应 **`m1` 相对 `m0` 的增速**）、**`w2 = 0.55`**（对应 **`m2` 相对 `m1` 的增速`**）。

**1. 小类两月加权增速（`G_sub`）**

`g_sub_1 = R_sym(S(m1), S(m0))`  
`g_sub_2 = R_sym(S(m2), S(m1))`  
`G_sub = w1 * g_sub_1 + w2 * g_sub_2`

**2. 大类两月加权增速（`G_cat`）**

将 **`S`** 换为 **`B`**：  

`g_cat_1 = R_sym(B(m1), B(m0))`  
`g_cat_2 = R_sym(B(m2), B(m1))`  
`G_cat = w1 * g_cat_1 + w2 * g_cat_2`

**3. 竞争力综合增长率（`G_comp`）**

`G_comp = 0.7 * G_sub + 0.3 * G_cat`（**小类权重 0.7、大类权重 0.3**）。

**4. 竞争力系数**

`C_comp = 1 + G_comp * E_comp`。

**5. 缺数：无有效近 2 月排名链时不做竞争力预测**

计算 **`G_sub`** 须 **`S(m0)、S(m1)、S(m2)`** 均可用于 **`R_sym`** 且 **`S(m1)+S(m0)>0`、`S(m2)+S(m1)>0`**（或按排名口径约定的非零条件）；**`G_cat`** 须 **`B(m0)、B(m1)、B(m2)`** 同理。  

若 **小类链或大类链任一不满足**（缺月、空值、分母为 0 等），则 **不再计算本节竞争力综合增长率**：**`G_comp = 0`**，**`C_comp = 1`**（等价于 **`G_comp * E_comp = 0`**，**竞争力系数不对销量连乘产生偏离**）。

### 3.6 超参数（系数 C_hyp）

由配置绑定 **超参系数（C_hyp）**；与五因子独立，通常 **连乘** 进总系数。

### 3.7 总系数（C_tot）与点预测销量（Q_pred）

- `C_tot = C_flow * C_pri * C_cvr * C_ad * C_comp * C_hyp`（顺序以开发为准）。  
- `Q_pred = Q_base * C_tot`（取整与边界由引擎处理）。

## 七、数值示例（从基准销量与价格基准起算）

虚构演示数，不代表真实 SKU。表格列「项」为 **中文名（符号）**；**分步推导**在 7.1、7.3、7.4：每步 **公式 → 代入 → 中间值**，式中只用符号。

### 7.1 全局基准

| 项 | 取值 | 说明 |
|----|------|------|
| 近一年总销量 | 1 440 件 | 输入 |
| 基准销量（Q_base） | 120 件/月 | 见下分步 |
| 近一年总销售额 | 14 400 元 | 输入 |
| 价格基准（P_base） | 10 元/件 | 见下分步 |

**分步（与第二节定义一致）**

- `Q_base = 年销量 / 12 = 1440 / 12 = 120`（件/月）
- `P_base = 年销售额 / 年销量 = 14400 / 1440 = 10`（元/件）

### 7.2 弹性与超参（配置假设）

| 因子 | 中文名（符号） | 取值（示例） |
|------|----------------|--------------|
| 流量 | 流量弹性（E_flow） | 1.0 |
| 价格 | 价格弹性（E_pri） | -0.5 |
| 转化 | 转化弹性（E_cvr） | 1.0 |
| 广告 | 广告弹性（E_ad） | 0.8 |
| 竞争力 | 竞争力弹性（E_comp） | 2.0 |
| 超参数 | 超参系数（C_hyp） | 1.02 |

### 7.3 各因子中间量与系数（逐步公式与代入）

以下与 **第三节** 公式一一对应；**已知数**在段首列出，每步为「关系式 → 代入 → 结果」。

#### 流量系数（C_flow）（对应 3.1）

已知：`y1=0.08`，`y2=0.10`，`y3=0.12`；`T_ysm=10000`；`T_base=10000`；`E_flow=1.0`（见 7.2）。

1. `G_flow = 0.2*y1 + 0.3*y2 + 0.5*y3 = 0.2*0.08 + 0.3*0.10 + 0.5*0.12 = 0.016 + 0.03 + 0.06 = 0.106`
2. `T_est = T_ysm * (1 + G_flow) = 10000 * (1 + 0.106) = 10000 * 1.106 = 11060`
3. `M_flow = T_est / T_base = 11060 / 10000 = 1.106`
4. `C_flow = M_flow * E_flow = 1.106 * 1.0 = 1.106`

#### 价格系数（C_pri）（对应 3.2）

本例 **价格基准（P_base）= 10**（与 7.1 一致）；`P_est = 10.5`；`E_pri = -0.5`（见 7.2）。

1. `M_pri = P_est / P_base = 10.5 / 10 = 1.05`
2. `C_pri = 1 + M_pri * E_pri = 1 + 1.05 * (-0.5) = 1 - 0.525 = 0.475`

#### 转化系数（C_cvr）（对应 3.3）

已知：`r1=0.02`，`r2=0.03`；`CR_d30=0.10`；`CR_ref=0.10`；`E_cvr=1.0`（见 7.2）。

1. `G_cvr = 0.4*r1 + 0.6*r2 = 0.4*0.02 + 0.6*0.03 = 0.008 + 0.018 = 0.026`
2. `CR_est = CR_d30 * (1 + G_cvr) = 0.10 * (1 + 0.026) = 0.10 * 1.026 = 0.1026`
3. `M_cvr = CR_est / CR_ref = 0.1026 / 0.10 = 1.026`
4. `C_cvr = M_cvr * E_cvr = 1.026 * 1.0 = 1.026`

#### 广告系数（C_ad）（对应 3.4）

已知：`A_ref=1000`，`A_est=1100`；`E_ad=0.8`（见 7.2）。

1. `M_ad = A_est / A_ref = 1100 / 1000 = 1.1`
2. `C_ad = 1 + M_ad * E_ad = 1 + 1.1 * 0.8 = 1 + 0.88 = 1.88`

#### 竞争力系数（C_comp）（对应 3.5）

预测月取 **9 月** 示例： **`m0=6`月、`m1=7`月、`m2=8`月**；**`w1=0.45`、`w2=0.55`**；**`E_comp=2.0`**（见 7.2）。**小类排名 `S`**、**大类排名 `B`**（演示取同序，便于核对）：

- **`S(6)=95`，`S(7)=105`，`S(8)=116`**
1. `g_sub_1 = R_sym(S(7),S(6)) = (105-95)/(105+95) = 10/200 = 0.05`
2. `g_sub_2 = R_sym(S(8),S(7)) = (116-105)/(116+105) = 11/221 ≈ 0.0497737557`
3. `G_sub = w1*g_sub_1 + w2*g_sub_2 = 0.45*0.05 + 0.55*0.0497737557 ≈ 0.0498755656`

- **`B(6)=95`，`B(7)=105`，`B(8)=116`**（同型）
4. `G_cat ≈ 0.0498755656`
5. `G_comp = 0.7*G_sub + 0.3*G_cat ≈ 0.0498755656`
6. `C_comp = 1 + G_comp * E_comp ≈ 1 + 0.0498755656 * 2.0 ≈ 1.099751131`（约 **1.100**）

#### 超参系数（C_hyp）（对应 3.6）

配置给定：`C_hyp = 1.02`（无中间式，与 7.2 一致）。

### 7.4 总系数（C_tot）与点预测销量（Q_pred）

由 7.3 得：`C_flow=1.106`，`C_pri=0.475`，`C_cvr=1.026`，`C_ad=1.88`，`C_comp≈1.099751131`，`C_hyp=1.02`。由 7.1 得：`Q_base=120`。

**总系数（连乘，顺序与 3.7 一致；每步保留足够小数再乘下一步）**

1. `C_tot = C_flow * C_pri * C_cvr * C_ad * C_comp * C_hyp`
2. `s2 = C_flow * C_pri = 1.106 * 0.475 = 0.52535`
3. `s3 = s2 * C_cvr = 0.52535 * 1.026 = 0.5390091`
4. `s4 = s3 * C_ad = 0.5390091 * 1.88 = 1.012537108`
5. `s5 = s4 * C_comp ≈ 1.012537108 * 1.099751131 ≈ 1.113537802`
6. `C_tot = s5 * C_hyp ≈ 1.113537802 * 1.02 ≈ 1.135809` → 约 **`1.1358`**（展示可四舍五入到 4 位小数）

**点预测销量**

- `Q_pred = Q_base * C_tot ≈ 120 * 1.135809 ≈ 136.30` 件/月（取整规则以引擎为准）。

> **说明**：因子多时连乘会放大舍入误差。建议实现侧 **全程高精度**，仅在展示或导出时按统一规则取小数位；对账时使用同一套 `C_*` 快照与同一条连乘顺序。
