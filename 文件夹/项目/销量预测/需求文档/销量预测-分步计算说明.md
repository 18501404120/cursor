# 销量预测：如何一步一步算出来（计算链路说明）

> **文档目的**：把「从配置与原始数据到主工作台展示」的计算顺序写清楚，便于开发自测、数据对接与测试验收时对照；并标明**会议口述**与**已定稿产品口径**的差异处。  
> **主要依据**：`会议/会议需求同步`（需求同步会口述链路）、《预测销量上下限规则-终版.md》《R1至R3规则说明.md》《销量预测管理-PRD.md》。  
> **量纲**：与已定稿一致，**销量一律按件数**；不在本文展开营收折算。

---

## 一、先定范围：算什么、算到谁

| 项 | 说明（与会议对齐） |
|----|-------------------|
| **渠道** | 先做 **亚马逊**；在售 Listing。 |
| **时间粒度** | 预测到 **自然月**；滚动 **未来 12 个月**（与「每天重算」的日批任务一致）。 |
| **货号粒度** | 主工作台按 **MSKU（店铺+MSKU 唯一）** 展示与导出；配置中心维护系数与因子绑定。 |
| **新品** | 在售但 **上架不足约 3 个月**：可不产出预测/达成率，界面可为空（会议口径）。 |
| **数据规模** | 会议提到全量在售量级与日批行数，实现侧按性能做分区、异步任务即可，不改变公式顺序。 |

## 二、名词与「到哪里去取数」

下列名词在 **主工作台详情**、**配置中心**、**超参数因子** 中反复出现，建议与界面字段一一绑定。

| 名词 | 含义（概要） | 典型来源 |
|------|--------------|----------|
| **基准销量** | 作为「乘总系数」的参照销量水平；详情里与「技术销量」等列同屏解释。 | 引擎按货号+月统计历史销量后做规则汇总（**细则以《预测销量上下限规则-终版》及配置中心红点为准**）。会议曾口述「近一年月均」等，**若与 PRD/终版不一致，以 PRD/终版为准**。 |
| **弹性系数** | 各因子（流量、转化、竞争力、广告、价格等）的 **敏感度参数**；算法侧产出，**可按品类维度提供**（会议：一品类下多 MSKU 共用一套，后续可细化到 SKU）。 | 算法/数据团队 → 写入 **预测配置**（或等价接口）；**产品不要求业务手填影响因子系数**。 |
| **倍数** | 相对「基准期」的流量（或各因子）涨跌比例；由 **历史窗口 + 预估月输入** 算得（会议以流量举例，见第三节）。 | 规则引擎或算法服务。 |
| **影响因子系数** | **倍数 × 该因子弹性系数** 得到该因子一条系数（会议口径）。 | 引擎在跑批时计算，详情列展示。 |
| **总系数** | 各因子影响因子系数（及业务约定的 **超参数因子系数** 等）按约定做 **连乘** 或其它合成（会议口述为「多个乘起来」；**具体合成顺序以开发实现与 PRD 锁定为准**）。 | 引擎。 |
| **目标 / 点预测（中值路径）** | **基准销量 × 总系数** 得到会议中描述的「目标推荐值」一类主数字；与《终版》中 **客观中值** 叙述为同一条业务主链时应对齐，**上下限另走情景带**（见第六节）。 | 主表月度单元格、图表柱。 |
| **目标 R1 / R2 / R3** | 在距目标月 1 号剩余天数进入各档阈值时，对当月预测做的 **锁定快照**；**计算逻辑相同，仅锁定时刻不同**。 | 见《R1至R3规则说明》。 |
| **客观下限 / 客观上限** | 与中值 **同一套销量合成公式**，因子取悲观/乐观路径（流量 ×0.5/×2，其它因子近窗 min/max 等）。 | 见《预测销量上下限规则-终版》第三节。 |
| **预测达成率** | 已关账月：\(100\% - \|A-P\|/\max(A,P)\)；窗口聚合见《R1至R3规则说明》。 | 主工作台 KPI、列、详情。 |

## 三、分步计算（主链路 · 与会议「详情」口述对齐）

下列步骤对应会议中「倍数 × 弹性系数 → 总系数 × 基准销量 → 上下限 → 达成率」的讲解顺序，便于一步一步实现与对账。

### 步骤 0：准备预测月与货号上下文

1. 取 **预测月 M**（自然月）与 **MSKU**（含店铺维度）。  
2. 校验是否在产：在售、渠道=亚马逊、上架时长等业务规则。  
3. 拉取 **配置中心** 已维护的：各因子弹性系数、超参数因子绑定、（若有）手工覆盖项。

### 步骤 1：算「倍数」（会议以流量因子展开）

会议口述的流量倍数逻辑可概括为：

1. **取同比窗口**：若要预测 **9 月**，先看 **6、7、8 三个月**（预测月前紧邻的三个月）相对 **去年同月** 的 **同比增长率**（每月一个增长率）。  
2. **加权合成综合增长率**：例如按 **0.2 / 0.3 / 0.5** 对三个月同比增长率加权求和，得到 **综合增长率** \(g\)（系数以产品最终配置为准）。  
3. **预估预测月流量**：用 **去年同月（M 的去年同月）实际流量** × \((1 + g)\)（或会议等价表述），得到 **预测月预估流量**。  
4. **基准流量**：取 **近一年月均流量**（会议：近一年总流量平均到月）。  
5. **流量倍数** = **预测月预估流量 ÷ 基准流量**。

> **说明**：转化、竞争力、广告、价格等因子在实现上各有「倍数」定义，**会议明确由算法侧提供倍数与弹性系数**；产品侧需保证 **详情里「倍数 → 影响因子系数」的展示顺序与命名一致**。

### 步骤 2：算各因子「影响因子系数」

对每个因子 \(f\)：

\[
\text{影响因子系数}_f = \text{倍数}_f \times \text{弹性系数}_f
\]

- **弹性系数**：来自配置/算法输出（**按品类**，可约定一月更新一次，会议）。  
- **倍数**：见步骤 1 类推到其它因子或由算法直接输出。

### 步骤 3：算「总系数」

将各因子的影响因子系数及 **超参数因子系数**（配置中心维护，会议：最后还要再乘一层）按 **产品约定的合成公式** 合并为 **总系数**（会议口述多为 **连乘**；若有加性、封顶等，以 PRD/开发说明为准）。

### 步骤 4：算目标点预测（主数字 / 中值路径对齐）

\[
\text{目标推荐（点预测）} = \text{基准销量} \times \text{总系数}
\]

- 结果取整规则、边界校验（缺失因子、除零）由引擎统一处理。  
- 该值在主工作台未进入 R1/R2/R3 锁定时，**三档展示可相同**；进入锁定后分别冻结为 **目标 R1/R2/R3**（见下一步）。

### 步骤 5：R1 / R2 / R3 锁定（与时间有关，与倍数公式无关）

1. 对每个目标月 **M**，自 **M−12** 起每日滚动重算点预测。  
2. 按距 **M 月 1 号** 的 **剩余天数** 与配置阈值（默认 **30 / 60 / 90 天**）依次锁定 **R3 → R2 → R1**。  
3. **R1、R2、R3 的数值算法相同**，区别仅是 **锁定时刻不同**；锁定后快照不随当日滚动预测回写。

详见：《R1至R3规则说明.md》。

### 步骤 6：客观下限 / 客观上限（情景带）

在已得到 **点预测（或各档锁定目标点值）** 后，用 **同一套销量合成公式**，仅替换因子为悲观/乐观路径：

- 流量：×0.5（下限路径）/ ×2（上限路径）等；  
- 转化、竞争力、广告：近 3 月 min/max（**不含预测月**）；  
- 价格：近 1 年月均价 max（悲观）/ min（乐观）（**不含预测月**）。

详见：《预测销量上下限规则-终版.md》第三节、第四节示例。

### 步骤 7：预测达成率（与实际对比）

对已关账月，取 **实际销量 A** 与所选档 **预测 P**（R1/R2/R3 之一）：

\[
\text{单月达成率} = 100\% - \frac{|A-P|}{\max(A,P)}
\]

列表与 KPI 的窗口聚合：

\[
100\% - \frac{\sum|A-P|}{\sum \max(A,P)}
\]

异常备注可排除区间内月份，见《R1至R3规则说明》第 7 节。

### 步骤 8：forecast 与其它展示轨（与计算主链的关系）

- 会议明确 **forecast 填写一期可先不做闭环应用**，主链仍以规则/算法预测与锁定快照为准。  
- 若界面勾选「系统规则」「forecast」等 **多轨展示**，导出与详情需标明 **列来源**，避免与主预测列混为同一口径。

## 四、页面与数据流（方便联调）

| 顺序 | 页面 / 模块 | 作用 |
|------|-------------|------|
| 1 | **超参数因子管理** | 维护因子库、编号、事件区间；与配置绑定。 |
| 2 | **预测配置中心** | 维护弹性系数、因子绑定、导入导出；为引擎提供基础参数。 |
| 3 | **批处理 / 引擎** | 按日跑：倍数 → 影响因子系数 → 总系数 → 点预测 → 上下限 → 锁定快照。 |
| 4 | **主工作台** | 筛选、图表、表体、详情、达成率、导出。 |
| 5 | **相关 SKU（若有）** | 会议称与前期一致，取数链路仍以该页 PRD 为准。 |

## 五、会议与定稿不一致时的处理原则

1. **锁定天数、达成率公式、上下限因子表**：以 **《R1至R3规则说明》《预测销量上下限规则-终版》** 为准。  
2. **基准销量一句口语**（如「销量÷销售额÷价格」）：若与引擎/PRD 中「参照月均、降级路径」等定义冲突，**以 PRD + 终版 + 配置中心红点** 为准，本文仅保留会议出处说明。  
3. **总系数是否严格连乘、是否含超参及顺序**：以 **开发锁定 + PRD** 为准，会议为口述确认方向。
