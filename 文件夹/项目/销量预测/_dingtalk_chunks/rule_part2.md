### 步骤 3：`P_i`（近30天平均价，折营收用）→ 三档全组营收（元）

| 汇总量 | 计算式 | 结果（元） |

| **`RevLo`（全组悲观营收）** | `Lo_A×P_A + Lo_B×P_B + Lo_C×P_C` = 79×12 + 168×15 + 25×20 | **3,968** |
| **`RevHi`（全组乐观营收）** | `Hi_A×P_A + Hi_B×P_B + Hi_C×P_C` = 413×12 + 830×15 + 121×20 | **19,826** |

### 步骤 4：`T_rev`（目标总营收）三种情况 → `R_i`（推荐销量，件）

以下均在同上 **A/B/C** 汇总范围内。具体判定与公式见 **第一节「推荐销量计算逻辑（`R_i`（推荐销量））」**。

**无 `T_rev`（目标总营收）**：`R_i`（推荐销量）= `Mid_i`（客观中值销量）→ **184 / 373 / 55**。

#### 情况甲：`T_rev`（目标总营收）**高于** `RevHi`（全组乐观营收）

- 设 **`T_rev`（目标总营收）= 25,000** 元（`25,000 > 19,826 = RevHi`（全组乐观营收））。  
- **逻辑**：目标超出乐观营收上沿，推荐**顶到乐观销量档**。  
- **计算**：对每个货号 **`i`**，`R_i`（推荐销量）= `Hi_i`（客观上限销量）。

| MSKU | `R_i`（推荐销量）= `Hi_i`（客观上限销量） |
|------|------------------------------------------|
| A | **413** |
| B | **830** |
| C | **121** |

（此档下 **`Σ_i (Hi_i × P_i)`（按近30天平均价折算的全组营收）** = **19,826** 元 = `RevHi`（全组乐观营收）。）

#### 情况乙：`T_rev`（目标总营收）**低于** `RevLo`（全组悲观营收）

- 设 **`T_rev`（目标总营收）= 3,000** 元（`3,000 < 3,968 = RevLo`（全组悲观营收））。  
- **逻辑**：目标低于悲观营收下沿，**不按目标把推荐销量往下压**。  
- **计算**：对每个 **`i`**，`R_i`（推荐销量）= `Mid_i`（客观中值销量）。

| MSKU | `R_i`（推荐销量）= `Mid_i`（客观中值销量） |
|------|--------------------------------------------|
| A | **184** |
| B | **373** |
| C | **55** |

#### 情况丙：`RevLo`（全组悲观营收）≤ `T_rev`（目标总营收）≤ `RevHi`（全组乐观营收）

- 设 **`T_rev`（目标总营收）= 12,000** 元（`3,968 ≤ 12,000 ≤ 19,826`）。  
- **逻辑**：目标落在「中间营收」可解释的带内，用**单一 `m`（汇总倍数）** 同比例缩放各货号 **`Mid_i`（客观中值销量）**，再卡到 **`Lo_i`（客观下限销量）～`Hi_i`（客观上限销量）** 内。  
- **计算**：  
  1. **`m`（汇总倍数）** = `T_rev`（目标总营收）÷ `RevMid`（全组中间营收）→ `12,000 ÷ 8,903 ≈ 1.347860…`  
  2. **`R_i`（推荐销量）** = ROUND（`Mid_i`（客观中值销量）× `m`（汇总倍数））  
  3. **`R_i`（推荐销量）** = min（max（`R_i`（推荐销量），`Lo_i`（客观下限销量）），`Hi_i`（客观上限销量））（本例未触发越界）

| MSKU | 计算 | `R_i`（推荐销量） |
|------|------|-------------------|
| A | `ROUND(184 × 1.347860…)` | **248** |
| B | `ROUND(373 × 1.347860…)` | **503** |
| C | `ROUND(55 × 1.347860…)` | **74** |

验算 **`Σ_i (R_i × P_i)`（按近30天平均价折算的全组推荐营收）**：`248×12 + 503×15 + 74×20 = **12,001**` 元，与 **`T_rev`（目标总营收）** **12,000** 元相差 **1** 元，属取整误差；落地规则可在 **`Lo_i`（客观下限销量）～`Hi_i`（客观上限销量）** 内做二次缩放，使误差落在约定阈值内（技术设计细化）。
