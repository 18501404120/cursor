# 销量预测 · 同步到钉钉「项目 / cursor」文件夹

## 本仓库脚本做什么

脚本路径：`scripts/sync_sales_forecast_to_dingtalk_kb.py`  

将本地目录一次性上传为钉钉**知识库里的文件**（与手动在知识库「上传文件」等价）：

- `需求文档/` 下全部 `.md`
- `原型/` 下 `.md`、`.html`、`.js`、`.css` 等（见脚本内扩展名列表）

钉钉内显示的文件名带前缀 **`需求文档/…`**、**`原型/…`**，便于在同一父文件夹下区分来源。

## 与「钉钉在线文档」的区别

| 形态 | 本脚本是否支持 | 说明 |
|------|----------------|------|
| 知识库 **文件**（md/html 等） | ✅ | 三步上传接口；钉内预览能力随客户端版本变化。 |
| **在线协作文档**（空白文档 + 块编辑器） | ❌ | 需开放平台「创建知识库文档」等**另一套**接口，或钉内新建后手工粘贴。 |

若产品口头说的「Markdown 换成钉钉文档格式」指的是**可排版、可协同的钉文档**，请钉内对上传文件使用 **「转为钉文档」/ 新建文档后导入**；或使用 `--docx`（需本机安装 [pandoc](https://pandoc.org/)）先把 Markdown 转成 Word 再上传，钉内按 Office 文档预览，仍属「文件」而非钉文档 API 直写。

## 环境变量与执行

与 `文件夹/项目/GTM角色和职责/竞品调研/scripts/sync_merged_to_dingtalk_kb.py` 相同：

1. 钉钉开放平台创建企业内部应用，开通**知识库 / 企业存储 · 上传文件**相关权限。  
2. 在钉钉网页打开目标知识库下的 **`项目` → `cursor`**（或你的实际路径），从网络请求或列举接口取得该文件夹的 **`dentryUuid`**，写入 `DINGTALK_PARENT_DENTRY_UUID`。

```bash
export DINGTALK_APP_KEY="..."
export DINGTALK_APP_SECRET="..."
export DINGTALK_UNION_ID="..."
export DINGTALK_PARENT_DENTRY_UUID="目标文件夹的 dentryUuid"

# 仅列出将要上传的文件
python3 文件夹/项目/销量预测/scripts/sync_sales_forecast_to_dingtalk_kb.py --dry-run

# 实际上传
python3 文件夹/项目/销量预测/scripts/sync_sales_forecast_to_dingtalk_kb.py

# 将每个 .md 先转为 .docx 再上传（需 pandoc）
python3 文件夹/项目/销量预测/scripts/sync_sales_forecast_to_dingtalk_kb.py --docx
```

可选：`DINGTALK_CONFLICT_STRATEGY`（默认 `OVERWRITE`，同名覆盖）。

## 获取 `dentryUuid` 的提示

与竞品调研 README 相同：在钉钉文档/知识库网页中进入目标文件夹，用浏览器开发者工具查看接口响应中的 `dentryUuid`，或调用开放平台「列举子文件」类接口。

## 依赖

- Python 3.10+（推荐）  
- 本机可访问 `https://api.dingtalk.com`  
- 可选：`pandoc`（仅在使用 `--docx` 时）
