# 基于规则的销量预测设计说明

> 核心因子：**流量、价格、生命周期、转化率、广告、竞争力排名、广告花费**  
> 目标：在可解释、可配置的前提下，用规则组合得到可落地的销量预测。

---

## 一、总体设计思路

### 1.1 为什么用规则做预测

- **可解释**：业务能看懂「为什么这周预测是 1000 而不是 800」。
- **可配置**：大促、调价、排名变化时，运营/计划可改系数而不等模型发版。
- **冷启动友好**：新品、新渠道没有长历史时，仍可用生命周期 + 广告等规则给出合理区间。

### 1.2 推荐公式骨架（规则预测的统一范式）

将销量拆解为「**基准销量**」经多因子**连乘或加权修正**：

\[
\text{预测销量} = \text{基准销量} \times f_{\text{流量}} \times f_{\text{价格}} \times f_{\text{生命周期}} \times f_{\text{转化率}} \times f_{\text{广告}} \times f_{\text{排名}} \times f_{\text{广告花费}}
\]

实务中可约定：

- 部分因子用**乘数**（如 0.8～1.3），部分用**加性修正**（如在基准上加固定件数），最终以业务习惯为准。
- **基准销量**通常取：近 N 周同 SKU 同渠道**平滑销量**（如 4 周加权平均）或「去年同期同周 × 年成长系数」。

下文按因子分别定义 **规则如何设计** 与 **示例**。

## 二、各核心因子：规则设计方法

### 2.1 流量（Traffic）

**含义**：Listing/店铺/站点的**曝光或访问量**（如 Sessions、PV、UV），反映「有多少人看到」。

**规则设计要点**

| 规则类型 | 逻辑 | 典型配置 |
|----------|------|----------|
| **同比/环比档位** | 本周流量相对「近 4 周均值」或「去年同期周」的变化档位 → 乘数 | 每 ±10% 流量 → 销量乘数 ±3%～5%（需业务标定） |
| **绝对阈值** | 流量低于某阈值视为「曝光不足」→ 封顶或下限 | 流量 &lt; 近 8 周 P25 → 乘数上限 0.85 |
| **大促周覆盖** | 大促周单独规则，可覆盖流量乘数 | Prime Day 周：流量乘数强制用活动表配置值 |

**示例规则（表格式）**

| 条件（相对近 4 周流量均值） | 乘数 \(f_{\text{流量}}\) |
|----------------------------|-------------------------|
| &lt; −20% | 0.85 |
| −20% ~ −10% | 0.92 |
| −10% ~ +10% | 1.00 |
| +10% ~ +30% | 1.08 |
| &gt; +30% | 1.15 |

**数值示例**：基准销量 1000，流量较均值 +25% → \(f_{\text{流量}}=1.08\) → 中间结果 1080。

---

### 2.2 价格（Price）

**含义**：**成交价或展示价**相对历史/竞品的变化，对转化与销量弹性大。

**规则设计要点**

| 规则类型 | 逻辑 | 典型配置 |
|----------|------|----------|
| **相对近 4 周均价** | 降价 → 乘数 &gt;1；涨价 → 乘数 &lt;1 | 每降价 5% → 约 +3%～8% 销量（品类不同需标定） |
| **价格带档位** | 落入不同价格带用不同基准或乘数 | 从 49.99 调到 39.99 触发「价格带跃迁」规则，额外 +10% |
| **与券/促销叠加** | 有 coupon 的周单独乘数 | 有站外券：\(f_{\text{价格}}\) 再 ×1.05 |

**示例规则**

| 本周均价 vs 近 4 周均价 | 乘数 \(f_{\text{价格}}\) |
|-------------------------|-------------------------|
| 涨价 &gt;10% | 0.88 |
| 涨价 5%～10% | 0.94 |
| ±5% 内 | 1.00 |
| 降价 5%～10% | 1.06 |
| 降价 &gt;10% | 1.12 |

**数值示例**：中间结果 1080，本周均价下降 8% → \(f_{\text{价格}}=1.06\) → 1144.8 ≈ **1145**。

---

### 2.3 生命周期（Lifecycle）

**含义**：SKU 处于 **新品爬坡、稳定期、成熟、清仓/退市** 等阶段，销量曲线形状不同。

**规则设计要点**

| 阶段 | 规则思路 | 示例乘数或基准调整 |
|------|----------|-------------------|
| **上架 0～4 周** | 按「周序号」爬坡表 | 第 1 周 0.2×稳定期基准，第 2 周 0.4，… 第 4 周 0.9 |
| **5～12 周** | 快速爬升到 1.0～1.1 | 线性或阶梯到 1.0 |
| **稳定期** | \(f_{\text{生命周期}}=1.0\) | 以历史同品类稳定周为参照 |
| **清仓/退市** | 逐周衰减 | 每月衰减 15%～25% 或按库存深度设上限 |

**示例规则（新品周序）**

| 上架后第 N 周 | \(f_{\text{生命周期}}\)（相对「同品类稳定 SKU 周均销量」归一后） |
|---------------|------------------------------------------------------------------|
| 1 | 0.25 |
| 2 | 0.45 |
| 3 | 0.70 |
| 4 | 0.90 |
| ≥5 且非清仓 | 1.00 |
| 清仓标记=是 | 取 `min(1.2, 1 + 折扣深度×0.05)` 或单独清仓表 |

**数值示例**：若为稳定期 SKU，\(f_{\text{生命周期}}=1.00\)，中间结果仍为 1145。

---

### 2.4 转化率（Conversion / CVR）

**含义**：**订单数/会话数**或 **订单数/点击量**，反映「流量质量与 Listing 效率」。

**规则设计要点**

| 规则类型 | 逻辑 |
|----------|------|
| **相对品类均值** | CVR 高于品类 P75 → 乘数 &gt;1；低于 P25 → 乘数 &lt;1 |
| **相对自身历史** | 本周 CVR vs 近 4 周自身 CVR |
| **异常检测** | CVR 暴跌可能详情页/差评 → 规则降预测并打标签 |

**示例规则（相对自身近 4 周 CVR）**

| 本周 CVR / 近 4 周均值 | \(f_{\text{CVR}}\) |
|------------------------|-------------------|
| &lt; 0.85 | 0.90 |
| 0.85～0.95 | 0.96 |
| 0.95～1.05 | 1.00 |
| 1.05～1.20 | 1.05 |
| &gt; 1.20 | 1.10 |

**数值示例**：1145 × 1.05 = **1202**（CVR 提升约 8%）。

---

### 2.5 广告（Ads，广义投放状态）

**含义**：是否**开启广告、广告类型变化、投放力度档位**（可与花费拆开：此处偏「有没有投、投什么」）。

**规则设计要点**

| 规则类型 | 逻辑 |
|----------|------|
| **开关** | 从停投到开投 → 阶梯提升预测 |
| **结构** | SB/SD/SP 占比变化 → 不同品类预设乘数 |
| **活动期** | 大促加投周 → 与「大促日历」规则合并，避免重复乘两次 |

**示例规则**

| 广告状态 vs 上周 | \(f_{\text{广告}}\) |
|------------------|-------------------|
| 持续未开广告 | 1.00 |
| 新开启广告（近 7 天由关→开） | 1.08 |
| 持续开广告 | 1.00（花费由 2.7 因子体现） |
| 大促加投标记=是 | 1.05（与日历互斥配置二选一） |

**数值示例**：1202 × 1.00 = **1202**（假设持续开投，由花费体现增量）。

---

### 2.6 竞争力排名（BSR / 类目排名等）

**含义**：**类目排名或关键词排名**越好（数字越小），通常流量与转化更有利。

**规则设计要点**

| 规则类型 | 逻辑 |
|----------|------|
| **排名分档** | 如 Top 100 / 100～500 / 500～2000 / 2000+ → 不同乘数 |
| **排名变化** | 较上周上升（名次变小）→ 正乘数；下滑 → 负乘数 |
| **多排名取权** | 主类目 + 核心关键词排名加权 |

**示例规则（主类目 BSR 分档，数值越小越好）**

| BSR 区间 | \(f_{\text{排名}}\) |
|----------|-------------------|
| 1～100 | 1.12 |
| 101～500 | 1.06 |
| 501～2000 | 1.00 |
| 2001～10000 | 0.94 |
| &gt;10000 | 0.88 |

**另设「周环比排名变化」修正**（可选）：

| 排名较上周（名次变化） | 额外乘数 |
|------------------------|----------|
| 提升 &gt;20% 位次 | ×1.03 |
| 基本不变 | ×1.00 |
| 下滑 &gt;20% 位次 | ×0.97 |

**数值示例**：BSR 800 → \(f_{\text{排名}}=1.00\)；若从 1500 进到 800，可再 ×1.03 → 1202×1.03 ≈ **1238**。

---

### 2.7 广告花费（Ad Spend）

**含义**：**广告投入金额**（如日/周花费），与「流量、CVR」强相关，规则上常与流量联动避免**双重计数**。

**规则设计要点**

| 策略 | 说明 |
|------|------|
| **与流量解耦** | 若 \(f_{\text{流量}}\) 已含广告带来的流量，则花费用**小幅修正**或只调「增量花费」 |
| **花费档位** | 本周花费 vs 近 4 周均值 → 乘数 |
| **ROI 门槛** | 花费高但 ACOS 爆表 → 规则可限制预测上限（业务策略） |

**推荐**：花费对销量的影响通过 **「花费 → 预期增量点击 → 增量订单」** 规则更直观：

\[
\Delta Q_{\text{花费}} = \text{增量点击} \times \text{CVR} \approx \frac{\Delta \text{Spend}}{\text{CPC}} \times \text{CVR}
\]

再折成乘数：\(f_{\text{花费}} = 1 + \Delta Q / \text{基准销量}\)。

**示例规则（简化档位）**

| 本周广告花费 vs 近 4 周均值 | \(f_{\text{花费}}\) |
|----------------------------|-------------------|
| &lt; 70% | 0.95 |
| 70%～130% | 1.00 |
| 130%～200% | 1.06 |
| &gt; 200% | 1.10（可设上限防虚高） |

**数值示例**：1238 × 1.06 = **1312**（花费高于均值 50% 档位示例）。

## 三、因子组合与冲突处理

### 3.1 避免重复计数

| 组合 | 建议 |
|------|------|
| 流量 × 广告花费 | 流量若已按「含付费流量」统计，花费用**增量档**或二者取主因子（二选一） |
| 广告开关 × 广告花费 | 开关用阶梯；日常波动主要靠花费 |
| 价格 × 大促 | 大促周可用「活动总乘数」覆盖部分子规则 |

可在配置层为每个 SKU **选择主驱动因子集合**（如亚马逊 Listing 以「排名+花费+价格」为主，独立站以「流量+转化+价格」为主）。

### 3.2 上下限与取整

- **预测下限**：max(基准×0.3, 近 4 周最小周销 ×0.5)（防异常过低）
- **预测上限**：min(基准×2.5, 仓容/产能上限)（防爆仓）
- **取整**：按「件」取整；套装按套数。

## 四、完整数值示例（单 SKU、单渠道、单周）

**假设**  
- 渠道：亚马逊美国站某 SKU  
- **基准销量**（近 4 周加权平均）：**1000 件/周**  
- 当周业务状态见下表：

| 因子 | 当周情况 | 选用规则 | 乘数 |
|------|----------|----------|------|
| 流量 | 较 4 周均值 +22% | +10%～+30% 档 | 1.08 |
| 价格 | 较 4 周均价 −6% | 降价 5%～10% | 1.06 |
| 生命周期 | 稳定期第 20 周 | 稳定期 | 1.00 |
| 转化率 | 较自身 4 周均值 +12% | 1.05～1.20 档 | 1.05 |
| 广告 | 持续投放 | 持续开广告 | 1.00 |
| 排名 | BSR 600，较上周从 900 提升 | 501～2000 + 提升修正 | 1.00×1.03 |
| 广告花费 | 较 4 周均值 +45% | 130%～200% 档 | 1.06 |

**计算**

\[
1000 \times 1.08 \times 1.06 \times 1.00 \times 1.05 \times 1.00 \times 1.03 \times 1.06 \approx 1310.6
\]

**取整后预测周销量：1311 件**（再与上下限校验）。

## 五、规则引擎落地形态（供研发/产品对齐）

### 5.1 配置结构（示例）

- **规则集**：按「渠道 + 品类 + 生命周期阶段」绑定不同规则表。
- **优先级**：大促日历 &gt; 清仓 &gt; 价格突变 &gt; 默认因子表。
- **版本**：规则集 v2026Q1，支持灰度 SKU。

### 5.2 伪代码流程

```
baseline = smooth_mean(sales, last_4_weeks)
for factor in [流量, 价格, 生命周期, 转化率, 广告, 排名, 花费]:
    m = lookup_rule_table(sku, channel, factor, current_metrics)
    baseline *= m
prediction = clamp(round(baseline), min_cap, max_cap)
return prediction, factor_breakdown  // 可解释输出
```

## 六、标定与迭代建议

1. **初版乘数**：由运营/计划根据经验填表，先跑 **回测**（用历史周数据「假装不知道当周销量」看偏差）。
2. **季度复盘**：按品类统计哪一因子规则误差大，调档位或改为「相对品类分位」而非绝对阈值。
3. **与 ML 的关系**：规则预测可作为 **baseline**；后续可用 ML 学「残差」，规则仍保留为约束与解释层。
