## 全渠道需求预测

> **关联框架**：与 **库存与分货**、**定价与促销管理**、**营销管理** 强相关；向 **数据与管报** 输出偏差与准确率；与 **业务经营目标** 衔接目标达成风险。  
> **版本**：V3.0 · 2026-04-21  

---

### 1. 业务目标与范围

| 维度 | 说明 |
|------|------|
| **要解决** | 在促销、新品、季节、渠道差异下，输出 **SKU×地点×时间桶** 的需求分布；驱动补货、分货、安全库存、采购与产能预案。 |
| **边界** | 预测输出应为 **可解释** 的区间或情景，须绑定促销日历、事件变量。 |
| **与相邻模块** | 强依赖库存与分货、定价与促销、营销管理；向数据与管报提供偏差监控；与业务经营目标衔接。 |

### 2. 关键用户与场景

1. **需求计划**：基线预测、促销 uplift、人工覆盖与审计。  
2. **供应链**：安全库存、分货、补货与产能预案。  
3. **电商运营**：大促事件字典、复盘。  
4. **经管**：预测 vs 目标 vs 实绩三方对账。

### 3. 能力清单

| 层级 | 能力项 |
|------|--------|
| **必备** | 历史销量清洗、促销与节假日特征、基线预测、人工覆盖与审计。 |
| **期望** | 全渠道需求拆分、概率预测、与分货优化联动。 |
| **可选** | 深度学习、外部数据（天气、舆情）——需评估 ROI。 |

## 业务经营目标管理与目标规划

> **关联框架**：见附录性说明；**口径**：本章指业务经营数值目标（销量、销售额、毛利、核心费用、库存周转等），不含纯 HR 绩效口号层。  
> **版本**：V3.0 · 2026-04-21  

---

### 1. 业务目标与范围

| 维度 | 说明 |
|------|------|
| **要解决** | 经营目标在区域、渠道、品类、SKU、店铺、团队等维度 **可分解、可跟踪、可纠偏**；与预算版本、滚动预测、大促预案对齐。 |
| **边界** | 不替代法定合并；费用目标须与费控/营销等科目预先对齐。 |
| **与相邻模块** | 输出给数据与管报、定价与促销、库存与分货；输入来自管报关账与需求预测偏差。 |

### 2. 关键用户与场景

1. **经管 / 财务 BP**：下达与调整目标；监控费用率与毛利。  
2. **电商 / 渠道运营**：店铺级销量与推广费目标；大促闭环。  
3. **供应链计划**：在目标约束下配置库存与分货。  
4. **管理层**：同一套目标事实进入经营会材料。

### 3. 能力清单

| 层级 | 能力项 |
|------|--------|
| **必备** | 目标版本、分解矩阵、滚动修订、权限与审计、与实际对账。 |
| **期望** | 情景规划、资源约束可行性校验、与 S&OP 节奏绑定。 |
| **可选** | 与 EPM 直连、AI 辅助目标建议。 |

## 业务管理报表（管报口径 · 经营闭环）

> **关联框架**：与「数据与管报/BI」工具链互补：本章侧重 **管报关账、合并与指标口径**。  
> **版本**：V3.0 · 2026-04-21  

---

### 1. 业务目标与范围

| 维度 | 说明 |
|------|------|
| **要解决** | 法定与管理双口径下看清业务；GMV、净收入、毛利、费用、库存资金、应收与现金周期 **月结闭环**；异常可下钻订单/客户/SKU。 |
| **边界** | 管报侧重口径与关账；BI 侧重自助分析——可同平台或分层（指标中台 + BI）。 |
| **与相邻模块** | 强依赖数据与管报与财务/ERP；订单与库存估值须与管报事实一致。 |

### 2. 关键用户与场景

2. **业务财务 BP**：渠道贡献、费用分摊解释。  
3. **IT / 数据**：指标字典、血缘、调度与权限。  
4. **管理层**：移动端订阅与预警。

### 3. 能力清单

| 层级 | 能力项 |
|------|--------|
| **必备** | 指标字典、维度一致性、关账日历、版本对比、权限。 |
| **期望** | 管报与预算/预测偏差、董事会模板、移动端订阅。 |
| **可选** | NL 问数（口径冻结前提下）。 |

## 定价与促销管理

> **关联框架**：与营销管理、会员与 CRM、B2B 经销价目表易重叠，须定义单一定价引擎或主从。  
> **版本**：V3.0 · 2026-04-21  

---

### 1. 业务目标与范围

| 维度 | 说明 |
|------|------|
| **要解决** | 价盘版本、区域/渠道/客户组差异价、促销叠加、限价与防击穿；试算/仿真与审计；与平台大促规则对齐或定义主从。 |
| **边界** | 与营销券、会员权益价、经销价目表划界。 |
| **与相邻模块** | 读商品主数据；驱渠道展示价；可占用库存促销锁。 |

4. **大促指挥**：规则仿真、叠加冲突检测。  
5. **审计**：规则变更影响范围。

### 3. 能力清单

## 产品全生命周期管理

> **关联框架**：PLM 管工程事实与变更；PIM 管渠道可售表达。  
> **版本**：V3.0 · 2026-04-21  

---

### 1. 业务目标与范围

| 维度 | 说明 |
|------|------|
| **要解决** | 从需求、设计、BOM、变更、试产、认证到上市/退市流程同源；工程 BOM 与可售 SKU、成本、供应商协同一致。 |
| **边界** | PLM 不替代 PIM 渠道呈现；须输出受控物料与变更事件给 PIM/ERP。 |
| **与相邻模块** | 与商品主数据、定价（成本与生命周期定价）、订单（新品切换）交叉。 |

### 2. 关键用户与场景

1. **研发 / 项目**：里程碑、文档、评审与发布。  
2. **工程 / 工艺**：BOM、ECN、试产回流。
