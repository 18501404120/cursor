## 自行补充截图（推荐命名）

将 PNG 放入 `screenshots/`，命名建议：

- `m02-manhattan.png`、`m05-salesforce-mc.png`、`m09-zendesk.png` 等  
- 在 **`竞品调研-全渠道模块竞品分析-图文版.html`** 中搜索 `shot-placeholder`，按注释替换为 `<img src="./assets/screenshots/你的文件.png" alt="…" />`。
