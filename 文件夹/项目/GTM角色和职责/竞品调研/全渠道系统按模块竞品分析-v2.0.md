## 订单与履约管理 · 竞品分析

### 1. 业务目标与范围（摘要）

多触点订单归一、审单与拆合单、库存占用、仓配路由、发货回传与异常编排；**不替代** WMS 库内作业与平台侧交易终裁。

### 2. 关键用户与场景（摘要）

运营/客服审单改址、仓储调度路由、集成幂等与监控、管理层履约 SLA（常接 BI）。

### 3. 能力清单（摘要）

**必备**：接入、统一模型、状态机、拆合单、取消拦截、发货回传。  
**期望**：DOM/寻源路由、预售分批发、灰度与规则引擎。

### 4. 竞品解决方案详解（2 + 1）

#### 4.1 Fluent Commerce（Order Management / DOM）

| 类型 | 链接与说明 |
|------|------------|
| **产品说明 / 功能文档** | [Fluent Commerce Docs 总门户](https://docs.fluentcommerce.com/)（含寻源、工作流、扩展等主题） |
| **开发者 / API** | 文档内 [API references](https://docs.fluentcommerce.com/) 分区；[GitHub 组织入口](https://github.com/fluentcommerce) |
| **界面与流程** | 公开文档中的 UI 类指南示例：[Manage Locations via UI](https://docs.fluentcommerce.com/by-type/manage-locations-via-ui)；其余后台配置页 **需 Sandbox / POC 截屏** |

**要点**：云原生 API/微服务、DOM 叙事强；实施与集成治理要求高。

---

#### 4.2 IBM Sterling Order Management

| 类型 | 链接与说明 |
|------|------------|
| **产品说明** | [IBM Sterling OMS 产品页](https://www.ibm.com/products/sterling-order-management)（能力概览） |
| **官方文档** | [IBM Documentation · Sterling（检索 Order Management）](https://www.ibm.com/docs/en/search?query=sterling%20order%20management) |
| **界面与流程** | 以 IBM 文档中的 **配置与业务流程** 章节为主；典型管理控制台 **需企业版 Demo** |

**要点**：大型复杂网络、B2B/B2C 混合；TCO 与实施周期高。

---

#### 4.3 聚水潭（国内 · 订单 / 仓配一体化）

| 类型 | 链接与说明 |
|------|------------|
| **产品说明 / 操作手册** | [聚水潭学院](https://www.erp321.com/app/support/document.html)（操作手册、视频教程、快速入门） |
| **开放平台 / API** | [聚水潭开放平台](https://openweb.jushuitan.com/) |
| **界面与流程** | 百科内 **Web 端操作手册** 按菜单拆解（订单审核、合并拆分、发货等），含步骤说明；部分深度页面需登录 |

**要点**：国内多平台电商闭环快；复杂 DOM、全球多法人非主战场时需个案验证。

---

### 5. 对比维度要点

| 维度 | Fluent | IBM Sterling | 聚水潭 |
|------|--------|----------------|--------|
| 资料可研性 | 文档门户完整 | 企业文档深但分散 | 手册/视频贴近实操界面 |
| DOM / 路由 | 强 | 强 | 中等、偏发货实操 |
| 典型客群 | 中大型全球化 | 大型供应链 | 国内电商卖家到中大型 |

### 6. 差距与机会（对我方）

在「**平台深度 + 可编排 DOM**」之间取平衡；避免仅有抓单而无统一状态机与预留语义。

### 7. 风险与依赖（摘要）

主数据一致、Webhook 幂等、审单权限与内控。
