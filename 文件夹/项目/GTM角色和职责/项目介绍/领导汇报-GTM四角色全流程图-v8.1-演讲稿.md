# GTM 四角色全流程图（v8.1）· 领导汇报演讲稿

> 口播时长约 9～12 分钟；若限时，可压缩横轴六步为两三句，保留四段「核心价值」主干。

---

各位领导好。下面我用一张流程图，说明全渠道 GTM 在年度经营中的主链路，以及四个角色在各阶段承担的任务与交付关系。

这张图不是四个岗位的简单罗列。横向是时间维度，自年度起点至复盘滚动，划分为六个阶段；纵向是四条职责主线：商业洞察、产品 GTM、区域 GTM、需求计划。每个单元格对应的是：在该阶段由谁主责、须形成哪些可交接产出、与上下游如何互锁。内容已与会议纪要及 GTM 资料中的流程表述、IPMS 与 GM 相关要点对照整理，便于内部统一口径。

先说横轴六步，便于把握全貌。

第一步，市场扫描与机会挖掘，形成外部环境与内部经营的结构化输入。第二步，年度 BP 启动与规划准备，并与关键日历锚定，例如次年新品规划在三、七月的释放节奏，以及年终复盘与次年 BP 定稿等节点，使规划工作可检查、可追责。第三步，产品规划与上市项目立项，将机会转化为 Roadmap、项目计划与 GR 评审路径。第四步，渠道、价格与区域策略展开，明确区域打法、渠道结构、价格与规则边界。第五步，预测、要货与供应执行，依托月度计划委员会与 PSI，将销量假设、要货、库存、发运与生产纳入同一套共识机制。第六步，经营跟踪、复盘与滚动迭代，对销售、营销与经营结果进行复盘，形成对下一轮规划与资源配置的正式输入。

下面重点说明四个角色的核心价值。四者之间是前后承接关系，而非彼此独立的职能块。

商业洞察的核心价值，在于降低经营决策中的信息不对称，将市场、竞争与用户侧信息转化为可复核、可传承的判断依据。在规划前期，其产出为 BP 与新品规划提供统一分析框架与证据链；在产品与区域策略形成阶段，为优先级与资源配置提供外部视角；在预测与经营环节，为假设与波动提供可解释的市场原因；在半年度与年度复盘时，对前期判断与结果偏差进行归因，支撑下一轮情报与模型迭代。

产品 GTM 的核心价值，在于承接市场判断与经营目标，在单品与产品线层面完成「机会—立项—上市—生命周期」的闭环管理，并与研发及交付体系互锁。具体包括：需求评估与排序、与 BP 对齐的产品线议题、关键 GR 节点推进、Roadmap 与 One Page 的滚动维护；将上市准备（样机、KV、物料、首单意向等）结构化，并与需求计划在口径上对齐；向区域输出首销期定价输入及复盘后的完整 4P 策略；在退市与新老品切换上牵头制定规则并协同供应链执行，避免生命周期末端职责真空。

区域 GTM 的核心价值，在于将总部战略与产品节奏转化为限定市场内的可执行经营方案，并对渠道结构、价格纪律与区域经营结果承担主线责任。其工作涵盖：BP 目标在区域与国家维度的拆解，分渠道目标的锁定与 baseline 管理口径；基于 Roadmap 的区域导入方案、重点 SKU 与战役规划；全渠道价格与渠道策略的主责落地，以及大促与资源编排与 baseline 的一致性；执行期对 PSI、动销、库存与价格执行的跟踪；在无新品承接情形下的区域退市流程主导与供应链协同；以半年度与年度为周期，从销量、利润、费用与周转等维度开展区域经营复盘。

需求计划的核心价值，在于将前述经营意图与策略约束转化为组织可承诺、可执行的供需计划，并通过 PSI 机制形成跨部门的共识与纠偏闭环。其工作包括：在明确假设前提下开展预测并与 BP 对齐，对目标 gap 进行可说明的拆解；以计划委员会与 PSI 一级、二级机制落实供需平衡、需求评审与准确率管理；依据产品上市节奏安排首批、补货与退市减速；将区域目标与打法落实为可评审的预测、要货与全渠道分货；在执行中监控产销协同、物料与库存风险，并就 H1 与全年交付及库存健康度组织复盘，将结论反馈至下一轮滚动计划。

图下方另有角色交接示意、系统与数据支撑说明，以及 GR、PCT 与 PD 接口和培训材料对照表，用于内部执行对齐；若时间有限，可会后查阅。当前版本为 v8.1，对区域执行阶段中退市与 EOM 的表述作了合并，并对与需求计划在职责边界上的交叉作了收敛，以 OC 定稿及最新批注为准。

最后作三点归纳。第一，六阶段构成公司全渠道 GTM 的年度主流程。第二，四角色为职责接力关系，由 BP、GR、PCT、PSI 与 baseline 等机制嵌入节奏与问责。第三，本图可作为组织对齐与后续系统建设、数据口径设计的参照底稿；职责或数据在某一格长期无法闭环，通常对应会议争议或线下补救成本较高的环节。
