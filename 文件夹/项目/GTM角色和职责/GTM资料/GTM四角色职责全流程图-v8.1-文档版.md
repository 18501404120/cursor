# GTM四角色职责全流程图 v8.1（文档版）

## 1. 文档目的
将《GTM四角色职责全流程图-v8.1.html》转写为可阅读、可评审、可复用的文档版本，用于职责对齐、系统规划与制度沉淀。

## 2. 角色与阶段总览
### 2.1 四角色
- 商业洞察：最早启动，负责把市场、竞争与区域经营信息转化为经营判断和机会输入。
- 产品 GTM：把市场机会转成产品路线、项目动作、上市节奏和生命周期管理。
- 区域 GTM：把总部规划转成区域打法，主责渠道、价格、销售目标拆解与经营策略调整。
- 需求计划：通过 PSI 把预测、要货、库存、发运、生产和供应变成共识计划。

### 2.2 六阶段
1. 市场扫描、预测与机会挖掘：形成外部与内部输入，判断市场、用户、竞争与机会窗口。
2. 年度 BP 启动与规划准备：以 3 月/7 月次年新品规划释放为锚点，衔接春季务虚会、秋季复盘会与 12 月年终复盘、1 月次年 BP 释放。
3. 产品规划与上市项目立项：把机会转成产品 Roadmap、项目节点、GR 评审动作、状态流转和上市准备。
4. 渠道、价格与区域策略展开：确定区域打法、渠道结构、客户策略、价格带与调价规则。
5. 预测、要货、供应与执行落地：通过月度计划委会与 PSI 会议，让预测、要货、库存、发运和生产形成共识计划。
6. 经营跟踪、复盘与滚动迭代：围绕销售、营销、经营结果复盘，形成调价、调货、调策略和下一轮输入。

## 3. 各角色职责明细
### 3.1 商业洞察
#### 3.1.1 扫描 / 预测 / 挖掘
- 扫描市场份额、竞争格局、渠道变化、平台规则和用户偏好。
- 基于连续两到三年的数据，预测下一年度市场体量和结构变化。
- 输出 SWOT、机会清单、风险清单和优先级建议。
- 围绕新品上市窗口输出市场容量、竞品动态、用户需求洞察（含次春新品、次年 Q2 新品）。
- 沉淀 VOC、评论、listing、外部情报，形成长期可复用资产。

#### 3.1.2 规划前置输入
- 参与年度 BP 准备，明确规划所需的市场信息维度和分析框架。
- 承接 3 月、7 月次年新品规划释放节奏，组织半年度/年度产品规划市场输入。
- 围绕“五看四定”梳理行业、PEST、用户、竞争和自身的观察口径。
- 定义后续预测和机会判断所需的数据源、时间跨度和市场颗粒度。

#### 3.1.3 为产品规划供输入
- 把洞察结果转化为“明年上什么、为什么上、优先做什么”的输入。
- 识别产品机会区、价格带空档和竞争压力最大的品类。
- 为产品 GTM 提供用户痛点、竞争差异和卖点方向。
- 将宏观档位、竞争大盘与微观用户偏好结构化输出，支撑产品线在卖点、配置与档位布局上立项。

#### 3.1.4 为区域策略供判断
- 输出区域市场差异、渠道机会和竞争态势，支撑区域 GTM 定策略。
- 提供价格带判断、渠道趋势和重点客户环境变化。
- 为营销预算投向和重点战役选择提供市场依据。

#### 3.1.5 为预测模型供系数
- 把市场判断转成销售预测的前置参数，而不是只给结论。
- 参与解释销量假设变化背后的市场原因和结构变化。
- 协助识别新品导入、旺季、促销期和竞争变化带来的波动风险。

#### 3.1.6 复盘与滚动更新
- 沉淀区域月度经营数据与月度复盘结论，输出经营分析简报。
- 复盘市场判断与实际结果的偏差，修正下一轮洞察模型。
- 跟踪竞争对手调价、上新、渠道动作，及时反馈给业务侧。
- 在年中/年度 BP 制定中输出区域市场趋势输入，并形成半年度、年度经营结果复盘。
- 为下一轮 BP 提前准备持续更新的市场情报库。

### 3.2 产品 GTM
#### 3.2.1 消化洞察形成规划
- 承接商业洞察输出，把市场机会转成产品规划建议和节奏判断。
- 组织次年新品需求评估与排序，识别增长机会点并制定新老品迭代规划。
- 结合用户痛点、竞争差异和产品空白，明确产品定义方向。
- 验证产品机会是否具备价格、渠道和经营上的可落地性。

#### 3.2.2 承接规划框架
- 基于年度 BP 和经营目标，提前准备产品线维度的规划议题。
- 梳理现有产品组合、生命周期状态和下一年度需要承接的关键品类。
- 识别哪些产品继续推进、哪些需要升级、哪些要准备退市。

#### 3.2.3 项目立项与上市准备
- 建立 GTM 项目计划，明确里程碑、评审点、状态流转和责任人。
- 组织 H2 新品、次春新品、次年 Q2 新品等关键 GR1/GR2 节点评审并推进结论闭环。
- 以新品上市项目经理视角推动全链路信息打通，与 PD 关键节点互锁，将研发/制造/品牌等资源聚焦到核心项目。
- 组织新品首单需求收集：面向各渠道/区域汇总首单规格、数量意向、到货窗口与约束条件，形成可进入预测与要货评审的结构化输入，并与需求计划对齐口径。
- 维护产品信息库（关联 SKU 技术信息库），包含 GTM 负责人、上市时间、新品标签、状态等。
- 制定上市节奏与组织判定，持续更新 Roadmap 与 One Page。
- 推动样机、产品图、KV、营销物料、POS 打样等三级流程按时交付。
- 协调研发变更、版本调整和上市节点，避免前后端节奏脱节。
- 锁定上市策略和渠道营销策略。

#### 3.2.4 为区域和价格准备条件
- 新品首销期：产品 GTM 为区域 GTM 提供定价输入，包含 RRP 价和促销价。
- 新品复盘后：产品 GTM 为区域 GTM 提供 4P 策略输入（产品、价格、渠道、推广）。
- 输出产品 Roadmap、上市节奏、SKU 结构和生命周期状态，为区域导入和资源倾斜提供产品依据。

#### 3.2.5 支持导入与执行
- 与各渠道沟通，收集并锁定与年度 BP 对齐的分渠道目标（销量、结构、节奏与资源假设），作为导入期滚动预测、分货与营销资源的共同约束。
- 同步新品上市节点，让需求计划可据此安排导入预测和补货节奏。
- 在执行中处理产品状态、版本、参数和资料的变更影响。

#### 3.2.6 生命周期收口
- 复盘新品导入效果、上市节奏和产品资料准备质量。
- 产品 GTM 负责新老品切换的老品退市，由产品/PCT 主导规划并协同供应链核料执行。
- 把执行流程中暴露的问题与经验沉淀到流程优化机制中。
- 建立新品切换信息月度刷新机制，跟进老品 EOM、清库方案落地和退市窗口下单节奏。
- 联合区域 GTM，基于全渠道经营分析看板跟踪 BP 目标达成与结构偏差，将结论回灌为产品组合、主推与节奏调整输入。

### 3.3 区域 GTM
#### 3.3.1 吸收市场判断
- 承接商业洞察对区域市场、价格带、竞争格局和渠道机会的分析。
- 判断哪些市场适合扩渠道、哪些市场更适合做价格策略或结构优化。
- 识别高风险区域和重点争夺的渠道场景。
- 准备下一年度区域打法的核心假设和需要验证的问题。

#### 3.3.2 区域经营准备
- 制定全年 BP 目标，拆分重点区域、重点国家和重点客户。
- 明确区域维度需要重点观察的渠道结构、客户结构和价格带差异。
- 与各渠道充分沟通，收集并锁定对年度 BP 有约束力的分渠道目标（销量、结构与资源），与总部 BP、产品节奏对齐后写入区域导入计划与跟踪基线。
- 建立全渠道 baseline 管理口径（含例外审批），用于指导价格策略、促销力度与调价边界。

#### 3.3.3 准备区域导入方案
- 根据产品 GTM 输出的 Roadmap 和上市节奏，形成区域导入计划。
- 输出区域维度的市场深挖、线下核心 SKU 列表、品类 Campaign 规划、新客拓展规划、价格促销规划与区域增长策略。
- 识别不同区域适配的 SKU 结构、上市顺序和资源重点。
- 输出区域执行方案，明确客户沟通路径、铺货节奏、促销机制、主推计划、责任人与里程碑。

#### 3.3.4 渠道与价格主责
- 制定全渠道策略，覆盖线上、线下、运营商、分销商和重点客户路径。
- 主导价格平台业务规则，管理 RRP、FOB、授权价、渠道点位和调价。
- 承接总部/产品侧制定的新品首销期定价与促销策略，落地区域执行；首销复盘后形成后续区域策略建议。
- 围绕 PD/PFD/BFCM 等大促节点制定区域大促规划，并在 baseline 约束下做资源与玩法编排。
- 围绕主推 SKU、价差结构和渠道利润空间做区域落地判断。
- 依托全渠道经营分析看板跟踪 BP 目标达成进度与结构偏差，据结果迭代渠道组合、资源投放与价格策略。
- 跟踪全渠道促销与活动信息，确保重点产品各渠道划线价（MSRP 展示口径）一致，价格执行不击穿 baseline 要求。
- 建立区域月度/季度例会机制，拉通市场前端与产研资源，对季度达成和开支节奏做滚动评估。

#### 3.3.5 执行跟踪与策略调整
- 通过 PSI、SO 和全渠道看板跟踪 Sell Out、库存、动销和价格执行。
- 根据销售达成偏差发起调价、调资源、调节奏和调客户动作。
- 退市管理（EOM）：按月刷新 Roadmap 与老品 EOM 管理状态，跟进 H1/H2 清库方案制定与执行闭环；无新品替代的区域/渠道退市由区域 GTM 主导推进退市流程，供应链核料与执行。

#### 3.3.6 区域经营复盘
- 以半年度/年度为前提，复盘区域达成、渠道健康度、价格纪律和重点客户经营结果。
- 结合经营平台数据判断利润、费用和周转，不只看销量。
- 把市场反馈、客户反馈和价格表现回灌到下一轮区域策略。

### 3.4 需求计划
#### 3.4.1 建立预测前提
- 吸收商业洞察关于市场趋势、旺季变化和增长假设的输入。
- 纳入公司资源投入（如营销费用、价格策略等）作为预测前提。
- 预测对齐 BP 目标，结合 BP 目标 gap 拆解并给出预测值。

#### 3.4.2 计划体系准备
- 围绕年度 BP 确定预测口径、时间维度和计划颗粒度。
- 以月度计划委会与 PSI 会议为主机制：一级计划定供需平衡，二级计划做需求评审与准确率复盘。
- 梳理销售预测、要货、库存、供应和发运所需的数据接口。
- 明确 PSI 在下一年度应承担的核心业务边界。

#### 3.4.3 承接产品节奏
- 接收产品 GTM 的上市节奏、SKU 结构和生命周期状态。
- 据此安排新品导入预测、首批备货、后续补货和退市降速计划。
- 确保产品计划不是停留在规划层，而能进入可执行计划层。

#### 3.4.4 形成需求计划
- 把区域 GTM 的目标拆解、渠道打法和价格策略转成预测和要货计划。
- 围绕渠道提报预测开展需求评审，确保预测与要货合理；基于共识计划实施全渠道分货。
- 结合库存、在途、供应能力和发运能力形成计划版本。
- 接入客户 SO 和渠道 Sell Out，提升需求计划真实性。

#### 3.4.5 PSI 闭环执行
- 通过 PSI 管理销售预测和要货计划两大核心动作。
- 协调需求计划与工艺计划、生产计划、发运计划和库存约束。
- 根据年度 BP 变化及时调计划；并向供应链释放年度产能规划。
- 输出共识计划、供需缺口、异常预警和必要的情景测算。
- 持续监控产销协同、应急与预警、库存与物料风险。
- 持续监控渠道、SKU、时间维度上的实际消耗与预测偏差。
- 建立经营看板，持续跟踪渠道健康度、库存周转、呆滞、预测准确率与要货准确率。

#### 3.4.6 偏差复盘与再计划
- 复盘预测准确率、供需偏差、库存结构和发运执行表现。
- 将偏差原因拆解为市场问题、产品问题、区域问题或供应问题。
- 补充 H1 与全年交付达成及库存健康度复盘，沉淀新老品差异化供需管理策略。
- 把复盘结果带回下一轮滚动预测和计划优化中。

## 4. 角色交接关系
- 商业洞察 → 产品 GTM：输出市场机会、用户痛点、竞争变化和价格带判断。
- 产品 GTM → 区域 GTM：输出 Roadmap、上市节奏、SKU 结构、生命周期状态与卖点资料。
- 区域 GTM → 需求计划：输出区域目标、渠道打法、客户节奏、价格政策与主推SKU策略。
- 需求计划 → 区域 GTM / 产品 GTM：反馈供需差异、库存压力、发运约束与预测偏差。

## 5. 系统与数据支撑
- PSI / 月度计划委会：需求计划与区域 GTM 的共同数据底座。
- 价格管理平台：支撑 RRP、FOB、授权价、渠道点位、特商申请与调价管理。
- 产品信息库与项目管理系统：支撑产品状态、上市节点、里程碑、物料交付与生命周期流转。
- 经营平台 / 管报：提供利润、费用结构、周转与偏差复盘视角。

## 6. GTM机制与PD接口（摘要）
### 6.1 GTM机制
- GTM 是集成产品、营销、销售与服务的一体化流程，目标是把声量与资源转化为经营结果。
- PCT 是围绕产品商业成功的统一作战单元。
- 四快一慢：上市热度快、销量起量快、策略调整快、产品收尾快，上市准备必须慢。

### 6.2 PD与GTM关键接口
- PD → GTM：输出产品信息、样机、规格、BOM、状态节点、上市条件。
- GTM → PD：输出市场目标、销量预期、价格带、渠道需求与供应规划要求。
- 关键评审接口：CD↔GR1、ES↔GR2、BT/CR↔GR3、MP↔GR4。

## 7. 各角色重点交付物
### 7.1 商业洞察
- 年度市场扫描报告
- 趋势预测说明与假设
- 竞争地图、价格带地图
- SWOT 与机会清单
- 用户洞察专题输入

### 7.2 产品 GTM
- 产品 Roadmap 承接清单
- 上市项目计划与里程碑表
- 与 GR/IPD 对齐的评审材料包
- 产品信息库字段与状态规则
- 上市前物料齐套清单
- 生命周期收口方案

### 7.3 区域 GTM
- 区域渠道策略方案
- 价格体系与调价规则
- 区域目标拆解与跟踪表
- 客户与渠道经营分析
- 区域复盘与策略调整建议

### 7.4 需求计划
- 滚动销售预测
- 要货计划与补货节奏
- PSI 周报 / 月报
- 供需差异与风险预警
- 库存与执行偏差复盘

## 8. 生命周期视角（简表）
- 商业洞察：规划前识别机会 → 上市前竞争/用户输入 → 稳定售卖期跟踪 → 退市期替代机会识别。
- 产品 GTM：规划承接与立项 → 研发跟节奏 → 上市前三个月重点操盘 → 稳定售卖与退市收口。
- 区域 GTM：上市前完成区域 4P 策略 → 稳定售卖期价格体系维稳 → 持续要货与分货管理 → 退市阶段区域切换和清货。
- 需求计划：承接上市节奏形成预测 → 首批备货与补货闭环 → 稳定售卖期 PSI 跟踪 → 退市期库存与供需收尾。
