# 区域 GTM 岗位职责

> 依据：《会议-GTM全流程》全渠道流出会议纪要整理。会议中对应表述为「区域 GPM / 陈志渊（陈俊渊）」侧工作，按区域与城市维度承接公司年度 GTM 中的渠道与价格主线。

## 1. 定位与范围

- 在公司 **年度 BP** 时间轴下，与「产品 GTM」「商业洞察」「销售计划」等角色协同，主责 **渠道（Place）** 与 **价格（Price）** 在 **区域/国家/城市** 颗粒度的策略、落地与跟踪。
- 与 **销售指标** 强相关：将渠道策略转化为可执行的销量目标、节奏与区域达成管理；**经营指标** 以需求方身份对接财务/管报，支撑点位与损益判断。

## 2. 核心职责

### 2.1 渠道策略与目标

- 制定并维护 **全渠道（含线上全渠道等）** 的渠道策略：渠道结构、拓展方向、客户增长与渠道组合。
- 将年度/月度 **销量目标** 拆解到区域、渠道与客户维度，并与发货、供应链节奏对齐（与 SOP、要货、PSI 等数据衔接）。
- 基于 **销售达成**（如各渠道 Sell Out、PSI 中的消耗数据）做 **月度/周度策略复盘与调整**。

### 2.2 价格与渠道政策（主责之一）

- 作为 **价格管理 / 价格平台** 的业务 Owner（会议明确归此侧）：统筹 **定价管理、FOB/出货价、渠道毛利与点位、授权价、调价** 等。
- 维护 **全链条损益测算** 所需输入：从 RRP 倒推各层渠道点位，区分不同渠道结构下的毛利空间；与 BOM、成本、FOB 预留点位等模块对齐（与供应链/财务协同）。
- 管理 **促销 / 特批价格**：在统一平台内规范特批申请与记录，避免口径分散在群聊与 Excel。
- 输出 **渠道政策类文档**（如报价规则、主策略、选品与资源倾斜的可见口径），推动各渠道 **Follow 统一策略**；**主推/主卖** 等与 **定价梯度、SKU 间价差** 策略一致。

### 2.3 数据、系统与协同

- **数据需求方**：接入 **PSI**（全渠道预测与执行数据中枢）、**客户 SO**（尤其商超等）、**财务/经营平台与管报**，用于看板、达成跟踪与策略决策。
- 使用 **全渠道看板**：以 PSI 等为数据源关注各渠道、各 SKU 的销量与营收口径；与财务侧对齐利润等指标口径。
- 与 **产品 GTM** 对齐 Roadmap、上市节奏与价格变更；与 **销售计划** 对齐预测、要货与库存周转；与 **商业洞察** 消费市场扫描与竞争结论，反哺渠道与定价策略。

## 3. 产出物（示例）

- 区域/渠道维度的销量目标与跟踪表、策略调整说明。
- 价格平台内的定价、FOB、调价、授权价与特批记录；渠道政策与报价指引。
- 基于 PSI/看板的销售达成分析与月度复盘材料。

## 4. 边界说明（会议共识）

- **DOS（库存周转天数）** 等与库存、流速强相关的指标，会议中倾向于与前端流速及备货策略 **联合** 看待，与 **销售计划/供应链** 数据打通后共担，而非单一角色闭门计算。
- **经营指标** 的权威输出仍在 **财务/管报/经营平台**；区域 GTM 侧重 **销售指标** 达成与 **价格/渠道** 策略，并作为经营数据的 **使用者** 参与策略制定。
