## 表二：功能清单（功能名称 · 功能描述）

> 与表一功能一一对应；**功能名称**与表一「功能」列完全一致，便于检索与导入需求池。

| 功能名称 | 功能描述 |
|----------|----------|
| BP 目标管理 | 在系统内管理 BP 相关目标、打和结果与变更过程留痕，避免仅用「全年目标、大版本」等口语却无法在系统中追溯。与「仅看结果的复盘报表」区分：本功能侧重管目标与版本，复盘侧见第五层。承接会议中对 BP 与执行跟踪关系的讨论。 |
| Baseline 管理 | 对全渠道经营基线（Baseline）进行新建、调整与过程留痕，并与价格执行、促销边界等联动；命名统一为 Baseline 管理，便于与区域 GTM、价格平台模块对齐。 |
| 新品商业判定与节奏决策留痕 | 承接 OC 中 3 月/7 月新品规划释放后、4 月/8 月商业判定与上市节奏规划相关结论的系统化归档，便于产品 GTM、区域 GTM、需求计划、商业洞察按同一事实源协同。 |
| 中长期 SP 与 BP 衔接视图（暂保留） | 若公司后续强化 SP→BP 体系，可在本域增加与中长期规划的对照视图；当前边界未完全统一，暂保留占位，不强制纳入首期范围。 |
| 分渠道目标执行跟踪 | 在 BP 与区域导入方案确定后，对各渠道目标达成过程进行跟踪，支撑月度过程管理与 gap 识别；数据尽量与 PSI、订单与看板同源。 |
| 区域导入方案与执行基线 | 将区域导入计划、执行基线与责任人、里程碑结构化，对应 v8.1 区域 GTM 在阶段 03～04 的输出，便于与预测、分货、价格策略联动。 |
| 月度操盘委员会策略调整留痕 | 记录月度操盘会上的策略调整结论（选品、资源、价格与促销边界等），与 Baseline、价格平台策略形成可追溯闭环。 |
| PD / PFD / BFCM 大促节奏协同 | 对大促节点进行跨角色节奏配置与提醒，支撑区域 GTM 在 v8.1 中的大促规划与执行编排，避免仅依赖表格与群消息。 |
| 半年度 / 年度复盘对比与归因（报表/看板） | 半年度、年度经营复盘所需的对比、下钻与归因在第五层「经营复盘与管报消费」中统一实现；本层不重复建设复盘分析引擎，仅保证 BP 与执行数据可被报表消费。 |
| 洞察结论摘要与系数登记 | 由商业洞察岗位产出的结论摘要、预测外生系数等结构化录入，供需求计划 PSI 与经营看板引用；不替代线下/专用工具完成的深度扫描与建模。 |
| 机会清单 / 优先级 / 附件归档 | 维护机会与风险清单、优先级及附件，支撑产品 GTM 立项与排序输入，对应 v8.1 阶段 01～03 中洞察向产品的 handoff。 |
| 竞品与 VOC 要点录入（暂保留） | 是否统一录入竞品与 VOC 细项、与外部数据源如何分工仍待拍板；暂保留为可选轻量能力，避免与独立 VOC 平台重复建设。 |
| 为 PSI 预测提供外生参数 | 将洞察侧系数与假设以接口或固定字段形式提供给 PSI 预测模型，落实 v8.1 中「商业洞察 → 需求计划」的输入关系及会议中对预测前提的讨论。 |
