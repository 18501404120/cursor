v6.0 相对 v5.1 的架构调整说明

  • 流程对齐：显式对齐 v8.1 六阶段（扫描与机会 → BP 准备 → 产品规划与立项 → 渠道价格区域策略 → 预测要货与落地 → 经营复盘迭代），各层 subtitle 标注阶段映射，便于需求排期与验收对照。
  • OC 与 FP&A：按《OC工作内容》保留四组主责；将会议中「财务管报 / 经营视角」上升为独立模块倾向，并以 FP&A「待建立」占位，避免与纯 BI 报表混为一谈。
  • 会议-GTM全流程：强化「价格管理平台」与「经营管报 / 看板」联动；PSI 作为公司级中转；产品信息库与上市项目、GR 与 PD 里程碑互锁列为重点建设项（与 v8.1「系统与数据支撑」一致）。
  • 调研会议：预测需显式纳入 BP 目标 gap、资源投入假设；新老品迭代退市由产品 GTM / PCT 主导、区域主导无替代退市等边界在供应层与 PIM 状态中体现；全渠道数据接入（含 SO）归入集成层。
  • 延续 v5.1 收敛：仍不把客服售后、财务对账结算作为主模块展开；PCT 例会机制本身不作为系统模块，通过「项目与 GR」与通知类能力承载。

分期建设建议（结合会议优先级表述）

  • P0：PSI（预测 + 要货 + 一级二级计划委会）+ 全渠道关键数据接入 + 库存 / 订单主链路可读。
  • P0+：价格与促销经营平台（RRP/FOB/授权价/调价/特商/baseline）与经营看板 / 管报口径对齐。
  • P1：产品信息库深化 + GTM 项目与 GR 节点 + 区域执行与 baseline 过程管理数字化。
  • P2：FP&A 经营分析能力建制、营销项目深度编排、iPaaS 场景化自动化。
