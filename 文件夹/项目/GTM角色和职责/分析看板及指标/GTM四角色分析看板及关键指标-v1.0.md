# GTM 四角色：重点分析看板与关键指标（v1.0）

> **版本**：v1.0  
> **编制依据**（仓库内同源材料）：  
> - `职责流程图1/GTM四角色职责全流程图-v8.1.html`  
> - `OC工作内容.docx`（正文组织口径：商业洞察、产品 GTM、区域 GTM、需求计划；FP&A 经营分析待建立）  
> - `调研会议`（需求计划：PSI、预测、渠道健康度、库存周转、呆滞、预测准确率、要货准确率等看板方向）  
> - `会议-GTM全流程`（BP 闭环、销售/营销/经营三类结果、经营看板与 PSI、价格平台、产品信息库等系统边界）  

**说明**：下列「看板」按**业务可读名称**归纳，实施时可对应到具体 BI 主题域或产品（如经营平台/管报、PSI、价格中台、全渠道经营分析等）。同一物理看板可能被多角色共阅，表中用 **主责 / 共阅** 标注关注重心。

---

## 一、四角色共享的数据与系统底座（非单独「角色看板」，但为各看板供数）

| 底座 | 作用（摘自流程图与会议材料） | 各角色典型用法 |
|------|-------------------------------|----------------|
| **PSI / 月度计划委会** | 承载销售预测、要货、库存、发运、渠道 Sell Out、客户 SO；一级定供需平衡、二级做需求评审与准确率复盘 | 需求计划主责；区域 GTM 强共阅；产品 GTM 共阅上市与切换节奏 |
| **价格管理平台** | RRP、FOB、授权价、渠道点位、特商、调价 | 区域 GTM 主责监控执行；产品 GTM 首销期规则输入 |
| **产品信息库（含 SKU 技术信息关联）** | 上市节点、状态、GTM 负责人、新品标签等 | 产品 GTM 主责；区域/需求计划共阅 |
| **经营平台 / 管报** | 营收质量、费用、利润、周转；BP 与预算过程跟踪 | 区域与产品共阅经营结果；商业洞察用于复盘对照；需求计划共阅费用与资源假设对预测的影响 |

## 二、商业洞察：重点看板与关键指标

### 2.1 市场扫描与机会看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 市场规模与增速（TAM/SAM 或内部口径） | 支撑「明年上什么、上多少」的体量判断 |
| 品类/价位段结构占比 | 识别机会区与空档 |
| 竞品份额与价格带分布 | 竞争压力与定价空间 |
| 渠道与平台规则变化指数（定性+关键事件） | 规则突变对预测与策略的前置输入 |
| 新品窗口市场容量（次春/次年 Q2 等口径） | 与产品 GTM 规划节奏对齐 |
| SWOT / 机会清单闭环率 | 洞察是否进入立项或否决记录 |

### 2.2 预测假设与「系数」输入看板（主责 · 对接需求计划）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 市场趋势假设版本号 | 与滚动预测版本对齐，可追溯 |
| 季节系数 / 大促系数（若已模型化） | 调研会议中讨论的大促月、量价关系的外显监控 |
| 资源投入假设（营销、价格策略）对销量的弹性区间 | 会议材料：市场因素 vs 资源投入权重讨论 |
| 预测偏差解释标签分布 | 市场/竞争/规则类原因占比，用于修正模型 |
| 区域/渠道偏差系数（相对大盘） | 颗粒度与需求计划 SKU×区域×渠道 对齐 |

### 2.3 区域与品线经营洞察简报看板（主责 · 支撑 BP / 复盘）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 区域月度经营结论条数 / 覆盖率 | 流程图：沉淀区域月度经营数据与简报 |
| 半年度 / 年度「市场侧」复盘输入准时率 | 对齐 BP、12 月复盘、1 月 BP 节奏 |
| 价格带异动 SKU 数 | 支撑区域与产品策略 |
| VOC / 评论 / Listing 热点主题 Top N | 卖点与质量反馈回流 |
| 情报库资产更新频次 | 可复用资产是否持续刷新 |

### 2.4 经营与财务摘要看板（共阅）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 营收 / 毛利 / 费用率（分区域、分渠道） | 与「不只看销量」一致，校验洞察与经营结果 |
| 周转天数、现金周期（若管报可得） | 与库存健康叙事一致，用于复盘材料 |

## 三、产品 GTM：重点看板与关键指标

### 3.1 全渠道经营分析看板（共阅 · 与区域联合）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| BP 销量 / 销售额达成率 vs 时间进度 | 流程图：跟踪 BP 目标达成 |
| 产品结构达成（系列、价位、新品占比） | 「结构偏差」回灌组合与主推 |
| 新品 vs 老品贡献占比 | 生命周期与切换决策 |
| 主推 SKU 达成与掉队清单 | 资源倾斜与节奏调整 |
| gap 根因标签（产品/供应/区域/市场） | 与需求计划、区域例会闭环 |

### 3.2 产品与项目健康看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| GR1～GR5 节点准时率 / 阻塞项数 | IPMS/GR 与 PD 互锁 |
| Roadmap / One Page 更新及时率 | v8.1 明确持续更新 |
| 产品信息库字段完整率（负责人、上市时间、标签、状态等） | 与 SKU 技术信息关联质量 |
| 里程碑物料齐套率（样机、KV、POS 等） | 上市准备度 |
| 在研/在上市项目风险等级分布 | PCT 例会跟踪 |

### 3.3 新品导入与生命周期切换看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 首单需求收集完成率（渠道/区域覆盖） | 与需求计划口径对齐 |
| 首批到货满足率 vs 上市窗口 | 导入期执行 |
| 新老品切换月度刷新执行率 | EOM、清库方案落地 |
| 老品 EOM 执行状态（按计划/滞后） | 产品主导迭代型退市 |
| 上市后 90 天销量达成 vs 预测 | 首销复盘输入 |

### 3.4 首销期定价与促销规则看板（主责输入 · 区域执行监控共阅）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| RRP / 促销价发布版本与生效范围 | 调研会议：首销期由产品侧制定 |
| 首销复盘结论闭环率 | 区域填报渠道/价格后回传 |

## 四、区域 GTM：重点看板与关键指标

### 4.1 全渠道经营分析看板（主责 · BP 与策略）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 区域 / 国家 / 渠道 BP 达成率 | 制定全年 BP 与分渠道锁定 |
| 重点客户销售与利润贡献 | 客户经营结果 |
| 资源投放 vs 产出（若可拆分） | 策略调整依据 |
| 与总部 gap 关闭进度 | 调研：打和、卷积、满足增长要求 |

### 4.2 PSI · SO · 执行跟踪看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| Sell Out（分渠道、分 SKU） | 流程图执行跟踪 |
| SO 达成与节奏 | 与预测、要货对齐 |
| 渠道库存与在途 | 调节奏、调货 |
| 动销率 / 售罄率 | 渠道健康 |
| 分货执行满足率 | 与需求计划共识结果对照 |

### 4.3 价格与 baseline 合规看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 各渠道划线价（MSRP 展示）一致性 | 不击穿 baseline |
| 实际 ASP / RRP 折扣深度分布 | 调研会议：促销力度、量价 |
| 特商 / 特殊促销审批占比与例外清单 | baseline 管理口径 |
| 价格违规（低于授权/低于 baseline）件数 | 价格纪律 |

### 4.4 渠道与区域作战看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 区域月度 / 季度例会决议完成率 | v8.1：例会机制 |
| 大促（PD/PFD/BFCM 等）目标 vs 实际 | 大促规划与 baseline 下资源编排 |
| 线下核心 SKU 列表执行覆盖 | 准备区域导入方案 |
| 新客 / Campaign 目标达成 | 区域增长策略 |
| 无新品替代型退市流程节点完成率 | EOM 区域主导路径 |

### 4.5 区域经营复盘看板（主责 · 半年度 / 年度）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 渠道健康度综合指数（自定权重亦可） | 复盘主视角之一 |
| 利润、费用、周转 vs 预算 | 经营平台数据，不只看销量 |
| 价格纪律得分 | 与合规看板汇总一致 |

## 五、需求计划：重点看板与关键指标

### 5.1 PSI 与计委共识看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| PSI 周 / 月报发布准时率 | 流程图交付物 |
| 共识计划版本号与变更次数 | 可追溯供需决策 |
| 一级计委决议执行率（供需平衡动作） | 一级定平衡 |
| 二级计委议题关闭率（需求评审、准确率复盘） | 二级复盘 |
| 供需缺口金额 / 数量及关闭周期 | 反馈区域/产品调价调节奏 |

### 5.2 预测与要货质量看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| **预测准确率**（滚动维度：SKU×渠道×周月） | 调研会议与 v6.2 脚注一致 |
| **要货准确率** | 同上 |
| 预测 vs BP gap 拆解（产品/区域/市场） | 建立预测前提 |
| 渠道提报预测评审一次通过率 / 打回率 | 需求评审质量 |
| 8+4 / 13+3 等滚动窗达成率（以公司口径为准） | 会议与流程图材料 |

### 5.3 库存、分货与呆滞看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| **库存周转天数**（整体 / 分仓 / 分渠道） | 调研会议明确 |
| **呆滞库存金额与 SKU 数** | 同上 |
| 全渠道分货执行偏差 | 流程图：分货控货 |
| 在途库存天数、超期在途批次 | 发运与供应约束 |
| 安全库存触线次数 | 补货节奏健康 |

### 5.4 产销协同与交付健康看板（主责）

| 关键指标 | 指标说明 / 用途 |
|----------|-----------------|
| 产销协同异常关闭周期 | v8.1：监控产销协同、应急与预警 |
| 生产 / 发运计划达成率 | 与工艺、生产、发运计划协调 |
| **H1 / 全年交付达成** | v8.1：交付与库存健康复盘 |
| **库存健康度评分**（自定规则亦可） | 新老品差异化供需策略沉淀 |
| 年度产能规划释放与执行偏差 | 向供应链释放产能规划 |
| 物料风险预警处理率 | 物料风险监控 |

## 六、跨角色对齐与后续建设（v1.0 边界说明）

1. **FP&A 经营分析（待建立）**：OC 正文口径；深度利润拆解、统一管报科目、预算滚动偏差可归入未来 FP&A 主题域，本 v1.0 在「经营平台/管报」与各角色经营类看板中**预留指标位**，不重复建一套角色看板。  
2. **会议-GTM全流程** 强调经营看板需能拆到周、系列、渠道等细粒度——上表指标应支持同一指标字典下的多维下钻（实现阶段再定技术方案）。  
3. 看板名称与报表编号可在落地时与企业现有数据项目（PSI、ERP、经营中台）映射；**指标定义以财务与供应链主数据口径为准**。
