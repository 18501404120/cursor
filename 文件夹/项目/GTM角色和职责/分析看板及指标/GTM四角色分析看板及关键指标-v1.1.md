## 二、共享底座（非「角色专属看板」，但承载跨看板指标）

以下对象在 v8.1 中列为「系统与数据支撑」，各角色看板指标往往由此取数或回写。

### 2.1 PSI / 月度计划委会


| 项目              | 内容                                                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **看板名称**        | PSI / 月度计划委会数据与决议视图（可拆为多张屏）                                                                                                      |
| **名称解读**        | 「PSI」强调**预测（P）、发运/供应（S）、库存（I）** 的一体化共识；「月度计划委会」在流程图中对应**一级（供需平衡）与二级（需求评审、预测准确率复盘）** 的节奏。名称含义：**把渠道需求与供应能力拉到同一张时间轴上决策**，避免产销各说各话。 |
| **主责 / 共阅**     | 需求计划 **主责**；区域 GTM **强共阅**；产品 GTM **共阅**（上市、切换、首单窗口）。                                                                            |
| **关键指标 / 数据对象** | 滚动预测版本、要货计划版本、共识计划号、一级/二级会议纪要闭环率、供需缺口金额与关闭周期、渠道 Sell Out 接入覆盖率、客户 SO 接入覆盖率。                                                      |


### 2.2 价格管理平台


| 项目              | 内容                                                                                                                  |
| --------------- | ------------------------------------------------------------------------------------------------------------------- |
| **看板名称**        | 全渠道价格与授权视图                                                                                                          |
| **名称解读**        | 「价格管理」指 **RRP/FOB/授权价/渠道点位/特商/调价** 的规则与版本在同一平台治理；名称含义：**把「标价—成交价—促销」与 baseline 规则对齐**，支撑「不击穿 baseline」「划线价一致」等执行纪律。 |
| **主责 / 共阅**     | 区域 GTM **主责**执行监控；产品 GTM **主责**首销期规则输入；需求计划 **共阅**（促销与资源假设进预测）。                                                     |
| **关键指标 / 数据对象** | 生效价目表版本、特商审批占比、价格违规笔数、各渠道 MSRP 展示一致性抽检结果、ASP/RRP 折扣深度分布。                                                            |


### 2.3 产品信息库（含 SKU 技术信息关联）


| 项目              | 内容                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------- |
| **看板名称**        | 产品主数据与上市状态视图                                                                                                |
| **名称解读**        | 「信息库」强调 **GTM 负责人、上市时间、新品标签、状态** 等与 **SKU 技术信息** 关联；名称含义：**让「卖什么、何时卖、处于生命周期哪一段」成为单一事实来源**，供区域拆目标、需求计划排产与分货。 |
| **主责 / 共阅**     | 产品 GTM **主责**维护；区域与需求计划 **共阅**。                                                                             |
| **关键指标 / 数据对象** | 字段完整率、状态变更及时率、与 GR 里程碑一致性、新老品切换标签准确率。                                                                       |


### 2.4 经营平台 / 管报


| 项目              | 内容                                                                                                      |
| --------------- | ------------------------------------------------------------------------------------------------------- |
| **看板名称**        | 经营结果与预算偏差视图                                                                                             |
| **名称解读**        | 「经营平台/管报」把 **营收质量、费用、利润、周转** 从财务科目转成业务可读切片；名称含义：**把 BP 里「不只看销量」的经营结果做成可周/月跟踪的过程看板**（会议-GTM全流程 亦强调多维下钻）。 |
| **主责 / 共阅**     | 区域与产品 **共阅**经营达成；商业洞察 **共阅**作复盘校验；需求计划 **共阅**资源与费用假设对预测的影响。                                             |
| **关键指标 / 数据对象** | 收入/毛利/费用率 vs 预算、分渠道经营利润、库存资金占用、周转天数、预算执行偏差标签。                                                           |

## 三、商业洞察：看板清单（名称 · 解读 · 关键指标）

### 3.1 市场扫描与机会看板


| 项目          | 内容                                                                                                    |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| **看板名称**    | 市场扫描与机会看板                                                                                             |
| **名称解读**    | 「扫描」指对外部市场、竞品、渠道规则的持续采集；「机会」指可进入产品/区域决策清单的结论。含义：**回答「外部世界发生了什么、与我们何干」**，为规划与预测提供**方向与体量**，而非替代系统交易数据。 |
| **主责 / 共阅** | 商业洞察 **主责**；产品 GTM **共阅**立项输入；需求计划 **共阅**宏观假设。                                                        |
| **关键指标**    | 市场规模与增速；品类/价位段结构占比；竞品份额与价格带分布；渠道与平台规则变化（事件+影响评级）；新品窗口市场容量；SWOT/机会清单闭环率。                               |


### 3.2 预测假设与系数输入看板


| 项目          | 内容                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------- |
| **看板名称**    | 预测假设与系数输入看板                                                                                                     |
| **名称解读**    | 「假设」指对明年趋势、大促、资源投入的可文档化前提；「系数」指进入滚动预测模型的乘子或调整项（与调研会议中量价、季节、区域偏差等讨论一致）。含义：**把「为什么这样预测」说清楚并可版本化**，便于二级计委复盘准确率时归因。 |
| **主责 / 共阅** | 商业洞察 **主责**输出；需求计划 **主责**消费与回写偏差；产品/区域 **共阅**重大战役假设。                                                            |
| **关键指标**    | 假设版本号与生效区间；季节/大促系数（若模型化）；资源投入弹性区间；预测偏差解释标签分布；区域/渠道相对大盘偏差系数。                                                     |


### 3.3 区域与品线经营洞察简报看板


| 项目          | 内容                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------- |
| **看板名称**    | 区域与品线经营洞察简报看板                                                                                |
| **名称解读**    | 「简报」强调**高频、可行动**的洞察沉淀（流程图：区域月度经营数据与结论）；名称含义：**把分散在区域经营前线的信号结构化**，输入半年度/年度 BP 与复盘，而非替代管报财务精度。 |
| **主责 / 共阅** | 商业洞察 **主责**；区域 GTM **共阅**事实校正；产品 GTM **共阅**品线机会。                                             |
| **关键指标**    | 区域月度结论覆盖率；半年度/年度市场侧复盘输入准时率；价格带异动 SKU 数；VOC/Listing 热点 Top N；情报库更新频次。                         |


### 3.4 经营与财务摘要看板（共阅）


| 项目          | 内容                                                                                    |
| ----------- | ------------------------------------------------------------------------------------- |
| **看板名称**    | 经营与财务摘要看板                                                                             |
| **名称解读**    | 「摘要」指从管报抽取与洞察主题相关的**最小必要经营切片**（营收、毛利、费用、周转）。含义：**校验「市场判断」与「经营结果」是否自洽**，避免洞察与真实利润结构脱节。 |
| **主责 / 共阅** | 商业洞察 **共阅**；财务/经营分析职能若未建全，可先由现有管报 **供数**。                                             |
| **关键指标**    | 分区域/渠道营收与毛利；费用率；周转天数、现金周期（若可得）。                                                       |

## 四、产品 GTM：看板清单（名称 · 解读 · 关键指标）

### 4.1 全渠道经营分析看板（与区域联合）


| 项目          | 内容                                                                                                          |
| ----------- | ----------------------------------------------------------------------------------------------------------- |
| **看板名称**    | 全渠道经营分析看板                                                                                                   |
| **名称解读**    | 「全渠道」强调**不按单一平台割裂**看达成；「经营分析」强调在销量之外看**结构与利润贡献**（流程图：与区域联合跟踪 BP 与结构偏差）。含义：**从产品线视角解释「卖得好/不好」是组合问题还是单品问题」**。 |
| **主责 / 共阅** | 产品 GTM **主责**组合与节奏；区域 GTM **共阅**本地执行差异。                                                                     |
| **关键指标**    | BP 销量/销售额达成率 vs 时间进度；结构达成（系列、价位、新品占比）；新品 vs 老品贡献；主推 SKU 达成与掉队清单；gap 根因标签（产品/供应/区域/市场）。                      |


### 4.2 产品与项目健康看板


| 项目          | 内容                                                                               |
| ----------- | -------------------------------------------------------------------------------- |
| **看板名称**    | 产品与项目健康看板                                                                        |

| **主责 / 共阅** | 产品 GTM **主责**；PD/项目办 **共阅**（按组织实际）。                                              |
| **关键指标**    | GR1～GR5 准时率与阻塞项；Roadmap/One Page 更新及时率；信息库字段完整率；里程碑物料齐套率；在研/在上市项目风险分布。           |


### 4.3 新品导入与生命周期切换看板


| 项目          | 内容                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------- |
| **看板名称**    | 新品导入与生命周期切换看板                                                                            |
| **名称解读**    | 「导入」覆盖首单需求到首批到货；「切换」强调**新老品并行期与 EOM**（流程图：产品侧主导迭代型退市、月度刷新）。含义：**把「上新—铺货—下老」做成一条可度量流水线**。 |
| **主责 / 共阅** | 产品 GTM **主责**；需求计划 **共阅**备货与降速；区域 **共阅**区域退市流程配合。                                        |
| **关键指标**    | 首单需求收集完成率；首批到货满足率 vs 上市窗口；切换月度刷新执行率；老品 EOM 状态；上市后 90 天达成 vs 预测。                          |


### 4.4 首销期定价与促销规则看板


| 项目          | 内容                                                                                      |
| ----------- | --------------------------------------------------------------------------------------- |
| **看板名称**    | 首销期定价与促销规则看板                                                                            |
| **名称解读**    | 「首销期」对应调研会议结论：**RRP 与促销由产品侧制定**，区域在首销期内以执行与监控为主；名称含义：**把「规则版本」与「生效范围」管起来**，避免区域与总部口径漂移。 |
| **主责 / 共阅** | 产品 GTM **主责**发布；区域 GTM **共阅**执行与异常上报。                                                   |
| **关键指标**    | RRP/促销价版本与生效范围；首销复盘结论闭环率；例外申请占比。                                                        |

### 6.2 预测与要货质量看板

| ----------- | --------------------------------------------------------------------------- |
| **看板名称**    | 预测与要货质量看板                                                                   |

| **主责 / 共阅** | 需求计划 **主责**；区域 **共阅**提报质量；商业洞察 **共阅**假设。                                    |
| **关键指标**    | 预测准确率（SKU×渠道×时间窗）；要货准确率；预测 vs BP gap 拆解；渠道提报评审一次通过率/打回率；滚动窗（8+4/13+3 等）达成率。 |


### 6.3 库存、分货与呆滞看板


| 项目          | 内容                                                                        |
| ----------- | ------------------------------------------------------------------------- |
| **看板名称**    | 库存、分货与呆滞看板                                                                |
| **名称解读**    | 「分货」对应流程图 **全渠道分货控货**；「呆滞」对应调研会议与 v6.2 看板指标。含义：**回答「货在何处、是否积压、是否按共识分配」**。 |
| **主责 / 共阅** | 需求计划 **主责**；区域 **共阅**渠道侧执行。                                               |
| **关键指标**    | 库存周转天数；呆滞金额与 SKU 数；分货执行偏差；在途天数与超期批次；安全库存触线次数。                             |
