## 1. 需求背景与目标

### 1.1 背景

营销类项目在 PMP 立项时，需要提前规划各收益周期内的营销费用预算，明确：

1. 费用覆盖的收益日期范围；
2. 品牌费用项（营销投入末级）；
3. 商品范围（场景品类 / model / SKU / 新品标签）；
4. 地理与渠道范围（区域 / 国家 / 渠道 / 店铺）；
5. 费用承担部门。

当前阶段（CKW-003）：本页**不展示分摊模式**。费用一律挂全公司、暂不拆到商品；范围字段允许业务多选填写，系统只做记录，待分摊规则确定后再执行（预计 11 月，不在本期）。

### 1.2 建设目标

1. 在项目「预算」页签提供**行级预算维护**能力：新增、编辑、复制、删除、批量删除、保存。
2. 本页去掉「分摊模式」字段；所有行挂全公司、暂不分摊，不生成 MSKU 分摊结果。
3. 范围字段（场景品类 / model / SKU / 区域 / 国家 / 渠道 / 店铺）均可多选、可全空，仅记录。
4. 与费用部门主数据、销售主数据、区域国家渠道店铺主数据、费用项主数据联动。
5. 实时汇总预算合计，支撑立项评审与后续预算使用对比。

### 1.3 目标用户

| 角色 | 主要场景 |
|------|----------|
| 项目经理 / 立项发起人 | 录入项目营销预算、填写范围与金额、提交立项 |
| 营销负责人 | 审核预算范围与金额合理性 |
| 财务 BP | 核对费用部门、币种与规划口径 |
| 管报运营 | 了解项目预算规划，为后续费用导入对账提供基准 |

### 1.4 上下游

| 方向 | 说明 |
|------|------|
| 上游 | PMP 项目主数据、费用部门主数据、销售主数据（model/SKU）、区域国家渠道店铺主数据、场景品类主数据 |
| 下游 | 项目立项评审、营销费用规划/使用看板；后续分摊规则确定后按本页记录的范围回算（本期不执行） |

### 1.5 与费用导入的关系（重要）

| 环节 | 项目预算页 | 费用填报管理（导入） |
|------|------------|----------------------|
| 业务阶段 | 立项规划 | 实际费用发生与入账 |
| 分摊模式 | **不展示**；一律挂全公司、暂不分摊 | **批次级**，仍按原规则（本次不动） |
| MSKU 分摊 | **不生成** | 分摊模式下生成并落库 |
| 部门 | **必填**（记录承担部门） | 不分摊时必填；分摊时可空按店铺映射 |
| 范围字段 | 可多选，只记录 | 按批次分摊/不分摊规则校验 |
| 状态 | 编辑中 / 已保存（原型本地） | 待生效 / 已生效 / 失效 |

**核心原则：预算页只做规划记录与范围留存；本页暂不分摊。费用导入页仍按自身批次规则独立校验。**

## 4. 全局业务规则

### 4.1 立项约束

1. **立项提交前至少须有一行校验通过的预算。**
2. 空表点击「保存预算」须拦截，提示：`预算为必填：请至少新增一行并填写营销费用规划`。
3. 每行「营销费用规划」须 **> 0**。

### 4.2 暂不分摊（本页口径 · CKW-003）

| 属性 | 规则 |
|------|------|
| 页面字段 | **不展示**「分摊模式」列，用户不可选 |
| 处理方式 | 本页所有行一律**挂全公司、暂不分摊** |
| 是否生成 MSKU 分摊 | **否** |
| 范围字段 | 可多选、可全空，**只做记录** |
| 费用部门 | **必填**（记录承担部门；挂全公司指分摊对象，不是取消部门） |
| 适用费用项 | 不论品牌费用项选到品牌营销、产品营销还是基础固定花费，口径相同 |
| 作用范围 | **仅项目预算页**；费用导入页仍按自身批次规则，本次不动 |
| 后续 | 预计 11 月提供分摊规则后，按本页记录的范围再执行分摊与回算（不在本期） |

**字段注释（问号说明）：**

> 本页暂不分摊：金额挂全公司，不拆到商品。场景品类 / model / SKU / 区域 / 国家 / 渠道 / 店铺允许业务多选，系统只记录，供后续分摊规则确定后再用。费用部门仍必填。

### 4.3 预算行状态（原型）

| 状态 | 含义 |
|------|------|
| 编辑中 | 可新增、修改、复制、删除；尚未通过保存校验或尚未点击保存 |
| 已保存 | 校验通过并持久化；可继续编辑后再次保存 |

```
编辑中 ──顶部「保存预算」且校验通过──→ 已保存
已保存 ──修改任意字段或增删行──→ 编辑中
```

正式环境须与项目状态（草稿 / 审批中 / 已立项）联动，立项通过后是否允许修改预算另行定义。

### 4.4 预算合计

1. 实时汇总当前表格各行「营销费用规划」数值；
2. **不按币种折算**，各币种金额直接相加（展示层约定，正式环境可改为分币种展示）；
3. 新增、修改金额、删除行后自动刷新；
4. 保存成功 Toast 中的合计与标题区合计一致。

## 5. 范围记录规则

### 5.1 总览

| 维度 | 本页规则 |
|------|----------|
| 规划对象（场景品类 / SKU / 新品标签） | **可全空、可多选**（新品标签仍单选）；只记录 |
| 费用部门 | **必填** |
| 范围多选 | 各列可多选，不再按「不分摊每列最多 1 个」裁减 |
| 列间关系 | AND 条件（记录口径，本期不执行匹配） |
| 区域/国家/渠道/店铺/model 全空 | 表示该维度不限 |
| MSKU 分摊预览 | 无 |

### 5.2 全空含义

范围全空 = 不限定商品/渠道，整笔挂全公司（按指定费用部门承担），本期不拆到 MSKU。

**拦截提示（部门为空）：** `第 N 行：请填写费用部门`

### 5.3 与费用导入规则的说明

本期预算页与费用导入页**刻意不一致**：导入页仍保留分摊/不分摊批次规则。预算页记录的范围供 11 月分摊规则确定后回算使用。

| 差异点 | 预算页 | 费用导入页 |
|--------|--------|------------|
| 分摊模式 | 不展示，一律暂不分摊 | 批次级，用户可选 |
| 是否执行分摊 | 否 | 是（分摊模式预览并落库） |
| 费用项 / 归属月 | 无（用收益日期范围代替） | 有 |
| 批次状态机 | 无 | 待生效 / 已生效 / 失效 |

## 6. 字段详细规则

### 6.1 收益日期范围

| 属性 | 规则 |
|------|------|
| 必填 | 是 |
| 组件 | 日期范围选择器（开始日 + 结束日） |

| 与分摊 | 本期无联动；不再因含未来日锁定任何字段 |

### 6.2 品牌费用项

| 属性 | 规则 |
|------|------|
| 必填 | 是 |
| 组件 | 树形下拉单选（搜索、展开/收拢、父级置灰；与费用项管理树交互对齐） |
| 数据来源 | 费用项主数据（`FeeItemMaster`）中 **营销投入**（`T040201`）子树 |

| 多选 | 可多区域；可全空 |

### 6.10 国家

| 属性 | 规则 |
|------|------|
| 必填 | 否 |
| 组件 | 多选筛选 |
| 联动 | 选项依赖已选区域；未选区域时国家列表为空 |
| 数据字段 | `countries: string[]` |
| 区域国家映射（原型） | NA：美国/加拿大/墨西哥；EU：德法意英西；APAC：日澳新 |
| 多选 | 可多国家；可全空 |

### 6.11 渠道

| 属性 | 规则 |
|------|------|
| 必填 | 否 |
| 组件 | 多选筛选 |
| 枚举 | 亚马逊、Shopify、APP商城、线下商超、商超3P、线下分销 |
| 联动 | **变更渠道后，已选店铺清空**，店铺选项按渠道刷新 |
| 数据字段 | `channels: string[]` |
| 多选 | 可多渠道；可全空 |

### 6.12 店铺

| 属性 | 规则 |
|------|------|
| 必填 | 否 |
| 组件 | 多选筛选 |
| 联动 | 选项依赖已选渠道；未选渠道时展示全部店铺（原型行为） |
| 数据字段 | `stores: string[]` |
| 多选 | 可多店铺；可全空 |

### 6.13 营销费用规划

| 数据字段 | `currency: string` |

## 7. 操作与交互

### 7.1 新增一行

1. 在表尾插入一行；
2. 默认值：

| 字段 | 默认值 |
|------|--------|
| 收益日期范围 | 当年 1/1 ～ 12/31 |
| 品牌费用项 | 空（须手工选择营销投入末级） |
| 费用部门 | 空 |
| 场景品类 | 默认「观影 / TV灯带」一组 |
| model / SKU | 空 |
| 新品标签 | 空 |
| 区域 | NA（北美区），可再多选 |
| 国家 / 渠道 / 店铺 | 空 |
| 营销费用规划 | 0（保存前须改为 >0） |
| 币种 | USD |

3. Toast：`已新增一行，请填写后保存`

### 7.2 保存预算（顶部）

1. 校验**全部行**；
2. 至少一行；
3. 全部行通过后，以当前 DOM 同步列表并持久化；
4. Toast：`预算已保存（合计 {合计值}）。费用挂全公司，范围已记录，暂不分摊。`

> 本页**无行内保存**；行操作仅「复制」「删除」，整表保存只走顶部「保存预算」。

### 7.3 复制

1. 复制源行全部字段，生成新 `id`；
2. 插入列表末尾并重新渲染；
3. Toast：`已复制该行`

### 7.4 删除（单行）

1. 二次确认：`确定删除该预算行？`
2. 从存储移除并刷新表格与合计；
3. Toast：`已删除`

### 7.5 批量删除

| 规则 | 说明 |
|------|------|
| 启用条件 | 至少勾选 1 行 |
| 未勾选 | 按钮禁用 |
| 全选 | 表头复选框可全选/半选当前全部行 |
| 确认 | `确定删除选中的 N 行预算？` |
| 结果 | 批量移除并刷新；Toast：`已删除 N 行` |

### 7.6 示例数据（首次进入）

原型首次进入（无本地缓存）时预置 3 行示例预算，用于演示不同区域/类型组合。示例行 id 固定，避免删除与 DOM 不同步。

## 9. 校验规则汇总

### 9.1 保存前校验顺序

对每一行依次校验：

1. 收益日期范围完整；
2. 品牌费用项已选（须为营销投入末级）；
3. 费用部门已选；
4. 营销费用规划 > 0。

> 注：场景品类、SKU、新品标签等范围字段**均可全空**，不做「至少填一类」校验。

### 9.2 校验场景矩阵

| 场景 | 规划对象 | 部门 | 预期 |
|------|----------|------|------|
| 范围全空 | 全空 | 已填 | 通过（挂全公司、暂不分摊） |
| 缺部门 | 任意 | 空 | 拦截 |
| 正常行 | 有范围 | 已填 | 通过 |
| 金额为 0 | 满足 | 满足 | 拦截 |
| 空表保存 | — | — | 拦截 |
| 未选品牌费用项 | 任意 | 任意 | 拦截 |

### 9.3 级联清空矩阵

| 变更字段 | 联动行为 |
|----------|----------|
| 区域 | 清空国家；按已选区域并集刷新国家选项 |
| 渠道 | 清空店铺；刷新店铺选项 |

## 10. 异常与边界

| 场景 | 处理 |
|------|------|
| 费用部门主数据未加载 | 下拉显示「费用部门主数据未加载」；保存时部门为空则拦截 |
| 销售主数据索引加载失败 | 使用内置 model 子集，不影响保存 |
| 历史数据字段迁移 | 自动处理 monthStart/monthEnd、model 字符串、npTag 旧格式、BP 部门名、旧三列营销类型/场景/类型 → 品牌费用项编码、`region` → `regions`、忽略 `allocMode` |
| 浏览器缓存清除 | 原型数据丢失，恢复示例数据；正式环境走服务端 |

## 12. 测试验收要点

### 12.1 基础校验

1. 空表点「保存预算」→ 提示至少新增一行。
2. 金额为 0 或空 → 拦截并提示。
3. 收益日期、品牌费用项、费用部门缺任一 → 按行号提示。

### 12.2 暂不分摊

4. 表头无「分摊模式」列。
5. 保存成功 Toast 含「费用挂全公司，范围已记录，暂不分摊」。
6. 范围全空且部门已填 → 可保存。
7. 部门为空 → 拦截，提示 `第 N 行：请填写费用部门`。
8. 区域 / 国家 / 渠道 / 店铺 / SKU / 场景品类均可同时选多项，不裁减为单选。

### 12.3 级联与组件

9. 修改区域后，国家被清空。
10. 修改渠道后，店铺被清空。
11. 场景品类级联：hover 切换右列、父级全选子级、半选态正确。
12. 新品标签下拉显示当前年 ±3 年共 7 项。
13. 费用部门树形下拉：搜索、展开收拢、清除、禁选节点不可见。
14. 品牌费用项树形下拉：仅展示营销投入子树；可展开/收拢；父级置灰不可选；只能选末级；联合营销无下级、可选。

### 12.4 操作

15. 新增一行：区域默认北美区；保存前须补齐必填项（含费用部门）。
16. 复制行生成新 id，字段全部带出。
17. 批量删除：未勾选禁用；勾选后可删；全选生效。
18. 操作列仅「复制」「删除」，无行内「保存」；顶部「保存预算」校验全部行。
19. 保存后刷新页面，数据仍在，合计正确。

### 12.5 与费用导入

20. 费用导入页仍保留自身分摊模式，不沿用本页暂不分摊口径。
21. 预算页不出现 MSKU 分摊预览、分摊明细弹窗、批次状态等导入页专属能力。
