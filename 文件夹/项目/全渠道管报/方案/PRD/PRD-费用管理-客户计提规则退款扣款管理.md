# 费用管理 - 客户计提规则、退款管理、扣款管理 PRD

文档日期：2026-07-15

适用范围：全渠道管报 → 费用管理 → 客户计提规则管理、退款管理、扣款管理。

参考原型：
- `原型/费用管理/客户计提规则管理.html`
- `原型/费用管理/退款管理.html`
- `原型/费用管理/扣款管理.html`

## 1. 需求背景与目标

商超渠道存在销售退款、促销扣款、销售折扣、现金折扣、销售费用等费用计提与实际入账对账场景。系统需要提供统一页面维护客户计提规则、录入实际退款/扣款，并根据规则自动计算计提金额、余额、差异状态，支撑财务对账与管报费用取数。

本次建设目标：
1. 建立客户维度的扣款计提规则维护能力，支持固定比例、部门固定比例、销售费用规则维护。
2. 建立退款管理台账，支持按滚动退款率计算期初余额、期末余额与当月计提退款，并录入实际退款。
3. 建立扣款管理台账，支持四类费用项的计提扣款、实际扣款、余额滚动与差异状态判断。
4. 三个页面规则联动：规则页调整后影响扣款管理计提结果；退款与扣款实际值录入后影响当月及后续月份余额。

## 2. 功能范围

本 PRD 覆盖以下页面：
1. 客户计提规则管理：维护商超零售商的促销扣款、销售折扣、现金折扣、销售费用计提规则，以及客户部门主数据。
2. 退款管理：按客户、月份维护实际退款金额，系统计算滚动退款率、期初计提退款余额、当月计提退款、期末计提退款余额。
3. 扣款管理：按客户、月份、费用项维护实际扣款金额，系统计算计提扣款、期初余额、期末余额、差异和状态。

不在本次范围：
1. 费用项主数据维护页面的完整设计。
2. 财务系统、金蝶、ERP 订单系统的数据同步接口细节。

## 3. 全局业务规则

### 3.1 基础口径

1. 金额币种统一为 USD，页面展示金额保留两位小数并带千分位。
2. 期间按自然月管理，格式为 `YYYY-MM`。
3. 计提用收入 = 销售收入 - 退货退款对应收入。该收入用于扣款比例计提与退款滚动率分母，与实际退款、实际扣款入账分开维护，不重复扣减。
4. 销售退款与商超扣款均按客户维度管理；扣款管理额外按费用项维度管理。
5. 系统存在初始化台账与初始化规则。用户在页面录入或调整后，展示结果应以“系统初始化数据 + 用户保存的调整”为准。
6. 尚无历史台账的月份可按规则生成“滚动测算”行，实际值未录入前按 0 参与测算。
7. 默认月份筛选为最近 3 个自然月；若当前筛选没有结果但系统存在数据，恢复默认最近 3 个月。

### 3.2 保存与重算

1. 客户计提规则保存后，应提示用户：保存将联动扣款管理，对未关账月份重算计提结果，已关账月份不变。
2. 退款实际值保存后，应重算该客户从当前月份起后续月份的滚动率、期初余额、期末余额和当月计提退款。
3. 扣款实际值保存后，应重算同客户、同费用项从当前月份起后续月份的期初余额和期末余额。
4. 所有成功保存动作均需记录操作日志，日志至少包含操作对象、操作类型、金额/规则变化摘要、操作时间。
5. 已关账月份清单与最早未关账月份由产品经理提供初始化数据；所有规则调整、目标窗口调整和重算均不得影响已关账月份。
6. 规则调整需保留历史版本，并按保存当月及后续月份使用新规则，历史月份仍按当时生效规则追溯展示。

### 3.3 操作日志

1. 客户计提规则管理日志按客户记录。
2. 退款管理日志按客户 + 期间记录。
3. 扣款管理日志按客户 + 费用项 + 期间记录。
4. 列表操作区展示“日志”入口；有日志时显示日志数量。

## 4. 客户计提规则管理

### 4.1 页面定位

客户计提规则管理用于维护各商超零售商的扣款计提规则。该页面是扣款管理计算“计提扣款”的上游规则来源，退款滚动规则不在本页维护。

### 4.2 页面结构

页面包含：
1. 顶部导航：目录、客户计提规则、退款管理、扣款管理。
2. 查询区：客户下拉筛选、重置筛选。
3. 规则说明区：展示计提用收入、部门固定比例、销售费用规则、币种及重算范围说明。
4. 零售商计提规则列表。
5. 部门管理弹窗。
6. 调整计提比例弹窗。
7. 调整销售费用计提规则弹窗。
8. 操作日志弹窗。

### 4.3 查询规则

1. 客户筛选默认“全部”，展示所有有扣款规则的零售商。
2. 选择客户后，列表仅展示该客户。
3. 点击重置筛选，清空客户条件并刷新列表。
4. 从扣款管理点击“调整规则”跳转本页时，应自动带入对应客户筛选。
5. 筛选仅影响展示结果，不修改已保存规则。

### 4.4 零售商计提规则列表

列表一行代表一个零售商，字段如下：
1. 客户。
2. 促销扣款比例。
3. 销售折扣比例。
4. 现金折扣比例。
5. 销售费用计提方式。
6. 销售费用规则。
7. 操作。

展示规则：
1. 促销扣款、销售折扣、现金折扣支持固定比例和部门固定比例。
2. 若采用固定比例，列表展示该费用项固定比例。
3. 若采用部门固定比例，列表展示按部门金额和部门比例折算后的综合有效比例，明细不在列表展开。
4. 销售费用展示计提方式和规则摘要，如月固定金额、年总额按月分摊、固定比例等。
5. 列表展示结果应综合系统初始规则与用户保存调整。

操作规则：
1. 点击促销扣款、销售折扣、现金折扣比例单元格，打开调整计提比例弹窗。
2. 点击销售费用计提方式或销售费用规则单元格，打开调整销售费用计提规则弹窗。
3. 操作列提供“促销 / 销折 / 现折 / 销费 / 日志”入口。

### 4.5 部门管理

部门管理用于按客户维护部门主数据，供“部门固定比例”计提方式使用。

入口：
1. 页面列表右上角“部门管理”按钮。
2. 若当前页面已筛选客户，新增部门时默认带入该客户。

弹窗字段：
1. 筛选客户：支持全部客户、多选、搜索、清空。
2. 客户：每行必填，下拉选择。
3. 部门编码：每行必填。
4. 部门名称：每行必填。
5. 操作：删除当前部门行。

交互规则：
1. 打开弹窗时，默认展示全部已维护部门；若客户未维护部门，可带出 ERP 订单部门作为编辑起点。
2. 筛选客户后，仅展示所选客户部门；不筛选时展示全部相关客户部门。
3. 点击“新增部门”新增一行。若仅筛选了一个客户，新行默认带入该客户；否则优先带入页面客户筛选值。
4. 删除行仅从当前弹窗列表移除，需点击保存后生效。
5. 保存时按客户分组写入部门清单。
6. 同一客户下部门编码不可重复。
7. 若筛选了客户，保存时不允许出现筛选范围外客户的部门行。
8. 筛选某一客户时，仅更新该客户部门清单；筛选全部时，更新列表中出现的各客户部门清单。
9. 若保存范围内某客户无部门记录，应二次确认是否清空该客户部门清单。

校验规则：
1. 客户为空：提示选择客户。
2. 部门编码为空：提示填写部门编码。
3. 部门名称为空：提示填写部门名称。
4. 同一客户部门编码重复：提示重复并阻止保存。
5. 无任何可保存部门：提示至少维护一条部门记录。

保存后影响：
1. 该客户后续选择“部门固定比例”时，比例弹窗按新部门清单展示部门行。
2. 若同一客户的计提比例弹窗已打开，部门表需即时刷新。
3. 保存部门清单不自动修改已保存的部门比例数值。
4. 保存成功后写入对应客户操作日志并刷新主表。

### 4.6 调整计提比例

适用费用项：
1. 促销扣款。
2. 销售折扣。
3. 现金折扣。

弹窗字段：
1. 客户：只读。
2. 费用项：只读。
3. 计提方式：固定比例、部门固定比例。
4. 计提比例：固定比例方式下填写，范围 0～1。
5. 部门固定比例清单：部门固定比例方式下展示，包含部门编号、部门名称、固定比例。
6. 备注。

固定比例规则：
1. 计提扣款 = 当月计提用收入 × 固定比例。
2. 固定比例必须填写，且必须为 0～1 之间的数字。

部门固定比例规则：
1. 部门来源优先取客户在部门管理中维护的部门；未维护时回退 ERP 订单部门。
2. 部门编号、部门名称只读，只允许维护部门固定比例。
3. 部门固定比例必须在 0～1 之间。
4. 计提扣款 = Σ（部门订单金额不含税并减去退款金额 × 部门固定比例）。
5. 当订单上有折扣数据时，直接取订单上的折扣比例；没有订单折扣数据时，再使用固定比例或部门固定比例。
6. 部门取不到时，比例按 0 计算。
7. 无部门清单时不可保存，需先在部门管理中维护部门。
8. 所有部门比例均为 0 时，需二次确认是否仍保存。

保存规则：
1. 点击保存前，先提示保存后将联动扣款管理重算未关账月份，已关账月份不变。
2. 用户取消确认则不保存。
3. 校验通过后保存规则，写入客户操作日志，关闭弹窗并刷新主表。
4. 保存后，扣款管理中该客户、该费用项未关账月份的计提扣款应按新规则重算。
5. 若保存参数与系统初始规则一致，视为取消手工覆盖，后续按系统初始规则计算。

### 4.7 调整销售费用计提规则

弹窗字段：
1. 客户：只读。
2. 计提方式：月固定金额、年总金额月均分摊、固定比例。
3. 月固定金额：选择月固定金额时填写。
4. 年总金额：选择年总金额月均分摊时填写。
5. 固定比例：选择固定比例时填写，范围 0～1。
6. 备注。

计算规则：
1. 月固定金额：每月按填写金额计提销售费用。
2. 年总金额月均分摊：销售费用 = 年总金额 ÷ 12。
3. 固定比例：销售费用 = 当月计提用收入 × 固定比例。

交互规则：
1. 切换计提方式时，仅显示当前方式对应输入项。
2. 未点击保存前，仅做页面预览，不写入系统。
3. 保存前同样提示联动扣款管理重算未关账月份。
4. 保存后仅影响扣款管理中“销售费用”费用项，不影响促销扣款、销售折扣、现金折扣。
5. 若参数改回与系统初始一致，取消手工覆盖，扣款管理恢复默认计提数。

校验规则：
1. 固定比例必须在 0～1 之间。
2. 金额字段应为有效数字，允许录入负数。

## 5. 退款管理

### 5.1 页面定位

退款管理用于管理商超渠道销售退款的滚动计提台账。页面按客户、月份展示销售收入、实际退款、滚动退款率、目标窗口、当月计提退款与期末计提退款余额。

### 5.2 页面结构

页面包含：
1. 顶部导航。
2. 退款数据总览卡片。
3. 查询区：月份范围、客户、重置筛选。
4. 退款明细列表。
5. 录入实际退款弹窗。
6. 退款计算过程弹窗。
7. 导入实际退款弹窗。
8. 操作日志弹窗。

### 5.3 汇总卡片

按当前筛选结果实时汇总：
1. 记录数。
2. 期初计提退款余额合计。
3. 实际退款合计。
4. 期末计提退款余额合计。

金额展示规则：USD，保留两位小数，千分位展示。

### 5.4 查询规则

1. 月份范围默认最近 3 个自然月。
2. 月份范围与客户筛选同时生效。
3. 客户默认“全部”；选择客户后仅展示该客户记录。
4. 点击重置筛选，恢复默认月份范围并清空客户。
5. 筛选结果为空但系统存在退款记录时，自动恢复默认最近 3 个月。

### 5.5 退款明细列表

列表一行代表一个客户 × 一个自然月。

字段：
1. 期间：自然月；尚无历史台账的测算月份显示“滚动测算”标签。
2. 客户。
3. 销售收入：按计提用收入口径展示。
4. 期初计提退款余额。
5. 实际退款：唯一允许人工录入或导入的金额字段。
6. 上月滚动退款率。
7. 本月滚动退款率。
8. 目标窗口（月）。
9. 当月计提退款。
10. 期末计提退款余额。
11. 备注。
12. 更新时间。
13. 操作。

展示规则：
1. 期初余额、上月滚动退款率、本月滚动退款率、目标窗口、当月计提退款、期末余额可点击查看计算过程。
2. 若本页录入过实际退款，优先展示录入值；否则展示系统历史台账值；再否则按滚动规则测算。
3. 未录入实际退款时，实际退款按 0 参与测算。
4. 未来或缺失历史台账的月份可显示“滚动测算”，仍参与公式计算。

### 5.6 退款计算规则

滚动退款率：
1. 上月滚动退款率 = 截至上一自然月末，近 12 个月实际退款合计 ÷ 近 12 个月计提用收入合计。
2. 本月滚动退款率 = 截至当月末，近 12 个月实际退款合计 ÷ 近 12 个月计提用收入合计。
3. 首月或历史不足时，可使用系统预置历史结果。
4. 计算中的实际退款按正数金额参与。

目标窗口：
1. 目标窗口表示计算期初、期末余额时连续取多少个月的计提用收入。
2. 默认目标窗口为 3 个月；部分客户可为 1 个月。
3. 目标窗口可在计算过程弹窗调整并保存。
4. 保存目标窗口后，同客户从保存当月及后续月份继承新窗口，并触发期初、期末、当月计提连锁重算。
5. 目标窗口调整不影响已关账月份。

期初余额：
1. 期初计提退款余额 = 上月滚动退款率 × 目标窗口内截至上月的计提用收入合计。
2. 也可理解为上月期末计提退款余额顺延。

期末余额：
1. 期末计提退款余额 = 本月滚动退款率 × 目标窗口内截至当月的计提用收入合计。
2. 期末余额作为下月期初余额的计算基础。

当月计提退款：
1. 当月计提退款 = 实际退款金额 + 期末计提退款余额 - 期初计提退款余额。
2. 实际退款变化后，当月计提退款即时预览，保存后写入并触发后续月份重算。

### 5.7 录入实际退款

入口：退款明细列表操作列“录入实际值”。

弹窗字段：
1. 期间：只读。
2. 客户：只读。
3. 期初计提退款余额：只读。
4. 上月滚动退款率：只读。
5. 本月滚动退款率：只读。
6. 期末计提退款余额：只读。
7. 实际退款金额：可编辑。
8. 系统计提退款：只读，随实际退款金额即时预览。
9. 备注：可编辑。

保存规则：
1. 未填实际退款金额时按 0 保存。
2. 保存后记录实际退款金额与备注。
3. 保存后重算该客户从当前月份起后续各月的滚动率、期初、期末、当月计提。
4. 保存后写入操作日志，关闭弹窗，刷新列表与汇总卡片。

建议校验：
1. 实际退款金额应为数字。
2. 实际退款金额允许录入负数，用于支持红冲、反向退款等业务场景。

### 5.8 导入实际退款

入口：退款明细列表右上角“导入”。

导入匹配键：
1. 期间。
2. 客户。

导入字段：
1. 期间：必填，格式 `YYYY-MM`。
2. 客户：必填，须匹配系统客户主数据。
3. 实际退款金额：必填。
4. 备注：非必填。

导入规则：
1. 仅更新实际退款金额和备注。
2. 滚动退款率、目标窗口等由系统按规则计算，不允许通过实际退款导入直接覆盖。
3. 导入后按客户从导入月份起顺延重算后续月份余额与计提。
4. 导入成功后记录操作日志。
5. 导入文件需支持 CSV 和 Excel 两种格式。
6. 正式环境需解析文件并返回成功行、失败行及失败原因。
7. 导入存在失败行时，需支持下载失败行文件，便于用户修正后再次导入。

### 5.9 退款计算过程弹窗

入口：点击列表中带下划线的金额或比率。

弹窗内容：
1. 顶部展示期间、客户、销售收入、目标窗口。
2. 展示销售收入取值口径说明。
3. 上月滚动退款率计算块。
4. 本月滚动退款率计算块。
5. 期初计提退款余额计算块。
6. 期末计提退款余额计算块。
7. 当月计提退款计算块。
8. 目标窗口编辑区。

交互规则：
1. 根据用户点击字段，弹窗自动定位到对应计算块。
2. 修改目标窗口时，期初、期末、当月计提即时按新窗口预览。
3. 未点击“保存目标窗口”前不写入系统。
4. 关闭弹窗不保存目标窗口修改。

## 6. 扣款管理

### 6.1 页面定位

扣款管理用于管理商超四类费用的冲销台账：促销扣款、销售折扣、现金折扣、销售费用。页面录入实际扣款，系统根据客户计提规则计算计提扣款，并输出差异与匹配状态。

### 6.2 页面结构

页面包含：
1. 顶部导航。
2. 扣款数据总览卡片。
3. 查询区：月份范围、客户、费用项、重置筛选。
4. 扣款明细列表。
5. 录入实际扣款弹窗。
6. 扣款计算过程弹窗。
7. 导入实际扣款弹窗。
8. 客户扣款计提规则入口。
9. 操作日志弹窗。

### 6.3 汇总卡片

按当前筛选结果实时汇总：
1. 记录数。
2. 期初余额合计。
3. 实际扣款合计。
4. 期末余额合计。

金额展示规则：USD，保留两位小数，千分位展示。

### 6.4 查询规则

1. 月份范围默认最近 3 个自然月。
2. 客户默认“全部”，支持清空。
3. 费用项默认“全部”，可筛选促销扣款、销售折扣、现金折扣、销售费用。
4. 月份范围、客户、费用项筛选同时生效。
5. 点击重置筛选，恢复默认月份范围，清空客户和费用项。
6. 筛选结果为空但系统存在扣款记录时，自动恢复默认最近 3 个月。
7. 筛选只影响展示，不修改实际扣款或计提规则。

### 6.5 扣款明细列表

列表一行代表一个费用项 × 一个客户 × 一个自然月。

字段：
1. 期间：自然月；尚无历史台账的测算月份显示“滚动测算”标签。
2. 客户。
3. 费用项。
4. 期初余额。
5. 实际扣款：唯一允许人工录入或导入的金额字段。
6. 计提比例/规则。
7. 计提扣款。
8. 期末余额。
9. 差异：实际扣款 - 计提扣款。
10. 状态。
11. 备注。
12. 更新时间。
13. 操作。

展示规则：
1. 期初余额、计提比例/规则、计提扣款、期末余额可点击查看计算过程。
2. 展示结果综合系统初始数据、客户计提规则调整、本页录入实际扣款。
3. 尚无历史台账且未录入实际扣款的月份显示“滚动测算”，实际扣款按 0 参与测算。
4. 计提比例/规则来源于客户计提规则管理。

### 6.6 扣款计算规则

期初余额：
1. 首月期初余额取系统扣款台账期初值。
2. 后续月份期初余额等于上月期末余额。
3. 滚动测算月份按上月期末余额顺延。

计提扣款：
1. 促销扣款、销售折扣、现金折扣支持固定比例和部门固定比例。
2. 固定比例：计提扣款 = 当月计提用收入 × 计提比例。
3. 部门固定比例：计提扣款 = Σ（部门订单金额不含税并减去退款金额 × 部门固定比例）。
4. 销售费用按客户计提规则管理配置计算，支持月固定金额、年总金额月均分摊、固定比例。
5. 当订单上有折扣数据时，直接取订单上的折扣比例；没有订单折扣数据时，再使用固定比例或部门固定比例。
6. 部门取不到时，比例按 0 计算。
7. 规则页保存调整后，扣款管理对应客户、对应费用项的计提扣款应重算。

期末余额：
1. 期末余额 = 期初余额 - 实际扣款 + 计提扣款。
2. 本月期末余额作为下月期初余额。

差异与状态：
1. 差异 = 实际扣款 - 计提扣款。
2. 差异绝对值小于 0.01 USD，状态显示“匹配”。
3. 差异为正，状态显示“实际>计提”。
4. 差异为负，状态显示“实际<计提”。
5. 状态不是“匹配”时，操作列显示“调整规则”入口。

### 6.7 录入实际扣款

入口：扣款明细列表操作列“录入实际值”。

弹窗字段：
1. 期间：只读。
2. 客户：只读。
3. 费用项：只读。
4. 期初余额：只读。
5. 当月销售收入：只读，按计提用收入口径展示。
6. 计提比例/规则：只读。
7. 系统计提扣款：只读。
8. 实际扣款金额：可编辑。
9. 预计期末余额：只读，随实际扣款金额即时预览。
10. 备注：可编辑。

保存规则：
1. 实际扣款金额变化时，预计期末余额即时更新。
2. 预计期末余额 = 期初余额 - 实际扣款 + 计提扣款。
3. 保存后写入实际扣款与备注。
4. 保存后从当前月份起，同客户、同费用项后续各月的期初、期末余额顺延重算。
5. 保存后写入操作日志，关闭弹窗，刷新列表、汇总、差异和状态。

建议校验：
1. 实际扣款金额应为数字。
2. 实际扣款金额允许录入负数，用于支持红冲、返还等业务场景。

### 6.8 导入实际扣款

入口：扣款明细列表右上角“导入”。

导入匹配键：
1. 期间。
2. 客户。
3. 费用项。

导入字段：
1. 期间：必填，格式 `YYYY-MM`。
2. 客户：必填，须匹配系统客户主数据。
3. 费用项：必填，支持促销扣款、销售折扣、现金折扣、销售费用。
4. 实际扣款金额：必填。
5. 备注：非必填。

导入规则：
1. 仅更新实际扣款金额和备注。
2. 计提比例、计提扣款仍按客户计提规则计算，不允许通过导入覆盖。
3. 导入后，同客户、同费用项从导入月份起后续月份余额顺延重算。
4. 导入成功后记录操作日志。
5. 导入文件需支持 CSV 和 Excel 两种格式。
6. 正式环境需解析文件并返回成功行、失败行及失败原因。
7. 导入存在失败行时，需支持下载失败行文件，便于用户修正后再次导入。

### 6.9 客户扣款计提规则入口

1. 扣款管理列表右上角提供“客户扣款计提规则”入口，跳转客户计提规则管理页。
2. 非匹配行操作列提供“调整规则”入口，跳转客户计提规则管理页并自动选中对应客户。
3. 导入或录入实际扣款只修改实际金额，不修改计提规则。

### 6.10 扣款计算过程弹窗

入口：点击列表中带下划线的期初、计提比例/规则、计提扣款、期末余额等字段。

弹窗内容：
1. 顶部展示期间、客户、费用项、当月销售收入。
2. 展示销售收入取值口径说明。
3. 客户计提比例/规则计算块。
4. 销售费用计提计算块。
5. 期初余额计算块。
6. 计提扣款计算块。
7. 期末余额计算块。

显隐规则：
1. 促销扣款、销售折扣、现金折扣展示比例类计提规则说明。
2. 销售费用展示销售费用计提说明。
3. 部门固定比例时，应展示各部门订单金额不含税并减去退款金额、部门比例、部门计提结果，并汇总为计提扣款。
4. 点击不同字段时，弹窗自动定位到对应说明块。

## 7. 三页联动关系

### 7.1 客户计提规则管理 → 扣款管理

1. 促销扣款、销售折扣、现金折扣的固定比例或部门固定比例来自客户计提规则管理。
2. 销售费用的月固定金额、年总额月均分摊、固定比例来自客户计提规则管理。
3. 规则保存后，扣款管理中对应客户、对应费用项的计提扣款重算。
4. 规则保存不修改扣款管理中已录入的实际扣款金额。
5. 已关账月份不应被规则重算影响；未关账月份从产品经理提供的最早未关账月份开始重算。
6. 规则调整需保留历史版本，新规则从保存当月及后续月份生效。

### 7.2 退款管理 → 全局计提用收入

1. 计提用收入已扣减退货退款对应收入，用于扣款比例计提与退款滚动率计算。
2. 实际退款金额在退款管理中单独维护，不重复从扣款或销售收入中扣减。
3. 退款管理的滚动率与余额结果可作为管报费用取数和商超计提口径说明的下游依据。

### 7.3 扣款管理 → 客户计提规则管理

1. 扣款管理中状态为“实际>计提”或“实际<计提”的记录提供“调整规则”入口。
2. 跳转到客户计提规则管理时，应自动带入对应客户筛选。
3. 用户调整规则后返回扣款管理，对应客户、费用项的计提扣款、差异、状态应刷新。

## 8. 数据与来源说明

### 8.1 上游数据

1. 客户主数据：用于客户下拉、规则维护、退款与扣款台账展示。
2. 销售收入数据：按计提用收入口径参与退款和扣款计算。
3. 退货退款收入数据：用于从销售收入中扣减，得到计提用收入。
4. ERP 订单部门及部门订单金额不含税：扣减退款金额后用于部门固定比例计提。
5. 系统初始化退款台账：包含历史实际退款、余额、窗口等基线数据。
6. 系统初始化扣款台账：包含历史实际扣款、计提扣款、余额等基线数据。
7. 系统初始化客户计提规则：包含各客户、各费用项初始规则。

### 8.2 用户维护数据

1. 客户部门主数据。
2. 客户扣款计提规则调整。
3. 销售费用计提规则调整。
4. 实际退款金额与备注。
5. 退款目标窗口调整。
6. 实际扣款金额与备注。
7. 规则历史版本。
8. 操作日志。

### 8.3 数据优先级

1. 用户保存的实际值优先于系统初始化台账实际值。
2. 用户保存的规则按生效月份优先于系统初始化规则：保存当月及后续月份使用新规则，历史月份使用当期生效规则。
3. 用户保存的客户部门清单优先于 ERP 订单部门；未维护时回退 ERP 订单部门。
4. 用户保存内容与系统初始化内容一致时，可视为取消覆盖，按系统初始化数据展示。

## 9. 异常与边界处理

1. 筛选无数据但系统存在记录：恢复默认最近 3 个月。
2. 退款或扣款无历史台账的未来月份：显示“滚动测算”，按规则推算。
3. 金额缺失：按 0 参与测算。
4. 滚动率计算分母为 0：滚动率按 0 处理。
5. 部门固定比例无部门：禁止保存并提示先维护部门。
6. 部门比例全部为 0：二次确认。
7. 部门编码重复：禁止保存。
8. 导入文件未选择：提示先选择文件。
9. 导入匹配不到台账行：列为失败行并提示原因。
10. 导入存在失败行：支持下载失败行文件。
11. 目标窗口输入小于 1 或非整数：按正整数校验，校验不通过时禁止保存。
12. 金额负数：允许录入并按公式参与计算。

## 10. 审计与生效

审计要求：
1. 所有保存、导入、规则调整、目标窗口调整都需记录操作日志。
2. 日志应能按页面行查看。
3. 日志保留操作前后关键信息，便于财务复核。
4. 本需求不内置审批流程，操作保存后仅记录日志并直接生效。

规则版本要求：
1. 计提规则、销售费用规则、目标窗口调整均需保留历史版本。
2. 新版本从保存当月及后续月份生效，不影响已关账月份。
3. 查看历史月份时，应按该月份实际生效的规则版本计算和展示。

## 11. 验收标准

### 11.1 客户计提规则管理

1. 客户筛选后列表仅显示对应客户，重置后恢复全部。
2. 从扣款管理非匹配行点击“调整规则”，能跳转并自动选中客户。
3. 部门管理中客户、部门编码、部门名称必填，重复部门编码被拦截。
4. 部门清单保存后，部门固定比例弹窗即时使用新部门清单。
5. 固定比例小于 0 或大于 1 时禁止保存。
6. 部门固定比例无部门时禁止保存。
7. 所有部门比例为 0 时出现二次确认。
8. 保存规则前出现联动重算确认；取消确认不保存。
9. 保存促销扣款、销售折扣、现金折扣规则后，扣款管理对应费用项计提扣款变化。
10. 保存销售费用规则后，仅扣款管理“销售费用”行计提变化。
11. 保存成功后主表刷新，日志数量增加。

### 11.2 退款管理

1. 默认进入页面展示最近 3 个月数据。
2. 月份范围与客户筛选组合生效，汇总卡片与列表一致。
3. 录入实际退款时，系统计提退款随实际退款金额即时预览。
4. 保存实际退款后，当前客户后续月份的期初、期末、当月计提连锁变化。
5. 点击上月滚动率、本月滚动率、期初、期末、当月计提，计算弹窗定位到对应计算块。
6. 修改目标窗口仅预览；关闭弹窗不保存。
7. 保存目标窗口后，当前客户从保存当月及后续月份继承新窗口并重算，已关账月份不变。
8. 导入实际退款仅更新实际退款金额和备注，不改变滚动率和目标窗口。
9. 导入 CSV 或 Excel 均可识别；存在失败行时可下载失败行文件。
10. 导入或录入成功后记录操作日志。

### 11.3 扣款管理

1. 默认进入页面展示最近 3 个月数据。
2. 月份、客户、费用项筛选组合生效，汇总卡片与列表一致。
3. 四类费用项可分别筛选，销售费用与前三类费用计算说明区分展示。
4. 录入实际扣款时，预计期末余额随实际扣款金额即时预览。
5. 保存实际扣款后，同客户、同费用项后续月份期初、期末顺延变化。
6. 差异绝对值小于 0.01 USD 时状态为“匹配”。
7. 差异为正时状态为“实际>计提”，差异为负时状态为“实际<计提”。
8. 非匹配状态下显示“调整规则”，匹配状态不显示。
9. 点击期初、计提规则、计提扣款、期末余额可查看计算过程。
10. 部门固定比例计算弹窗展示部门明细并能汇总到计提扣款。
11. 导入实际扣款仅更新实际扣款金额和备注，不改变计提规则。
12. 导入 CSV 或 Excel 均可识别；存在失败行时可下载失败行文件。
13. 导入或录入成功后记录操作日志。

## 12. 产品确认事项

1. 已关账月份清单和最早未关账月份由产品经理提供初始化数据。
2. 目标窗口调整不影响已关账月份。
3. 实际退款、实际扣款允许录入负数。
4. 导入文件正式支持 CSV、Excel，并支持失败行下载。
5. 不需要审批流程，保存后仅记录日志并直接生效。
6. 规则调整需保留历史版本，新规则按保存当月及后续月份生效。
