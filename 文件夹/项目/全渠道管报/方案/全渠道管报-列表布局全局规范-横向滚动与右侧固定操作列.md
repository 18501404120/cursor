# 全渠道管报-列表布局全局规范（横向滚动与右侧固定操作列）

- 生效日期：2026-05-08
- 适用范围：全渠道管报项目内所有“表格/列表型页面”
- 目标：保持大屏与小屏一致的列宽与可读性，小分辨率通过横向滚动查看，不压缩列

---

## 1. 统一原则（必须遵守）

1. 列宽以大分辨率设计稿为准，**小分辨率不压缩列宽**。
2. 列表外层必须支持**横向滚动**（左右滑动）。
3. 操作列必须固定在右侧（粘性列），滚动时始终可见。
4. 列表信息优先完整展示，不以压缩控件或强制换行换取“刚好塞满一屏”。

---

## 2. 页面结构规范

```html
<div class="table-scroll-wrap">
  <table class="biz-table">
    <thead>...</thead>
    <tbody>...</tbody>
  </table>
</div>
```

### 结构要求
1. 外层容器 `.table-scroll-wrap`：负责横向滚动。
2. 表格 `.biz-table`：设置 `min-width` 为“所有列宽总和”。
3. 操作列：加 `is-sticky-right` 类，固定到右侧。

---

## 3. 样式规范（基线）

```css
.table-scroll-wrap {
  width: 100%;
  overflow-x: auto;
  overflow-y: hidden;
}

.biz-table {
  border-collapse: separate;
  border-spacing: 0;
  table-layout: fixed;
  min-width: 1680px; /* 按实际列总宽配置 */
}

.biz-table th,
.biz-table td {
  white-space: nowrap;
}

.biz-table .is-sticky-right {
  position: sticky;
  right: 0;
  z-index: 3;
  background: #fff;
  box-shadow: -8px 0 8px -8px rgba(0, 0, 0, 0.18);
}

.biz-table thead .is-sticky-right {
  z-index: 4;
}
```

---

## 4. 列宽规范

1. 每列必须定义明确宽度（如 140/180/220）。
2. 复杂文本列（如场景品类）建议固定宽度并搭配摘要显示。
3. 操作列宽度固定（建议 120~180），不得被挤压。
4. 严禁在小分辨率下改成“自动压缩列宽”。

---

## 5. 交互规范

1. 小分辨率下允许用户左右滚动查看完整字段。
2. 右侧操作列固定，滚动时始终可点击。
3. 若页面有纵向滚动，建议表头吸顶（可选增强项）。
4. 列内容过长时使用“摘要 + 悬浮完整信息”模式。

---

## 6. 验收标准（必须通过）

1. 在 1920、1440、1366、1280 宽度下，列宽保持一致，不发生控件挤压变形。
2. 小于设计宽度时出现横向滚动条，可完整查看所有列。
3. 操作列在任意横向滚动位置都可见可用。
4. 固定列无透明穿透、无重叠乱码、无点击失效。

---

## 7. 后续新页面强制要求

1. 任何新增列表页面，默认采用本规范。
2. 如需例外（不固定操作列/不横向滚动），必须在需求评审中单独说明。
3. 代码评审需检查：`min-width`、`overflow-x`、`sticky right` 三项是否齐全。
