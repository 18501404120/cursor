# 线下分销费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 分销利润报表
- **页签**：年度 / 月度 / 国家 / 客户 / SKU
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（金蝶分销仓销售、分销订单运费、样品订单、海外仓、站外导入、分销利润报表）

---

## 1. 先看结论

线下分销费用项**不是页面即时现算**，而是：

1. 从金蝶 **分销客户仓** 销售订单取销售收入、税额、销售数量（按客户 + MSKU）；
2. 从分销订单取 **已报关** 的运费收入（按报关月份，不是下单月份）；
3. 样品订单取样品费（货值 + 头程 + 关税）；
4. 海外仓账单分摊为物流成本；站外导入佣金、推广等；
5. 页面按国家 / 客户 / SKU 聚合换汇展示。

分销利润报表的结果列叫 **销售利润**（不是「销售毛利」），公式与全渠道边际贡献对齐。

管报「销售额」= 销售收入 + 运费收入；「尾程运费 / FBA 物流」= 物流成本 + 尾程运费。不要只用销售收入或只拿尾程一列去对全渠道。

---

## 2. 数据从哪来

| 来源 | 用在哪些费用 | 说明 |
|------|----------------|------|
| 金蝶销售订单（分销仓） | 销售收入、税额、销售数量 | 指定组织+仓库，见 3.2 |
| 分销订单明细 | 运费收入 | 仅「已报关」，按报关时间落月 |
| 金蝶退货 / 导入 | 销售退款、销售折扣 | 折扣、退款以入账结果为准（常为导入或金蝶冲减） |
| 采购价快照 | 采购成本 | 数量 × 单价 |
| 头程物流单价 | 头程、关税 | 单件 × 数量 |
| 分销样品订单（已发货/部分发货） | 样品费、样品数量 | 货值 + 头程 + 关税 |
| 海外仓店铺汇总 | 物流成本（海外仓） | 按当月分销 MSKU 销售收入占比分到商品 |
| 站外费用导入 | 佣金、推广；物流成本导入任务现网已停 | 导入后分摊 |
| 渠道分摊 / 仓杂 | 运杂费 | 归集到运杂费列 |
| 客户主数据 | 客户、国家 | SKU 行带客户编码、国家 |

**主链路**：分销仓销售 → 运费收入（已报关）→ 货值物流样品 → 海外仓物流成本 → 导入佣金推广 → 页面展示。

---

## 3. 通用口径

### 3.1 统计粒度

- 明细：**店铺 + 客户 + MSKU + 月份**。
- 页面另有国家页、客户页。
- 内部 4 位小数，页面取整。展示币种按查询选择，原币先换到站点币种。

### 3.2 哪些金蝶仓算分销销售

现网按「组织 + 仓库名称」圈定分销仓，主要包括：

- Offline-Trading 分销客户仓（在途）；
- 智岩客户仓（在途）；
- Trading DE 分销客户仓。

不是这些仓的金蝶销售，不进分销利润报表。

店铺所属平台 = 分销；店铺名含 `offline-other` 会归分销。

### 3.3 分摊

- 海外仓物流成本：店铺层总额，按当月分销各 MSKU **销售收入占比** 分摊。
- 站外佣金 / 推广：指定商品则直接记，否则按净额或销售收入类占比分摊（与导入维度有关）。
- 匹配不到进空 MSKU。

---

## 4. 收入、税、退款、折扣、运费收入

### 4.1 销售收入

- 金蝶分销仓销售订单金额，换到展示币种。
- 页面列名「销售收入」；月度科目也有写成「销售额」的，指的是这一列 **不含运费收入**。

### 4.2 税额

- 金蝶销售税额。
- **全渠道「销售税 / VAT」**：本列。

### 4.3 销售数量

- 金蝶销售数量。

### 4.4 销售退款、销售折扣

冲减项。来源为入账后的退款、折扣子项（导入或金蝶冲减）。毛利和净额都要扣。

### 4.5 运费收入（容易错月）

- **来源**：分销订单明细里的运费金额。
- **只计报关状态 = 已报关**。
- **落月按报关时间所在月**，不是订单创建月。
- 查询会向前多看若干月订单（默认约 2 个月，可配置），再过滤报关月 = 本月，避免漏掉跨月报关。

**全渠道「销售额」** = 销售收入 + 运费收入。  
利润报表上这两列分开，对管报必须加总。

### 4.6 净额

**净额 = 销售收入 + 运费收入 − 销售退款 − 销售折扣 − 税额**

与全渠道「收入净额」一致。月度组装按此重算，不依赖「先加收入再忘扣税」。

---

## 5. 货值、样品、物流

### 5.1 采购成本

销售数量 × 采购单价。

**全渠道「发货成本」**：本列。分销没有单独退货成本列。

### 5.2 样品费

渠道 = 分销、订单类型 = 样品、发货状态 = 部分已发货或全部已发货。

**样品费 = 采购货值 + 头程 + 关税**（样品数量 × 对应单价）。

**全渠道「样品费」**：本列。不要和推广费合并。

### 5.3 头程运费、关税

正品销售的头程、关税（与样品费里的头程关税分开，样品已打进样品费）。

### 5.4 物流成本、尾程运费（两列，全渠道会合并）

| 利润报表列 | 现网主来源 |
|------------|------------|
| 物流成本 | 海外仓店铺汇总，按分销 MSKU 销售收入分摊 |
| 尾程运费 | 分销尾程类入账（海外仓尾程等） |

站外导入「物流成本」任务现网会清掉该来源中间表，**不要用导入物流成本去套现网「物流成本」列**。

**全渠道「尾程运费 / FBA 物流」** = 物流成本 + 尾程运费。

### 5.5 仓储费

仓储账单归属分销店铺。全渠道仓储费取本列（不分海外仓第二列；海外仓金额已进物流成本）。

### 5.6 运杂费

归集到运杂费列。全渠道单独一行「运杂费」，只对分销有数。

---

## 6. 推广费、佣金费

### 6.1 推广费

站外导入，落到分销店铺 / 商品。  
**全渠道「推广费」**：本列。与样品费分开。

### 6.2 佣金费

站外导入分摊。  
**全渠道「Commission Fee」**：本列。分销没有 OTIF、没有 4% 商超公式。

---

## 7. SKU / 客户 / 国家页怎么展示、利润怎么算

SKU 列：期间月、店铺、国家、客户、品线、sales、SKU、MSKU、币种、销售利润、利润率、销售收入、税额、销售退款、销售折扣、销售数量、运费收入、净额、采购、样品费、物流成本、尾程、头程、关税、仓储、推广、佣金、运杂费。

**销售利润**：

销售收入 + 运费收入  
− 税额 − 销售折扣 − 销售退款  
− 采购 − 样品费 − 物流成本 − 尾程 − 头程 − 关税 − 仓储  
− 推广 − 佣金 − 运杂费

利润率 = 销售利润 ÷ 净额。

月度 / 年度 / 全渠道边际贡献同一公式。

## 8. 月度科目与全渠道 / 管报列对照

| 管报 / 全渠道科目 | 线下分销取值 | 说明 |
|-------------------|--------------|------|
| 销售额 | 销售收入 + 运费收入 | 利润报表是两列 |
| 折扣 / 优惠合计 | 销售折扣 | — |
| 销售收款 | 销售额 − 折扣 | — |
| 销售退款 | 销售退款 | — |
| 销售税 / VAT | 税额 | — |
| 收入净额 | 销售收入 + 运费收入 − 退款 − 折扣 − 税 | 即净额 |
| 发货成本 | 采购成本 | — |
| 退货成本 / 平台赔偿 / 广告费 | 0 | — |
| 推广费 | 导入推广 | — |
| 样品费 | 样品货值 + 头程 + 关税 | — |
| 头程运费 | 头程运费 | 不含已打进样品费的部分 |
| 尾程运费 / FBA 物流 | 物流成本 + 尾程运费 | 两列合并 |
| 仓储费 | 仓储费 | — |
| 关税 | 关税 | — |
| Commission Fee | 佣金费 | — |
| 运杂费 | 运杂费 | 仅分销 |
| 平台服务费 / 收单 / 店铺费用 / FBA 佣金 | 0 | — |
| 边际贡献 | 与第 7 节销售利润一致 | — |

全渠道表头对分销尾程的提示有时只写「物流成本」，现网合并时仍加上尾程列，对账以两列之和为准。

---

## 9. 必须记住的特殊规则

1. **管报销售额必须加运费收入。**
2. **运费收入按报关月、且必须已报关**，会与订单月不一致。
3. **样品费已含样品的头程关税**，不要再把样品头程加进头程列去对样品订单。
4. **全渠道尾程 = 物流成本 + 尾程**，利润报表是两列。
5. 站外导入物流成本不是现网物流成本列的主来源。
6. 结果列名称是「销售利润」，不是「销售毛利」。
7. 只含分销仓销售，不要把商超 Trading 仓订单并进来。

---

## 10. 给管报初始化的用法

1. 优先对月度 / 全渠道合并结果。
2. 运费收入单独核对报关清单，不要用未报关订单运费。
3. 样品费、推广费、佣金三列不要混。
4. 刷新顺序：金蝶分销仓销售、报关运费、样品发货、海外仓汇总都跑完，报表才准。

## 11. 费用项速查

| 页面名称 | 一句话取值 |
|----------|------------|
| 销售收入 | 金蝶分销客户仓销售金额 |
| 税额 | 金蝶税额 |
| 运费收入 | 分销订单已报关运费，按报关月 |
| 销售退款 / 销售折扣 | 入账冲减项 |
| 净额 | 销售收入 + 运费收入 − 退款 − 折扣 − 税 |
| 采购成本 | 销售数量 × 采购单价 |
| 样品费 | 分销样品订单货值 + 头程 + 关税 |
| 物流成本 | 海外仓店铺汇总，按销售收入分摊 |
| 尾程运费 | 分销尾程入账 |
| 头程 / 关税 / 仓储 | 正品物流与仓储 |
| 推广费 / 佣金费 | 站外导入 |
| 运杂费 | 分摊/归集的运杂 |
| 销售利润 | 净额再扣采购、样品、两列物流、头程关税仓储、推广佣金运杂 |
