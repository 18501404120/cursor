# 商超 3P 费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 商超利润报表（筛选平台 = 新渠道商超 3P）
- **页签**：年度 / 月度 / 零售商 / 国家 / SKU；与线下商超同一张表、同一套商超费用结构
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（金蝶 Trading 销售/退货、3P 店铺名单、站外导入、商超利润报表）

---

## 1. 先看结论

商超 3P **不是另一套利润引擎**。它和线下商超共用：

- 同一张「商超利润报表」；
- 同一套费用子项和毛利公式；
- 同一套金蝶组织（Trading / Trading US）取数；
- 同一套站外导入分摊（按零售商销售收入占比）。

差别是 **店铺归属**：配置名单里的 3P 门店（默认 Walmart、Best Buy、Lowe's）记到「新渠道商超 3P」，其余 Offline-US / Offline-CA 记到线下商超。

全渠道经营报表对这两个平台走 **同一套商超科目映射**。管报初始化按渠道切开店铺即可，不要改公式。

---

## 2. 店铺怎么划到 3P

同时满足下面任一规则，即归 3P（现网以配置名单为主，店名规则用于物流/仓等侧识别）：

| 规则 | 现网默认 |
|------|----------|
| 配置的 3P 店铺名单 | 默认三家：Walmart、Best Buy、Lowe's（名单可追加，不必改计算逻辑） |
| 店铺名包含 | `wm 3p-us`、`wm 3p-ca`、`bby 3p-us`、`lowes 3p-us` |

- 3P 行币种按 **美元**、站点按美国处理。
- 不是上述店铺、且是 Offline-US / Offline-CA 的，归线下商超。
- 商超利润报表店铺下拉同时含两类，**取 3P 渠道必须过滤 3P 店铺**。

金蝶销售/退货一次拉取「商超 + 3P」，再按店铺写入对应平台，避免同一张金蝶订单两边各记一次。

---

## 3. 和线下商超完全相同的费用项

下列与《线下商超费用项取值逻辑》一致：

| 科目 | 口径摘要 |
|------|----------|
| 销售收入 / 销售税 / 销售数量 | 金蝶 Trading 销售，换美元 |
| 退货数量 | 金蝶退货 |
| 销售折扣 | 导入：Advertising Fees + 价保 + Trade Allowance |
| 现金折扣 | 导入，按零售商本月销售收入占比；无收入用最近有收入月 |
| 销售退款 | 导入：RMA + Shortage − Dispute Back |
| 净收入 SKU | 销售收入 − 两折扣 − 退款（不扣税） |
| 净收入月度 / 全渠道 | 上式再减销售税 |
| 采购 / 头程 / 关税 | 数量 × 单价 |
| 尾程 | 海外仓店铺尾程汇总 |
| 仓储 / 海外仓 | 分列；全渠道合并 |
| 佣金 | **导入额**，不是页面 4% 提示 |
| 广告宣传费 | 订单投入 + 非订单投入 |
| OTIF | 导入；全渠道进平台服务费 |
| 销售毛利 | 净收入 − 采购 − 头程 − 关税 − 尾程 − 海外仓 − 佣金 − 广告 − 推广 − OTIF − 仓储 |

币种、分摊、空 MSKU、精度规则相同。

---

## 4. 3P 与线下商超的关键差异

### 4.1 样品推广费不会自动落到 3P

线下商超推广费 = 领料部门「销售中心-线下商超」样品订单的货值 + 头程 + 关税。  
现网这段计算把平台 **写死为线下商超**，因此：

- 线下商超：有自动样品推广；
- 3P：利润报表「推广费」通常为 0，除非另有导入或其他手工入账。

全渠道「样品费」对 3P 也按利润报表推广费取，多数月份为 0。不要把线下商超样品费按零售商再拆一份给 3P。

### 4.2 广告 / 佣金 / OTIF / 退款必须按 3P 店铺导入

站外导入带店铺平台。导入到商超店铺的不会自动出现在 3P。3P 要对齐管报，需要 **按 3P 店铺分别导入** 折扣、退款、广告、OTIF、佣金、海外仓等。

### 4.3 尾程、仓储仍看 3P 店铺的海外仓汇总

海外仓店铺汇总按店铺 ID 挂。3P 门店要有对应海外仓归属，尾程/海外仓才进 3P；否则费用会留在线下商超店铺。

### 4.4 页面提示同样滞后

3P 在同一张 SKU 表上，佣金列仍提示 4% 公式，现网同样已改为导入佣金。净收入表头仍不写扣税，月度仍扣税。

---

## 5. SKU 页与毛利

列结构与线下商超相同。零售商一般是对应 3P 客户（Walmart / Best Buy / Lowe's 等）。

毛利公式见第 3 节。SKU 用未扣税净收入，月度 / 全渠道用扣税净收入。

---

## 6. 月度科目与全渠道 / 管报列对照

全渠道对「商超」和「商超 3P」走同一套映射，对照表与线下商超文档第 8 节相同。渠道切分只看店铺：

| 管报 / 全渠道科目 | 商超 3P 取值 |
|-------------------|--------------|
| 销售额 | 3P 店铺金蝶销售收入 |
| 折扣 | 3P 店铺销售折扣 + 现金折扣 |
| 销售退款 | 3P 店铺导入退款 |
| 销售税 / VAT | 3P 店铺销售税 |
| 收入净额 | 收入 − 两折扣 − 退款 − 税 |
| 发货成本 | 采购成本 |
| 推广费（全渠道列） | 广告宣传费合计 |
| 样品费（全渠道列） | 利润报表推广费（通常无自动样品，多为 0） |
| 头程 / 关税 / 尾程 | 3P 店铺对应金额 |
| 仓储费 | 海外仓 + 仓储 |
| 平台服务费 | OTIF |
| Commission Fee | 导入佣金 |
| 边际贡献 | 与商超毛利公式一致（扣税净收入） |

---

## 7. 必须记住的特殊规则

1. **公式同线下商超，店铺不同。**
2. **样品推广自动计算不进 3P。**
3. **导入费用必须挂 3P 店铺**，否则对不上。
4. 佣金不是 4%；净收入 SKU 不扣税、管报扣税。
5. 全渠道「推广费 / 样品费」列名与利润报表对调关系，与线下商超相同。
6. 新增 3P 门店以配置名单追加为准，不必改费用公式。

---

## 8. 给管报初始化的用法

1. 从商超利润报表或全渠道表过滤 **平台 = 商超 3P**（或直接按 3P 店铺清单筛）。
2. 不要用「商超合计 − Offline-US/CA」当定义；可以拿来核对店铺有没有漏划。
3. 样品费不要从线下商超分摊过来。
4. 佣金、OTIF、广告以 3P 导入结果为准。

---

## 9. 费用项速查

| 页面名称 | 一句话取值 |
|----------|------------|
| 销售收入 | 金蝶 Trading 销售，仅 3P 店铺 |
| 销售税 / 折扣 / 现金折扣 / 退款 | 与线下商超相同算法，限 3P 店铺与对应导入 |
| 净收入 | SKU 不扣税；月度/管报扣税 |
| 采购 / 头程 / 关税 / 尾程 / 仓储 | 同线下商超，限 3P 店铺 |
| 佣金 | 3P 店铺导入分摊，不是 4% |
| 广告宣传费 | 3P 导入的订单 + 非订单投入 |
| 推广费 | 自动样品逻辑不跑 3P，通常为 0 |
| OTIF | 3P 导入；全渠道进平台服务费 |
| 销售毛利 | 与线下商超同一公式 |
