# 线下商超费用项取值逻辑（产品口径）

- **对应页面**：财务系统 → 报表 → 商超利润报表（筛选平台 = 商超，不含商超 3P 店铺）
- **页签**：年度 / 月度 / 零售商 / 国家 / SKU
- **整理视角**：产品经理口径，不体现系统内部字段名
- **用途**：全渠道管报初始化取数、对账、费用项映射
- **整理日期**：2026-09-18
- **依据**：财务系统现网前后端实现（金蝶 Trading 销售/退货、站外导入、样品出库、海外仓、商超利润报表）

---

## 1. 先看结论

线下商超费用项**不是页面即时现算**，而是：

1. 从金蝶 **Trading / Trading US** 组织取销售订单、退货单，按店铺拆成销售收入、销售税、销售数量、采购、头程、关税；
2. 站外导入折扣、现金折扣、退款、广告、OTIF、佣金、海外仓等，按 **零售商销售收入占比** 分到 MSKU；
3. 推广费按「销售中心-线下商超」样品订单的货值 + 头程 + 关税计算；
4. 页面查询时换汇（商超统一按美元汇总）后展示。

商超利润报表店铺下拉同时含 **商超** 和 **商超 3P**。本渠道只取：

- 店铺 **Offline-US、Offline-CA**（线下商超主店铺）；
- 不属于配置名单里的 3P 门店。

Wayfair 现网已拆成独立平台，**不要按线下商超去取 Wayfair**。

SKU / 零售商页与月度页对「净收入是否扣税」不一致，管报初始化以 **月度 / 全渠道（扣税）** 为准。

## 2. 数据从哪来

| 来源 | 用在哪些费用 | 说明 |
|------|----------------|------|
| 金蝶销售订单（Trading、Trading US） | 销售收入、销售税、销售数量 | 本位币金额换到美元 |
| 金蝶退货单 | 退货数量；采购/头程/关税用销售与退货数量 | 销售退款金额不从金蝶直接当「退款列」，退款列主要来自导入 |
| 采购价快照 | 采购成本 | 销售数量口径 × 单价 |
| 头程物流单价 | 头程运费、关税 | 按出库仓取单件 × 数量 |
| 站外费用导入 | 销售退款、销售折扣、现金折扣、广告（订单/非订单）、OTIF、佣金、海外仓等 | 有零售商则按该零售商当月 SKU 销售收入占比分摊 |
| 样品订单 + 金蝶其他出库 | 推广费 | 领料部门 = 销售中心-线下商超；货值 + 头程 + 关税 |
| 海外仓店铺汇总 | 尾程运费（现网主路径） | 挂到对应店铺；站外导入尾程分摊任务现网已停 |
| MSKU 关系快照 | SKU 归属、零售商 | 匹配不到进空 MSKU |

**主链路**：金蝶销售/退货 → 拆数量与货值物流 → 导入费用按销售收入分摊 → 样品推广入库 → 页面按零售商 / 国家 / SKU 展示。

## 3. 通用口径

### 3.1 统计粒度

- 明细：**店铺 + 零售商 + MSKU + 月份**。
- 页面还有国家页（按零售商国家）。
- 币种：**统一美元**。
- 内部 4 位小数，页面取整。

### 3.2 店铺怎么划到线下商超

- 店铺所属平台 = 商超。
- 店铺名含 `offline-us` / `offline-ca` 归商超。
- 配置名单中的 WM / BBY / Lowe's 等 3P 店铺归 **商超 3P**，本渠道不含。

### 3.3 站外费用怎么分到 SKU

导入时：

1. **指定了零售商**：按该零售商本月各 SKU **销售收入占比** 分摊；若当月该零售商无收入，用**往前最近一个月有收入**的 SKU 占比；
2. **未指定零售商、只到店铺**：按店铺本月 SKU 销售收入占比分摊；
3. 仍匹配不到：进空 MSKU 行。

现金折扣列头提示与上述规则一致。

### 3.4 正负号

商超利润报表费用列按**费用为正**展示。毛利公式对费用取反。

## 4. 收入、折扣、退款、税

### 4.1 销售收入

- **来源**：金蝶销售订单本位币金额，换到美元。
- **全渠道「销售额 / 销售收款」**：销售收入（收款还要再减折扣，见下）。

### 4.2 销售税

- 金蝶销售订单税额，换到美元。
- **全渠道「销售税 / VAT」**：本列。

### 4.3 销售数量、退货数量

- 销售数量：金蝶销售订单数量。
- 退货数量：金蝶退货单数量。

### 4.4 销售折扣

页面提示：

**销售折扣 = Advertising Fees（冲减收入）+ Price Protection Deduction + Trade Allowance**

来源是站外导入，不是金蝶促销字段。按零售商 / 店铺销售收入分摊。

### 4.5 现金折扣

站外导入。分摊规则见 3.3。

**全渠道「折扣 / 优惠合计」** = 销售折扣 + 现金折扣。

**全渠道「销售收款」** = 销售收入 − 销售折扣 − 现金折扣。

### 4.6 销售退款

页面提示：

**销售退款 = RMA + Shortage − Dispute Back**

来源是站外导入，按销售收入占比分摊。不要用金蝶退货金额直接当本列。

### 4.7 净收入（两套口径，必须分开）

| 页面 | 公式 |
|------|------|
| SKU / 零售商 / 国家（页面提示） | 销售收入 − 销售折扣 − 现金折扣 − 销售退款 **（不扣税）** |
| 月度 / 年度 | 上式再 **减去销售税** |
| 全渠道「收入净额」 | 与月度相同，扣税 |

管报初始化用 **扣税后的净收入**。用 SKU 页净收入去对全渠道会偏大（少扣了税）。

落库的「净额」子项按不扣税公式计算；月度页展示时重算并扣税。

## 5. 货值与物流

### 5.1 采购成本

销售数量 × 采购单价（当月快照），换到美元。

**全渠道「发货成本」**：本列。商超没有单独「退货成本」列。

### 5.2 头程运费、关税

出库仓对应的单件头程、单件关税 × 数量。销售与退货仓库数量会合并后再取价。

### 5.3 尾程运费

现网主路径：海外仓 **店铺维度汇总的尾程**，挂到商超店铺。  
站外导入「尾程运费」分摊任务现网已关掉，不要按导入尾程去套利润报表本列。

**全渠道「尾程运费 / FBA 物流」**：本列。

### 5.4 海外仓费用、仓储费

利润报表 **分两列**。海外仓也可来自导入。仓储来自仓储账单。

**全渠道「仓储费」** = 海外仓费用 + 仓储费。全渠道表头提示写「商超：海外仓费用」，现网合并时仍把仓储费加进去，对账以合并结果为准。

---

## 6. 佣金、广告、推广、OTIF

### 6.1 佣金费（页面提示与现网计算不一致）

SKU 列表头仍写：

**佣金 =（净收入 − 广告费（订单投入）− OTIF）× 4%**

现网月度 / SKU 组装里，**这条 4% 公式已停用**。佣金取 **站外导入的佣金费**，再按销售收入分摊。

管报初始化按 **导入并分摊后的佣金**，不要用 4% 反算。广告「仅订单投入参与佣金计算」的提示，是旧公式遗留。

**全渠道「Commission Fee」**：导入佣金。

### 6.2 广告宣传费

导入后分两块，页面加总为一列：

| 构成 | 说明 |
|------|------|
| 广告宣传费（订单投入） | 旧佣金公式曾扣这一块 |
| 广告宣传费（非订单投入） | 不参与旧 4% 公式 |

**全渠道「推广费」列（注意列名）**：商超映射的是 **广告宣传费合计**，不是利润报表上的「推广费」。

### 6.3 推广费（样品）

页面提示：**发给客户的样品的货值 + 运费 + 关税**。

现网：当月领料部门 = 销售中心-线下商超 的样品订单，物流计划发货后推金蝶其他出库，按出库数量取货值、头程、关税。

计算时平台被写死为 **线下商超**，因此本渠道有样品推广，3P 不会走这条自动样品逻辑。

**全渠道「样品费」**：商超利润报表的推广费（样品），不是广告。

### 6.4 OTIF 费用

站外导入，按销售收入分摊。

**全渠道「平台服务费」**：商超映射为 OTIF（不是佣金、也不是独立站那种平台服务费）。

## 7. SKU / 零售商页怎么展示、毛利怎么算

SKU 列：期间月、店铺、零售商、SKU、金蝶物料分组、MSKU、币种、销售毛利、毛利率、销售收入、销售税、销售数量、销售退款、销售折扣、现金折扣、净收入、退货数量、采购、头程、关税、尾程、海外仓、仓储、佣金、广告宣传费、推广费、OTIF。

**销售毛利**（SKU / 零售商，净收入不扣税）：

净收入（不含税口径）  
− 采购 − 头程 − 关税 − 尾程 − 海外仓 − 佣金 − 广告宣传费 − 推广费 − OTIF − 仓储

毛利率 = 销售毛利 ÷ 净收入。

**月度 / 全渠道毛利**用扣税后净收入，其余扣项相同。因此 **SKU 毛利加总 ≠ 月度毛利**（税差）。

## 9. 必须记住的特殊规则

1. **净收入 SKU 不扣税、月度/全渠道扣税**。
2. **佣金现网是导入额，不是 4%**；表头提示落后于代码。
3. **全渠道「推广费」= 广告宣传费，全渠道「样品费」= 商超推广费**，和利润报表列名对不齐。
4. 销售退款、折扣来自导入口径（RMA / Advertising Fees / 价保 / Trade Allowance），不是金蝶销售字段。
5. 样品推广只跑线下商超平台。
6. 尾程以海外仓店铺汇总为准，导入尾程任务已停。
7. 与 3P 同页，必须按店铺切开。

---

## 10. 给管报初始化的用法

1. 用月度 / 全渠道扣税净收入和毛利，不要直接拷贝 SKU 净收入。
2. 佣金按导入结果，不要用 4% 重算。
3. 映射全渠道列时看第 8 节，避免把「推广费」对错行。
4. 只含 Offline-US / Offline-CA，不含 3P 配置店铺、不含 Wayfair。
