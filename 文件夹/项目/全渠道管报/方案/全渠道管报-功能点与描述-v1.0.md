# 全渠道管报项目功能点与描述

- 版本号：1.0
- 产出日期：2026-04-20
- 来源范围：`全渠道管报`目录下全部文件（需求、方案、项目规划、竞品调研、会议纪要、财务渠道逻辑表）

## 1. 统一经营分析底座

| 功能点 | 功能点描述 |
| --- | --- |
| 多源数据接入 | 对接亚马逊、独立站、App商城、TikTok、线下商超、分销、京东、小红书、Wayfair及ERP/费控/BP系统，形成统一可分析数据底座。 |
| 统一主数据管理 | 统一维护品牌、品类、产品线、SPU/SKU/MSKU、渠道、店铺、区域、组织、负责人等主数据，避免跨系统口径错位。 |
| 统一指标口径字典 | 建立销量、营收、净销售额、毛利、边际贡献、经营利润、达成率、同比等统一定义，支持版本化管理和变更留痕。 |
| 双轨口径管理（财务轨/业务轨） | 同时维护财务结账口径与业务经营口径，并沉淀差异解释规则，支撑“过程管理可用、月结可对账”。 |
| 收入确认链路标准化 | 统一“销售额→折扣→退款→税费/VAT→收入净额”的计算链路，明确不同渠道字段映射与取值规则。 |
| 全渠道费用项标准清单 | 建立跨渠道统一费用项字典（广告、推广、样机、物流、仓储、平台费、返利、服务费等），并定义归属层级。 |

## 2. 渠道与SKU损益分析

| 功能点 | 功能点描述 |
| --- | --- |
| SKU+渠道损益模型 | 以SKU/MSKU+渠道为最小分析颗粒度，计算并展示收入、成本、费用、利润，支持单品单渠道盈利判断。 |
| 多维下钻分析 | 支持“公司→渠道→区域→品类→MSQ/MSKU”逐级下钻，快速定位利润、增长或偏差来源。 |
| 同比分析（同区间） | 按选择区间自动提供去年同期同区间对比，满足月中过程管理（如1-10日、1-24日）需求。 |
| 新品同比边界处理 | 对无去年同期MSKU的新品默认不展示同比，并提供标识说明，避免错误对比。 |
| 渠道结构分析 | 支持线上/线下、平台/自营、区域渠道结构对比，识别增长渠道与低效渠道。 |
| 产品结构分析 | 支持按品类/产品线对销售、费用、利润贡献进行结构分析，辅助资源配置和产品策略调整。 |

## 3. 费用归集与分摊引擎

| 功能点 | 功能点描述 |
| --- | --- |
| 五层归属规则 | 费用支持订单级、SKU级、店铺/渠道级、品牌/品类级、公司共享级归属。 |
| 直接归属能力 | 对可直接关联订单或SKU的费用（如订单级平台费、可映射广告费）直接落单，不走二次分摊。 |
| 分摊池机制 | 支持渠道费用池、品牌费用池、公司共享费用池分层管理，按规则分摊回SKU/渠道。 |
| 分摊基数配置 | 支持按销售额、净销售额、销量、出货量、库存、毛利、固定比例等多基数分摊，并可按费用类型配置。 |
| 广告费用归集 | 支持站内广告（SP/SB/SD/SBV）和站外广告（Google/Meta/TikTok等）接入、归集与分摊。 |
| 样机费用分层管理 | 支持市场样机、研发样机、测试样机分类管理，避免样机费用口径混淆。 |
| 物流仓储成本归集 | 支持头程、尾程/FBA、退货物流、仓储、海外仓、关税等物流链路成本归集。 |
| 平台交易费用归集 | 支持佣金、服务费、收单费、店铺费、风控费等平台费用接入与归集。 |
| 费用可追溯性 | 每项费用可追溯来源系统、单据、期间、币种、分摊规则，支持审计和复盘。 |

## 4. BP预算联动能力

| 功能点 | 功能点描述 |
| --- | --- |
| BP与管报同源 | BP与管报使用同一主数据、同一费用结构、同一利润结构和同一分析颗粒度。 |
| BP对象管理 | 支持按渠道、区域、品类、MSQ/MSKU、费用项、负责人建立预算对象。 |
| BP达成进度计算 | 按所选时间窗口自动计算预算进度达成率，支持过程管理。 |
| 预算-实际偏差分析 | 自动计算预算与实际差异，并按销量、价格、费用、结构等维度归因。 |
| 滚动预测支持 | 在预算执行中支持滚动预测与动态调整，推动预算从“静态快照”升级为“动态计划”。 |

## 5. GTM过程管理与导出能力

| 功能点 | 功能点描述 |
| --- | --- |
| 一体化宽表导出 | 导出结果内置当期值、去年同期值、同比、BP目标、BP达成等字段，减少表外二次清洗。 |
| 阈值筛选与异常清单 | 支持按规则（如达成率<80%）一键筛选异常渠道/MSQ/MSKU，形成整改清单。 |
| 统一看板视图 | 支持把同比和BP对照放在同一视图中，减少多看板切换和重复操作。 |
| 月中经营快报 | 支持月中多节点（如10日/24日）快速查看进度与偏差，提升运营纠偏时效。 |

## 6. 预算分发与填报协同

| 功能点 | 功能点描述 |
| --- | --- |
| 系统分发机制 | 系统按组织与负责人自动分发SKU级填报任务，不再依赖“下载-填表-上传”。 |
| 在线填报与批量导入 | 同时支持在线录入与模板导入，覆盖不同团队操作习惯。 |
| 自动汇总与版本控制 | 自动汇总各责任人数据并保留版本，避免手工合并和版本混乱。 |
| 历史预填能力 | 基于历史数据进行预算预填（如样机、营销费用），降低填报成本。 |

## 7. 数据治理与对账校验

| 功能点 | 功能点描述 |
| --- | --- |
| 三类校验机制 | 支持订单/平台校验、经营/财务校验、预算/实际校验，保障核心指标可信。 |
| 口径差异解释机制 | 对“业务口径 vs 财务口径”差异提供结构化解释与追溯，减少会议扯皮。 |
| 数据时效分层 | 支持日级过程数与月级结账数并存，明确数据状态与可用场景。 |
| 映射血缘可视化 | 支持字段、映射、分摊规则血缘追踪，解决“配置黑盒”问题。 |
| 数据质量问题闭环 | 支持问题登记、责任归属、修复验证闭环，持续提升口径稳定性。 |

## 8. 管理驾驶舱与决策输出

| 功能点 | 功能点描述 |
| --- | --- |
| 管理层驾驶舱 | 展示营收、净销售额、毛利、边际贡献、经营利润、预算偏差、关键风险。 |
| 渠道经营看板 | 展示各渠道规模、利润、费用结构、投产比、达成率、同比表现。 |
| 费用结构看板 | 展示广告、物流、仓储、平台费、样机、返利等费用结构与变化趋势。 |
| 预算执行看板 | 展示预算执行进度、偏差归因、预测趋势、纠偏建议。 |
| 经营复盘输出 | 支持按渠道/品类/SKU生成复盘报表，支撑月度经营会与管理决策。 |

## 9. 实施与里程碑支持能力

| 功能点 | 功能点描述 |
| --- | --- |
| 分阶段交付管理 | 支持一期（基础损益）、二期（费用深化）、三期（BP闭环）分阶段建设与验收。 |
| 验证样例管理 | 支持口径一致性、SKU损益样例、费用归集样例、BP联动样例验证。 |
| 过渡期双轨运行 | 支持老口径与新口径并行对比，保障系统切换期间业务可连续运行。 |
| 时间节点保障 | 支持围绕“字段定义上线、分发上线、BP切换”进行项目节点跟踪与风险预警。 |
