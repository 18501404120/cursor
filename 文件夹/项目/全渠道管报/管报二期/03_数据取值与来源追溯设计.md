# 数据取值与来源追溯设计

## 1. 数据设计目标

二期数据设计的核心是建立统一追溯链路：

`管报汇总金额 -> 费用明细 -> 来源记录 -> 来源单据/规则/批次 -> 计算过程 -> 财报对照`

任何页面汇总金额，都不应只保存一个结果数，而应能追溯到构成它的明细和来源。

## 3. 主取值模式与追溯方式

| 主取值模式 | 一期取值重点 | 二期追溯重点 |
| --- | --- | --- |
| 业务系统单据取数 | 从金蝶销售出库单、销售退货单、GTM 等取订单和成本 | 单据号、订单号、物料、客户、部门、金额、审核状态 |
| 平台报告取数 | 从亚马逊交易报告、广告报告等取费用字段 | 报告名称、报告期间、交易类型、订单号、原始字段 |
| 项目预算取数 | 项目立项通过后按预算金额进入管报 | 项目编号、预算行号、收益日期、营销类型、预算金额 |
| 费用导入分摊 | 按归属月、费用项、金额、费用部门导入并分摊 | 导入批次号、导入行、范围条件、分摊模式、写入状态 |
| 计提/扣款规则计算 | 按客户计提规则、销售收入、实际扣款计算 | 客户、费用项、计提方式、比例/固定金额、销售收入、实际扣款、计提扣款 |
| 退款规则计算 | 按滚动退款率和目标窗口计算当月计提退款 | 客户、期间、滚动率、目标窗口、实际退款、期初/期末余额 |
| 比例/参数计算 | 按费率、尺寸、数量、天数等参数计算 | 参数版本、适用范围、输入数量、单价/费率、计算公式 |
| 财务系统同口径取数 | 直接取财务字段金额 | 标记为无明细来源，仅展示来源类型、期间、金额、币种/汇率、取值口径；不展示凭证号、科目、核算维度、账簿 |
| 汇总公式计算 | 由下级费用项汇总 | 下级费用项构成、汇总公式、参与明细 |

## 5. 来源追溯链路

### 5.1 直接取数类

`汇总金额 -> 费用事实 -> 来源单据行 -> 来源单据头 -> 原系统单据`

适用：销售收入、销售退货、平台交易报告费用，以及**出货授权成本 / 退货成本下的末级**（采购成本、关税、预留毛利）。

出货授权成本、退货成本本身不再走本链路，见 §5.6。

若来源单据不能提供稳定行号，则只保留来源单据头或来源汇总记录，费用事实标记 `no_detail_flag=Y`，页面展示“该来源无明细下钻”。

### 5.2 导入分摊类

`汇总金额 -> 分摊明细 -> 费用事实 -> 导入批次行 -> 导入批次 -> 原始导入文件`

适用：品牌联合投放、临时推广、样品、线下商超进场费等。

### 5.3 项目预算类

`汇总金额 -> 分摊明细 -> 费用事实 -> 项目预算行 -> 项目立项`

适用：项目立项预算通过后进入管报的营销费用。

### 5.4 计提/扣款类

`汇总金额 -> 费用事实 -> 规则运行结果 -> 客户计提规则版本 -> 销售收入/实际扣款/部门明细`

适用：促销扣款、销售折扣、现金折扣、销售费用。

### 5.5 退款滚动类

`汇总金额 -> 费用事实 -> 退款台账结果 -> 滚动率计算明细 -> 销售收入/实际退款`

适用：销售退款计提。

### 5.6 汇总公式类

`汇总金额 -> 下级费用项汇总 -> 下级费用明细 -> 各自来源链路`

适用：市场投入合计、公共费用合计、贡献利润、营业利润；以及 **出货授权成本、退货成本**。

出货授权成本 / 退货成本：

- 父级金额 = 采购成本 + 关税 + 预留毛利，不再直接取出货授权价。
- 费用事实落在六个末级；父级只存汇总结果，追溯先到三个末级，再进入各末级的单据链路。
- 看板默认只展示父级打包金额；展开树后才看末级。
- 本项树变更上线时，已运行月与已关账月全部按新树重取数并覆盖原父级快照，不沿用「已关账冻结不回溯」。

`T020102` / `T020202` 为货值侧授权关税，与仓储物流路径下的关税/头程分列，禁止串用来源。

## 6. 关键控制点

1. 来源字段必填
   - 每条 `mgmt_expense_fact` 至少要有 `source_type + source_doc_id`，规则计算类至少要有 `rule_run_id`。

2. 分摊前后可对上
   - 同一来源行的分摊后金额合计应等于分摊前金额，允许汇率和四舍五入差异单独记录。

3. 已关账月冻结
   - 常规规则：已关账月的 `data_batch` 和 `is_frozen` 固定，页面展示冻结快照。
   - **例外**：出货授权成本 / 退货成本下拆上线时，已关账月也按新树重取末级并重算父级，覆盖原快照。

4. 财务覆盖可解释
   - 若 `是否财务定稿覆盖=是`，必须记录覆盖来源、覆盖金额、覆盖原因和审批/定稿信息。

5. 历史过渡口径单独标记
   - 历史分不开的费用项要保留 `是否历史过渡口径`，分析页面默认可筛选或标注。

6. 无明细来源单独标记
   - 财务系统同口径取数、部分不能提供稳定行号的业务单据，只保留来源汇总记录，不强制生成来源行。
   - 页面允许从费用明细查看来源摘要，但不提供原始行级明细下钻。
