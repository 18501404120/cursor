# 待确认事项

## 1. 费用项与口径

1. `字段取值逻辑-V4归类版` 是否作为二期费用项取值逻辑的冻结基线。
2. 费用项主数据以原型 `fee-item-master-data.json` 还是 Excel 中 `管报费用项清单/字段取值逻辑-V4归类版` 为准。
3. 费用项编码是否需要统一重编，避免原型和 Excel 编码不一致。
4. 汇总公式类费用项是否只展示汇总，不生成来源单据，还是生成虚拟来源记录。
5. 历史过渡口径费用项是否默认参与趋势分析。

## 2. 来源单据

1. 已确认：金蝶销售出库单、销售退货单、费用凭证等原始单据大部分可以提供稳定单据号和行号；无法提供稳定行号的单据标记为无明细来源，只展示来源摘要。
2. 亚马逊交易报告、广告报告等平台报告是否能保留原始报告文件和报告行唯一键。
3. 已确认：财务同口径取数不展示凭证号、科目、核算维度、账簿，标记为无明细来源，只展示来源摘要。
4. 导入批次的原始文件是否需要长期留存。
5. 项目预算行是否有正式项目编号和预算行编号。

## 3. 分摊与计算

1. 按营收占比分摊时，营收基数采用净收入、销售收入还是正向销售收入。
2. 分摊到日时，无法归到天的数据是否一律按归属月天数均摊。
3. 分摊尾差如何处理，是落到金额最大行，还是单独尾差行。
4. 已确认：计提/扣款规则变更后，未关账月自动重跑。
5. 已确认：已关账月如需更正，走差额调整，不覆盖原数据。

## 4. 页面与权限

1. 二期页面入口放在“管报”下，还是“费用管理”下。
2. 是否允许业务用户看到原始单据金额、客户、凭证等敏感信息。
3. 导出明细是否需要按角色控制字段脱敏。
4. 财报差异处理是否只允许财务角色维护。
5. 管报费用总览默认展示 USD，还是按币种和 USD 同时展示。

## 5. 定稿与关账

1. 定稿状态枚举是否沿用模板中的未定稿、业务预估、财务定稿、已锁定。
2. 财务定稿覆盖的审批链和记录字段由哪个模块提供。
3. 已锁定月份是否允许查看最新重算模拟值，还是只能查看冻结值。
4. 数据批次命名规则和保留周期。
5. 管报进库和财务关账的先后关系。

## 6. 对账与差异

1. 哪些费用项必须与财报验平。
2. N:M 对照关系的差异如何归因。
3. 财务金额为 0 时差异率展示规则。
4. 差异阈值是否按费用项、渠道、金额级别分别配置。
5. 差异处理结果是否需要进入审计日志。
