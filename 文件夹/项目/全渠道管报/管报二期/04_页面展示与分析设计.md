# 页面展示与分析设计

## 1. 菜单建议

建议在全渠道管报下增加或完善以下菜单：

- 管报费用总览
- 费用项分析
- 费用明细
- 来源单据追溯
- 财报对照差异
- 数据批次与定稿

如果菜单需要更轻量，也可以只放一个入口：`管报费用分析`，内部用页签承载总览、明细、来源、差异。

## 2. 管报费用总览

### 2.1 页面布局

1. 顶部筛选区
   - 月份范围、日期范围
   - 渠道、店铺、国家
   - MSKU、SKU、产品名称
   - 费用部门
   - 费用项
   - 主取值模式
   - 数据批次、定稿状态

2. 汇总卡片
   - 净收入
   - 市场投入
   - 公共费用
   - 贡献利润
   - 营业利润
   - 财报差异金额

3. 费用项树形表
   - 费用项路径
   - 金额
   - 金额 USD
   - 占净收入比
   - 环比
   - 同比
   - 是否分摊
   - 主要来源
   - 定稿状态
   - 操作：分析、明细、差异

### 2.2 交互规则

- 默认展示最近一个未锁定月份。
- 费用项树默认展开到二级，末级按需展开。
- 点击金额进入费用明细，并自动带入当前筛选条件和费用项。
- 点击费用项名称进入费用项分析。
- 财务定稿覆盖金额需显示标识。

## 3. 费用项分析

### 3.1 分析对象

分析对象可以是：

- 单个末级费用项。
- 一个费用项父级。
- 多个费用项组合。
- 某个渠道/店铺/MSKU 下的费用项。

### 3.2 分析模块

| 模块 | 内容 |
| --- | --- |
| 趋势 | 月度金额趋势、环比、同比 |
| 结构 | 按渠道、店铺、MSKU、费用部门、来源类型拆分 |
| 来源 | 自动取数、导入、项目预算、规则计算、财务同口径的金额占比 |
| 分摊 | 分摊前金额、分摊后金额、分摊规则、异常分摊 |
| 差异 | 管报金额、财务金额、差异金额、差异率 |
| 利润影响 | 对贡献利润、营业利润的影响 |

### 3.3 异常提示

建议二期支持以下异常标签：

- 无来源单据
- 无明细来源
- 来源单据金额不一致
- 分摊合计不等于分摊前金额
- 费用部门为空或禁止直选部门
- 已定稿月仍有未定稿明细
- 财报差异超过阈值
- 负数方向异常
- 历史过渡口径

## 4. 费用明细

### 4.1 列表字段

费用明细列表应以 `MSKU店铺费用明细` 模板为基础扩展追溯字段。

建议列：

| 列组 | 列 |
| --- | --- |
| 时间 | 月份、日期 |
| 经营维度 | 渠道、店铺、国家、MSKU、SKU、产品名称、SKU归属部门 |
| 费用归属 | 费用部门、费用大类、费用子类、场景L1、场景L2、场景L3、费用项 |
| 金额 | 正/负数、金额、币种、汇率、金额USD |
| 分摊 | 是否分摊、分摊规则、分摊基数、分摊前金额、分摊比例 |
| 来源 | 主取值模式、取值来源、来源单据类型、单据号、来源行号、导入批次号、规则运行编号 |
| 管理 | 是否导入、是否财务定稿覆盖、是否历史过渡口径、数据批次、定稿状态、备注 |

### 4.2 操作

- 查看来源：打开来源单据详情。
- 无明细来源：财务同口径取数、来源单据无稳定行号等记录仅打开来源摘要，不展示行级明细。
- 查看计算：打开分摊/计提/退款/扣款计算过程。
- 查看差异：跳转财报对照差异。
- 导出：按当前筛选导出明细。

### 4.3 明细查询规则

- 从总览点击金额进入时，继承总览筛选条件。
- 支持费用项多选，但默认只查当前费用项及其下级。
- 已定稿数据默认展示冻结批次。
- 未定稿数据默认展示最新批次。

## 5. 来源单据详情

### 5.1 页面结构

1. 顶部基础信息
   - 来源类型、来源编号、归属月、单据日期、状态、来源系统、数据批次。

2. 来源金额
   - 原始金额、币种、汇率、折算金额、可进入管报金额。

3. 来源明细
   - 单据行、订单号、物料、客户、部门、费用字段、金额。

4. 管报落点
   - 该来源金额进入了哪些费用项、渠道、店铺、MSKU、费用部门。

5. 操作日志
   - 导入、审核、规则运行、重算、定稿、锁定。

### 5.2 不同来源的差异化字段

| 来源 | 关键字段 |
| --- | --- |
| 金蝶出库/退货 | 单据编号、客户、物料、部门、价税合计、税额、汇率、审核状态 |
| 平台报告 | 报告期间、交易类型、订单号、费用字段、原始金额 |
| 费用导入 | 批次号、导入人、费用项、归属月、金额、范围条件、分摊模式 |
| 项目预算 | 项目号、预算行、收益日期、营销类型、费用部门、预算金额 |
| 扣款计提 | 客户、费用项、计提方式、销售收入、比例、实际扣款、计提扣款 |
| 退款计提 | 客户、实际退款、滚动率、目标窗口、期初/期末余额、当月计提 |

## 6. 计算过程

### 6.1 导入费用分摊

展示：

- 导入批次基础信息。
- 导入行费用项、金额、币种、费用部门。
- 渠道范围、产品范围。
- 分摊模式：分摊或不分摊。
- 分摊基数：营收或订单商品销售收入。
- 分摊结果：店铺 + MSKU 明细。

### 6.2 项目预算分摊

展示：

- 项目预算行。
- 收益日期范围。
- 预算金额和币种。
- 费用部门。
- 分摊范围和分摊规则。
- 进入管报的月份和金额。

### 6.3 扣款计算

展示：

- 客户、期间、费用项。
- 当月销售收入。
- 计提方式：固定比例、部门固定比例、月固定金额、年总额月均分摊。
- 计提扣款计算。
- 实际扣款。
- 期初余额、期末余额、差异状态。

### 6.4 退款计算

展示：

- 客户、期间。
- 计提用收入口径：销售收入减退货退款收入。
- 上月滚动退款率、本月滚动退款率。
- 目标窗口。
- 期初计提退款余额、实际退款、当月计提退款、期末计提退款余额。

## 7. 财报对照差异

### 7.1 页面字段

- 月份、渠道、店铺、MSKU。
- 管报费用项、管报金额。
- 财务字段组、财务字段、财务金额。
- 对照关系：1:1、1:N、N:1、N:M。
- 对照公式/说明。
- 差异金额、差异率。
- 差异处理。
- 是否可对账验平。
- 是否财务定稿覆盖。
- 定稿状态。

### 7.2 操作

- 查看管报明细。
- 查看财务来源。
- 标记差异原因。
- 导出差异清单。

## 8. 权限建议

| 权限 | 能力 |
| --- | --- |
| 查看管报 | 查看总览和分析 |
| 查看明细 | 查看费用明细和来源单据摘要 |
| 查看敏感来源 | 查看原始单据金额、客户、凭证等敏感信息 |
| 导出 | 导出汇总、明细、差异 |
| 定稿复核 | 查看定稿批次、锁定状态、差异处理 |

## 9. 页面验收重点

1. 总览金额能与明细合计一致。
2. 明细金额能与来源单据或规则运行结果一致。
3. 分摊后金额能回汇总到分摊前金额。
4. 已定稿数据展示冻结批次，不能被未定稿重算结果覆盖。
5. 财报差异能从差异页面回跳到管报明细和财务来源。
