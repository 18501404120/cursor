# 项目理解与一期二期边界

## 1. 项目定位

全渠道管报项目的目标是把收入、成本、费用按“月份/日期 + 渠道 + 店铺 + MSKU + 费用部门 + 费用项”沉淀为可分析、可追溯、可对账的经营数据。

现有资料显示，管报已经围绕以下对象形成基础框架：

- 费用项主数据：原型数据约 135 条费用项，覆盖收入、成本、市场投入、公共费用、利润等层级。
- 费用部门主数据：原型数据约 66 条费用部门节点，结合金蝶组织、BM 部门、管报归属对象、是否进渠道贡献利润等字段。
- 管报模板：已定义 `MSKU店铺管报汇总`、`MSKU店铺费用明细`、`收入成本明细`、`费用项取值说明`、`分摊规则说明`、`财报对照与差异`。
- 费用取值逻辑：`字段取值逻辑-V4归类版` 约 217 行，主取值模式包括业务系统单据取数、平台报告取数、项目预算取数、费用导入分摊、计提/扣款规则计算、比例/参数计算、财务系统同口径取数、汇总公式计算。
- 费用管理原型：已覆盖费用来源定义、费用导入分摊、项目立项预算、客户计提规则、退款管理、扣款管理、费用项主数据、费用部门主数据。

## 2. 一期项目重点

一期重点是“取值”，也就是把每个管报费用项的数据取出来、算出来、落下来。

一期应优先解决：

1. 费用项清单标准化
   - 明确费用项层级、末级费用项、正负方向、费用大类/子类/场景。
   - 明确每个费用项是否进入管报、是否参与贡献利润。

2. 取值来源标准化
   - 自动取数：来自业务系统、金蝶单据、平台报告。
   - 规则计算：来自费用来源定义、客户计提规则、退款/扣款规则。
   - 人工导入：来自费用填报管理的导入批次。
   - 项目预算：来自项目立项预算。
   - 汇总公式：来自下级费用项汇总。

3. 费用部门映射
   - 金蝶组织、金蝶 BM 部门与管报费用部门对照。
   - 业务可选部门、禁止直选容器、默认组织、是否进渠道贡献利润。

4. 分摊规则落地
   - 不分摊：已有单据或导入明细能直接落到店铺/MSKU。
   - 按营收占比分摊：月度或场景费用分摊到店铺 + MSKU。
   - 按订单商品销售收入占比分摊：扣款/退款类费用。
   - 按参数计算：仓储费、费率类费用。

5. 数据快照与关账
   - 未关账月允许重算。
   - 已关账月冻结快照，原则上不回溯，需保留差额说明或重跑审批。

## 3. 二期项目重点

二期重点是“展示、分析、明细、追溯”。一期解决金额怎么来，二期解决金额怎么被业务看懂、查清楚、对得上。

二期应重点建设：

1. 管报费用项页面展示
   - 按费用项层级展示汇总金额。
   - 支持按月份、渠道、店铺、MSKU、国家、费用部门、费用来源、定稿状态筛选。
   - 支持费用项树形下钻：费用大类 -> 费用子类 -> 场景 -> 末级费用项。

2. 数据分析
   - 趋势分析：按月查看费用变化。
   - 结构分析：按费用项、渠道、店铺、费用部门拆分。
   - 异常分析：环比、同比、预算偏差、财报差异、未分摊/分摊异常。
   - 贡献利润影响分析：费用对毛利、贡献利润、营业利润的影响。

3. 明细数据
   - 每个汇总金额可以下钻到 `MSKU店铺费用明细`。
   - 明细必须包含费用项、金额、币种、汇率、金额 USD、分摊规则、分摊基数、分摊比例、取值来源、单据号、来源单据类型、导入批次号、数据批次、定稿状态。

4. 来源单据追溯
   - 每个费用项金额需要能追溯到来源单据或来源记录。
   - 来源类型包括金蝶销售出库单、销售退货单、平台交易报告、广告报告、费用导入批次、项目预算行、计提规则运行结果、退款/扣款台账、财务同口径取数结果。
   - 用户点击单据号、批次号或规则运行编号，可以看到该费用项相关的各项费用信息和计算过程。

5. 对账与定稿
   - 管报金额与财务字段金额对照。
   - 展示差异金额、差异率、差异处理方式、是否财务定稿覆盖。
   - 支持从差异回跳到明细和来源单据。

## 4. 一期与二期关系

一期是数据底座，二期是使用界面和分析闭环。

| 维度 | 一期 | 二期 |
| --- | --- | --- |
| 核心问题 | 金额从哪里来、怎么算 | 金额如何展示、解释、追溯、分析 |
| 主要对象 | 费用项、取值逻辑、来源配置、分摊结果 | 管报页面、分析图表、明细弹窗、来源单据详情 |
| 数据粒度 | 取值记录、分摊明细、快照 | 汇总 + 明细 + 单据 + 计算过程 |
| 关键用户 | 财务运营、系统配置人员 | 管报分析人员、财务、业务负责人 |
| 成功标准 | 每个费用项可取数且口径明确 | 每个金额可解释、可下钻、可对账 |

## 5. 二期设计原则

1. 汇总不脱离明细
   - 页面上的每个费用金额都应该能下钻到明细行。

2. 明细不脱离来源
   - 每条费用明细都需要保存来源类型、来源编号、来源行号或规则运行编号。

3. 来源不脱离计算过程
   - 对导入、分摊、计提、规则计算类费用，应能看到计算输入、公式、结果和版本。

4. 分析不改变数据
   - 二期页面主要用于展示、查询、分析、追溯，不直接改写一期取值结果。

5. 定稿与未定稿分层展示
   - 未定稿支持刷新和重算，已定稿展示冻结快照和差异说明。
