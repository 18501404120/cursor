本页为销售额 / 营收 / 毛利与费用项的口径与漏斗示意；业务管理报表菜单（含「经营分析看板」「经营分析明细」「全渠道产品分析看板」及图例「二期规划」等）已在与 V2 对齐的 全渠道管报项目规划原型-v2.html「01 项目规划」中维护。

一、三大指标关系（先看总公式）
销售额
以RRP价为基准的规模指标。
净销售额 = RRP价 × 销售数量（含退货数量）
销售额 = 净销售额 + 运费收入 + 包装收入
→
营收（收入净额）
反映扣减后的真实收入。
优惠合计 = 折扣 + 直接扣减折扣
销售收款 = 销售额 - 优惠合计
收入净额 = 销售收款 - 销售退款 - 销售税/VAT
→
毛利
收入扣除成本费用后的经营质量指标。
毛利 = 收入净额 - 货值成本净额 - 广告宣传小计 - 物流成本小计 - 交易及平台费用小计 - 运杂费
二、费用项关系图（汇总 / 扣减 / 分摊）
A. 销售额到营收（扣减链）
汇总：销售额（净销售额+运费收入+包装收入） 扣减：优惠合计（折扣+直接扣减折扣） 扣减：销售退款 扣减：销售税/VAT 结果：收入净额（营收）
B. 毛利扣减项（成本费用链）
货值成本净额 = 出货授权成本 + 退货成本 + 平台赔偿 广告宣传小计 = 广告费 + 推广费 + 样品费 物流成本小计 = 头程运费 + 尾程运费/FBA物流 + 退货运费 + 仓储费 交易及平台费用小计 = FBA佣金 + 平台服务费 + 收单费用/Payment Discount + 店铺费用 + Commission Fee 其他扣减 = 运杂费
