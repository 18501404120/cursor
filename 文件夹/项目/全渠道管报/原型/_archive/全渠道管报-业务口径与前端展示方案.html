全渠道管报 · 业务口径展示（优化版）

目标：把“销售额、营收、毛利”三大指标关系讲清楚，并明确每个费用项是如何进入报表（汇总、扣减、分摊）。

核心关系清晰 费用路径可解释 月中估算+月末回写
一、三大指标关系（先看总公式）
销售额
以RRP价为基准的规模指标。
净销售额 = RRP价 × 销售数量（含退货数量）
销售额 = 净销售额 + 亚马逊运费收入 + 亚马逊包装收入
→
营收（收入净额）
反映扣减后的真实收入。
优惠合计 = 折扣 + 直接扣减折扣
销售收款 = 销售额 - 优惠合计
收入净额 = 销售收款 - 销售退款 - 销售税/VAT
→
毛利
收入扣除成本费用后的经营质量指标。
毛利 = 收入净额 - 货值成本净额 - 广告宣传小计 - 物流成本小计 - 交易及平台费用小计 - 运杂费 - 预留毛利
二、费用项关系图（汇总 / 扣减 / 分摊）
A. 销售额到营收（扣减链）
汇总：销售额（净销售额+亚马逊运费收入+亚马逊包装收入） 扣减：折扣 扣减：直接扣减折扣 扣减：销售退款 扣减：销售税/VAT 结果：收入净额（营收）
B. 毛利扣减项（成本费用链）
货值成本净额 = 发货成本 + 退货成本 + 平台赔偿 广告宣传小计 = 广告费 + 品牌营销费 + 推广费 + 样品费 物流成本小计 = 头程运费 + 尾程运费/FBA物流 + 退货运费 + 仓储费 + 关税 交易及平台费用小计 = FBA佣金 + 平台服务费 + 收单费用/Payment Discount + 店铺费用 + Commission Fee 其他扣减 = 运杂费 + 预留毛利
C. 分摊原则（进入SKU）
先直连：订单/活动可定位到SKU直接归属 再映射：Campaign/品牌/店铺映射到SKU 再分摊：无法直连时按净销售额占比 月末回写：按账单确认值覆盖估算值

展示重点（前端建议）

1. 顶部固定三大指标公式
用户先看“怎么算”，再看明细。
2. 费用项按关系分组
不要平铺罗列，必须区分“汇总项、扣减项、分摊项”。
3. 同屏展示小计公式
广告宣传小计、物流成本小计、交易及平台费用小计都应直接展示构成。
4. 标注数据状态
区分月中估算与月末确认，避免把预提数误读为财务结账数。
该页面可直接作为“业务口径讲解页”。下一步可在每个费用chip上加hover弹层，展示“数据来源、取值逻辑、分摊规则、偏差率”。
