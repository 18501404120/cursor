全渠道管报 · 业务口径展示（v3）

本页按最新管报科目树展示营业收入、毛利、营业利润和费用项。菜单仍在 项目规划原型 v2 维护。上一版漏斗见 业务口径 v2。 取值示例见 经营分析看板 · 管报科目树。

结果链营业收入 → 毛利 → 营业利润。毛利只扣成本。
收入构成零售销售额与销售收入，扣减渠道激励和税费。
费用两段市场投入（营销、渠道、销售），公共费用（仓储物流、售后、其它）。
改挂费用包装收入、运费收入、包裹险在其它费用，不进营业收入。
一、结果指标（先看总公式）
营业收入
零售额与销售收入扣减渠道激励、税费后的收入。
营业收入 = 发货零售销售额 + 退货零售销售额 + 发货销售收入 + 退货销售收入 − 渠道激励 − 税费
→
毛利
营业收入扣除货值成本后的结果。平台费、广告、物流在下一步扣。
成本 = 出货授权成本 + 退货成本
毛利 = 营业收入 − 成本
→
营业利润
毛利扣除全部费用后的经营结果。
费用 = 市场投入 + 公共费用
营业利润 = 毛利 − 费用
二、科目关系（汇总 / 扣减 / 结果）
汇总，计入上级 扣减 费用 结果 件数或并列，不进金额公式 改挂在其它费用
A. 收入 → 营业收入
发货零售销售额 = RRP × 发货销量 退货零售销售额 = − RRP × 退货销量 发货销售收入 退货销售收入（退款金额，记负数） 渠道激励 = 价保 + 返利（前返、后返）+ 临时激励（划线价折扣、Discounts） 税费 营业收入 渠道商利润：单独列示，营业收入不含本项 销量：发货销量、退货销量，只计件数
B. 成本 → 毛利
出货授权成本 退货成本（同单价冲回，记负数） 页面列这两项；采购、关税、预留毛利写在取值说明里 毛利 = 营业收入 − 成本
C. 市场投入
营销投入 = 自主营销（产品营销、品牌营销、基础固定花费）+ 联合营销 渠道投入 = 自主营销（平台费用、广告投放）+ 联合营销（广告投放） 销售投入 = 自主营销（平台费用、广告投放）
D. 公共费用 → 营业利润
仓储物流 = 物流费用（头程、尾程）+ 仓储费用（仓储租金、仓储其他） 售后服务 = 品质问题 + 物流问题 + 其他问题 + 售后手续费 + 售后未影响部分 其它费用含透明标签费、运杂费、运费收入、包裹险、包装收入、其它 营业利润 = 毛利 − 市场投入 − 公共费用
三、图形化总览
主链自上而下：收入经渠道激励、税费得到营业收入，再扣出货授权成本与退货成本得到毛利，再扣市场投入与公共费用得到营业利润。橙色块是扣减或改挂项；灰色「渠道商利润」单独列示。末级科目在下一节。
