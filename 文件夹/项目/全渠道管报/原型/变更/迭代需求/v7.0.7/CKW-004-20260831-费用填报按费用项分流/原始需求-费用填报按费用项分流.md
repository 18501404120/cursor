确认结果：
- 「品牌营销费用类型」按哪条路径判 → 用户选择：整棵「营销投入」（产品营销 / 品牌营销 / 基础固定花费）都挂部门先记录（已被后续口径覆盖）
- 品牌营销费「先不分摊」时金额挂到哪里 → 用户选择：挂到本笔所选费用部门（整笔不拆 SKU）；部门必填（已被后续口径覆盖）
- 去掉「分摊模式」后，非品牌营销费用还能不能「整笔挂部门」 → 用户选择：不能。非品牌营销一律按营收分摊；部门不填、由店铺映射带出
- 非「营销投入」费用按营收分摊时，ASIN / 订单号 / DL批次号还要不要给填 → 用户选择：保留可填，仍可用 ASIN/订单号/DL 收窄营收命中
- 「营销投入只能在项目平台维护」本期指哪个入口 → 用户选择：就是现有项目平台 → 项目 → 预算页签（CKW-003 已挂全公司、只记录范围）；填报页不再接营销投入实际费用
- 批量导入若仍填了营销投入末级费用项，怎么处 → 用户选择：该行校验失败，提示「营销投入请到项目平台维护」，不写入
- 后续口径覆盖：填报页费用项树「营销投入」及以下全部置灰不可选；去掉填报页营销投入挂部门 / 暂不分摊逻辑，只保留现行营收分摊
- 部门放开且可空后，「选了部门」怎么用 → 用户选择：仍按营收拆到各店铺；选了部门则各行部门都覆盖成用户选的；没选则仍按店铺映射带出
- 批量导入部门列同一套：可空；填了就覆盖映射，空则走店铺映射；不再报「部门须留空」
