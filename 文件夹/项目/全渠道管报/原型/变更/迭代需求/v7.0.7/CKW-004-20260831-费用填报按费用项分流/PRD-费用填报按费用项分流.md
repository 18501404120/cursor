【费用模块】费用填报去掉营销投入

公开原型：[在线访问](https://18501404120.github.io/cursor/文件夹/项目/全渠道管报/原型/02-费用管理/手工简易填报.html)

改动位置：费用管理 → 费用填报管理 → 新增/导入费用弹窗、列表筛选、批量导入、分摊明细

本次改动：
1. 去掉「分摊模式」。新增弹窗、列表、批量导入模板均不再展示该字段。旧模板若仍带该列，忽略不读。
2. 费用项树中，「营销投入」及其全部下级（自主营销 / 联合营销 → 产品营销、品牌营销、基础固定花费及末级）置灰、不可选。父级仍可展开查看。筛选费用项同样不可选这些节点。提示用户：营销投入请到项目平台 → 项目 → 预算页签维护。
3. 本页只保留营收分摊，不再按费用项分流挂部门或暂不分摊。所有可选费用项规则相同：
   - 渠道/产品范围各列可多选、可空；空 = 该维度不限；列之间取交集。新品标签仍为年份单选。
   - 从归属月当月营收池筛匹配记录作基数；营收小于 0 不参与；按营收占比拆金额，两位小数，末笔补差，合计等于原金额；结果落到店铺。
   - 部门选填，控件可点。选了部门：各行店铺不变，金蝶部门一律覆盖为用户所选，不再按店铺映射。没选部门：各行仍按店铺映射带出金蝶组织/部门。
   - 列表部门列：有选显示所选部门，没选显示空；明细各行展示最终部门。
   - ASIN、订单号、DL 批次号可填，用于收窄命中。
4. 仍须先预览再确认写入；改费用项、金额、归属月、币种、部门、备注或任意范围后须重新预览。预览展示店铺/商品分摊表及各行最终部门。摘要写明：按营收分摊；选了部门则覆盖映射，没选则按店铺映射。关账前分摊明细每日自动重算。
5. 批量导入：费用项若属于营销投入，该行失败，提示「营销投入请到项目平台维护」，不写入。部门列可空；填了则该行分摊结果部门覆盖为所填部门，空则按店铺映射。

异常处理：
- 未选费用项、未填归属月、金额无效：沿用现网提示
- 预览无命中：沿用「当前范围交集为空，无法预览分摊」；有新品标签时沿用现网新品无命中文案
- 未预览或改关键字段后未重新预览：提示「请先完成预览；修改关键字段后需要重新预览」
- 导入营销投入费用项：提示「营销投入请到项目平台维护」
