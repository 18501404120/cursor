# 财务各渠道逻辑 — 品牌营销费（业务维度）与《营销费用规划》拆月对齐说明

> **配套文件**：`财务各渠道逻辑.xlsx`（同目录）  
> **对齐原型**：`文件夹/项目/全渠道管报/原型/营销费用规划-系统原型.html`（其中 `splitPlan` / `monthsForPlanSplit` / `bpMonthlyRevenueForMockRow` 为拆月与 BP 权重的参考实现；上线后以**真实 BP/MSKU 主数据**替换原型中的哈希示例值即可。）

本文把 Excel 截图中「品牌营销费」业务取值、拆月逻辑写完整，并**补全**与物流相关的两条「现有公式」描述（头程分区域 + 月度参数表；海外仓估算 + 月末回写），便于业务与实施直接对照，无需再翻聊天记录。

## 一、品牌营销费 — 业务维度【取值】（与《营销费用规划》一致）

### 1.1 数据来源

- **系统**：营销费用规划（本仓库原型对应前端本地存储 `marketing_expense_plan_v3`；正式环境为同名或接口约定的规划主数据）。
- **含义**：管报**业务维度**下「品牌营销费」某一展示粒度（如：店铺 + 渠道 + 月份）的金额，应来自**已发布/已生效**的营销费用规划中，与该粒度**命中条件一致**的规划行的 **规划额（年度/期间总额，USD）**，再按下文规则**拆到自然月**后汇总。
- **与财务维度区别**：业务维度走「规划 → 拆月」链路；财务维度仍按财务系统科目与映射配置取数，二者**不互相替代**。

### 1.2 规划行如何「命中」管报业务粒度（概念）

规划行至少具备：**规划年度**、**场景×品类（可多叶子）**、**可选 SKU（MSKU 多选）**、**可选新品标签（单选）** 等（与原型表结构一致）。  
管报在汇总「品牌营销费」时，用当前行的**店铺 / 渠道 / 区域 / MSKU 归属**等与规划条件求交：仅将**命中的规划行**纳入集合 \(\mathcal{P}\)。（具体命中键以产品字典为准，本文只定链路。）

### 1.3 拆月所依据的「月份集合」\(M\)

设用户或管报默认给出的**月份范围**为 \([m_{\min}, m_{\max}]\)（`YYYY-MM` 闭区间）。  
设某条规划行的**规划年度**为 \(Y\)。  

则该规划行参与拆月的自然月集合为：

\[
M \;=\; \{\, t \in [m_{\min}, m_{\max}] \;\mid\; t\text{ 的日历年}=Y \,\}
\]

即：**筛选月份范围**与**规划年度**取**自然月交集**（与原型 `monthsForPlanSplit` 一致）。若 \(M=\emptyset\)，该规划行在当期管报月份窗内**不产生**业务侧拆月金额。

### 1.4 双层分摊（与原型 `splitPlan` 一致）

对集合 \(\mathcal{P}\) 中每一条规划行 \(p\)，记其规划额为 \(P_p\)（USD，非负）。  

**第一步 — 拆到月（按「月维度 BP 权重」）**

在月份集合 \(M\) 内，对每个自然月 \(t\)，先取该规划行在 \(t\) 月**命中的 MSKU 集合** \(\mathcal{U}_{p,t}\)（与原型 `collectEligibleMskus` + 场景/品类/SKU/新品标签过滤一致）。  
对每个 MSKU \(u\) 取**业务 BP 营收**在月 \(t\) 的权重 \(BP_{u,t}\)（原型为 `bpMonthlyRevenueForMockRow`；生产为接口/数仓的「MSKU × 月」BP 或等价营收指标）。

定义月 \(t\) 上该规划行的「可摊基数」：

\[
W_{p,t} \;=\; \sum_{u \in \mathcal{U}_{p,t}} BP_{u,t}
\]

再对整段 \(M\) 归一，得到规划额 \(P_p\) 在月 \(t\) 的**月预算**（先向下取整再尾差处理，与原型一致）：

\[
\text{若 } S_p = \sum_{t \in M} W_{p,t} > 0:\quad
Budget_{p,t} \;=\; \left\lfloor P_p \cdot \frac{W_{p,t}}{S_p} \right\rfloor \text{，尾差补到 } M \text{ 的最后一月}
\]

\[
\text{若 } S_p = 0:\quad
Budget_{p,t} \text{ 在 } |M| \text{ 个月内等额拆分，尾差补最后一月}
\]

**第二步 — 月内拆到 MSKU（按「月内 BP 占比」）**

在固定 \(p,t\) 下，对 \(u \in \mathcal{U}_{p,t}\)：

\[
Amount_{p,t,u} \;=\; \left\lfloor Budget_{p,t} \cdot \frac{BP_{u,t}}{\sum_{v \in \mathcal{U}_{p,t}} BP_{v,t}} \right\rfloor
\]

月内尾差补到该月**最后一笔** MSKU 行（与 `fixRounding` 一致）。

**第三步 — 汇总到管报展示粒度**

将各 \(Amount_{p,t,u}\) 按管报行键（店铺、渠道、区域、MSKU…）**聚合求和**，即得到业务维度「品牌营销费」在**月 \(t\)** 的金额。

### 1.5 可写入 Excel / PRD 的一行话（【取值】完整版）

**【取值】（品牌营销费 · 业务维度）**：来源于「**营销费用规划**」系统已生效数据。对每条命中的规划行，取其**规划额（USD）**；拆月月份集合为**「筛选月份范围」与「规划年度」的自然月交集**；先将规划额按各月**命中 MSKU 的月度 BP 合计占比**分摊到各自然月，再在各自然月内按**各 MSKU 月度 BP 占该月合计**分摊到 MSKU；最后按管报维度（店铺/渠道/区域/MSKU 等）汇总。原型实现见 `营销费用规划-系统原型.html` 中 `splitPlan`；生产环境以主数据 BP 表替换示例哈希。

## 二、截图中与物流相关的两条公式补全（N24 / N25）

以下与「品牌营销费」并列，属于**物流/仓储类费用项**在业务或财务侧的取数升级说明，便于把 Excel 里半截话写全。

### 2.1 N24 头程 / 分区域 — 完整逻辑与公式化表达

**业务文字（可直接贴表）**  
【取值】：**保留现有「分区域」头程核算公式**不变；在此基础上增加**月度参数表**（字段至少包含：**运价**、**汇率**、**体积重/计费重权重**或产品定义的权重因子），按**版本号 + 生效区间**管理；每月运算时取**当月生效版本**的参数代入原区域公式。若某区域某月缺少参数版本，则回退到「上一生效版本」或按数据治理规则报警并沿用最近版本（需在产品中二选一并写死）。

**公式化（示意，区域 \(r\)、月份 \(t\)）**  

设现有分区域模型可抽象为：

\[
Head_{r,t}^{(0)} \;=\; f_r\big(\text{货量、距离、柜型、口岸、历史单价等}\big)
\]

引入月度参数向量 \(\theta_{r,t} = (\text{运价因子}, \text{汇率因子}, \text{权重因子})\)（均相对基准=1）：

\[
Head_{r,t} \;=\; Head_{r,t}^{(0)} \cdot \theta_{r,t,\text{运价}} \cdot \theta_{r,t,\text{汇率}} \cdot \theta_{r,t,\text{权重}}
\]

其中 \(\theta_{r,t,\cdot}\) 来自**版本化月度参数表**在 \(t\) 月、区域 \(r\) 的生效行。  
**关账**：月末以物流/财务确认的**实际头程账单**或结算单为事实源做差异回写（与 2.2 同一类「估算 → 回写」机制）。

### 2.2 N25 海外仓 — 完整逻辑与公式化表达

**业务文字（可直接贴表）**  
【取值】：**月中**继续采用当前**海外仓费用估算模型**（如：在库天数 × 体积/件数 × 费率档、或按出库件数阶梯计费等——以各仓合同为准）；**月末**必须以**海外仓服务商账单**（或 WMS 计费接口）为**唯一真值**做**整月回写**：用账单总金额覆盖或调整当月估算序列，差异记入指定调整项/次月冲销（二选一由财务政策定）。

**公式化（示意，店铺或仓 \(w\)、月份 \(t\)）**  

设月中估算序列为 \(\hat{C}_{w,t}\)（可按日累加），月末账单实报为 \(C_{w,t}^{\text{bill}}\)：

\[
C_{w,t}^{\text{final}} \;=\; C_{w,t}^{\text{bill}}
\qquad
\Delta_{w,t} \;=\; C_{w,t}^{\text{bill}} - \sum_{\text{日内}} \hat{C}_{w,t,\text{day}}
\]

\(\Delta_{w,t}\) 按财务规则分摊到 SKU/订单（如按**当月末库存货值占比**、**出库件数占比**或**账单明细行**）后，回写业务管报与总账接口。

## 三、实施与校验清单（建议）

| 项 | 说明 |
|----|------|
| 规划源 | 明确「生效」状态与版本（发布/审核）后才进入管报拆月。 |
| BP 主数据 | 生产用 `BP_{u,t}` 与 MSKU 归属必须与规划命中逻辑同源，避免拆月分母为 0。 |
| 空月 / 零 BP | 与原型一致：全月 BP 合计为 0 时退化为**月均**；仍无 MSKU 命中则该规划行当月为 0。 |
| 多规划行 | 同一 MSKU 多月多行允许并存；汇总键需定义是否去重（默认**不去重**，与原型展示一致）。 |
| 对账 | 业务侧「规划拆月」与财务侧「账单」应能在月报上对比差异率，超阈告警。 |
