# 品牌营销费 · 付款直摊分摊逻辑

> **适用场景**：无事前规划；用户提交**付款申请**并审批通过后，将**本笔实付金额**按适用范围分摊到 **自然月 × MSKU（× 店铺）**，供全渠道管报归集。  
> **不适用**：年初营销费用规划额拆 BP 预览（另见《财务各渠道逻辑 — 品牌营销费与拆月对齐说明》）。

---

## 一、输入与输出

### 1.1 输入（付款单 / 费控单）

| 字段 | 说明 |
|------|------|
| **本笔金额 A** | 付款申请或财务确认入账金额（如 USD），本逻辑对**单笔**付款守恒 |
| **适用月份范围 M** | 闭区间，如 `2026-03`～`2026-06`，与活动期一致，**不以付款日代替** |
| **分摊范围** | 场景×品类、新品标签、区域/国家、渠道/店铺、可选 SKU 等；用于圈定每月命中的 MSKU 集合 |
| **费用项** | 如「品牌营销费」，对应管报科目 |

### 1.2 输出

| 输出 | 说明 |
|------|------|
| **分月金额** `Budget_t` | 本笔 A 在每个月 t∈M 上的份额，满足 Σ Budget_t = A |
| **分 SKU 明细** `Amount_{t,u}` | 月 t、MSKU u 的分摊额，满足 Σ_u Amount_{t,u} = Budget_t |
| **版本** | `暂估（BP）` / `实摊（实际营收）`；月结账后可生成调整差额 Δ |

---

## 二、前置判断：月份范围是否「完全过去」

以**财务月是否已结账**为准（`month_closed`），不要仅用日历日期。

| 情况 | 定义 | 走哪套权重 |
|------|------|------------|
| **完全过去** | M 内每一个自然月均已结账 | 全部月份用 **实际营收**（逻辑 A） |
| **未完全过去** | M 中至少有一个月未结账 | **已结账月**用实际营收；**未结账月**用 **BP 目标营收**；某月结账后对该月改为实际并更新（逻辑 B → A） |

> **付款日晚于活动月**：例如 7 月才付 4–6 月费用，若 4–6 月均已结账，则整笔走**逻辑 A（全部实际）**，管报在对应月做追溯体现（与分摊公式无关，属入账/关账流程）。

---

## 三、核心公式（两层，必须先月后 SKU）

对**本笔付款金额 A**、适用月份集合 **M**、每月命中 MSKU 集合 **U_{t}**（由分摊范围 + 主数据计算，每月可不同）。

### 3.1 权重营收 r_{u,t} 与月权重 W_t

对每个 t∈M：

1. 在 **U_{t}** 内取每个 MSKU u 的权重营收 **r_{u,t}**：
   - 月 t **已结账** → 用 **实际营收**（与管报「营收」口径一致）；
   - 月 t **未结账** → 用 **BP 目标营收**；
   - 若 u 在 t 月 BP=0 且实际=0 → 参与**等额**分摊，并打标 `权重来源=等额`。
2. 月权重：**W_t = Σ_{u∈U_t} r_{u,t}**（仅命中集合内合计，**不用全公司营收**）。

### 3.2 第一层：拆到月

设 **S = Σ_{t∈M} W_t**。

- 若 **S > 0**：

  **Budget_t = A × (W_t / S)**  

  金额向下取整时，**尾差补到 M 的最后一月**，保证 Σ Budget_t = A。

- 若 **S = 0**（整段无 BP 且无实际）：**Budget_t 在 |M| 个月内等额**，尾差补最后一月。

### 3.3 第二层：月内拆到 MSKU

在固定月 t、本笔 Budget_t 下：

**Amount_{t,u} = Budget_t × (r_{u,t} / Σ_{v∈U_t} r_{v,t})**  

月内尾差补到该月**最后一笔** MSKU 行（与现有 `fixRounding` 一致）。

### 3.4 逻辑 A / B 对照（易懂版）

| 步骤 | 逻辑 A（范围已全部结账） | 逻辑 B（范围含未结账月） |
|------|--------------------------|---------------------------|
| 1 | 每月 W_t、r_{u,t} 均用**实际营收** | **已结账月**用实际；**未结账月**用 **BP** |
| 2 | 按第三节公式算 Budget_t、Amount_{t,u} | 同上 |
| 3 | 完成 | 某月 t 结账后：该月 r、W 改为**实际**，**重算分月 + 月内明细**，记暂估→实摊差额 |

### 3.5 月结后更新规则（逻辑 B）

1. 将月 t 的权重由 BP 改为**实际营收**，重算 **W_t** 及 **Budget_t、Amount_{t,u}**（分母 S 中：已结账月用实际，仍未结账月仍用 BP）。
2. **管报展示**：至少更新月 t 的明细；若 t 以前月份已关账不可改账面，则 t 的差额通过**分摊调整单 / 调整凭证**体现（产品需与财务约定）。
3. **多笔付款**：每笔 A 独立分摊，管报费用**累加**，不互相覆盖。

## 四、流程图

```text
付款生效（金额 A，范围 R，月份 M）
        ↓
逐月计算命中 MSKU 集合 U_t
        ↓
M 是否全部已结账？
   ├─ 是 → 每月权重 = 实际营收 → 分月 → 分 SKU → 实摊版本
   └─ 否 → 已结账月=实际，未结账月=BP → 分月 → 分 SKU → 暂估版本
                ↓
        某月 t 结账 → t 改实际权重 → 重算 → 实摊版本（记 Δ）
```

## 五、场景示例一：范围完全过去（3 月–4 月）

**背景**

- 本笔付款 **A = 1,000,000** 元（品牌营销费）
- 适用月份：**2026-03～2026-04**（当前为 2026 年 5 月，两月均已结账）
- 命中 3 个 MSKU：M1、M2、M3（范围略）

**第一步：实际营收（仅示意，单位：元）**

| MSKU | 3 月实际营收 | 4 月实际营收 |
|------|-------------|-------------|
| M1 | 300,000 | 400,000 |
| M2 | 200,000 | 100,000 |
| M3 | 100,000 | 200,000 |
| **当月合计 W_t** | **600,000** | **700,000** |

**第二步：第一层 — 拆到月**

S = 600,000 + 700,000 = **1,300,000**

| 月份 | 计算 | 分月金额 Budget_t |
|------|------|-------------------|
| 3 月 | 1,000,000 × 600,000 / 1,300,000 | **461,538** |
| 4 月 | 1,000,000 × 700,000 / 1,300,000 | **538,462** |
| **合计** | | **1,000,000** |

**第三步：第二层 — 月内按占比拆到 MSKU**

**3 月（Budget = 461,538）**

| MSKU | 3 月占比 | 3 月分摊额 |
|------|----------|------------|
| M1 | 300,000 / 600,000 = 50% | 230,769 |
| M2 | 200,000 / 600,000 = 33.33% | 153,846 |
| M3 | 100,000 / 600,000 = 16.67% | 76,923 |
| **合计** | | **461,538** |

**4 月（Budget = 538,462）**

| MSKU | 4 月占比 | 4 月分摊额 |
|------|----------|------------|
| M1 | 400,000 / 700,000 ≈ 57.14% | 307,692 |
| M2 | 100,000 / 700,000 ≈ 14.29% | 76,923 |
| M3 | 200,000 / 700,000 ≈ 28.57% | 153,846 |
| **合计** | | **538,462** |

**核对**

- 分月之和 = 100 万；每月内 MSKU 之和 = 当月 Budget。
- M1 两月合计：230,769 + 307,692 = **538,461**（占全笔约 53.8%，与其营收权重较高一致）。

> **易错点**：不能对 3 月、4 月各用「100 万 × 当月 MSKU 占比」而不先分月，否则总额会变成约 200 万。

## 六、场景示例二：范围未完全过去（3 月–6 月）

**背景**

- 本笔付款 **A = 1,000,000** 元
- 适用月份：**2026-03～2026-06**
- 当前：**2026 年 5 月** → 3、4 月已结账；5、6 月未结账
- 命中 MSKU：M1、M2、M3

### 6.1 初次分摊（5 月、付款刚生效）

**权重来源**

| 月份 | 状态 | 权重来源 |
|------|------|----------|
| 3 月 | 已结账 | 实际营收 |
| 4 月 | 已结账 | 实际营收 |
| 5 月 | 未结账 | BP |
| 6 月 | 未结账 | BP |

**营收数据（示意，单位：元）**

| MSKU | 3 月实际 | 4 月实际 | 5 月 BP | 6 月 BP |
|------|----------|----------|---------|---------|
| M1 | 300,000 | 400,000 | 350,000 | 400,000 |
| M2 | 200,000 | 100,000 | 250,000 | 200,000 |
| M3 | 100,000 | 200,000 | 150,000 | 400,000 |
| **W_t** | **600,000** | **700,000** | **750,000** | **1,000,000** |

**第一层：拆到月**

S = 600,000 + 700,000 + 750,000 + 1,000,000 = **3,050,000**

| 月份 | 计算 | Budget_t（暂估版） |
|------|------|-------------------|
| 3 月 | 1,000,000 × 600,000 / 3,050,000 | **196,721** |
| 4 月 | 1,000,000 × 700,000 / 3,050,000 | **229,508** |
| 5 月 | 1,000,000 × 750,000 / 3,050,000 | **245,902** |
| 6 月 | 1,000,000 × 1,000,000 / 3,050,000 | **327,869** |
| **合计** | | **1,000,000** |

**第二层：5 月暂估（BP，Budget = 245,902）**

| MSKU | 5 月 BP 占比 | 5 月暂估分摊 |
|------|--------------|--------------|
| M1 | 350,000 / 750,000 | 114,754 |
| M2 | 250,000 / 750,000 | 81,967 |
| M3 | 150,000 / 750,000 | 49,181 |
| **合计** | | **245,902** |

（3、4、6 月同理按当月 r_{u,t} 计算；略。）

---

### 6.2 5 月结账后 — 改为实际营收并重算

**5 月实际营收**

| MSKU | 5 月实际 |
|------|----------|
| M1 | 320,000 |
| M2 | 280,000 |
| M3 | 120,000 |
| **W_5（新）** | **720,000** |

重算时：**3、4 月仍用实际 W**；**5 月用新实际 W_5**；**6 月仍用 BP W_6 = 1,000,000**。

S' = 600,000 + 700,000 + 720,000 + 1,000,000 = **3,020,000**

| 月份 | 新 Budget_t（实摊版） | 与暂估差（约） |
|------|----------------------|----------------|
| 3 月 | 198,675 | +1,954 |
| 4 月 | 231,788 | +2,280 |
| 5 月 | **238,411** | **−7,491** |
| 6 月 | 331,126 | +3,257 |
| **合计** | **1,000,000** | 0 |

**5 月实摊 — 月内明细（Budget = 238,411）**

| MSKU | 5 月实际占比 | 5 月实摊额 |
|------|--------------|------------|
| M1 | 320,000 / 720,000 | 105,960 |
| M2 | 280,000 / 720,000 | 92,715 |
| M3 | 120,000 / 720,000 | 39,736 |
| **合计** | | **238,411** |

**5 月暂估 vs 实摊（M1 示例）**

| 项目 | 暂估（BP） | 实摊（实际） | Δ |
|------|------------|--------------|---|
| M1 在 5 月 | 114,754 | 105,960 | **−8,794** |

> **说明**：分月重算后，3、4、6 月的**月总额**也会相对暂估略有变化（因分母 S 变了），保证 Σ Budget_t 仍 = A。若 3、4 月利润已关账，业务上可只发布 **5 月 MSKU 明细的调整额**；3、4、6 月差额走财务「分摊调整」策略（需与财务确认）。

## 七、规则速查表

| # | 规则 |
|---|------|
| 1 | 只对**本笔付款金额 A**分摊，先**月**后 **MSKU** |
| 2 | 占比分母 = **当月命中 MSKU 集合**，不用全公司 |
| 3 | 已结账月 → **实际营收**；未结账月 → **BP** |
| 4 | BP/实际都为 0 → **等额**，并打标 |
| 5 | 月结账 → 该月改实际，**重算分月与月内**；多笔付款**累加** |
| 6 | 「完全过去」= M 内**全部结账**，不是日历上今天已过 |

## 八、与系统模块关系（建议）

| 模块 | 关系 |
|------|------|
| 付款申请 / 费控 | 提供 A、M、范围；审批后触发分摊 |
| 分摊引擎 | 实现第三节公式 + 版本/重算 |
| 全渠道管报 | 读取**已生效**分摊结果，计入 SKU 维度品牌营销费 |
| 营销费用规划（可选） | 事前参考，**不参与**本笔付款公式 |
